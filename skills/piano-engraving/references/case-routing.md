# 案例提醒：按当前问题读取

本文件收纳0.34入口中已有的具体条件与反例；原意保留，避免每次调用都加载全部案例。根据标题读取相关部分，再由知识库定位器查原专题。

## context

视频截取先分音乐视窗与物理页，局部空白不作分页诊断。经`piano`／`spacing`查`BALLADE_POLONAISE_PREVIEW_READING.md`：连续伴奏与独立上层先辨主读节奏和共同时间列，再评间距；段落标记与a tempo可在行中，保准备、到达及实际生效点。

技术指令连同作用层、开始与恢复一起检查，恢复可以按本谱约定隐含；经`piano`／`notation`查`POLONAISE_TECHNIQUE_READING.md`的Hand muting／ord.。先核动作再选专用符头，保再现的有意义差异，行末调号预告和新行表头各自保护。

小谱先分ossia、条件演奏cue、持续提醒及脚注材料，核主路径、替代范围和返回；经`notation`查`R09_OSSIA_READING.md`。不由小字号决定不播放或合入声部；移位后检查该方案所需记号及文字小节引用。

跨版本对照的小节号，先核弱起与显示计数，再按实际边界／音型对应。经`sources`／`layout`查`R09_PREVIEW_COMPARISON.md`；缩略预览可作段落总览，读不清的限定词、连音与辅助谱不能由另一版补成已核事实。

符号的编辑角色先按本谱图例判断；不同出版者的括号、指法字体和弧线约定不能直接互套。经`sources`／`notation`查`BALLADE_EDITORIAL_CONTEXT.md`，遇到真实编辑分歧保留所选版本并单列音乐提议；PDF对齐有解释说明时，先核实际计量再作空间调整。

重排表距、分行或标记位置后，即使无碰撞也重查作用层。经`spacing`／`markings`查`BALLADE_PERFORMANCE_CONTEXT.md`的印刷表距案例；局部长短节奏先分书面值与演奏实现，持低音先分仍响的音与指持／踏板动作，不从字形或对象类型独自推定功能。

教程对照经`sources`／`spacing`查`KOKE_COLA_CAUSAL_REVIEW.md`：Kokecola两降号仍错列，缩列距不等于合列；间距图还改变休止高度。将作者明确操作、可见变化和本次解释分别记录，比较布局收益时核同一音乐及其它条件。

## spacing

间距按每拍实际复杂度选择空间重点，旋律身份通过声部／干向／标记另行保护；不能固定照顾某只手、某一表或全曲音头最多的层。速度改变不自动改变同系统同类时值的间距，必要变音／换号空间按条件处理；经`spacing`查`BALLADE_PREVIEW_CONTINUATION.md`的350／400秒对照与Gould三页。

连梁及局部间距经`beams`／`spacing`查`BEAM_OPERATIONS_STUDY.md`：先区分拍号默认、成员连接与整组梁属性。Local relayout只重排所选组内部；先核其它层的共同起音，单层拉匀及完整MIDI保持仍可能误示先后。混合细分原生反例已拒绝，不机械套用为钢琴间距修复。

跨表间距经`spacing`／`cross-staff`查`STEM_OPTICAL_CONTEXTS.md`及前篇：头侧、干轴、真正先后和共同起音一起核。只移音组会错开独立层，联合同刻各层可在具体情境兼顾；二度按正常侧头辨列，不按最低头或外框中心吸附。相同挂头差可使偏移跨宽度复用，仍须看当前容量和其它层；本机Local relayout未自动提供该光学策略。

`STEM_OPTICAL_LIMITS.md`补独立快线与容量：同步保持后仍须核各层节奏轮廓，主要跟读层按音乐任务辨认；行宽已装不下时先解决容量。横偏移会参与原生重排，端点offset为0也不保证实际不动，不能照搬孤立例的坐标假设。

`STEM_OPTICAL_SHAPES_MARKS.md`补余两类：Note小头与Chord整体缩放分辨，字号属性不独自决定grace／cue或播放。按当前真实挂头和干轴核补偿，不预断换字体／字号必失效。Slur、指法与共同列保持后仍要看动态通道；文字替代另列记法代价，隐藏播放辅助须验交换，本机实导回会重显发夹并移梁。

`AETHER_SPACING_LAYERS.md`把实谱宽首格分为优先比较、保护变音后比较和保留；先看相对波动及实际占位。提示变音可保读者确认功能，省写另列；将来重分须联合同刻低部和标记。上下力度通道按角色保留，PDF文本页漏头的实例也提醒先核原图与其它提取结果。纸面坐标不当原生候选。

`AETHER_NATIVE_RECONSTRUCTION.md`补四处原生检查：新预算已近匀时保默认，5＋3分行不可代替原七小节预算。变音必要性结合调号和谱位，不能只凭cautionary标志；共享符头可以对应两个声部时值，先保护结构再调整间距。

`AETHER_ENTRY_CLEARANCE.md`接续整行核查：本例优先入口放宽版，先使小节线与变音—和弦单元分开，再协调内层连续运动、持音和dim.起点。保原小节宽与末音预算；按正常侧定位翻头和弦，梁是否含休止单独核。半格净距只作为此构型候选，不设全谱常量。

定版面预算先量实际谱线起止，分清括号／缩进及片段首末附加元素；最小占位与撑满行分验。经`layout`／`baseline`查`AVID_WIDTH_BUDGET.md`，具体原生检查见候选参考。

间距检查须量到接收点，不只看连音内部几个头。经`spacing`／`rhythm`查`SHAMSHIR_PREVIEW_READING.md`：另一层插入事件仍应保护主要脉冲；梁内休止与拍端延梁分别判断。公开合作署名不证明具体排法的修改者，也不证明源软件。

## rhythm

特殊梁形经`beams`／`rhythm`查`FANNED_BEAMS_READING.md`：羽状梁保组内自由快慢与总时长，音头可等距，不用常规等距／MIDI检查替代其记法含义。半梁按拍内归属判断，休止邻近允许不同体例；普通休止与整小节休止的横向检查分别处理。

跨小节梁经`beams`／`notation`查`BEAM_ACROSS_BAR_READING.md`：连音跨线后的首个头可能晚于新小节起点，先算时值再查对齐。常规认拍、无内部重音音阶及整段乐句的分组条件分别读；震音连接另保逻辑中点。教程的同voice连接条件不决定用手；图形补梁须核音乐模型与重排依附，静帧不补成完整操作配方。

速度等式经`tempo`／`layout`查`TEMPO_EQUATION_CLARITY.md`：确认音值归属后，比较前行预告、新行方向提示与速度确认；摆放提前不等于实际换速提前。含义未定时给可核对的结构假设，不用表情词或早先BPM自动改写。

完整组、显拍与续行的实谱取舍经`rhythm`／`layout`查`REAL_SCORE_READING_TRADEOFFS.md`：普通三音梁不自动构成三连音；分别解释保组形、保第三拍接收和保行中八度终点的阅读收益。比例或跨页终点未定时保存具体问题，先处理能确认的部分。

分层复拍子可经`piano`／`rhythm`查`PURRVOICE_PREVIEW_READING.md`与`LAYERED_COMPOUND_READING.md`：先核真实梁端，再分长弧、拍组和换表；共头双干可有不同记谱时值和休止，同音另一层继续时不推成琴键提前释放。显拍改写须保各层时值，分组自身也可表达异重音；虚线不规定所有节点必须串行。

## native

跨线时点的原生例经`notation`／`spacing`查`CROSSBAR_TUPLET_NATIVE_STUDY.md`：本例优先真实两小节显拍；把E5吸到首拍会误示同时，完整MIDI保持也不能放行。长小节补形虽音符事件相同，MIDI拍号变4/4，作诊断；核播放时包含拍号和小节结构，分开记录音符与完整文件等价。真两小节完整显示仍缺，不预断必需改本体。

完整跨线组的显示组合经`notation`／`layout`查`CROSSBAR_DISPLAY_COMPOSITION.md`：同音tie片段可在受控单行合并显示，先核真实持续和独立起音。父对象visible不独自证明子元素隐藏；宽度改变重查端点与居中，换行核新段。原生保存稳定不保证交换稳定；导回播放变化加普通基线控制，不把gate或CC变化一概归因显示修改。

复杂跨表片段先按音乐层次联合安排弧线、连音和奏法，分别检查端点依附、整组范围、交干与穿头／梁。连音数字优先全部或部分谱外，白底另核遮挡；保存后核完整限定词与实际力度。移动前量本行已有上下沿，再按材料分配谱间距，局部成立不证明整页成立。Avid三批实曲正反例经`curves`／`notation`／`layout`／`markings`定位，原生检查见[候选参考](native-review.md)。

跨表连音的数字／括号，经`notation`／`cross-staff`查`TUPLET_CHANNEL_STUDY.md`：先核梁外休止和部分梁范围，再核数字是否归对层、横线是否穿干／混梁。端点范围正确与MIDI保持仍可能留下可读性问题；独立层见`TUPLET_OWNERSHIP_STUDY.md`：无碰撞仍须核归属，必要时单列显示换表点与加线的记法取舍。m97旧端点候选已撤回采用倾向；`M97_TUPLET_TRANSFER.md`的新实曲候选已核，四条加线和本页间距联动须一并说明，用户已初步偏好原版方向，见`M97_DIRECTION_FEEDBACK.md`；三种括号探针均已拒绝；另有保原六连的渐强局部候选供比较，先保方向再核范围／归属。

含首休止的跨表连音，经`rhythm`／`beams`查`TUPLET_REST_SCOPE_STUDY.md`：先认完整组界及普通尾音，再讨论分梁／省括号；完整梁本身仍可能自动反向、数字归错层或与渐强争空间。把分梁作为记法提议，休止短符干按出版体例判断；换宽度后重新看通道，不照搬局部offset。

实曲的组界／干长联动，经`beams`／`cross-staff`查`M97_GROUP_BOUNDARY_TRANSFER.md`：重新检查全部梁层和谱线，按实际最短干平衡两向比例，再复查数字与休止；保存／音乐通过后仍可能有明显比例问题。当前平衡版保原显示分配，分梁与浅尾梁代价另列。发夹的源voice不证明作者作用层，未确认时保护原控制并保留音乐含义问题。

长动态文字经`markings`／`layout`查`LONG_DYNAMIC_TEXT_STUDY.md`：先保完整指令、作用层和起止，再比较铺词、起点写全及续行提醒；多词／多行不自动变成多次力度。短发夹和文字也可能参与横向预算，软件最小值不能直接当规范。

涉及MusicXML导回时，经`beams`／`notation`查`BEAM_EXCHANGE_CLEF_STUDY.md`：逻辑归属、显示staffMove、逐音干向和逐层梁断口分别核；合并后的起音相同仍可能改变轨道、释放与读法。原生副本候选和格式转换各记验证范围。
