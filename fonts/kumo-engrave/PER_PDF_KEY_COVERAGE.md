## 覆盖了什么

键限定为“具体 PDF＋去前缀字体名＋实际源编码”，不是跨 PDF 通用编码。基于 schema 3 全部 146 份／1,135 页：

| 分区 | 键数 | 当前证据 |
| --- | ---: | --- |
| 音乐候选字体／编码 | 5,723 | 本轮逐键取样；5,606 可见、117 待审后关闭 |
| 原隐藏字体组的实际键 | 3,866 | 已完成全部源对象与代表复核，见 [HIDDEN_FONT_COVERAGE](HIDDEN_FONT_COVERAGE.md) |
| 新增 U+0000 字体／编码 | 2 | A125／A132 的全部实际对象已看图，见 [SOURCE_CHARACTER_INVENTORY](SOURCE_CHARACTER_INVENTORY.md) |
| 全部非普通文字键 | **9,591** | 三个集合无交集、无遗漏，和 schema 3 全目录一致 |

“非普通文字”是清点的候选范围，含待分类的字体名，并非断言其中全是音乐。隐藏组中大量内容最终是普通标题／表情文字。常规文字字体仍由文字排版处理，不把其英文字母、脚注星号等一律换成音乐字体。

## 为什么不能按相同编码直接替换

343 个代表分组对应 104 个已有目标角色，包括常规符头、谱号、变音、休止、拍号、旗尾、发音、踏板、力度、速度／swing、八度、琶音／滑音、呼吸、震音和大括号。目标全部在实际 Study Music 与 Text 的 cmap 中存在。代表归类是人工看图决定，不以自动匹配器名称代替判断。

实际回页的几个关键例子：

| 位置 | 只看字形容易怎样误判 | 原页证据／处理 |
| --- | --- | --- |
| K0055，A002 p1 | 把点与横线组合认成断奏／保持音 | 在 `Grave` 后的二分音符与 88 之间，是速度约等于；对应 `kumoTempoApproxEquals` |
| K0063，A002 p12 | 把数字 8 认成拍号 | 位于低声部下方八度线开头；使用裸 8 的 `ottava`，不是改变拍号 |
| K0099／K0109，A005 p70／p12 | 把点、横线位置颠倒，混淆上／下方发音 | p70 在音符下方为点上横线下，p12 在音符上方为横线上点下；现有字形方向正确 |
| K0165，A017 p6；K0200，A034 p3 | 只把短部件当普通八分旗尾 | 原页为下／上符干的 32 分旗尾组合，已有内部旗尾及原生完整字形 |
| K0188／K0257，A031 p1／A059 p2 | 把逗号状记号认成八分休止 | 原页在谱表上方，为呼吸记号；不是另加一个休止时值 |
| K0267，A080 p6 | 把两枚速度音符认成普通八分连梁 | 右侧含三连音括号、四分与八分音符，为 swing 等式；已有对应组合 |
| K0309／K0310，A128 p1 | 认为独立的 8 和 va 需要两个新音乐角色 | 原页组合为 8va，原生 `ottavaAlta` 提供完整形式 |
| K0013，A001 p1；K0052，A002 p2；K0311，A128 p2 | 把相似折线互认成休止、旗尾 | 分别为竖直琶音、斜向波浪滑音、竖直琶音；已有不同原生路径 |

上／下方发音方向另与实际 Leland／Study 字形对照，并核对 [SMuFL Articulation](https://smufl.formats.music/latest/tables/articulation.html) 的独立上下字名。没有发现需要因这次方向核查修改生产字形的情况。该对照只是识别方向，不是原生谱面尺寸验收。

104 个角色不是 104 个新制作字形；它们已经存在于 0.500。不同年代的 Pavane／Opus 字形采用当前已选的官谱方向适配，不为每份历史字体加入互相冲突的默认造型。圆点、横条、矩形和括号保留多种合法用途，不能把一个代表的语义套给组内所有音符。

## 117 个无可见取样键怎样关闭

不是把“提取失败”当作“缺字”。按具体源位置合并既有证据并补读，合计 **544 个实际源字符**：

- 457 个来自此前三项音乐空白键的全位置检查；两个空位图对象另有原页隔离 32x／64x 纯白证据和可见对照。
- 15 个来自 schema 3 新增键的已核对源位置。
- 另外 16 个字体／PDF 键的 72 个位置本次全部重新取原对象 32x 位图，目标字符框无墨迹；全部 72 个整对象图另保存并审视，其中少量是带前后空格的 f／mf／fp／p，不能把邻字当成空格字形。

按“PDF／页／对象／字符索引／字体／编码”去重，位置计数与当前索引逐键一致。没有把空白键删除，也不声称字体程序本身没有该字形；原 PDF 和 MSCZ 不变。

## 尚未完成的具体范围

这次完成了**逐 PDF 字体名／编码层级**的队列。仍不能宣布全目标结束：18 个候选“PDF／字体家族”在一份谱内有多个原始 subset 名称，例如 A002、A092、A115 的 Pavane。现有索引每键只保留少量尺寸样本，尚未证明每个原始 subset 都被这批代表覆盖。下一步逐原始字体名／编码取样，先对这些具体家族查同码异形；不再重复整个空白／隐藏队列。

18 个家族清单在 `dist/per-pdf-coverage-190/coverage.json` 的 `raw_subset_families_remaining`。它是实际读取所得的剩余项，不是泛称“还需更多验证”。每次出现的音乐语义、实际印刷和用户对每个字形的审美认可也不由本次轮廓分组证明；后者不作为当前看图研究的前置要求。
