# Chaconne Ex 直接字形对照修订（0.3）

2026-10-18。用户明确否定0.2：整体过细，音符看不出接近Chaconne Ex，整体观感不如Leland；要求直接按Chaconne Ex做。这是本轮的方向依据，不再把“纤细、内孔大”当作已确认的个人偏好。

## 这次具体改什么

直接重看本机官方完整字形表：第6–7页谱号、第9页常规符头、第25页休止，并检查第15–16、19页的旗尾/变音上下文。只渲染PDF观察；没有读取字体程序、获取PDF路径或自动拟合像素。官方栅格与本项目轮廓放在同一张图比较，避免只有“目标方向”的文字描述。

| 项目 | 0.2的问题与0.3动作 |
| --- | --- |
| 黑符头 | 原来斜势弱；增加斜势、采用更圆的端部和较饱满的外形。不是给全部符号统一加粗。 |
| 半符头 | 单独设计外形和孔的方向/比例；保持白孔两端圆润，避免变成细线或尖梭。黑/半不再共用相同外形参数。 |
| 全符头 | 参考更宽的横向外形和反向倾斜白孔；advance明确从373改为438单位，保留字宽不能成为阻止形状接近目标的理由。 |
| G/F谱号 | 修正G谱号主笔、上环与细脊的粗细层次；F谱号的圆点、肩部和收尾重新配重。不能仅凭线圈形状算完成。 |
| 四分/短休止 | 四分休止重画有分量的斜折笔和下钩；短休止增大圆点和杆/分支的分量。 |
| 旗尾、变音、琶音等 | 加强旗尾肩部、变音横竖笔对比和琶音波纹；延长号顶弧与圆点配重。箭头及系列延伸不能当作已取得对应官谱证据。 |

新增独立家族 **Kumo Piano EX**。相对0.2实际改变26个轮廓；相对Leland仍是38个替换码位，其余沿用底库。旧家族、旧源码绘制函数及0.2包保留。没有把部分常用字形修订说成全字库已经模仿完成。

构建、度量、孔形和接杆检查由本线完成。用户可以直接看少量对照，不以安装/打印作为当前反馈的前置条件。当前是更直接的仿制方向草案，尚未获得本轮审美认可；不宣称与Chaconne Ex逐字相同。踏板、力度、装饰、数字和组合记号仍待专项重画。
