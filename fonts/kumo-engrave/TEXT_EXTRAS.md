# 0.420 起支持的行内额外符号

0.470补充：sf、8va/8、音符括号、速度八分与三项swing轮廓更新，入口保持。速度八分字符不含邻接附点；需要附点时仍单独输入对应附点符号。来源和混排验证见 [REMAINING_CURVES](REMAINING_CURVES.md)。

0.460补充：普通32分下音符现在自动使用补齐的字形；上下marcato-tenuto仍从奏法记号操作。U+F706的历史短下符尾备选继续保留；原页已确认它是内部组合部件，无需手工输入它来拼正常32分音符。

0.450补充：圈叉、呼吸、32分上符尾、组合奏法、反复点与大括号使用软件原有操作。独立`wiggleGlissando`与`tremolo2`虽可作为音乐符号插入Text，原生滑音和Tremolo另走复用/几何路径，不能通过插入文字代替实际音乐对象。具体边界见 [OBSERVED_SYMBOLS](OBSERVED_SYMBOLS.md)。

先安装并选择 Kumo Score Study 与 Kumo Score Study Text。8va／数字8、音符括号和 sf 使用原有八度线、括号及力度操作即可，不必输入下面的私有码位。sf 的内容仍为 sf，由字体 liga 选择完整形状，回放不变。

下列字符用于独立文字中的速度／swing标记。在文字编辑状态选中这些字符，将该段字体设为 **Kumo Score Study Text**；普通说明文字继续用原来的文字字体。私有码位在其它字体中可能显示为空框。

| 复制字符 | Unicode | 含义 |
|---|---|---|
| ≒ | U+2252 | 近似等号，官谱速度标记中的两点两横线 |
|  | U+F700 | 两个连梁八分音符 |
|  | U+F701 | 附点八分＋十六分音符 |
|  | U+F702 | 三连音四分＋八分音符 |
|  | U+F703 | 两个连梁十六分音符 |
|  | U+F704 | 三连音八分＋十六分音符 |
|  | U+F706 | 短下符尾，单独备选字形 |

等号可从软件音乐符号列表插入 `timeSigEquals`。内部富文本示例（用于脚本或MSCX，非普通文字编辑器直接粘贴的代码）：

```xml
<text><font face="Kumo Score Study Text"/><sym>timeSigEquals</sym></text>
```

这只是视觉说明，不改变软件的 swing 回放、连音语义或普通音符符尾。普通十六分 swing 应输入 ＝；不要为了排版把谱内实际音符替换成文字。U+F706不会接管现有旗尾，也不借用“直符尾”开关。

来源是所给官谱中的具体文字对象／字符范围；未取得Chaconne字体程序。所有额外字形只放在本机研究构建中。元数据将额外Unicode记入 `kumoUnicodeExtras`，不把私有名称当作标准SMuFL符号名交给宿主。
