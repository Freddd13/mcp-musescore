# 字体版本记录

## 0.1.0／OTF 0.100 — 2026-10-09

- 固定 OFL Finale Maestro／Text 基础资产及哈希，建立局部 CFF 替换构建，保留完整字库和字宽。
- 独立设计 E0A4、E0A3、E0A2 三个常规符头；交付只改名 Control、常规候选和加大内孔 Open。JSON 回写实际外框，保留普通干锚点，更新 cutout／分叉锚点。
- 用户明确目标为 Chaconne Ex 后，观察官方公开字形表第9页，新增独立 `Kumo Engrave JP` 候选；以更通透的半符头、外平内斜的全符头和更饱满的黑符头为方向。保留初版家族作工程对照，设计依据单列。
- 配套 Text 目前仅改名，未补原字库缺失码位。发现内置家族 Qt 回退规则差异；推荐字体试用保留 Finale Maestro Text，后续补覆盖并重新验收。
- 加入结构化字体验证、独立 Windows 原生渲染及白纸像素对照。源谱只读、测试副本仅修改字体样式。
- 第一轮为审美候选，未完成打印／用户评审或谱号等 F2 字形设计，不改宿主本体与个人版本号。
