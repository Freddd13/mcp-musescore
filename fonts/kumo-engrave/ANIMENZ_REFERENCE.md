# Animenz 官谱观察与 Leland 路线（0.2）

2026-10-09 用户再次明确：以所给 Animenz 官谱为主要审美目标，不只看 Chaconne Ex 字形表；以 Leland 代替 Maestro 做新版底库，并扩展参考谱范围。

## 从观察到设计决定

| 观察及阅读作用 | 0.2 设计决定 | 仍需核查 |
| --- | --- | --- |
| 黑符头显著而空心孔通透；全符头外部较平、内孔有方向 | 以 Leland 的接杆位置／advance 为约束，分别设计黑、半、全符头，避免只放大底本 | 真实纸张墨色、二度及共享符头接杆 |
| 谱号具有笔画对比、清楚的内空间，不能由单一粗细的线圈替代 | G/F 谱号采用独立曲线中心线与可变宽带，圆点单独设计 | 当前为造型草案；还不是与官谱一致的定稿 |
| 四分休止的折线和下钩应区别；八分休止圆点与细杆形成对比 | 独立绘制四分休止与短休止的圆点、分支和细杆 | 32/64 分形态是系列延伸，未找到足够放大参考；不能声称照官谱确认 |
| Sharp/natural 的细竖杆与较重横笔易区分；flat 有尖下缘和弧形肩 | 分开控制竖杆、横笔和肩部，不做整字统一加粗 | 密集变音的空隙、同键多变音、实际打印 |
| 连续琶音应成一条紧凑的波纹，连接痕迹会破坏节奏感 | 用相同周期、位置、切线绘制重复片段；保留 Leland advance/repeatOffset，另画方向端部 | 官谱选样主要是无方向形式；箭头是独立功能扩展，需原生连接验收 |
| 第 145 页延长号拱与圆点分工明确；KICK BACK 的 accent 是细长楔形，marcato 更直立 | 重画上下延长号、accent/marcato/tenuto/staccato/staccatissimo，控制方向和上下位置 | 组合发音符号仍沿用 Leland，尚未统一重画 |
| Ped. 和释放星号是独立风格元素；文本、拍号数字、连音数字有不同任务 | 本轮保留 Leland 的踏板、力度、数字及 Text，加入测试；后续单独研究这些系列 | 不把“换底库”写成“独立重画全部字形”；指法与连音数字继续分开 |

已独立替换 38 个码位，其余字形保留 Leland。Leland 音乐字体 493 字、Text 182 字，和 Maestro 原型 2745/373 的覆盖不同：没有删减 Leland 的字库，但也没有把 Maestro 的全部附加字库混入新版。宿主对缺失符号的回退仍需按实际使用核查。

## 字体、样式与净书分别验收

“干净”来自符号内部空白、笔画对比、相邻墨迹间距和全页留白的共同效果；用宽一点的白孔替代全部问题不能成立。符干、连梁、弧线、加线、渐强线和页面布局主要由引擎／样式生成。KICK BACK 的震音梁也不是本轮字体的字形。

第一组原生试验固定为 `Leland Text`，关闭自动优化样式，只改音乐字体。第二组单独检查改名的 `Kumo Piano Text`，避免将 Text 缺字回退或推荐样式的变化误算成新字形效果。0.2 不默认应用 MSS，不修改本体或硬编码字体回退。

下一轮以实际用户评审为输入，按系列修正，而不是同时改字体与整页参数：先谱号／休止／旗尾及琶音连接，再踏板／装饰符号／力度和组合发音，最后拍号和特定数字的比例。每一轮保持基准谱、宿主和可读性验收相同。
