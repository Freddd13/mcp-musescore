## 最近真正增加了哪些判断

- [十二对十一原生研究](POLYRHYTHM_SPACING_STUDY.md)：默认共同到达已正确，等时值仍会受合并时间轴上单段／双段非线性分配及最低宽度影响。模型重建了诊断版的内部变化；隐藏谱号、移单头与简单加留白均不成为有效优化，当前保留默认并保存后续改进情境。
- [My Dearest](INTEGRATED_READING_MY_DEAREST.md)：P段12／11运行的中间音不同步，不能逐头吸齐；首处共同到达约错列0.83sp，后六处对齐，值得比较局部候选。S的力度位置却对应不同进入，应保留不齐。
- [Mixed Nuts](INTEGRATED_READING_MIXED_NUTS.md)：熟悉长值型可保持简洁，第三拍的tie接收又可能很有计数用途。不能统一拆拍或合并；末尾五连与8va的旧误读已更正。
- [跨表弧](CROSS_STAFF_SLUR_ROUTING.md)：避开梁还要保住端点归属；局部关闭自动避碰并不冻结原曲率。原创外绕候选经过原生保存重载，具体形状不是全谱预设。
- [间距模型](SPACING_MODELS.md)与[实曲迁移](SPACING_TRANSFER.md)：必要占位、光学均衡、时间列余宽和整行预算要分开。变音造成的不均匀有合理部分，也有可重分的部分；更均匀的数值不能独自证明更好读。

这些经验正在形成一种能力：面对同样的“挤、散、不齐”，先找到音乐和空间原因，再决定保留、微调或提出记法建议。

## 本阶段继续执行的计划

### 1. 按判断缺口继续学习

从整曲及对应再现处找问题，先作判断，再核规范和旧案例。已讲清的旧例只记复核；新材料应带来新的判断、边界或反例。

| 优先方向 | 接下来要解决的具体问题 | 有用的产出 |
| --- | --- | --- |
| 横向间距与异分同步 | 哪些地方是真正共同时间点，哪些只是近邻；变音、换号和左右手怎样影响稳定感 | 可定位的诊断、保留理由、固定预算的少量候选及反例 |
| 梁干与弧线 | 宽度改变后梁坡怎样保持组形；密集／跨表时如何避碰又不失归属 | 原创可编辑构型与重排检查，明确参数适用范围 |
| 多层钢琴织体 | 手、声部、谱表和持续如何分读；休止、共头和奏法何时该保留 | 能区分外观调整与音乐记法提议的完整片段解释 |
| 系统和页面 | 怎样按材料密度安排小节，何时段首留在行中；怎样评价跨行范围和翻页机会 | 包含前后行页的比较，不只展示漂亮裁图 |
| 规范例外和外部实践 | Gould条件与出版体例何时冲突，教程调整为什么有效 | 中文归纳及来源定位；可得材料优先，受限资源保持未读 |

近期首个12／11原创短谱研究已完成，见上述原生研究。下一步换宽度及其它比例检验机制的边界，再用于有可编辑输入的实际织体；不将本例的固定总宽、单一字体和诊断模型冒充全谱解法。官谱仍只读，独立构型不是官谱原工程的替代版。

### 2. 整理成能调用的知识

每个真正的新收获保存“情境、读者任务、判断、理由、替代代价、例外和证据”。维护专题入口和少量关键案例，及时更正旧误读，避免不断追加重复规则。

持续区分四类内容：用户已明确的偏好、规范适用条件、谱面可见事实、待验证解释。字体暂作固定输入；不能同时换字体和布局后把收益全算给某一方。

完成依据是：面对另一个同机制的片段，能找到相关知识并作出有理由的判断；能说明什么时候不该照搬。

### 3. 用skill检验迁移能力

选择近期没有精读过的片段，先给出整体阅读判断，再回看来源和旧记录。检查是否抓住主要问题、是否误报合理排法、是否保住作者定义，以及建议是否能在原生副本实现。

把实际误判回写到相关参考，不靠不断加长skill正文解决。格式和链接检查只保证能调用，实际谱例判断才检验是否有用。

### 4. 再做你的乐谱综合审查与少量候选

回到《如果有来生》，沿用已有整谱审查，但重新建立当时输入与原生渲染基线。先选阅读收益明确的少量问题，将纯外观、记法疑问和播放／范围问题分开。

候选固定字体和空间条件，保留原方案作对照，展示完整两手、相邻小节及行页连带效果。组合局部改动后重新核整曲，不能把过去各自通过的候选直接叠成成品。

原PDF、MSCZ继续只读。音乐、归属、原生保存重载及必要的播放覆盖由agent负责；你只在确有明显取舍时给少量直观反馈。打印和试奏放在准备采用时，不作为现在学习的前置要求。

### 5. 逐渐形成你的审美取舍

记录你在具体候选里的真实选择及理由，例如“这组更稳，但不要把长音空间压得太紧”。只将已表达的选择记作偏好，允许两版都不喜欢或看不出差别。

这一阶段的成果是：既能自主提出高价值建议，也知道哪些情况应保留、哪些必须解释后再选。目标包含美观和可读性，不能被规则数量、页数减少或几何方差取代。

## 后续软件适配路线 本阶段不启动

以下保留完整目标，待学习与应用准备充分后开展；不以旧接口笔记代替届时的实际能力检查。

1. **审计当时的MuseScore与工具能力。** 对照已验证案例，确认能读到哪些音乐结构、有效样式、局部覆盖、实际坐标、可见谱表和范围；先解决单位与当前保存版本的对应。
2. **建立只读诊断。** 输出具体位置、阅读问题、依据、置信程度和未知项；先诊断间距、梁弧与标记归属，不先自动写回。
3. **建立原生副本预览。** 读取音乐／几何，生成少量候选，比较局部收益与整行全曲代价；支持保留原样和人工锁定。
4. **实现有限自动净书。** 先处理有足够正反例的局部外观操作；明确范围、旧值匹配、撤销和中断恢复。记法及演奏含义改变单列提议。
5. **研究系统和页面优化。** 联合考虑密度、重复材料、导航、持续与翻页媒介，再调整局部空间，避免固定四小节一行等模板。
6. **只为已复现的能力缺口改软件。** 优先现有属性和插件，MCP负责调用；确需本体改动时最小化耦合，并按AGENTS维护用户指南、开发日志和提交。

未来可用于比较的具体情境已有行首留白容量、局部弹性非单调、NoBreak请求与实际分行不一致、第四层梁断点导入等。各自仍须按当时版本复现，不能一概称为已经修复或必需改本体。

## 怎样判断这条线接近目标

完整目标的完成需要实际证据：在多种代表性整曲情境里，能解释好排法的作用，发现并区分问题与合理例外，给出可行改法或有理由保留；skill能调到这些知识；原生候选在保护音乐后仍有明确阅读收益。个人细微审美和最终使用效果需要真实选择，不能由自制测试替代。

当前已经具备基础知识、具体判断及少量原生应用证据；下一步着力补迁移、组合应用和个人取舍。软件自动净书是后续实现目标，未借本轮报告宣布完成。
