## 为什么移到谱外没有把这一行撑高

最低的普通八分E1已经在行下方占出空间。10及括线下移后仍在这个下沿以内，tre corde也有位置，因而不用继续增加行距。

| 实际核查 | 结果 |
| --- | --- |
| 10数字上沿至低音表最下谱线 | 约1.18sp，已完全在谱外 |
| 括线整体下沿与tre corde字形上沿的保守外框净距 | 约0.65sp |
| 数字与音头、梁、Slur、谱表文字 | 实际轮廓采样均未相交 |
| 两版第一行全部墨迹外框，120dpi | 同为(96,85)–(932,300)，占用高度保持 |
| 除连音显示与谱表文字外 | 543个绘图对象的矢量属性相同，四条Slur也保持 |

这里的收益来自利用已有空间，不能推成“所有数字下移都不占高度”。没有低音尾音、下面有踏板或歌词、邻行更紧时，应重新比较。Gould p194建议数字全部或部分放在谱外；本次给出了这个钢琴多层片段里可实现且不增加行高的做法。

原白底版保留作为比较：它较靠近组内材料，但会中断谱线；初版曾使5的白底压过弧，后以数字移位修正。谱外版保住两组实际成员，撤去白底；5恢复无白底的位置后也未碰弧或梁。先解决时间范围与层次，再把数字、奏法和整行下沿一起摆放，优于逐件挪到最近的空白。
