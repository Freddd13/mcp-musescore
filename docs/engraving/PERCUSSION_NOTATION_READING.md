# 打击乐记谱：先让演奏者找得到该做的动作

**本段的净书原则是按演奏任务组织信息。** 总谱上每件乐器占一条线还不够，演奏分谱、实际分配、谱表位置、名称和换乐器准备必须能对应；图面整齐只是其中一环。

## 分配与谱表 p271–272

多名打击乐演奏者应有明确的乐器分配，兼顾相关乐器、槌棒、舞台移动和共享条件；编号为查找方便，不表示难度排序。总谱／演奏用总谱按人排列谱表，可在合理编号条件下把有定音和不定音乐器成组。

p272完整总谱例包含一人多表、换乐器预告、局部音色／槌棒与持续说明。应把这些作为一个人的执行路线读，不能把所有谱表当独立的人，再以“每人一样高／一表”压缩。完整乐器清单与每人清单应在分谱中可见，因为演奏者未必会拿到总谱。

用于钢琴的边界：声部、手、谱表和人同样需要分清，但不能把打击乐分人／换乐器的全部操作规则套给钢琴。后续自动审谱可借用“先列读者任务，再安排信息”的判断次序。

## 名称与规格 p273–274

说明实际所需音域、数量、相对音高与额外器具；有移八度习惯的键盘打击乐要说明书写／发音关系。钹的尺寸与音高并非稳定一一对应，不能以大小替代所需相对音高。共享器具在双方清单都注明，避免误备两件。

首次进入或清单里给全名，必要时解释缩写；四语言对照表说明近似名称可能指不同乐器。重复进入仍需足够标签，因为每曲的谱位分配可能不同，演奏者从排练任一点重进时不能靠记忆猜位置。只有标签频密到真正妨碍读谱时，才另找简洁办法。

这也给钢琴`r.h.`、局部状态和恢复提示提供取舍思路：先问重进时还能否正确识别，再决定是否省写。重复文本不是自动删除依据；其音乐含义仍按作品与钢琴规范查证。

**紧凑布局只有在演奏者仍能迅速认出动作时才有收益。** 减少线数、删休止、合符干和增加留白，各有适用条件；本段的前后对照提供了这些条件。

### 标签和定音打击乐 p275–278

频繁交替的器具可在每行开始预先标全，避免动作途中找名称；分谱的换器具／换槌指示可提前放在足够休止中，经过长等待后在新入口重述。总谱则靠近实际入口。图形槌棒符号可能太小或含义不统一，文字更容易识别。这说明“提前准备”和“实际生效”可以有不同位置，不能把重复标签统一去重。

定音打击乐通常尽量减少大段加线，偶尔单音保加线；钟琴／古钹／木琴的惯用书写八度应明确。音域适合单一谱号时不频繁换号，宽音域马林巴可用两表显示距离；多人器具切换、独奏翻页和纵向紧凑又影响是否持续用两表。打击乐的发音移八度约定不套给钢琴。

单线旋律跨两表可只写实际节奏中的休止，和声部独立保持的情境分开。颤音琴及管钟有制音机制，也可能有手制音；踏板说明有实际动作含义。颤音琴motor on／off要分清。定音打击乐的单音震音用斜杠；`tr`通常另指上方邻音，定音鼓另有例外。该器乐传统允许某些两音／两和弦震音写成单个和弦斜杠；不能据此批量改写钢琴两音震音。

### 不定音的谱位与符头 p278–282

一两件器具可用单线组，便于和定音乐器区分；一人操纵多件时，熟悉且紧凑的五线表往往更快读。高低音谱号用于定音，不能让不定音乐器看起来有固定音高；打击乐谱号取消这一暗示。演奏分谱中很小的谱号／位置暗示可能读不清，应提前用足够大的示意音头标位置。

谱位通常参照相对音高与实物排列；主导节奏线也可因阅读需要在上部。不同器具各有固定位置，同组相邻、异组分开，必要的一两条加线可比把异组塞在中部更清楚。编号和头型应有稳定含义。爵士／摇滚鼓组的镲常用叉头，位置惯例有变体；开闭踩镲及脚动作也不能仅由叉头猜测。

叉头可以突出快速复杂段中的器具切换，但连续叉头比实心头弱，且同曲不能给它多个冲突含义。需要兼记有定音／不定音时尤其要说明区分。钢琴中的叉头滑奏端点应按本谱动作说明读，不能导入鼓组含义。

### p283–286：为什么最少的线、最多的空白都可能更难读

p285 Table 1的推荐方案用紧凑五线和稳定谱位表达多器具；每件一条线仍可接受。过宽的线组把同一次动作拉得太远，过少的线又让相邻位置难辨。图例里的局部叉头有条件脚注：若同曲已经用它表示边击、制音等动作，就不能再拿它纯作器具识别。

两三线采用适当较宽线距有助区分；放在空间中的音头又以常规间距更清楚。休止按整组中部或拍内邻音位置放置；单线常用上行干可把力度／奏法与上方连音分开，多线又可向中间走干。这些安排服务于查找速度，没有“所有线距越大越好”的统一答案。

一人多器具若形成一条节奏，可共用符干、梁、力度与一套休止。**有独立重叠持续时，应恢复独立符干和休止**，两部相背，超过两部允许同向的两条干；条件消失后可合回。这与钢琴G／M的保留判断相通，但具体合并仍查键盘规范，不能单凭“同一演奏者”删掉独立层。
