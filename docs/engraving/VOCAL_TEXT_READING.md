## 分词：字形结构和发音时点须一并考虑

p441–444的英文规则优先帮助识别整词、按时发出音节，并保持相似结构的一致体例。复合词、词缀、可构成词首的辅音组、双辅音、单一音素和成音节辅音各有条件；不能直接把正文排版的字典断词当歌词拆分。某些词缀可因实际发音把辅音移到后一音节，但应评估整词是否更难认，跨行／跨页时尤其如此。个别短曲可接受的折中，长作品中可能造成不一致。

p444–446的拉丁文同样兼顾词形、双元音、辅音发音和演唱习惯。德式／意式读音可影响某些分界；一字多音、音节被拉开很远时，让辅音留在真正要唱的位置更重要；逐字近邻时，整词识别又较容易。省音可用撇号或下方小连接符说明，正当分词时同一词内不必另补省音弧；若两个元音必须分唱，则需避免看似省成一音节。

这些条件是语言和演唱的编辑判断。无文本原稿或演唱定义时，先标出疑问，不凭排版程序自动重分词、改标点或改词。

## 延伸线和连字符各说明什么

**p447：词末／单音节词跨多个书面音时，用靠文字基线的延伸线，接到最后书面音的位置。** 它不用画到最后长音持续结束；标点跟词走，在延伸线之前。单音节只占一个写出时值时通常无需延伸线。短休止间可连续，长间隔则可断开并以括号重提示原词，括号表示没有重新发音。

系统末变调／变拍时延伸线止于小节线；若刚在行末开始延伸，要预留可见的起线空间，续行从首音之前恢复。它服务于文字沿哪些音延续，不能给所有八度／踏板／渐变线套同一个视觉终点。

**p448：词内连字符置于文字中部高度，连接两个音节；不能用基线延伸线替代。** 否则会把未完的词看成已经结束。跨行时上一行尾须有连字符，下一音节较晚才进入时须保可读的续接；新行第一音就结束该音节时，补行首提示更清楚，但有版本省略。末端变调／变拍前留开边界。

两音节词仅在不会误省音时可条件性省连字符；多音节词仍需分明。长距离可均匀补连字符，位置避开恰在音下看似tenuto。节省墨迹必须保住词内关系、进入时间及续行提示。

## 2026-10-27续读：替代歌词与声音角色

完整新读p449–460／PDF469–480十二实质图文页，没有正式编号表或辅助页。图页与哈希见[本批证据](gurenge_hacking_closeout_evidence.json)。本节承接前文，不称声乐章完成；下一页p461继续。

| 来源与条件 | 编辑判断及理由 |
| --- | --- |
| p449，多段词只有少量节奏差别 | 可共用一行谱；差别经常出现时分开写，避免读者同时解码多条路线。同表容纳一条替代节奏，第三条宜另给小谱表；原文／优先语言靠谱表，另一语言的字态帮助区别 |
| p449–450，主／替代节奏 | 普通与小型反向干、共正常头及附点时分头有具体条件；主词统一上干也可减少翻转的注意成本。替代休止用小型，两个节奏仍须完整计量，不能将本条反推为钢琴附加旋律都要补齐休止 |
| p450，连音共享与独占 | 数字共同管两种节奏时置上方；只管一条时回到该条干侧。先说明作用对象，再选位置，不能把声乐上方通道做成全局不可例外的规则 |
| p450–451，音节数不同 | 可用额外时值或条件性的虚线tie表示；主词音节弧实线，替代词专属弧虚线，较短的靠近音。中间谱线可能使虚线tie难认，应与额外时值方案比较，不为统一线型改变主／替代关系 |
| p451–452，生僻语言／拆到不同声部的音节 | 提供IPA或已定义的熟悉语言参照；孤立音节必要时脚注给整词。翻页后长花唱可括起重提示音节，括号表示继续原发音，不代表重新唱一次 |
| p452–454，元音渐变与持续辅音 | 箭头给过渡长度并替代延伸线；同音tie在此可保不断音，即使发音成分改变。持续辅音可先给可识别整词，再括起具体辅音；不括起重复的声音会提示另一次发音。词形完整和动作精确之间应按作品取舍，不能只按字典拆分 |
| p453–454，强调尾辅音与自由重复 | 通常用末音奏法强调尾辅音，避免把普通词强拆到末端；实际持续或反复辅音才另记。自由吟诵可用单值和循环提示，明确歌词重复仍写完整，不把任何长文字当成任意反复 |
| p455，无词唱／哼唱／滚舌 | 无词声音在歌词位置，长段可省延伸线并在新行括起提示。hum置上方，避免被当成要唱的词；mm可直接置歌词处，＋等替代符号首次须定义。滚舌rr的文字、括号和震音提示共同辨认，不能见斜划就当钢琴两音震音 |
| p456–458，假声与说话 | 假声圆圈或菱形须配定义，保留其它技法的符号预算。无计量叙述可用文字而不补休止；按节奏说话则区分旁白单线和歌者五线中的交叉头，并说明相对／精确音高。单线定音会误导正常语调，只有单调吟诵才适合 |
| p458–460，唱说之间／有声无声／吸呼气及其它效果 | 相似交叉头可能难区分，重要转变补文字；同一交叉头若已用于Sprechstimme就不能又无说明代表普通说话。过渡箭头可提示有声向无声的持续变化，吸呼气箭头和非文字效果也须单独定义；p460页末只到其它效果开头 |

这些条件可迁移的是**先辨角色、再处理外形和省写**。同一个小字、括号、虚线或交叉头，在不同音乐里可以说明不同任务；一个声音角色也可能用多种合法版式。对钢琴PDF仍须追本谱的手／声部／持续及首次定义，不由声乐符号表推定播放。
