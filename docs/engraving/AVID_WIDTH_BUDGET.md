2026-11-03。**既定整页对照1/1、六行结构1/1、原生重载1/1完成。** 在固定Leland／Leland Text／Edwin、A4和原页实际谱线边界下，m65续行版容纳目标18小节于一页六行；本批指定的完整m65另起行版为两页七行。加上两端上下文后，两份文件分别为三页／四页，上下文不计入目标页。当前优先保留续行研究候选，用户尚未采用。[证据](avid_width_budget_evidence.json)记录原始宽度、约束控制、最终图及保护核查。

## 先修正此前准备谱的预算口径

此前把`pagePrintableWidth=184.3913mm`直接写成“小节线宽预算”不够准确。该值还包含谱表左侧的括号预留，实际要扣约2.0546mm；独立片段的首行还多出5sp缩进，即约7.493mm。继续减小音符间距前，必须先核实际印出的谱线起止。

独立18小节输入还自动带初始4/4与末终止线。本例中，它们分别让首组三小节、末组三小节多占约3.315mm、1.349mm。上下文不仅补续弧，也让目标页恢复正常的开头、结尾状态。

本轮按原页第一条小节线约12.78255mm、谱线跨度约184.3913mm校准：为括号预留留出空间，再调页面左边界。最终SVG中60条谱线的起点约12.78283mm、跨度约184.39102mm，与目标均相差不到0.001mm。名义printable宽约186.44588mm，页面左边距约10.72797mm；这是本字体、括号及谱间大小下的换算，不能照搬到其它字体或文件。

上述口径更正影响“与原页等宽”的说法；此前同一输入内的弧线、数字及保存比较仍按原条件成立。后续先查有效谱线边界，避免把试验输入的额外预留当成软件容量限制。

## 怎样找到真正占宽的对象

冻结宿主提供`-L / --layout-debug`，本例用于关闭横向／纵向伸展。普通撑满后的行宽不能直接说明最低需要多少空间；关闭伸展，再用加宽诊断画布容纳完整组，才能读出最小组宽。诊断画布不作为成品。

| 材料／条件 | 未伸展的音乐组宽，约mm | 与184.3913mm实际谱线跨度的关系 |
| --- | ---: | --- |
| 完整m65–67 | 193.212 | 超约8.820 |
| 带上下文的m68–70 | 182.969 | 余约1.423 |
| m65后半、66–67，最小tie长度1sp | 185.841 | 超约1.450 |
| 同组，最小tie长度0.5sp | 182.095 | 余约2.296 |
| 同组，只把加线外伸设为0.15sp | 173.658 | 有较大余量，但改变加线外观 |
| 最终续行候选，最小tie长度0.8sp | 184.343 | **只余约0.049** |

m65–67在18小节／20小节两份输入中的六个Measure子树完全相同，该组宽度由加宽探针取得；m68–70另外按带上下文的实际组测量，排除片段末终止线的占位。CLI样式覆盖探针未改变MSCX的页幅，保留为失败记录，没有把日志“使用样式”算成几何生效。

这些结果把处理对象缩小到具体机制。加线外伸能明显改变密集内层的最低占位；最小同音弧长度也参与弧前后的空间要求。它们都要与实际字形、加线辨识和后续撑满一起判断。最小tie长度是下界，各条最终可见弧长仍随上下文变化。

本批保留原加线长度，选择较温和的0.8sp tie下界；完整／续行两版使用相同设置。最终第五行只有约0.05mm余量，**更换字体、字号、内容或宿主版本后需要重新核容量**，不能发布成通用样式预设。

## m65拆行的收益与代价

前两拍承接m64保持音，带fermata和休止；第三拍a tempo、ff sub.及快速群开始。把前半放在前一行末，可使用那一行的余宽；快速群从下一行开始，随后进入I段。完整m65另起行则把保持、等待和快群一起交给下一行，本批指定分组无法合住m65–67。

源谱把换行动作放在等待之后，准备快速动作的线索更集中；代价是新行从第三拍续读，需要看清前行的两拍及续行范围。两种收益应放回前后行比较。当前结果支持本例续行方案，没有证明所有钢琴谱都应拆小节，也没有穷尽其它分行方法。

## 分行成功以后，继续核层次与路径

最初六行版仍有不可取的自动大弧。最终根据新布局中的实际梁端重新拟合S弧：先避开首组三层梁，再调弧腹，保留快层B5到低尾音E1的连接。高分辨轮廓核查得到符头相交0、梁相交0；仍有五处中途穿干，按本跨表路径单独记录，未声称全谱零相交。

连音10使用完整谱外括线，范围从首休止到第九音；5和普通八分尾音的范围仍分开。数字与tre corde借用低尾音已有空间。旧局部offset没有直接复制为成品，端点和弧腹均重新读取当前梁位置。

文字也要表达正确层次：`cresc.`回到上表下方，`p calando`组成同一条下方指令，避免上下分散；速度、rit.及踏板文字使用现有Edwin斜体。把F谱号放在前行末的同一实际拍点，补出下一行的换号预告。格式／位置调整保持原音高、时值、voice与力度值，未制作字体。
