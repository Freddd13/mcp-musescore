# 换拍、速度关系与停顿：先读时间，再排位置

2026-10-20，接续[节拍阅读](RHYTHM_READING.md)。补看Gould印刷p174–190／主PDF p194–210全部17页图文，覆盖同时／交替拍号、变动重音、速度文字与等式、延长及全体休止；不是自由华彩章节的完整学习。复看A085 p4、A083 p6、A146 p8及用户p3／8，原件只读。本轮无新原生导出或排版候选，另读回已有原生MIDI／MusicXML中的E、F边界；范围、哈希及实际数值见[证据](metre_tempo_evidence.json)。

## 1. 为什么“横着排齐”之前要先解读时间

净书要帮助读者一边保持脉冲，一边辨认什么时候换组、换速、等待与继续。书写音值、真实时长、拍组重音及段落位置不是同一件事。相同八分符号在不同比例／速度中可以不等长；一次换拍也可以换了符号，却保持大拍时长。

因此跨表对齐的对象是已确定的同时事件，不是形状相同的符号。Gould p174–177允许用不同拍号简化复杂关系，但要求明确比例与实际同步；各部小节长度不同时，小节线可以不重合。若一部的音与另一部小节首的音同时发生，应让音符对音符，不能把本部音符吸到对方的小节线上。这里的非同长小节／多速度多为合奏情境，不据此给普通钢琴谱增加独立小节线或指挥提示表。

| 可见形式或情境 | 真正要回答的问题 | 净书取舍及不能省去的条件 |
| --- | --- | --- |
| 简单／复合拍互换 | 是八分不变，还是大拍等值？ | 在转换处保留足够关系提示；不能只从新拍号推断速度 |
| 两拍号并列／括起 | 是等值大拍的可互换记法，还是按固定次序交替？ | Gould p174的互换形式与p179的加号交替形式不同，不能当装饰性排字互换 |
| 5或7等变动拍组 | 读者需要辨认哪种重音分配？ | 先用梁组、长音／休止的分割表达；需要时才加3+2等分组文字或内部虚线，不要求所有音头等距 |
| 分组长期固定 | 每小节重写会增加多少负担？ | 清楚建立并声明持续的分组可沿用，变化处再提示；不随意省略真正的拍号变化 |
| 混合分母／非二次幂分母 | 是否确实降低了阅读成本？ | 可表达特殊关系，但少数孤立小节可能用熟悉记法和连音更易读；不能因数学上紧凑就自动改写 |
| 小音值写在拍号或拍组旁 | 是要弹的音、拍组说明还是速度关系？ | 先分类；Gould p179／182提醒避免把纯说明写得像待演奏音符 |

Gould p178–182的选择是在音乐分组明确、提示负担和熟悉程度之间取舍，不是“复杂拍子总要加更多符号”。例如固定3+2用一次分组说明，可以比每拍放一串小音符更省注意；若两手本已用梁明确同一分组，再加虚线也可能只是增加黑度。改变梁／拍号仍是记法提议，不能混进纯间距调整。

## 2. 速度等式的方向不能靠位置猜

Gould p185–187明确讨论了历史体例差异：旧谱可在新小节内把新音值写在左边，现代节拍调制常用左旧、右新。所以同一串不同音值的等式，不能脱离体例直接生成播放或修改建议。把等号放在转换边界、让两边各归相应小节，有助于直接读懂；必须整串移到新行时，左右方向箭头或明确的新速度可以消歧。

**A085《Madoka Magica - Piano Suite Medley》p4提供了真实边界例。** m92 Calando旁是二分＝附点二分，整串在新C拍号后，没有方向箭头。如果解释为“旧二分＝新附点二分”，新四分速度是旧四分的3/2；若是“新二分＝旧附点二分”，则为2/3。Calando是表情／趋向文字，不能单独证明采用哪一种精确关系。本轮未核其出版体例说明或音源，**不决定方向、不自动改写，也不说官谱有错**。

同页E的Allegro agitato使用**附点八分＝164**，高分辨率原页已确认旗尾和点，不是附点四分。这个单位相当于附点四分每分钟82次；只保留164或按熟悉的复合拍单位替换，会差一倍。这也说明识别音乐字体时，旗尾与点是音乐数据，不能当混排噪声滤掉。

| F／m66，整曲四分单位位置203 | 前80，新120 | 旧四分0.75秒，新附点四分也是0.75秒 | 此处支持左旧右新，保持大拍；不要把两个四分BPM强行改成一样 |

原工程开头是附点四分80，E的新四分80与这个初始名义拍速相同；工程还另存不可见的四分122.5。这里不能只拿开头120四分去证明E边界“完全等值”，也不能仅凭隐藏对象所属XML小节容器认定它在演奏时间的生效位置。本轮以上“前速度”取自实际导出在边界前的最后有效Tempo事件。

F的单位关系已有正面证据，当前保留。E的偏差可能涉及演奏微调或保存／速度状态，**尚未判定原因与意图**；它是显示关系和播放一致性的待核项，不是音符错、版面错或本体bug的定论。本轮未试听、未新导出、未改Tempo、followText或渐变线。既有导出的身份与源副本哈希已核，但不把它说成当前GUI或任何未来宿主的实测。

F行首整串等式位于新侧，若以后给不熟悉作品的人制作清晰版，可以单项比较方向提示／新单位确认；增加提示也会占用F字母、Vivace和上方弧的空间，目前没有新候选或阅读收益证明。上一系统末的6/8预告提前告知换拍，有独立用途，不因新行已再印拍号就删除。

## 3. 官谱为何把速度放在那里

**A146《Zen Zen Zense》p8：先恢复可计量的进入，再到主题。** 第三系统从短6/4运行回C，接保持、休止的延长与双斜线；Meno mosso作用于该行末带四分休止的三个四分引入，下一系统M才进入长和弦主题。把Meno mosso搬到M旁，虽能让标题和字母同列，却遗漏了引入小节的速度。当前应保留这个生效点；如文字拥挤，应先整理它自身的净空，不把音乐阶段挪到行首。休止同样需要适用速度，第一颗有声音的音不是唯一锚点。

**A083《Last Stardust》p6：a tempo与Tempo I承担不同回收任务。** Meno mosso建立局部慢速，rit.／延长／双斜线后有a tempo；下一行另有rall.、ad lib.及其后的恢复。更后面N才明确Tempo I。读者需要知道是在收回局部渐变／自由处理，还是回到开头速度，不能把所有恢复统一成a tempo或Tempo I。本轮没有它的工程／播放，不能由PDF给这些恢复填入具体BPM。

**同页的字重差异也有理由保留为体例选择。** 官谱将Meno mosso、Tempo I做得醒目，而rit.、rall.、a tempo等仍常见小斜体；Gould p182更倾向将全体速度变化用粗正体、将局部独奏rubato与表情区别。这是规范作者的设计建议与实际出版体例的差异。应检查作用层、可找到程度与全谱一致性，不能据书中建议批量把官谱／用户所有rit.改粗体，更不能认定斜体证明只作用于一只手。

Gould p183–185还给出一个比“所有标题等高”更实用的目标：有新拍号时速度文字与其左边界形成清楚关系；无新拍号时与该时点首个记谱元素（可含变音或休止）关联。多项速度变化可共同形成易追踪的水平通道，但贴近各自内容、保持能辨认的距离比整行绝对等高更重要。渐变延续跨行时可加括起提醒或水平延续线，不把文字挂到斜线上随音高起伏。

## 4. 延长、断开与等待不是一种空白

Gould p187–190区分额外断开、对音／休止的延长及严格计量的全体静默：

- 逗号／双斜线说明断开及额外时间，不能仅把前一个音拉长来替代。延长号必须有明确承载对象，不悬在两音之间的空白上。
- 延长号通常对音头、休止或小节线居中，而不是对符干或整和弦外框居中。双干独立层、两音震音及八度线有各自条件，不能所有记号一律吸到同一高度／横坐标。
- 不同形状的延长号没有足以通用于所有谱子的固定秒数；有特殊时长要求应给本谱定义，不能见三角形便自动设某个播放倍率。
- 单纯延长后不必每次补a tempo；此前有速度变化、需要明确恢复时才判断提示。G.P.在合奏中可表示严格计量的全体静默，另加延长号才说明延长；不把G.P.本身解释为无限等待。
- 严格合奏在同一拍点共同延长，与独奏／华彩上方活动、陪伴层等待是不同情境。必要时可拆陪伴长值显出精确停点，但不得只为符号排齐拆音。

**用户p8是后一种条件必须保留的问题。** 活动层的终点延长，与下方长保持层起处的延长在横向并不相同；附近还有senza misura和速度／织体转换。不能照搬“所有延长号必须同一x”，也不能由最后一颗音推断每层的释放。p190本就引到华彩／自由段的专门条件；本轮尚未补p610–613的完整图文与该工程精确范围，暂保留原排法，不给四谱表判错或批量补移记号。

## 5. 后续怎样用这些认识

诊断换拍和停顿时，先读两侧拍号、书写单位、真实连音、作品定义及相关速度／等待范围；位置疑似不齐时先确认是否真同时。再判断提示是否足够、是否只需局部净空，以及改分行会不会把关系提示与生效点拆开。页面容量问题仍连[分行与翻页](PAGE_FLOW_STUDY.md)处理，不让一处漂亮对齐破坏前后导航。

若工程和PDF存在，则将可见等式、原生对象与实际速度事件分别核对。像F可形成保留判断，像E保存精确偏差但不擅定意图；像A085未消歧则停在记法判断边界。不要通过把两个数值相等、统一字体、重挂到首音等快捷动作“解决”它们。

下一项有实际关联的学习是自由段进入／退出、持续背景和同步提示的专门条件，再回用户p8核查。对于固定复合拍／异拍比例，还需独立谱例与实际演奏验证；本轮完成17页阅读与上述具体判断，不能称已稳定处理任意polymetre或自动全谱净书。skill仅增加知识检索与判断提醒，没有修改MuseScore、MCP或插件接口。
