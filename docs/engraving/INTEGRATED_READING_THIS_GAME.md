# This Game两版：共同时间列、不同编配与范围提示

2026-10-30，单代理完成A131《This Game (2014 ver.)》9页53系统、A132《This Game (2021 ver.)》8页47系统的问题回查。17张既有整页、61张完整双表系统细图、八张局部双表放大及Gould15张完整页均实际查看，共101个不同视图，32复用、69新图。[证据](this_game_closeout_evidence.json)记录来源保护、页／系统、177条去重头原点、165个内部间距及16项有理时值配方。Gould为复读，新增覆盖0；本批无新原生试验或软件适配。以下q为四分单位，页／系统从1计；排法的阅读收益是本线解释，未获出版者亲述。

**最重要的收获：同一曲、相近伴奏，仍须先核实际编配和共同时间列。** 2014版的上部六连／三十二分，会合理改变下部普通十六分的步幅；2021版相近位置的上部换成较稀疏写法，下部便能更稳定。不能由9页与8页，或字形外观，单独归因排版质量。

## 1. 哪种“整齐”应当保住，哪种变化有阅读任务

**2014版D，p3s1下部每小节16个普通十六分。** 三小节48个时间事件、45个内部原点距约9.240–9.960pt；每拍四音分梁、整小节上行再回落的弧形，帮助眼睛连续跟随。上部保持和声、后半拍进入和接收仍各读自己的符干／时点，不应把两表分别排齐。这个稳定背景值得作为保留参照。

**2021版F，p3s1并非同样16音。** 下部是八个普通十六分、两个普通八分、一个四分，合4q，共11次事件；三小节33个原点的内部距约10.554–17.533pt。后段间距加宽有时值变化，不能把整行11个头均匀铺开，也不能因旋律轮廓像D就补成16音。上方第一小节又是二分和声、八分休止、三个八分，层间节奏也不同。

**更有辨识力的比较在两版p5s2。** 下部均是每小节16个普通十六分，双音和单音交替；同时双音只计一个时间列。三小节各48列，2021版普通内部距约9.368–9.842pt，整体稳定。2014版第一小节约8.160–10.320pt，中间小节约9.360–18.480pt，末小节约7.800–9.600pt：中间上部先休止，再普通16、两组六连16、普通32与8分，提供了与下部十六分不同的中间时点和占位要求。

这正是Gould p200的两层对齐情境：让复杂层能顺读，另一层的同值间距可能随之变化。p40、43又要求在同值稳定、符号净空与共同对齐之间取舍。这里应先保住共同时间关系，再检查是否还有可减的最大失衡；没有把18.480pt认定为最小必需值。两版完整编配不同，这不是同内容、同字体、同页面的引擎对照。

未来诊断应能说明某个宽格由什么触发：另一层有几次中间事件、谱号／临时号／tie是否需要空间，还是只剩多余空白。符头原点距是定位线索，不能代替符干轴、真实墨迹净距或原生碰撞核验。只报告“不等距”无法给出可靠修改建议。

## 3. 符头、符干、连梁怎样让织体有层次

2014 p4s5及p6s4的连续快层内，另干慢线、跨表组与低部旋律同时存在。干向和长短差让读者辨认哪个音需要保持、哪个音继续流动；共同梁让接手前后仍像一条运行。把所有干统一长度或把跨表头强行挪回一侧，会损失这些线索。Gould p311–312区分真正独立节奏与附加旋律指示，p315说明跨表梁的位置和角度还须兼顾音高轮廓、最短干与五线净空。

2021 p4s5的上部16分轮廓有三音循环感，主要分梁仍帮助看4/4拍组；音高循环、重音／tenuto和节拍层次可以同时存在，不能只按重复三音重连梁。2014 p8s3的运行在两表之间分配，较长弧形帮助沿同一运动接手；分表不自动产生两个独立声部。

2021 p3s6及p7s5的r.h.括形只指局部高音／上层和弦，p8s1的l.h.指内层运行。它们回答“谁接这一层”，与“这一表全由哪只手弹”不同。净书时应保护指示范围，再处理附近弧线通道和符干净空。

两PDF的音乐字映射不同：2014常用私有区字符，2021常用œ等提取映射；内部字体名不足以可靠识别真实音乐字体。图像形状、梁干规则、时值与手分配须分别评估，本批不从字符编码推断字体优劣，也未提取嵌入字体。

## 4. 力度和八度线要保住真正的入口

**2014 H在p5s3第二小节：高部p、低部mf。** 高频重复层退后，低部旋律更显；两套力度有明确任务，不能合成放在系统中间的全钢琴mf。下一系统有f对比、随后再回p／mf；8va也按局部段落结束、重新开始，不能延伸穿过对比段。

**2021 p1s5先mf，随后C写sub. p。** 前一个力度属于旧段收束与引入，后一个制造突然收敛；若为对齐标签把mf推到C，段落含义会变。2014 p7s6的f与8va在首个八分接收之后、q0.5的快速入口；2021 p6s6的ff也在同类入口。力度坐标接近某拍不表示能随意吸附到小节首。

2014 p3s3局部8va从六连第一头到梁外高峰八分，再在休止前收角。2014 p7s6则延至下一小节首二分延长之后，后面三个pp八分已原位；2021 p6s6先短8va包两个16，随后原位运行，最后五连又开始8va并包下一小节全音。Gould p28–29及324–325要求按谱表和实际角端读：不同干向不自行划出原位例外。

2014 p2s5下表在谱表下方写8va延线，按ottava bassa传统可表示低八度；不能仅因va字样就判成方向错误。2021末下表的低八度线跨到最后终和弦及滑奏，高部8va已在先前三个和弦后结束；两表范围分别保留。

## 5. 2021版跳转怎样减少纸张，又增加什么负担

静态路线是：首次从G／Segno（p3s4）顺行，经H及p4s3末To Coda，继续四升号I–L，到p6s2左段D.S.；再返回G，第二次到To Coda跳p6s2右段Coda／M，之后顺到结尾。G在系统首，Coda与D.S.共一纸面行，中间断开五线，并重写大括号、谱号与一升号调号，让目的地可单独辨认。

**出口后纸面预告的四升号属于首次顺行I，Coda实际仍一升号。** 跳转校对不能机械继承纸面下一段调号，也不能只匹配最近两个开放弧。Gould p238–240支持显著的目的地和断开后的谱号／调号重写；源谱只写D.S.，可优先比较补成D.S. al Coda。把Coda另起系统是否更好，须和全页、找回G及物理翻页成本一起比较；压成8页不自动代表易读。

这行还暴露了分析工具的弱点：80%横向投影漏掉短D.S.／Coda行两组五线，初得p6五系统。整页目视、完整双表行与60%投影确认实际六系统。正式记录已校正为47系统；不能由自动线检测或裁图存在来替代整页阅读。

## 6. 休止、开放持续和结尾：先保存音乐动作

2014 p7s6最后小节，上部二分延长＋八分休止＋三个八分＝4q，下部二分延长＋二分休止＝4q。2021 p6s6先有一整小节全音保持，再到上部二分休止＋八分休止＋三个八分；下部为全小节休止。相似的黑色短块须结合所在五线和上下文辨别，不能把二分休止认作全小节休止。Gould p159、311–312也区分整小节居中的休止与有真实起点的独立层休止。

2021 O在p7s3第二小节，下部先八分休止，两个普通16、四个16、八分，随后八分休止与四分休止，合4q。等待是在让上部与后续接手分层，不为凑满黑度而补伴奏。2021 p4s6末下部和弦后的开放持续弧也有任务；精确手指／踏板释放尚未由PDF确定，不作为“没有终点”的噪声删除。

**两种结尾要各保原意。** 2014 p9s6末小节由下部四个全音头及tie接收终和弦，上谱表留空。2021 p8s6上下都有终止保持，下部又有p的附点四分至八分滑奏，滑奏与旧和声并存。不得删除旧持续、把全部终和弦重奏，或把空上表自动补成全钢琴停奏。2021滑奏进入前未见明确先导休止，其准确计量时点／延长后借时仍待工程或演奏证据；本批撤回按横向坐标猜q2的读法，先保留疑问。
