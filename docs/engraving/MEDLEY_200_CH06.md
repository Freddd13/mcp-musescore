# A005第六章：用梁组织动作，用拍组和分层保持方向

2026-10-31，完整回查《200 Anime Songs Medley》PDF p65–76，Kyoto Animation Anime、所印Songs84–98，共12页71系统；另看p64、77衔接，放大15处问题。累计**6/13章、76/154页，余7章78页及全组曲衔接回查**；整份问题回查仍145/146、981/1135页。[总进度与完整计划](STATUS_AND_ROADMAP.md)／[逐章目录](corpus/READING_MEDLEY_200.md)。

**本章最值得学习的是三个组织方法：跨表梁让视线追随一个连续动作；分梁显露5/8的3＋2；手提示和独立长值让不同角色在同一位置共存。** 它们允许乐谱保持紧凑、稳定，同时给演奏者明确的数拍和接手线索。多数重点保原排法，没有为凑修改案例新增候选。

下文p为PDF实际页，s为系统行，q以四分为1从小节q0计。点坐标仅追溯PDF图形，原工程的voice、对象范围、播放和排版算法未验证；本批无原生候选／软件适配。原PDF及MSCZ只读，教材复读不增加已有查阅覆盖。

## 1. 跨表运行的近邻符头，为何会看起来忽然挤近

**p74 s1第二小节，M／Toki wo Kizamu Uta：保跨表共梁及上部持音。** 上部高八度从前小节接为附点二分，q0–3保持；同一时段，另一条八分线在上下表交替。首四个活动音按q0、0.5、1、1.5排列，显示在下、上、下、上，随后q2、2.5、3继续在上表。原上部背景在q3有八分休止，q3.5才有自己的新八度；下部q2换回低音号后另有q2、q3四分。

这条共同梁让读者把交替材料当一条八分线跟下去，高处持音又不必反复重写。若按“上表归右手、下表归左手”拆梁补休止，连续动作会被切碎；若把原上部休止吸进活动层，又会误示它的入口。谱表、分手和音乐层各有任务。

首四个活动符头的X为186.120、205.236、214.632、233.748，直接相减得到**19.116、9.396、19.116pt**，看起来一宽一窄。原因是下表上向干接在头右边，上表下向干接在头左边：沿这一条共梁恢复符干位置，得到190.908、205.236、219.420、233.748，步幅约**14.328、14.184、14.328pt**。它已经有稳定的八分脉冲，不能只凭符头左缘差判为坏间距，再把中间两音拉开。

这里的轴还原只用于这条共同梁。不同声部的同时和弦可能以符头关系对齐，不能推广成全谱所有头都按同一侧符干吸齐。Gould p315的同向／双向跨表干条件、p490的共同时间关系，支持先识别连接方式再评几何。

**p66 s3第三小节，B／Extra Magic Hour也有同类关系。** 上部前八个普通十六分占前2q，第二组后两音转下表，共梁仍连续；之后上部是q2、q3两个tenuto四分，下部另有自己的后半拍活动。跨表交界处两符头起点只差约3.708pt，沿梁恢复干轴后约8.496pt，延续此前十六分步幅。长slur与后面的短slur另有范围，不借美化梁坡将它们合成一条。

## 2. 重复音型保持节奏感，允许整行之间略有伸缩

**p67 s3、s4首小节，C／Cagayake!GIRLS：两行都适合保留。** 上部同样八个普通八分，下部相同位置的休止、重音和伴奏，临时升号也在相同节奏处。第一行七个头距约13.986–14.166pt，下一行约13.284–13.464pt，各行内部很稳；七格总跨度由98.280变为93.510pt，约缩短4.9%。

第二行后部材料变化，行末还要容纳六升号预告，共享整行预算。这里可接受轻微的整体伸缩，读者仍认得同一个音型及其组界。强制两行逐头复制坐标，便要把调整全压到其它小节；逐个变音都额外撑一格，又可能制造本来没有的波动。PDF能证明当前轮廓，不能反推出出版者唯一的间距算法。

它与[第五章J](MEDLEY_200_CH05.md)的完全重复坐标互补：结构相同且预算相容时复用轮廓很有利，整行内容改变时也可适度伸缩。Gould p40允许行间因材料容量变化调整统一步幅；p490要求保护多层时间关系。

首和弦还有一个为二度让位的侧置头，比同和弦其它头右移约4.788pt，它们仍在同一个q0。诊断应先将这些头归入同时和弦，再量相邻事件。把侧置头数成一个新时间列，都会错判后续间距。

## 3. 完整六连、五连与普通尾部，为什么分开看才好数

**p69 s6末小节，H／Motteke! Sailor Fuku：保两组六连16、四个普通16及末四分休止。** 每组六音各占1q，前组三个上表音接三个下表音，后组同样分布；两组有完整独立双梁和各自的6。q2起四个普通十六分另有双梁，q3四分休止；下表末两八分在q3、3.5，另按自己的材料读。局部换高音号、再回低音号服务真实音域。

跨表时两组各有斜梁和短弧，读者可以一次辨认一组的下行动作，再接回普通细分。若把两组六音连为十二个，或把尾部也收进6的范围，就会多花时间确认拍点。现有裸6邻近完整梁，范围可读；不必为“跨表”一律加大括号或把所有梁挪到系统正中。Gould p200与p315–316、320给出完整梁、梁侧和跨表提示的不同条件。

**p71 s6末小节，J／Sparkling Daydream：保两组五连16与后面的休止／普通八分。** 两个5:4组各占一拍，接q2四分休止、q3与3.5两个普通八分八度；下部先二分持续，再八分低音、八分休止、四分休止。rit.从快组开始，末两八分已有自己的f和奏法。两个完整双梁分别给范围，长slur再组织整体下行动作；slur不能替代组界，数字也不说明全部后续音都在连音中。

**p71 s1末小节，I／DREAM SOLISTER：保六连后的普通四分。** 先二分接收，q2起六个双梁十六分按6:4占1q，q3末单音是独立普通四分。降到低处的尾音与六连同被短弧覆盖，但不属于六连；下部q2、q3四分八度给两个共同位置。不能因外弧罩七个可见头便读作七连。

**p70 s6末小节，两手后半的四分三连保各自括号。** 前半上部二分，下部四个八分；后半q2、8/3、10/3两手同步三次起音，都是无梁四分。双括号使两层时段清楚，奏法离头保持近邻。与上述完整共梁省括号的情境分开，才不会把一种简洁体例误套到所有连音。

## 4. 5/8分成3＋2，让人读出持续的重心

**p74 s5起，M：保上部连续五个八分的3＋2主梁。** 前三个一组、后两个一组，反复旋律让眼睛一眼认出每小节的长短重心；下部常以附点四分接四分／两八分，配合这个结构。分梁让读者少数一次头，下一小节也容易重新定位。连成五个虽少一个断口，却会弱化内部重心；改2＋3又会改变本段的跟读方向。

**p74 s6中途6/8是实际加长的小节。** 前三个八分成一组，后面八分＋四分共构成另一组3，时值合3q；随后立即回5/8，mp与新高度的3＋2材料进入。不能为了整行小节看起来等长，把6/8压成五个八分，或让全段都套同一组法。

p75首行仍续5/8，最后6/8以附点二分和六八分过渡；下一行恢复普通C。Gould p153–156，尤其p155表中的5/8两种组合，解释了为何需按实际重心选3＋2或2＋3。5这个分子给总长度，具体分梁才揭示本段重心。本例记录3＋2的成立条件，未形成全谱5/8统一预设。

## 5. r.h.的范围可以跨小节，也可以只接和弦一个音

**p75 s4，N／Tori no Uta：保下表最后一个八分到下一和弦上音的r.h.提示。** 第一小节下部最后三八分向上，r.h.左括端选中末八分q3.5；下一小节下表三音全音和弦的最高音旁有对应括端，其下两个全音仍留原手。选中的两音音高不同，中间是向上接续的slur，不能创建一条同音tie。

这样既保住下表上行线的连续性，又提醒右手接过高处音；另一层上部旋律仍有自己的时值。把整个下和弦都移给右手，可能造成不必要的负担；只看r.h.文字最近的音而漏掉下一小节括端，又会丢掉接手范围。Gould p305允许保声部在原表，用短括号／文字指定分手，正解决这类角色与位置不一致的情境。

**p76 s2末小节，N：保普通四个16接跨表完整六个16。** 下部先附点四分、八分，到q2才有四个普通十六分；q3的六连由一个下表音接五个上表音，共占最后1q。上部q2的二分和弦仍在保持。长slur组织上行动作，梁与6给组界；跨表末六音不能与前四普通音合成十连，也不能把白头持续合掉。

## 6. 速度、装饰和终止分别跟自己的对象

**L、N的引入都先得到新速。** p73 s2尾部已有Slower四分90及p，四个上行八分从q2进入，L／Dango Daikazoku在下一行才标题。p75 s2首小节恢复C时已Slower四分124，先有长保持，第二小节到q2.5才pp的三个八分；N标题和两升号在后。将新速统一挪到段落字母，会推迟两个引入的速度依据。

本章A四分178，E／Daisy86，G／Hyadain no Kakakata Kataomoi-C180，K／Aozora no Rhapsody138，M144，O／Koi wo Shita no wa74。B、C、D、F、H、I、J、L、N标题没有各自新增的数字。段落变了也可能沿用速度，不能自动填另一个BPM。

**p68 s6，E接F／Sincerely前有三个小十六分装饰音。** 它们是较小字形、独立双梁，不应加入普通十六分时值总和；下部同期的八分、休止与重音照自己的计量读。初看将它们估成两个小32，放大核成三个小16；后续从工程读取时也须先识别装饰关系。

**p76末系统的延长分别附着于全音背景和最后四分和弦。** 上方持续全音在q0起，四个四分和弦另外活动，q3的两手最后和弦各有延长；这与“在q0先停一下再演奏活动层”不同。Gould p187、189关于承载对象及同表独立层的条件支持保清楚归属，不为拉齐符号随便拆全音或移动到另一音。dim. e rit.、等待和下一章预告保留，未据PDF指定延长秒数或释放时刻。
