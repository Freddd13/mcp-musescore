# Connect：省写的边界、连音分法与安静处的层次

2026-10-21。重新近读A031《Connect》全部8页、15处系统区域与6处细节，先保存整首首读，再回看旧笔记。历史批次仅p4／8近读；本轮不改写379页历史数，不称独立盲评。完整复看Gould印刷p52–55、108–109、115–116、203–204、215、323共12页，均为已有章节复核。[证据](connect_reading_evidence.json)记录来源和实际范围；原谱、教材与裁图不加入Git，没有该曲原工程、原生替代版或播放验证。

## 1. 先知道读者正在跟哪条线

| 位置 | 看得见的关系 | 为什么值得保留 |
| --- | --- | --- |
| p1 A、B、C及后面的F／P | 开头的旋律节奏进入不同和声、音域和伴奏构型；B／F／P有相似的和弦与下层运动，但时值、连接和装饰并非完全相同 | 熟悉轮廓可以帮助识别，再现仍需重读局部差异，不能整段照抄坐标或把所有短弧去重 |
| p2 D与p4 G后续 | D高处运行上方有p，慢线在其下并有l.h.；G后第三系统上方pp运行、下方上干部mp慢线与更低的长值并存，局部还有r.h. | 音高最高、起音最多不等于主题；手接管也不自动改变整个谱表的角色。先沿慢线读，再考虑文字通道 |
| p3 E／p5 I、p6 J | E／I保留相似的和弦旋律与低部动作；J反复出现强攻击、休止与后续较轻活动，并重新写f、mf | 同类动作有熟悉组形，明确的强弱转换仍须可见。重音、tenuto、断奏点和力度不承担同一任务 |
| p6 L、p7 M／N | L在行中进入，以pp／ppp和不同持续层变安静；poco rit.之后的M又在行中恢复速度。N之前已有延长、断开和pp小句，之后仍继续 | 安静并不等于单声部，停顿也不等于全曲结束。段落字母、织体、速度和连接共同说明入口，不必全部强制另起行 |
| p7 O到p8 P／Q | O的a tempo、fff和强攻击之后仍有P；Q又在前段收束后展开更轻的跨表运行、smorz.、freely和最后小句 | 不能让第一处大和弦、延长或渐弱替所有层决定结束，也不能把Q凭字母或角色改成Coda导航对象 |

这些是谱面事实及阅读解释，不是出版者对制作过程的自述。PDF没有给出内部voice、播放scope、实际踏板或精确演奏时长；音乐角色、手、谱表与软件容器分别判断。

## 2. H：不是一串同样的八分，也不是一个大连音

p4 H首小节的低部共有12个可见音头，按梁、干向、数字及完整4/4小节读取，是七连八分、三连八分、两个普通八分。大弧组织整段动作，没有取代内部三种分法。Gould p203–204的收缩体例与本处完整时值、上下共同位置一起用于核读；下表是音乐读法，不是从数字或字符数单独猜出的工程ratio字段。

| 具体位置 | 内部分组与书写音值 | 每音实际时长，以四分为1 | 合计 |
| --- | --- | --- | --- |
| p4 H首小节 | 7个八分按7:4；3个八分按3:2；2个普通八分 | 七连各2/7；三连各1/3；末两音各1/2 | 2＋1＋1＝4拍 |
| p5第一系统首小节 | 6个八分按6:4；3个八分按3:2；2个普通八分 | 前6个与随后3个均各1/3；末两音各1/2 | 2＋1＋1＝4拍 |
| p5第一系统末小节，H运行收束处 | 6个八分按6:4；3个八分按3:2；1个普通四分 | 前9个均各1/3；末音1 | 2＋1＋1＝4拍 |

因此，**不同数字可以有相同的每音时长**：这里6连与3连的单位相同，7连与3连却不同。不能看到不同数字就要求不同粒度，也不能把七连情境里所有黑头拉成一个等距网格。是否还需光学补偿、为其它层让位及怎样分配整行，须另看实际版面；上述时值没有规定唯一头距。

前两类反复型的末低音还可tie到下一小节首音，两个可见头不是两次新攻击；本轮没有从PDF建立完整NoteOn列表。最后一小节则用一个四分收住运行，不能因轮廓相似而自动补回末尾低音、延续同一模板或把它误报为少一个头。

当前保留变化处的数字、分梁和末尾时值。省数字的条件仍见[连音专题](TUPLET_READING.md)：相同型建立后可有条件省写，但变化、复杂配合及读者需要重新确认时另判。将整小节改成某个等分大组会改变内部时点；省去数字也不能删除真实连音结构。这些不是只减少墨迹的几何动作。

## 3. simile：官谱提供了实践，却没有替规范作结论

H前两小节在下表外围画出渐强／渐弱拱形，第三小节同一区域写simile，随后这些发夹不再逐小节出现；7、3及后续6的数字和逐组弧仍保留。就此局部而言，延用伴奏的强弱起伏是最有根据的解释，不能写成作者已经确认的作用域，也不能把它解释成全部记号都可省。

这一做法与Gould p109有明确分歧：该页要求反复的力度型完整写出，反对用simile代替，理由是演奏者容易忘记。p116允许在建立重复奏法后用simile／sempre，p215又允许在组形清楚时省重复连音数字；三种信息的记忆任务不同。

| 可能省掉什么 | 本例与规范怎样共同判断 |
| --- | --- |
| 重复的力度起伏 | 官谱减少了下表外的线量，局部重复也提供记忆线索；但跨行、7转6及旋律叠层后更容易忘记持续起伏。不能把这个选择升级为默认推荐，规范倾向写明 |
| 重复的奏法动作 | p116有条件允许省写；本处不能因存在simile就推定所有slur、触键和手提示也随之省略或无限延续 |
| 重复的连音数字 | 本曲仍逐组写出；变化到6、最后收束及上方独立层都有重新确认的价值。不能拿“力度已省”作为删数字的依据 |

本轮不改官谱。将来用户工程若出现同类情境，应先确认simile所指及终点，再比较保留与明确写出起伏的候选，检查局部通道和后续页；本轮未渲染该替代，不声称已经证明补写一定更好。补写或省写表达信息都应单列为编辑提议，不能混进自动美化。

## 4. 同时、同音与同力度是三个问题

### D／G：文字跟随角色，不跟随全谱的一条基线

p4第三系统上部pp短音与下表上干部mp慢线有不同突出程度，最下方长值另构背景；局部r.h.说明接管。把pp、mp一起挪到大谱表正中，会减弱目前的角色提示。D在上表叠入慢线、后来用虚斜线追到下表，也要求先跟线再理解手，而不是一表一手分配。

Gould p323支持让独立层的力度靠近相应干部，并在中间不够清楚时利用外侧；“通常居中”不能覆盖这些条件。这里的保留依据是可见归属，不是已经证明软件为每层设置了独立播放力度，相关边界见[力度与奏法](DYNAMICS_ARTICULATION.md)。

### L：黑头和白头的错开在解释持续

p6最后系统L处，同一谱位的黑头、白头并列，配不同干向及后续tie；一个层转向较低音，另一个继续保持。按分头记法读取，这是同一时点的不同持续角色，不能把横向错开直接当成迟到的起音，也不能为吸齐或减少头数把它们合并。

Gould p52将不同头型的分头作为一般写法，p53又讨论横向顺序、交叠及版本差异；钢琴章还允许特定重复型共头，不能反过来规定全谱永远分头。当前保留这组持续线索；是否有同样清楚的紧凑替代须另有原生候选，不能仅凭头框中心作决定，见[同音研究](UNISON_DOTS_STUDY.md)。

J处f、mf的反复转换也不因旁边已有强重音而冗余。力度层级、攻击强度和音间分离分别阅读；p115–116不支持将强重音统一换成绝对fff，或把组合符号拆掉一项以求外观一致。本曲没有实际播放或原工程，当前不替这些字样创建scope。

## 5. 收束之后还有什么，必须沿完整材料看

p7 M附近，长和弦的tie、延长、双斜断开与后续pp小句先后出现，N及其八度范围仍在后面。p8 Q则在较强段落之后继续：上层长值、局部r.h.、较轻运行从下表穿到上表，长弧保持动作连续，随后才有smorz.、freely及持和弦；loco之后还有l.h.小句和自己的延长。

阅读收益是不同层可以各自保持、移动或结束，读者不必把所有连接都当作同一个终点。代价是局部必须认真交代层与范围，稀疏也不能随手删休止、合并长弧或将所有延长按x对齐。最后小句的具体工程身份、踏板保持、自由等待和精确释音并未由本轮还原，见[自由段](FREE_PASSAGE_READING.md)及[八度范围](OCTAVE_READING.md)。

L／M在行中出现，与H运行的变化及页尾续线共同表明，字母入口、状态恢复、织体变化和系统边界是不同任务。这里没有翻页试奏、替代分行或最佳纸面预算结论。

## 6. 后续怎样实际使用这些认识

检查重复材料，先对时值、分法、持续与末尾变体，再比较图形一致性；数字和可见头数不是完整节奏。检查省写，明确它省的是动作、力度起伏还是分法，回到各自规范及后续变化，不用一个simile作用于全部属性。检查对齐，先区分同一时间列里的分头、错头与真正的新时点，再评价余宽。

这批提供实际保留判断、规范分歧与待比较的编辑方向，没有建立全谱评分、复制官谱坐标或增加软件控制能力。知识经现有markings／rhythm／piano入口查到；以后产生原生候选时，音乐、可见读法、行页影响与实际播放仍须按当前输入分别核查。
