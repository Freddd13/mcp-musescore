# 廻廻奇譚／残酷天使：快层间距、接手路线与独立范围

2026-10-30。A003《Kaikai Kitan》六页35系统，A007《A Cruel Angel’s Thesis》七页41系统，完成全部13页及76系统问题回查，另核十处范围放大；Gould印刷p40、43、54、78、185–187、199–200、203、207、213、215、303、305–307、311–312、319、321、324–325、333、337、487共26页复读，新增覆盖0。[证据](kaikai_cruel_closeout_evidence.json)记录原件校验、实际视图和局部核算；A003的[此前整曲研究](INTEGRATED_READING_KAIKAI.md)继续保留。

**本批优先保留连续快层的推进、慢线与快层的不同计拍，以及跨表接手和局部音区的明确边界。** 真正值得比较的是《残酷天使》rubato段五连的短范围提示；同曲后面的完整六连已有明确梁端，不再列为范围缺失。下面解释的是谱面支持的阅读收益，未取得出版者的制作过程说明。

## 1. 板正首先来自可追的运动层

《廻廻奇譚》H，p4第六系统，慢旋律用上干、下干连续十六分在同一上表推进，低部另有持续和切分。第二、三小节各16个快层时间位置，所选同文件符头原点内部距分别约9.240–9.600pt、9.120–9.600pt。旋律有附点、短接收和tie，共同发音处可以共头，快层仍清楚地按四音短组前进。

这里应当保存的是“眼睛能沿四音组连续移动，再在共同位置读出旋律”。若先把上表所有可见头按x排序，重复绘制的共头、慢音和附点会混进同一个数列；由此算出的忽大忽小并不对应快层的实际步幅。把上干旋律也压成相同短时值，或为消除重叠删掉另一根干，都会损失旋律保持。

《残酷天使》I，p5第三系统，下表三个小节各16个普通十六分，上方旋律的附点八分、十六分、八分接收共享其中的拍点。三小节所选快层内部距约9.606–9.962pt；第三小节约9.708–9.843pt。下表长弧罩住起伏，四音内梁让跟读无需逐颗重新计数。上部较疏的切分线条因此可以自由歌唱，下面的“传送带”仍稳定。

同曲D，p3第五系统，则是另一种进入：每小节先上部四分休止，再12个普通十六分，低部在首拍弹两个八分后secco休止。前两小节快层内部距约7.319–7.692pt、7.319–7.573pt。首个休止到快层进入的距离不能与十六分内部步长放在一起要求相等。下一系统首小节又变成八分休止＋14个十六分，应重新识别入口。

这些值只描述本例原点，不是净空标准或新的通用参数。Gould p40、43、200把节奏预期、前缀空间和多层对齐合起来考虑。后续间距诊断应先选定快层，核共同拍点、真实占位及光学轴，再比较异常；[此前红莲例](INTEGRATED_READING_ZANKYOU_GUREN.md)还说明，有理由的非等距轮廓同样能稳定。两类经验应同时保留。

## 2. N的慢音与快层休止恰好同时

《残酷天使》p7第五系统N仍在12/8，附点四分66。首小节的快层每半小节是**十六分休止＋11个普通十六分**；整小节22次快层起音和两个休止，合24份十六分＝6q。这里q为四分单位。两层梁在原PDF填充多边形中可分别核出，不能因密度误读成32。

第二个半小节开始q3，上表另有带附点的慢旋律头，同时快层写十六分休止，然后到q3.25才起动。所选q3原点189.953704pt，下一快层头约199.44pt。**这个慢头不是快层“补上的第十二个十六分”。** 它还通过虚线与下表旋律相连，告诉读者该突出哪条歌唱线。

因此当前保留独立休止和慢线，不为“连续24音”删休止或缩短慢音。与H的共头连续活动相比，N恰好是反例：同列既可以两层共同攻击，也可以一层攻击、一层休止。自动诊断必须还原每层的持续和活动，不能从纸面黑头密度推断。

Gould p307、311–312允许在重复织体中用附加干、共头强调旋律，也要求真正独立节奏的休止交代清楚。不能把附加旋律干一律扩成完整休止层，也不能把本例已经有意义的休止统一省掉。

## 3. 声部接手的虚线值得保留

《残酷天使》p5第四系统首小节，先有下表四个连续十六分；随后q1下表另起一个tenuto四分，q2在上表、q3再回下表。虚线追踪这三个旋律音，上表快层同时继续。先前若把下表第四个快音q0.75当起点，路线就早了一格。

当前判断是保留这条较淡的路线：读者无需在密集运动中猜哪几个音组成内线，tenuto、独立干和虚线提供一致线索。将它改成滑音会暗示连续滑奏；简单删除又会增加跨表寻找。Gould p307也以较轻的虚线区分声部引导与可能像滑奏的实线。

p2第四系统末、N及结尾也有类似接手，但须分别追实际端点。p3第四系统末的波浪下行滑奏则有不同动作。线条方向相似不能作为统一替换依据；[滑奏专题](GLISSANDO_READING.md)保留动作、键集合和端点条件。

## 5. 小音字号不能当成通用节奏分类器

《廻廻奇譚》A首低部两个小十六分在正常八分低音之前，字形大小约为正常头的75%；它们不能当作两份普通时值插进首拍。《残酷天使》开头小32跨两表进入正常旋律，结尾则是**四个小十六分**，字号约66%。同一份谱p7第三系统molto rall.的22个可见小头又约75%，连梁和上下文另有安排。

可保留的经验是：小音要先看梁层、连到哪个正常音、是否装饰／收尾、是否同其它层自由配合，再确定比较办法。不能固定“75%一定是装饰音”，也不能把所有小音设为零借时。两份PDF的黑头字符码不同，字体字号是字形证据，不直接证明语义对象。

《残酷天使》开头正常歌唱线、正常尺寸快速下降和小32插入并存；长弧追旋律，短弧又连接手势。当前保留层次，只记录可见身份，未做全部音高、原工程播放或装饰借时校勘。Gould p78关于小音配套变音大小的条件可用于符号检查，不能扩展成自由段的完整演奏规则。

## 6. 八度范围、手分配和踏板各有边界

《残酷天使》E，p4首系统，8va角端在x约95.4pt；首个l.h.伴奏和弦x84.964pt仍在线内，下一和弦x97.315pt已在线外。慢旋律虽然向上，八度线也作用于这段同表内声部。**先保留可见作用范围，不能凭“只有旋律该升八度”的直觉把它缩到首旋律音后。** 若要提议不同音区，先核原工程和音乐意图，再另列记法方案。

Gould p324–325明确八度线的谱表及多声部条件，并给单独转位、loco与必要换表的处理；p303、305–307则解释为何手、声部和谱表不能按高低机械绑定。E的局部手括号、之后下表r.h.、G的上层pp背景和下部p歌唱线都须连起来读。

p7第四系统进入12/8，低部首个附点四分在短8vb内，角端很快解除；Ped.继续跨两个小节，直到下一系统前释放。sf低音在q0，pp上部从q1.5才进入。八度角端只结束移位，不能顺带提前放踏板或把pp也吸到q0。Gould p333、337支持把按键持续、共鸣与独立范围分开检查。

## 7. F的mf提前，恢复说明另在边界后

《廻廻奇譚》p3末系统，F前最后十六分和弦已标mf，并有tie跨双线到下一小节；8va也提前罩住该和弦。F字母在双线附近偏左，小音符“16＝16”恢复说明的实际字形位于双线之后。放大后应保留这三个不同事实，不把mf、段号、说明都归到同一个默认锚点。

E的“两个16＝三连8＋16”定义同一八分内的长短演奏；F据上下文恢复straight。它们不自动成为真正变速等式，也不要求把书面横距按演奏2:1重排。Gould p185–187讨论变速等式的位置和跨行摆放，不能仅因有等号就套用。本次没有工程挂接和每层播放范围，所以不补写精确恢复时点；此前[专节](INTEGRATED_READING_KAIKAI.md#swing-reading)仍适用。

两曲首页各5系统，其后各6系统；标题页给题头留空，后页保持相近纵向节奏。段首有时在新行、有时在行中，是整曲内容预算下的选择。Gould p487建议在可行时让重要段落更醒目，仍须与过渡、系统预算及实际翻页一起判断；本次没有替代分页或打印试奏。

《廻廻奇譚》最后上部整小节休止延长，下部还有八分攻击、八分休止、四分休止、二分休止延长。末前高音组三连在4/4内有12音，不能照搬开头3/4的9音。《残酷天使》末12/8则是上部附点全音、下表高和弦附点全音保持，低层先附点二分休止，再附点二分琶音和弦；最后ppp、踏板释放与四个小16的接续另读。两种终止动作不适合套同一个“留白收短”模板。

## 9. 怎样转成后续自主判断

1. 间距先标活动层、持续层和装饰层；同列的共头／独立休止分别判，必要时还原真实干轴。选中快层才比较步幅，异常再追前缀、另一手插入和手动覆盖。
2. 先追声部路线，再决定是否挪记号。虚线接手、波浪滑奏、短tie、长分句弧各有读者任务，不按线型相似合并。
3. 连音逐层核梁端与普通首尾：完整6保简洁，部分5局部比较；休止同样是成员。数字和符头数量不能互相替代。
4. 八度、手、速度解释、力度与踏板按各自实际范围保护。段号在附近不能成为统一挂点。
5. 当前知识与skill已可用于审谱和有依据的保留／建议；需要实际修改时再在副本做少量高收益原生对照。本批未新增原生候选、用户审美选择、插件／MCP／本体适配或字体修改，原PDF／MSCZ保持只读。
