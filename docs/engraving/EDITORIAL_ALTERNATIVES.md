# 小音符、替代方案与提示声部

2026-10-23完整读图Gould印刷p495–498／本机PDF p515–518。来源及实际页图见[ninelie续读证据](ninelie_whole_reading_evidence.json)；这里只归纳教材条件，没有在官谱中确认新的ossia，也没有做原生／交换／播放试验。

## 先认演奏任务，再认字形

| 看见什么 | 可能的任务和有依据的处理 | 不能由此推出 |
| --- | --- | --- |
| 与主音共干的括起小头 | p497的单音ossia可给技术上可行的替代；连续替代音可共用一套括号 | 所有括起头都可不弹，或主音与替代音应同时播放。提示变音、持音提醒、装饰音须按其它定义判 |
| 一段小谱表 | 复杂替代可用标明ossia的小表，只覆盖实际替代范围，不必凑整小节；两套都需要完整力度／奏法等演奏信息 | 任何小表都是“不播放的提示”，或它与主谱应合并成新增声部 |
| 小表与主谱相连或悬空 | p497区分系统首实线、行中小节边界的虚线，以及小节内部不连接的浮置小表。有限省谱号只在所用谱号显然时可接受 | 为视觉整齐统一补全行小表、全部连实小节线，或省去必要音区／调号确认 |
| 被要求实际演奏的小音符 | p498的playing cue可在某乐器缺席、缩编或指定条件下由另一人承担；写明条件、实际移调和完整演奏指示 | cue身份就等于永不播放，或复制原音高便适合替代乐器；普通入场提示另有章节，尚未由此补全 |
| H／N式主次线括记或自定义方括形 | p496交代主线／次线的突出范围；只用方括形时须先有明确解释 | 任何字母H都是段号，或方括形表示可选、删节或连音 |

这些处理可能改变编辑／演奏方案，须与外观净书分开。在用户只要求美化时，不自动把密集音改成ossia或把难段移去小谱表。若明确要求给简化选择，才说明保留主谱、替代哪段、如何进入／退出，以及两种读法各自所需的完整信息。

## 指示文字也有进入时点

p495将恢复普通技法的ord.／nat.等放在下一次相关进入处，避免在前一段结束处被略过。它们不是清理多余文字的通用标签，也不由一次出现覆盖全部乐器。共用表情文字在钢琴双表间、接在力度后是可行通道；与发夹并置或空间有限又可分层。[ninelie的K](INTEGRATED_READING_NINELIE.md#10-不同锚点各有任务整曲阅读也不抹掉未知)可据此保留fp及sempre legato的通道；不能由横坐标或居中位置推软件播放作用域。

## 当前能用到哪里

可以用来辨别对象功能、提出记法问题与设计后续对照，不能据本轮宣称MuseScore已支持所有浮置ossia／条件播放或MusicXML往返保持。需实际修改时，核对作者目的、两种读法、范围、原生渲染及交换／播放；本轮不改用户工程或开发接口。
