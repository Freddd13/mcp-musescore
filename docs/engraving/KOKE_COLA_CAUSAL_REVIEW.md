## 1. 两个降号仍然错列：先压紧音高单元

**更正[旧笔记](SPACING_DECISIONS.md#4-新取得的实践对照图)的“把两降号收为同列”。** A/B放大后，B仍有左右两列；下方降号向右收近，上方降号与和弦的相对位置基本保持。作者正文只说明A太松、B更紧凑，没有说合成一列。

该图A、B的五线大小及三个全音符头轮廓相同，可用头列作局部归一化。按原图385×187像素的黑色竖笔与头包络量取：

| 相对量；均非最小墨迹净距 | A | B |
| --- | ---: | ---: |
| 两降号竖笔中心的横向差 | 13px | 7px |
| 上方降号竖笔到头列包络中心 | 24.5px | 24.5px |
| 下方降号竖笔到头列包络中心 | 37.5px | 31.5px |
| 全音符头包络宽度 | 22px | 22px |

即下方降号相对头列右收约6px，约半个本图谱间。这个数来自低分辨率说明图，不提供字体锚点或可直接套入MuseScore的offset。

**为什么好读：** 左侧最远的降号不再与和弦松散脱离，两个降号与三个头更像一个音高单元；同时仍能辨认各自所在的谱位和相互独立的轮廓。收益来自在保留归属的前提下利用字形周围的空白，不能概括成“列越少越好”。

两记号相隔约两个谱间，对应五度。Gould p88对五度及以内的两个变音保留高者近头、低者向左的基本安排，并允许部分形状嵌入空白而不接合；p89再讨论更多记号的交替排列。本图符合“保错列、缩列距”的解释，不能把八度变音可成列的条件搬来。

**对后续净书的用法：** 先检查同刻音高单元能否更紧凑、是否仍归对头，再把其真实前沿带入时间间距。释放了一点列内空间，也不证明某个小节会自动变窄或哪一拍能得到这些空间；后者还受全行分配影响。

## 2. 移休止是在说明声部入口

休止对照中，上表红色内层的四分休止从上部旋律／tie附近下移，后面同层的向下符干长值仍保留；黑色上层可继续按自己的长音与短音走向阅读。成品将颜色统一为黑，干向及相对位置仍承担归属。

**保留并移开休止有阅读收益。** 读者先知道该层此刻未进入，再接到它后面的长值；休止留在旋律通道会干扰上层的持续识别，也容易看似属于上层。只做无碰撞检测可能漏掉这个问题，因为错误的亲近关系也会增加辨认负担。

这里没有依据把它改成删掉所有附加休止。Gould p311–312允许明确的附加旋律干省休止，又要求有独立节奏的两部各自交代时间；p313的严格对位还要持续保部的身份。本例应按所见入口与后续持续解释，不能由Finale layer颜色或MuseScore voice编号决定音乐分类。作者工程未取得，未核其全部隐藏内容。

## 3. “间距前后图”同时含有其它变化

两面板有相同的五小节音乐总览及同一行末，几条内部小节线重新分配。按从第一条内部小节线起的四个完整小节（图示m11–14），黑色贯穿两表的小节线可得到：

| 小节宽；原图像素 | 调整前 | 调整后 |
| --- | ---: | ---: |
| m11 | 127 | 132 |
| m12 | 132 | 125 |
| m13 | 109 | 109 |
| m14 | 149 | 148 |

因此这幅图没有仅把全行等比例放大或压缩，也没有把所有小节宽拉平。某一小节多给、另一小节少给，整体仍在相同系统中。

**同时，m13开头的红色四分休止也从旋律附近下移。** 前后裁图中可直接看见；它让黑色长音及tie通道更清楚。故“调整后更好跟读”可以成立，但这张图没有隔离出间距一项的独立收益。也不能凭一组小节宽证明全部同值已等距、所有共同时间点或音乐内容已逐项保持。

Gould p40保同类时值的稳定参照，p43保必要符号占位与局部空间取舍。这里可学到先看整个音乐单元，再按真实负担分预算；要判断自动净书的具体算法收益，后续应固定其它对象，另外比较横向分配。

这也影响审谱的说法：可以指出“此处休止通道和横向预算都改善”，暂不能说“某软件间距算法提高了多少”。本轮测量仅核说明图的可见变化，没有原生重排或用户试奏结果。

## 4. 梁、弧与系统距离有处理依赖

作者这节用“符尾”指音符的棒，正文已明说其含义是stem；不能依字面将它映射为flag。无梁音的干长先由插件处理，梁角再调整；作者又明确把m10、14、16的跨表梁留到调整五线距离时处理，并允许后续改动已修过的梁。

梁前后图有干长／梁坡的小幅变化；综合图还改变弧形和其它对象通道。成品与“默认”整页对照则同时改变音乐字体、文字字体和手工设置，不能当作单一字体或间距算法的对照。Gould p17–18的梁／谱线白缝及干长条件支持联合看轮廓；这两页不证明作者具体使用了哪一套参数。

可迁移的处理依赖如下；局部问题从当前状态进入，不要求重做全谱：

| 改动 | 为什么还须回查 |
| --- | --- |
| 压紧变音、错头或附点单元 | 时间列的最低占位可能改变；符号仍须归对音 |
| 重分时间间距或系统行宽 | 梁的实际坡度、弧的跨度和文字通道随之改变 |
| 调整上下谱表距离 | 跨表干长、梁位置、弧／力度的归属和空间一起变化 |
| 调整梁／弧或其它外伸对象 | 系统实际高度可能改变，须回看相邻系统／页面 |

作者的实例说明这些依赖会互相反馈。手工固定几何后也要保留重排检查；文中在Finale手工阶段关闭自动间距的做法，不自动成为本项目全局关闭自动布局的要求。现有属性能否稳定表达某个实际候选，留到相应原生试验判断。
