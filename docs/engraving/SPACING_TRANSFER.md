# 间距判断的实曲迁移：m86为什么不能只追求等距

2026-10-20。将[已有间距方法](SPACING_DECISIONS.md)用于《如果有来生》第4页m85–88，重点为此前未调参的m86。完整复看用户原PDF p4及固定宿主的原生p4–5，核源事件、试排、实际图形及全曲连带效果。这是熟悉作品中的新片段应用，不是陌生盲测；原件只读，未改字体或软件。[证据](spacing_transfer_evidence.json)记录五个试排、保留候选及限制。

**本轮判断：m86后半需要更多空间，但原有前后反差并非完全不可调整。** 可以在保住变音构型的前提下，少压部分普通音头之间的余宽、给前半较简单材料补空间；不能把所有八分拉成同距，也不能只加空白后仍用总页数相同来判断成功。

## 1. 先从实际音乐说明不均匀，而不是先归罪于变音

m86下谱表有六个连续八分音符起点，首个是和弦；上谱表先保持附点四分和弦，之后四个普通十六分，再以三个十六分三连音结束。后半七个快速音中有四个可见变音，且多加线。它同时增加联合时间列与字形负担，不等同此前m51没有临时变音的例子。

四个变音在本处具有实际读音作用：调号中的F♯先变F♮，随后D♯、D♮与恢复F♯。不能通过省掉变音、翻干、删除加线或改音值来“美化”。下方六音的重复动作又给读者稳定参照，因此值得问：在密集组仍清楚时，前半是否不必相对那么紧？

这里沿用Gould p39–43／490与官谱A102五／七对三的已读条件，见[间距取舍](SPACING_DECISIONS.md)：复杂一部可获得更多空间，其它层仍应容易追；这不是后半必须与前半等宽的规范。此次没有重报新的教材／官谱覆盖量，也没有以另曲的间距方差排名软件。

## 3. 为什么这次没有把变音组硬挤坏

原生完整第4页及完整m85–88音乐区域均已实际看过。保留版仍能辨认四个变音、七个快音、三连数字、加线和原弧；没有发现新遮挡。这是本线视觉判断，不是打印／演奏通过或自动碰撞穷尽检查。

又对m86上部Note／Accidental的SVG路径作**保守控制点包络**核查：仅接受已确认的绝对M／L／C／Q／Z路径，应用其matrix，并确认没有遗漏父级变换。包络分离能支持本处不相交，包络重叠不能证明墨迹碰撞，不能把它当精确字形外框或通用净书解析器。

本组中，后三个变音与前一个邻音头的水平包络间隔约3.336pt、四个变音与所属音头约2.669pt，原版与保留版基本相同（读数差约0.002pt）。第一个变音前的长空白另随前半重分。两个普通邻音头的原点间距则有从约13.05pt缩到11.65pt的变化。因此本例可具体解释为：**保住目前清楚的变音构型，在其它可分配空间中作取舍**。这些是本输入的观察，不能宣称是引擎不可突破的理论最小值或全谱固定净距。

最初想用fontTools计算精确曲线边界，当前运行时没有该库；没有为此安装依赖，改用上述范围明确的保守核查与实际看图。不把未完成的精确边界分析写成通过。

## 5. 这次经验怎样改变后续做法

以后同样遇到“连续八分忽然变宽”，先分清是否有新的细分、变音／加线、错头、持续／休止或换行入口；再找哪一部分是必须保护的构型、哪一部分有可重分的余宽。只有看到完整两手和最后一段空间，才比较稳定收益。必要符号本身不能为了等距删掉，空间重分也不应默认越强越好。

具体适配方向仍是准备材料：需要解释每列的必要占位、局部弹性及整行预算，并显示完整行页连带效果；一次参数动作要能预览、保留或拒绝。这里没有开发布局优化器、MCP／插件／本体接口，也没有证明现有属性足以普遍解决问题。

候选是比原版前后反差更小的技术比较，本线倾向继续保留它作实际读谱备选；没有把几何比率当作个人审美分数，也不反复要求用户辨认微差。原PDF、MSCZ哈希未变；用户音乐、图像、MIDI和私有副本均不进Git。完整缓存位于`tmp/engraving/spacing-transfer-2026-10-20/`，重载副本为`native/m86-balanced-resaved.mscz`。全曲已知其它重导出问题尚未合并处理，不能把它当正式净书成品。
