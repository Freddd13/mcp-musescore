## 2. “省去3”不是把后面所有四分音符都缩短

p1先用括号和3建立长短三连细分，后写simile；既有研究已用p2 B首小节的四对长短、p3 C首小节的附点二分加一对复核过其读法。长音是写出的四分，旁边才是短八分，无法像连续普通八分一样直接共梁。为完整三音梁拆长音，会增加音头和tie，属于有代价的记法改写。

Gould p215允许明确重复型建立后省数字，仍以组形可辨为条件；复杂配合可能须保留。p210又区分显露每拍和流动的收益，不能用“所有拍都必须拆开”反推这首应重写。后页截成独立教材、学习者容易失去参照时，可以考虑局部恢复数字；本轮没有制作或采用该候选。

更关键的反例在p4第四系统末两小节（人工m95–96）：m95前半是从前一小节接收的二分和弦，后半明确一组“**四分休止＋两个四分音符**”，括号及3包括休止；m96是两组各三个四分音符。每组占两个普通四分拍，单位已经不同于开头的一拍内长短组。下表同时保持普通四加四的八分伴奏，提供另一套参照。

因此此处重新印3有实质用途：提示新单位、组内等待和与另一层的对应。把m95括号左端缩到第一音，会漏掉首份休止；把数字当重复信息删除，则要求读者自行猜测变化。反过来，也不能把旧simile解释成全曲、所有声部、所有四分音符自动按同一比例压缩。相似旋律、相同数字、实际组单位、显示省略是四件事。

旧原创两小节已证明当前宿主可保存真实Tuplet并单独省显示；本轮未重跑该实验，也没有据PDF补齐全曲每个未标组的精确比例。

## 3. F的八个整休止：先确认谁在休息

p5前两系统m109–116，下表各有一个整小节休止；上表同时存在旋律与全音符／二分音符和声。第三系统m117起下表恢复，前一系统末先给高音谱号，第四系统又有明确l.h.局部接手。

这不能折成一个仅属于下表的“休息8小节”而让上表继续普通小节；也不能仅据空表认证左手可翻页。上表不同层可能由一手或双手分担，具体指法、持键和踏板未由PDF证明。

Gould p305更提供了需要主动质疑官谱的条件：**当两手都移到同一表、且干向表示手分配时，另一空表的休止可能误导成一手休息，应避免。** p312的独立声部休止又有不同用途。这不是本例已经确定的错误：F尚无足够手分配证据，不能直接删八个休止。后续若工程／指法确认符合该条件，再比较空表休止的保留或隐藏，并核再进入；不能建立“所有空表删休止”规则。

新读Gould p564–565的多小节休止属于演奏分谱准备：计数、分段、宽度和结构变更帮助等待及恢复。这里要移用的是“等待时读者需要什么”的问题，不能把分谱缩写直接套给独奏钢琴的一张空表。

## 4. H的六次短8vb和I／J的斜虚线为何不合并

p6 H前六小节m133–138，8vb分别从每小节前半低音开始，延续线在后半高和弦之前回钩结束。相同标记重复出现并非无意义：若拉成覆盖整句的长线，后半和弦也会被卷入降八度。Gould p325要求范围无歧义；纸面“更干净”不能以改变音区解释为代价。此处只核可见范围，没有本曲工程播放验证。

I后段及J的虚斜线则在上下表的慢和弦之间接力。Gould p307用这种线保持中层的跨表路线，并提醒实线头到头可能像滑奏。它们不表示新增中间音，也不代替完整tie：慢线身份、持音关系和旋律短弧须各自保住。将慢线全部搬到上表可能挤入已占用的旋律层，改成实线或大slur又改变读法；本轮保留路线提示，没有替代版证据。

J高音区用了较多加线，值得以后固定字体、层次和预算比较；不能直接套新读p563的“管弦乐分谱极端加线才考虑八度符号”条件。那一条有特定编制前提，不是钢琴八度阈值。

## 6. 结尾完整tie、短拍和外层slur各有任务

p6末系统m163明确2/4，m164回C并写rubato；m162已有rit.。短小节是实际拍号变化，不是多挤一格后可删的布局标记；rubato也不自动恢复旧速度。m162→163的上下长音有完整连接，不能在新拍号处切断或重新起音。

m164上方琶音和弦接下一小节附点二分和弦，外层另有通往后续旋律音的弧；下方运行也有自己的外弧。最后m166–167琶音和弦以完整tie延到终止和弦，两表各有延长记号、ppp。这个结尾不能套[上一首末尾的开放留声弧](INTEGRATED_READING_MICHISHIRUBE.md)：本例看见的是实际有接收端的持续连接，外层弧又不承担同一任务。首轮“勿自动补所有开放弧”是一般边界，不能读成这里已确认存在开放弧。

本轮保留这些区别，没有自动合并和弦、补弧、补踏板或从外形猜演奏释放时点。
