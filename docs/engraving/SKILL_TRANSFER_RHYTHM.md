## G的五音：动作连在一起，拍子仍可分清

A007 p4第五系统G的首小节，上表每半小节是：**八分休止＋四个十六分＋一个八分**。每组五个符头，两组共十头及两个休止，普通时值已经填满4/4。初判把拱形看成四头，并暂以“内梁”解释分组；放大后纠正为五头、主梁2＋3断开。原初判完整保留，没有改写成全对的记录。

第一半小节以下表所列四分单位偏移计时，小节首为0；第二半同型整体加2。

| 事件 | 小节内偏移（四分单位） | 阅读作用 |
| --- | ---: | --- |
| 八分休止 | 0 | 说明入口晚半拍，不能为简洁省去 |
| 第1、2头，十六分 | 1/2、3/4 | 第一拍的后半，主梁连为一段 |
| 第3、4头，十六分 | 1、5/4 | 第二拍开始，新主梁起点 |
| 第5头，八分 | 3/2 | 同一动作的落点，持续到下一半小节 |

slur罩住五音，帮助手指和句法认出一个上行返回的动作；主梁的2＋3让读者找到第二拍。把五头全连主梁会弱化拍位，把弧也拆成2＋3又会切碎动作。两种分组各有工作，适合并存。

分梁处也没有刻意撑大：第一组四个相邻等时起点的符头参照X距约7.556、7.793、7.573、7.793pt，第二组约7.810、7.556、7.793、7.556pt。这里的间隔虽有微差，跨主梁断口仍平顺；读者可由梁断认拍，无需再制造一个明显宽格。数值取同字形的PDF参照点，只用于解释本组，不设美观阈值。

下表慢旋律另有四分休止、短值及tie接收的附点四分，低音还有长保持。所核偏移1、3/2、7/2的上下符头在原PDF共列；偏移2处上表休止与下表续音相遇，不把接收头算新攻击。上表pp和下表p cantabile／dolce ed espress.及r.h.提示保留，避免快层盖过歌唱层。
