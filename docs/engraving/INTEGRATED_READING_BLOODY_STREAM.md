# Bloody Stream：角色、符干参照与两种空间预算

2026-10-24，A021全5页及13处局部复读。**主要保留B段的角色分层、跨表十三连音的干列、F的留声提示与短2/4停顿；值得提出的两项编辑建议是补全D.C. al Coda字样，以及比较引子颤音波线的终点。** 最有价值的新间距认识是：跨表换干向时，单量符头会误报压缩；同干向五连组又展示了整拍略加宽、组内保持平顺的办法。

原件位于用户新官谱目录，文件名为Bloody Stream - JoJo's Bizarre Adventure.pdf，SHA256为bbc5adf41772e9d7071757aaa377978d415238a1783b2b85932a7bd10c09cdcb。图、测量方法及来源核对见[阅读证据](bloody_stream_whole_reading_evidence.json)。教材本轮复读12页，首次完整阅读印刷p576–582七页；图片与原谱均未加入Git。

## 1. 旋律在下面：干向先服务角色

p2 B=m21，上方重复音／和弦用上干，较慢旋律在其下用下干，低音另保持四分脉冲。这样读者能沿长值跟旋律，同时把短重复识别成连续节奏；若按音高排序后统一时值和干向，两个注意层会混在一起。

这处有作者依据：[Animenz官方视频说明](https://www.bilibili.com/video/BV18L4y1e7oi/)介绍0:36附近，把重复节奏放在安静旋律上方，时点配合使其可由一只手演奏；他还说明初稿塞入更多原曲声部后过于杂乱，后来集中于节奏和踏板。这支持角色分层的解释。所读是公开说明文字，未把它算成已看完／听完视频。

A段则是上干长旋律与下干短运动叠置；C的重音前景、长和弦和低部快型又形成另一种组织。好读的共同点是各条线能持续跟踪。具体哪条在上、哪种干向，要跟着本段角色走。重复型写出也让两手逐小节向前读；仅下表重复、上表变化时，保留两表实际材料，见第6节。

## 2. 跨表十三连音：符头忽然近，符干仍平顺

p3第2系统末小节，人工连续编号m49，13个黑头共用两层梁：前8个在上表，后5个降入下表，r.h.及角括形说明后段仍由右手接续。低音持续由另一层承担。共同梁保存一条下行手势，局部手标记消除了“下表等于左手”的误读。

跨表处两个同字形符头的PDF绘制原点为514.962、517.266pt，只差2.304pt；相应符干却在515.178、522.288pt，相隔7.110pt。前一个下伸干靠头左侧，后一个上伸干靠头右侧，两者附着偏移分别约0.216、5.022pt。整组12个干间隔为6.894–7.110pt，最大／最小约1.031。

**判断：保留这个过渡。** 沿共同梁看，干列保持平顺；两个头又分处不同高度。若为了符头等距把下表五音整体右移约一个头宽，会把原本平顺的干列撑开，并耗用更多行宽。诊断此类“突然挤了”时，应同时核头、干、干向转换及同时时点，不能只用一串头原点计算均匀度。

这是从原PDF线段核出的具体反例：已排除r.h.角括线和低音符干，没有提取字体。它给今后MuseScore间距诊断增加了判别依据；尚未对同构MuseScore输入作新试验。

### 最后一组为何换一种排法

p5 H后的m106同样有13个黑头，却留在上表并在组内改低音谱号，后接梁外八分休止；梁为三层，与m49的两层不同，低音此时还重新发音。因此应分别读两组的时值与低部任务。

前一处跨表能清楚保留下行路线，并引向D；最后一处把快线留在上表，低部仍有自己的动作。若照搬m49跨表造型，会把两条活动线挤进下表。反过来，给m49也套上表内换号，又会多一次组中识谱转换。这是有理由比较的两种组织，不能仅因都标13就统一。

## 3. 五连组：先分配整拍，再看组内

p3第4系统第2小节m54的上部，先有普通十六分组，随后五连组，再回普通组。五连的四个内部头距约8.514／8.676／8.496／8.676pt，最大／最小约1.021；前一普通组内部约9.90–9.92pt。字形、字号和头宽相同。

从一拍起点量到下一拍起点，前一普通拍约39.654pt，五连拍约42.858pt，后者宽约8.08%。**这是一种实用取舍：多一颗头的拍略多分空间，组内仍紧凑平顺。** 把两拍强成同宽会更挤五连；把所有快头强成同距又会把五连拍拉得更宽。现排法用组形、数字和拍间参照共同传递节奏。

今后比较Muse候选时，应分别问“复杂拍的总预算是否足够”“组内哪一格无故突出”“其它层是否仍在正确时点”。8.08%只是本例测量，不能作为全谱固定增宽参数。与跨表例合看，也不能把头距和干距混成一个评分，详见[间距取舍](SPACING_DECISIONS.md)。

## 4. 波线、开放弧与休止各自提示什么

引子m4在上部二分长音上标tr及很短波线，后接上层二分休止；中层l.h.、mf和后续进入另有归属。复看Gould p134–140后，我建议比较把波线延至该长音结束／上层休止之前的方案。p136允许单一时值只标tr；采用波线时则建议覆盖持续时段。延线能让结束点更明确，须同时避开手提示通道，不能一路拉到整系统末。原观察“波线很短”保留，新增加的是编辑判断，见[颤音专题](TRILL_READING.md)。

p4 F=m74标fp及tranquillo e legato：长和弦旁有不接下一头的开放弧，后来的完整tie和跨表短线另承担实际连接。Gould p337允许钢琴用开放弧提示留声，此处应保留和弦共鸣的读法。上层休止可与持续声共存。若以后需明确释放位置，可提出踏板范围方案；当前PDF没有给出精确释放时点。

m84是实际2/4，两表都全休止，m85恢复C，G=m86从下一页进入。它给前一段和新主题之间留了半小节的呼吸，删除会改变时间。A中反复的局部8vb又只罩低处短范围；不能为少画几条线把整行中间材料一起移八度。

## 6. 新读规范：写出的重复让眼睛向前

Gould p576–577把cue小表限定在必要互动范围；若只需节奏定位，可减少到节奏提示。独立拍号／重复层与合奏不重合时，分开的提示通道保留两种计量。小表不是装饰，具体见[提示与替代](EDITORIAL_ALTERNATIVES.md)。

p578强调有空间时把重复材料写出，眼睛可逐小节前进；简易小节重复符要提供连续计数，新行重新写实际型。钢琴大括号两表的重复符还应以两表都重复为条件。A021伴奏相似而旋律变化，保留实际低部更利于两手共同跟读，省墨不应增加回找。

p579–580要求总谱／分谱保持反复结构与排练定位一致。tacet适用于整乐章或已结束演奏的余段；长的中段等待仍需可数范围，紧接进入的attacca也须给准备依据。它们说明“少画休止”可能增大定位成本，不能拿来省掉m84的真实短停顿。

p580–582另读了分谱抽取后的提示变音、横向旋律拼写及合并演奏分谱条件。合并能帮助协调，也可能增加翻页；分线合表有节奏一致、不交叠及共同力度等条件。这些是合奏分谱规则的适用边界，钢琴手分配仍按本曲织体判断。
