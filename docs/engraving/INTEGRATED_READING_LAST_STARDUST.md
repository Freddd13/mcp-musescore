## 2. 标签、引入和恢复各有自己的位置

p1 A之前已出现p、局部换谱号及两个引入音，框A在后面的完整入口。把p统一挪到A，只得到图形整齐，却改变了引入的读法。p2 B后的p快型与随后f／ff又有自己的先后和层次，不因同一行已经出现力度就删去后者。

p6第三系统先Meno mosso、后rit.和延长，双斜线后已写a tempo及引入，M在下一完整入口。下一系统又有rall.、ad lib.、等待／收束和a tempo；再下一系统N附近才明确Tempo I。**局部恢复与回到最初速度不能合成一个“恢复默认”动作。** 本轮保留这些文字与起点；没有音源或工程，不给未标数值的慢速及局部a tempo擅补84。

这类不齐是信息各有起点，不是单纯字宽问题。若要另起行突出M或N，需同时保住先到的速度、力度和引入，比较前行留白及页高；本轮没有重排替代。

## 3. ad lib.仍有次序，背景也不能随意合并

p6第四系统的上部仍写音值、梁组与长弧，下方先有带延长的琶音长和弦，稍后另写长和弦，再到收束。Gould p610允许自由独奏保留分界和音值，p610–611又允许背景用便利的长值表示等待；“有普通头／小节线”不自动否定自由，“自由”也不授权删除所有时间线索。

放大两表后还能看见一个应保护的边界：下方自由段内前后两个长和弦没有全部用tie连成一次起音；右侧收束处又确有明确的局部tie。当前既不能将前两个自动合并为一次保持，也不能从静态PDF确定每个延长的实际秒数与脚法。需要比较省写或释放时，应先取得明确音乐意图／可编辑配方，把“重奏还是保持”单列为记法问题。

Gould p190讨论严格协调的延长时，需要核共同拍或细分；p610–612的独奏／背景等待又有不同条件。该处上下延长承载的长音起点不都共列，不能仅凭X不同就移齐，也不能仅凭ad lib.宣布所有对齐无关。先认活动、等待、实际收束和重新进入的关系；本轮没有把这些字样变成精确播放时钟。

收束后a tempo在同一行进入，后面仍继续计量材料。此处未明确取消原拍号，不需要为制造整齐而自动补一个新拍号。它也不同于用户明确senza misura后重新印6/8的情境，见[自由段专题](FREE_PASSAGE_READING.md)。作品各自的自由程度要分别读。

## 4. 尾部non Ped.使持音与留声的区别更具体

p6末行下部先长和弦，再有更密的重复起音，随后多音tie接收并逐渐减少活动，non Ped.在这个收束附近明确出现；上部也有自己的长连接和最后延长。先保留“重奏、仍保持、已经结束、停顿”几个不同层次，不把它们全归成一般共鸣。

尤其不能因为钢琴平常使用踏板，就认为删tie仍能保音乐：这里还明确要求不用踏板。反过来，完整tie也不独自指定唯一指法或证明工程已正确播放，不能替作者补演奏实现。此结论是读法保护，不是已经生成新的踏板方案。

纸面留白同时有导航作用。按首音乐页在右的通常双面装订假设，p1→2、3→4、5→6才涉及实际翻动；p2／3、4／5在同一对开。p5末仍有活动，p6立即继续，较后的自由段和延长不能倒过来证明页界可翻。实际媒介、手分工及是否有翻谱人未知，不凭长音或一表休止认证窗口。
