# 用户第4页：先读织体，再比较踏板的表达方式

2026-10-20。本次将[整页判断](INTEGRATED_REVIEW.md)延伸到《如果有来生》p4及相邻p3／5：保留有用途的声部、提示与行页结构，只在独立工程副本中比较m70–79的13组踏板。最终候选通过原生保存重载，完整MIDI与原版一致；这是可继续评价的风格候选，未获得用户采用。[证据](page4_review_evidence.json)保存来源、失败尝试、几何和控制事件核查。原PDF、MSCZ、官谱及教材均未修改，不把用户音乐或参考图加入Git。

## 1. 整页的任务不同，不能套同一种整理动作

| 系统 | 读者要追踪什么 | 判断与理由 |
| --- | --- | --- |
| m70–73 | 上部短和弦、旋律保持、下部内线与低音，以及不同踩放范围 | 保留各部干向、休止、弧和括起音；它们交代进入、持续及分层。可以单独比较踏板标记的重复负担，不能同时省休止、改分手或统一长弧 |
| m74–79 | 同类伴奏下的旋律与内线变化；有些踏板一小节，有些更早释放 | 保留实际分组。把所有范围延到小节线，或合成每拍换踏板的连续线，都会把差别抹掉 |
| m80–84 | 旧材料过渡到G／Comodo，力度与运动方式转换 | 保留行中入口。工程MusicXML确认G、Comodo、mf均从m82起点生效，但分别属于不同Part／对象；字样左边界不同不等于时间起点不同，不为“整齐”逐字吸附或强制另起行 |
| m85–88 | 半音走向、局部三连音与leggiero e delicato的轻巧层次 | 保留变音、组边界及文字通道。密集短音占宽有信息原因，不能仅按外框宽度将它们压到普通伴奏的密度 |
| m89–93 | 主层、低音和高处pp quasi eco应答分别进入 | 保留三谱表及上表预留的进入轨道。两次echo提示对应两次应答，不能按文字重复删除；不为少一条空表让上层突然出现或挤进主层 |

这里的“保留”是有根据的优先判断，不表示原排法每一处都最佳。工程有三个Piano Part，每个含两个逻辑谱表；这既不证明有三位演奏者，也不能直接当作三只手或三条音乐声部。需要联合看实际显示、材料连续性和手的动作。

用户成品PDF与release5工程没有建立逐对象同一关系。本次候选处理工程的原生重导出，不能声称改好了原PDF。`(S.P.)`的含义仍未确认，本次保留，不擅自扩写成某一种踏板或持键要求。

## 2. 踏板线为何有时更清楚，有时反而更碍眼

本次复读并看完整图页的Gould印刷p332–338／PDF p352–358，**已经在[钢琴织体专题](PIANO_TEXTURE_STUDY.md)读过**；这是应用与复核，不增加首次阅读页数。A056《Here》p8也为复看，不增加历史近读379页统计。

规范带来的判断不是“出版谱都用括线”：

- 单组的开始与释放要容易配对；连续短组可随局部空间变化高度，不必全行降到最低处。多类踏板及八度线又需分层。
- 直立Roman `Ped.`有利于明确字母锚点，垂直端钩可清楚交代终止；距离太远时还可能需要引导。传统花体Ped.／星号也有效，尤其长时间持续时，一条贯穿的长线可能分散注意。
- 立即换踏板与先释放、稍后另踩不同，不能把两个符号之间的空白一概修成尖角。重复模式的省写要以动作确实相同为条件，不能只看图形大致相似就用sim.代替。
- 踏板保持与手指持续按键是不同指令。声音相同，不代表可以缩短书写时值；图上Ped.与起音对齐，也不是脚在同一毫秒动作的证据。

A056分开标示两类踏板和两组叠放释放，有助于分别追踪控制；但`sus. Ped.`又有与sostenuto混淆的风险。应学习它的分层，而非无条件复制其缩写。详见[原例及条件](PIANO_TEXTURE_STUDY.md)。

用户p4前两行重复的花体字样／星号占据多处注意点。本次候选每行只在首组写Roman Ped.，其余各组仍独立画开始／结束钩，不合并跨度。13组开始的逻辑位置、释放位置、原手动微调和播放均受保护。阅读收益是假说：目光可跟随每一段踩放区间，减少重复辨认字样；代价是增加线条及依赖行首说明，不保证人人更喜欢。

原生MIDI也能反驳“所有相邻组都是立即换踏板”：m70一处释放与下一次踩下相隔241 tick，m72另一处仅1 tick（PPQ480）。本次仍保留独立组和原有可见释放位置，不把后者自动改成连续尖角；真实脚法与印刷约定的对应仍需具体判断，不能用MIDI重写用户意图。

## 3. 三个失败控制，说明不能只换符号

| 尝试 | 实际结果 | 学到什么 |
| --- | --- | --- |
| 每组都换Roman Ped.＋线，沿用旧端点偏移 | 首条线穿过下一组字样；13组中只有11条水平线画出，两个短跨度容不下重复文字 | 文字字宽、端钩与锚点共同决定图面；“逻辑范围没变、MIDI没变”不能证明释放提示还在 |
| 省重复字样并将端钩对到旧星号中心，只给新Segment写off2 | 初次导出正确；原生保存后，9组新增端点微调丢失，释放横移最大32.28 SVG单位，约1.45sp | 首次渲染不是稳定结果，端点调整还依赖保存状态 |
| 同时写入默认offset来保住off2 | 微调可保存，但部分踏板高度变近，且有其它布局对象变化 | 默认值不是此前的有效位置；若要隔离外形变化，还须保留实际渲染出的高度 |
| 最终：成对保存有效offset与端点off2 | 13组释放点保留，保存重载后8页SVG／PNG稳定 | 这是本输入上的可用控制，不是所有谱都该采用的踏板模板 |

当前只读源码中，`pedal.cpp`的端点定位会区分钩形；`line.cpp`的Segment保存条件联合检查OFFSET状态及offset／off2。固定宿主实测与此机制相符：新建off2单字段不能保证落盘，成对写入本候选的有效offset后保留。未证明该二进制对应当前源码提交，不据此宣称所有版本都有相同缺陷。本次已有数据侧可行路径，没有修改本体、插件或MCP。

## 4. 最终核查保护了什么

- **源内容：** 只允许13个Pedal子树变化；将它们还原后，整个XML树与源相同，包含富文本中的实际空格／尾文本，其它ZIP条目逐字节相同。音乐、声部、连接、休止、文字及断行数据保持。
- **印刷提示：** 13个释放钩对应原星号的实际墨迹中心，横向误差不超过0.005 SVG单位；其余11个起钩对应旧Ped.墨迹左边界，误差小于0.02单位。两处Roman字样的墨迹左边界因字形侧边距右移约0.484单位、0.022sp，不能说所有墨迹完全不动。匹配原印刷点是保守的外形对照，不是证明原点精确代表脚法时刻。
- **整曲：** 保持8页、38系统及各系统小节范围；其它7页SVG相同（去除文件标题／描述）。第4页有少量非踏板元素Y值变化，最大0.01 SVG单位，X相同；没有把它写成“整页其它图形逐字节相同”。
- **演奏：** 原版、控制和最终版完整MIDI逐字节相同；含2310个有效NoteOn、391个Tempo、310个CC64事件，不只核音高。未实际试听或验证多Part的物理踏板路由，也未确定S.P.的用途。
- **持久化：** 最终候选保存重载后，offset／off2读回保持，全部8页SVG（除标题／描述）、PNG像素、MusicXML和完整MIDI与保存前相同。

SVG里PedalSegment从30个路径变为6个文字路径加37条折线，图元数量反而上升。不能用节点数下降来替代“更简洁”；真正应评价的是踩放归属、识别负担和下方通道。

私有最终候选：`tmp/engraving/page-reading-2026-10-20/native/pedal-brackets-frozen.mscz`；对照图及整页路径见证据。图像来自180dpi原生PNG合白底／同框裁切，没有搬动符号或在图片上重排。

## 5. 可迁移的经验与后续边界

先判断一页各处承担的任务，允许“保留”与“比较”并存；再分别核逻辑动作、可见锚点、播放和保存。踏板符号替换不能简化为改beginText或把全曲统一成一条线。未来适配确有需要时，应能读到逻辑范围、每个绘制段的有效／保存偏移、钩与文字、实际图面和控制事件；这些是已复现情境提出的需求，不是本次开发任务。

试验只覆盖m70–79，m80–81仍保留旧式标记，属于控制边界，不建议成品故意混用。若以后选择该风格，应连同前后页的踏板语法一起检查，考虑长持续、立即换踩与明确断开的分别写法，形成一致的局部约定。当前没有用户审美选择、实际尺寸打印或演奏验收，不将本候选当作正式净书完成，也不要求用户先安装／打印才能继续学习。
