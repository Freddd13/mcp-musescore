## 1. 更正：本谱S.P.已有明确定义

**第一页第二系统写有`Sost. Ped.(S.P.)`。** 原MSCZ中也存在完全相同的StaffText。此前本库多处将后续`(S.P.)`列作含义未确认，是本线未充分利用全曲首次定义造成的判断缺口；现在更正，不能继续要求用户重复解释这个缩写，也不能只因一般规范认为它有歧义就拒绝采用本谱已经给出的定义。

本谱中，S.P.指sostenuto pedal，即选择延音／中踏板。这个结论有**作品自身定义**，不只是从字母猜测。它不推广到其它作品；Gould p336仍认为独立使用S.P.容易混淆，更倾向完整名称，这属于通用编辑建议。若以后整理成品，可讨论首次定义是否足够醒目、跨页是否需要提醒，不能把已定义的简称一律当错字或擅自改成普通Ped.。

## 2. 这条新证据怎样改变既有判断

**踏板候选需要区分两类控制。** [p4踏板括线](USER_PAGE4_REVIEW.md)只比较原13组Pedal的外形，其范围与CC64保持，不曾改七条S.P.文字。现在明确：不能将它们因为都与留声有关而合到一条普通Ped.线上，也不能把S.P.删成重复提示。Gould p336区分选择保留与普通延音；普通踏板的状态还可能改变中踏板捕捉的范围，编辑前必须联合读两类动作。本次没有补写CC66或重编脚法。

**m132–135的两条长弧现有作者确认。** 原生m132的四音和弦含外层A八度，同处有`S.P. for A octave`；两条异向Slur从该Chord指向m135同一个休止。2026-10-20用户说明：“选择性延音踏板保持 A 八度，长弧表示持续”。这将此前上下文支持的解释提升为本处明确意图：两弧用于持续提示，不按普通分句弧或重复对象删除。作者没有逐条指定与八度两端的对应、精确捕捉／释放拍点或替代写法，不能再由对象类型、休止位置或纸面x单独补出。

因此[休止与弧的旧试验](SUSTAIN_AND_RESTS.md)中，改整休止令弧尾移动约17mm的技术结果仍有效；其影响现可明确为持续提示的可见终点移动。下一步若比较隐藏辅助休止，应先检查这一层的停顿／离键信息是否仍需保留，以及跨行持续是否清楚。**不能从持续功能已知直接跳到批量隐藏或缩短时值。** 本次没有复跑或采用旧拒绝版；这条作者说明也不是线形审美选择。

**MIDI相同的保护结论也要收窄到实际证据。** 旧候选完整MIDI相同，仍能证明没有改变该文件已有演奏事件；其中310个CC64不能证明S.P.的中踏板实现。既有MIDI未见CC66，本轮没有试听、物理踏板或声学检验，不能把“保留现状”说成“原奏法已正确实现”。这是具体的未来研究需要，尚不是软件缺陷定论或开发任务。

这份谱并非缺乏层次：它已经用干向、内外弧、谱表数量、括起音和文字区分复杂任务。与目标出版观感的差距，应分成重复音型的空间分配、局部线重／归属和版本样式输入等具体原因；现有证据不支持“所有梁／弧／间距都应重新统一”或“一换字体便解决”。字体仍是独立输入，当前不在本线更改。

2026-10-20随后补核[速度单位与停顿](METRE_TEMPO_READING.md)：F／m66既有导出四分80→120，旧四分与新附点四分均0.75秒，保留关系。E／m58实际前值约122.5、新80，使等式两边有约2%的偏差；这是需区别演奏意图的播放复核项，未认定版面错误或修改。p8自由活动与陪伴等待也不能直接套严格合奏的同拍延长；本轮仍保留，待自由段专章及精确范围核查。

随后[自由段专章与p8续核](FREE_PASSAGE_READING.md)已补上述规范缺口：五个背景音为m148→149的Tie延续，活动终音与背景分别承载延长；本例保留四表和不同x的延长号有条件依据。隐藏4/4及Part／跨表容器不直接等同读者节拍或手分配；具体脚法与释放仍待核，无新改谱／试听或软件适配。

## 4. 下一次真正处理时的顺序

1. 先确定处理的是成品PDF观察、已保存工程还是当前GUI。已有PDF和release5存在差别，不能混称同一基线；本次没有操作GUI。
2. 读取本谱首次定义、脚注、局部限定和实际前后路线，已明示的名称直接采用；只把剩下的作用范围／动作问题列出。不要将常见缩写的通用歧义置于作品定义之上。
3. 优先处理可定位的干扰。当前工程的重复rit.属于这一类；线重、间距、踏板字形则分别作为受控风格比较，允许保留。
4. 记法提议另列：辅助休止、持续图形、踏板捕捉／释放、手分配不可混进外观清理。先说明更改哪种读法，不能以MIDI相同授权。
5. 单项方案都有依据后再考虑组合；组合仍要实际导出和核查，不能因为各项单独通过就宣称合并也通过。本轮没有生成组合候选或正式净书成品。

本轮的新进展首先是纠正了一个会阻碍后续判断的上下文遗漏，并把单专题应用整理成整谱优先级。它不是一次新的独立审美评测，也没有完成全谱逐音校对、所有脚法重建、实际打印／试奏或自动净书适配。知识库与skill应保存“先查作品自身定义、再区分名称／范围／播放”的方法，而非永久把本例简称塞进未知清单。
