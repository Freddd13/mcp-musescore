## 1. “不同细分不能都均匀”不是数学定理

Gould印刷p39–43与490应合起来读。p40提出同类时值在系统内保持稳定的目标；p43允许真实符号占位造成局部加宽；p490在多部情况下，先照顾**每一拍**最复杂的读法，再对齐其它层，并尝试减轻最大的失衡。这里不是固定照顾右手，也不是整首只挑音符最多的一部。

旧专题中“不同细分共存时，无法同时让每层都严格等距”过于绝对。设两层在同一拍内均分五份和三份，拍宽为W：上层位置可为`iW/5`，下层为`jW/3`。两层都可以各自均匀，并在真实同时时点对齐。这个构造证明几何上可行；不证明给定字形、宽度和上下文下它一定实用。

实际困难来自有限宽度、必要净空、传统时值压缩和光学关系。若为每一处额外符号都维持全组最大净距，整行可能过宽；若按所有事件的联合序列平均排，又会把不同的时间差画成一样长。两种“拉匀”都可能损害阅读。

**因此要保护的不是一个统一坐标模板，而是可辨认的拍组、同步关系和角色轮廓。** 简单重复伴奏适合先追求稳定；复杂细分可以获得更多空间，但仍须解释额外空间保护了什么，是否能减轻其它层的波动。允许牺牲不是默认排法最优的证明。

## 2. A102 p7：官谱中的三连伴奏也会不均匀

来源为《Owari no Sekai Kara》PDF p7第一系统第二小节。上部二分音符和弦延续到后面的五连组，继而七连；下部继续三连音。完整两手及p8上下文已复看。本次只把可见组和绘制位置作为证据，不声称还原了作者工程或其软件内部算法。

下面是同一文件、同一个实心符头字形的PDF绘制原点，单位pt。五连起点的和弦只计一个时间位置；三枚上下叠放的头不计作三个连续事件。表中均为组内距离，没有把穿过小节线的入口距离算进去。

| 层与范围 | 相邻位置的距离 | 能说明什么 |
| --- | --- | --- |
| 上部五连组 | 7.56 / 7.44 / 7.68 / 7.44 | 组内较稳定，有小幅变化 |
| 对应下部三连组 | 12.60 / 12.60 | 同一跨度内，另一层也可以较均匀 |
| 上部七连组 | 6.96 / 8.52 / 9.72 / 9.72 / 9.84 / 9.72 | 参考谱自身也没有坚持组内绝对等距；高处加线等轮廓同时变化 |
| 对应下部三连组 | 18.72 / 22.80 | 下部内部步长随上部实际分配改变 |

更值得学的是时间关系。七连起点为294.00，其第3、第4个头为309.48、319.20。三连第2个音位于七份中的`7/3`处，即两头之间的1/3：预测`309.48+(319.20-309.48)/3=312.72`，实际也是312.72。三连第3个音用相同办法预测335.48，实际335.52；五连对三连的两个预测误差最大约0.08pt。

这是与“沿复杂层的局部间距插入其它时点”相符的版面证据。它既没有把下部独立拉匀，也没有把附近不同起音强吸到同一列。微小差异可能包含输出量化或光学处理，不能靠这些数值确定制谱者使用了哪种程序。

**阅读解释：** 连梁、数字和重复音型让演奏者识别组的关系，不必把所有节奏都从横向距离重新计算出来。下部轮廓保持可认，而不是保持毫米步长不变。代价是伴奏有空间波动；好处是复杂上部有足够辨认空间，并仍能找到相应时间位置。这与Gould p200/490的有条件取舍一致。

**不能推出：** 七连组所有增宽都必需、每处都最优，或MuseScore现有25%波动因此合理。要判断“还有没有更好的”，仍需同一音乐、同一字形、同一宽度的替代排法。尤其不能比较两份不同音乐的间距方差，就排名软件。

### p8：把三小节分到两行，各一小节半

前两系统实际容纳的上部六连组分别是`4+2`与`2+4`，每行各36个连续时间位置。中间的半音密集小节在整拍边界拆成两段：第一行右端没有结束小节线，第二行先接12个音，再出现小节线。下部也对应先两拍、再两拍，不能仅凭上部音头数量判拆行。PDF向量另可核第一行中间小节线x369.60、第二行中间x278.04，第一行右端谱线至x559.20但无相应结束小节线；完整图确认了这一读法。

首系统无临时变音的前24个位置，组内步长约11.64–11.88pt；其后半音密集的12个位置约15.00–15.24pt，下一行接续12个位置约15.96pt。这是同类节奏因符号负担而改变空间预算的实际参照，不是整首六连都用同一毫米间距。值来自同文件相同头型的绘制原点，错头与和弦头按时间位置去重；没有把行首/小节线距离混入组内统计。

**为什么值得学：** 若把这三小节按两完整小节、一完整小节分到两行，事件数会变成48与24，而且较密的半音小节集中在第一行。各放一小节则需三行。现排法让两行各容纳36个位置，并把最密小节分担到两行，符合Gould p489所举三小节分两系统的情境。这里的密度均衡解释有实际图形与规范支持，不证明出版者作过上述候选比较。

**代价与保留条件：** 读者必须继续追踪未完小节。p489–490将拆小节限定为例外、要求整拍边界及清楚续接；器乐分谱另有续小节提示和不可跨页等条件。这个PDF片段没有显示教材所示括号续小节号或双斜线，不能把提示省略也奉为最佳。当前只分析同页两行；未验证本机软件怎样实现这种排法。

## 3. 同拍错列：先查归属，再判“不齐”

本次完整查看Gould印刷p47–53七页图文，补p491的一般对齐原则。

- 二度和弦的头需要分在干的两侧；密集相邻音还要考虑数量与干向。不能为了让外框居中，把正常侧头的时间参照挪走。
- 两部同音或相邻音可能需要同拍内错列，以免看不清哪个头属于哪根干。p53一般把下部移右；交叠声部又有符干向下的声部移左的情境。与其它谱表的同步参照因此要按实际构造确认，不能机械固定“上voice的X”或整个和弦中心。
- 分离的头、全音符与另一部的干不能贴成一个错误连接。p51的变化同音尤其强调变音与所属头的对应；挤紧而丢失归属，比多占一点宽更糟。
- p50变化同音可用斜接干连接错开的头，斜段须避开所属变音；梁/旗尾又须避开斜接点。某些位置可向前错开以利用已有空白。不是看到非垂直干就自动拉直；其连接形状在说明同一个和弦的不同音。
- p52的一般双干规则与钢琴章p307的共头例外要合读。一个可见头不等于软件中只有一个逻辑音；不能用去重后的图形对象直接改写voice或实际持续。

这些规则带来一个实用诊断：若视觉上两手“不齐”，先确认正常侧头、错头、干及同拍内的部位移。只有排除这些合理结构后，才判断共同时间列是否真的错了。

## 6. 以后怎样处理同类问题

先按音乐角色与拍组定位持续参照；还原真实时点，不把可见头数量当节奏。然后分开检查列内形状、列间最低净空和有余宽时的分配。最后在整行预算内比较：保持原样、压实确有多余的局部形状、调整时间空间或改变断行。每个方案都要说明哪一层更易读、哪一层付出代价。

若复杂层已经清楚，继续增宽却只使伴奏忽宽忽窄，应优先检验更稳定的分配；若复杂符号确实接近辨识极限，应先给它空间，必要时少放小节。不能把A102的波动程度当允许阈值，也不能把极简探针的25%当全谱判错阈值。

## 2026-10-24：换干向的头距错觉与整拍预算
