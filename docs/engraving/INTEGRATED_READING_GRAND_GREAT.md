# Grand Escape／Great Days：看对节奏参照，再决定哪些线该整齐

2026-10-27，单代理整曲问题回查。A051《Grand Escape》六页35系统；A052《Great Days》六页36系统，共12页71系统。近看49处完整系统，新读Gould p437–448十二实质页、复读十四页；[证据](grand_great_closeout_evidence.json)记录87张实际阅读图、17处计量配方、202次源字符原点核查及29个梁／符干／八度图元。

**本批主要保留现有组织。** 两表交替的脉冲要沿符干轴判断；八度线的局部抬高有明确净空作用；连音省写及再现变化须读完整前后文。可比较的编辑候选是部分梁三连的范围提示，以及重复次数的更明确措辞。没有改原谱或生成新的原生替代。

## 1. M段为什么符头不等距，却仍然有秩序

A052 p6 s6 M第一小节先二分和弦，再由上、下两表交替奏八个十六分和弦，主梁／内梁把两表串成连续动作。上表四次、下表四次，各攻击为两音和弦；头看起来有近有远，不能当作同时发音的上下和弦。

源PDF核这八次攻击：符头原点的七段距离约 **6.894–17.352pt**，符干轴的七段距离约 **11.664–12.546pt**。上层向下的头在干右侧，下层向上的头在干左侧，所以以头原点量时出现明显一宽一窄；共同梁上的干轴仍保持近稳脉冲。

**保留。** 读者跟随共同梁的连续动作，同时看到每手的和弦形状。若把两表头吸成同一列，会把先后关系误作同时；若把头原点严格均分，会使干轴和连接节奏忽宽忽窄。先确定音乐中的事件和读者跟随的视觉参照，才有资格评价间距。

M第二小节为十二次两表交替十六分，再四次上表十六分，合4拍；下表最后一拍为四分休止。最后一小节低八度在第一拍，随后休止；上八度在第三拍，前有二分休止。**尾部两次攻击也不能合成一个终止和弦。** 共同梁、休止及干向分别交代连续脉冲、退出和手的先后。[跨表](CROSS_STAFF_STUDY.md)、[间距](SPACING_DECISIONS.md)

## 2. 八度线抬高：范围不变，局部空间有变化

A051 p1 s1在第五小节前，把八度虚线从约y208.52pt抬到y193.81pt，避开高音与上方重音；p3 s4二分八度和marcato上方再有相同的竖折。A052 p5 s2则以一段斜虚线抬到较高水平，给长弧、重音及延长留空间。这些都是接着往右的范围线，不能当成结束钩或又升高一个八度。

Gould p29给出条件：有充分空间时优先保持水平，垂直受限时可以随材料避让，不能穿过其它符号。**当前保留清楚的抬高连接。** 将整条线放到最高点也可形成比较方案，但会占更多竖直空间；为统一线高而压低线，可能穿重音和弧。是否改平须看整页空间，不能从“有折线”自动报错。

八度的真实终点又须另核：A051 B前旧线确实结束，高层短双音与下方旋律改用原位加线分读；G前也结束。第二房末小节第二组六连十六分才开始8va，延续到H；H反复后I回原位。**不能为少几条加线，把范围扩到整个字母段或前一快组。** [八度](OCTAVE_READING.md)

新读的声乐p439要求歌词整行基线稳定，与八度线p29的例外不同。每一种线都有自己的读者任务，不能用“全平”或“能躲开就行”概括所有对象；详见[声乐文字](VOCAL_TEXT_READING.md)。

## 3. I段：三连省写、普通十六分与重音各有分工

A052 p5 s3 I首小节四组各三个八分，4个3全部印出；后两小节维持相同三音组并省3，下表四分和弦持续给大拍参照。三个小节内部头原点步长约 **12.744–13.104pt**，即使连续有升、还原、重升、降号，快层仍近稳。

p5 s4第一小节仍是十二个三连八分；第二小节开始改十六个普通十六分。其后重音放在重复轮廓的起点，梁主要按拍计数。p5 s5第二小节前三拍为普通十六分，最后一拍改三个三连八分，3重新出现。

**保留省写与变化处的提示。** Gould p215允许熟悉组形建立后省数字，条件是读法仍清楚；这里普通八分组三头若不按已建立的3:2读，每小节会多到6拍。到二层梁的十六分和重新出现的3，参照又改变。把省略处全部当普通音，或把后来的十六分继续套成三连，都会改计量；重音也不授权重连所有拍梁。

后来的两小节普通十六分头距约 **7.074–12.402pt**：有重复音的紧格，也有变音占位的宽格。当前保留音型及拼写；这份PDF尚不足以证明每个宽格均已最小，后续可用固定预算的同构输入分辨必要占位与余裕。不能将三连段的均匀数值直接用作十六分段的模板。

同页p5 s6快阶核为 **九个9:8十六分占2拍、五个5:4十六分占1拍、梁外普通四分占1拍**。两快组各两层梁，长slur贯穿整次上行。保9、5和普通尾音三段，不把15颗头合成一种连音。此前首轮“后面还有不同细分”的疑问在本处得到更明确计量。[节拍](RHYTHM_READING.md)、[连音](TUPLET_READING.md)

## 4. Grand Escape：同谱表的力度，按层进入

p1 s2末两小节以“4 times repeat”及起止反复线明确一个两小节块；同一上谱表上部旋律mp、连续八分背景p分别靠近各自层。A在下一系统加入下谱表旋律，mp在四分休止之后进入。**保留这些层次，不能按staff ID合并力度。** 近邻和干向帮助读者把相同时间的两个说明归到各自材料。

文字可以比较改成明确“四遍共奏”的措辞，避免读者理解成首遍外再重复四次；当前保留原指示及次数，实际播放展开仍需编辑数据核对。不能删掉文字后只留一次普通反复。

B的高层短音与中低旋律、C的r.h.括线、E之后的l.h.区段、H下表旋律中r.h.接管的单音，都表明手、声部与谱表各有角色。H上表连续八分第三小节有两处八分休止，恰与下部的手提示配合；不能为让八分轮廓更满而补音或删休止。F的长值旋律、内层短型及慢持续同样分读。[钢琴织体](PIANO_TEXTURE_STUDY.md)、[标记](DYNAMICS_ARTICULATION.md)

## 6. 字体输入和后续使用

源PDF音乐子集名称显示A051主要为 **Pavane**，A052主要为 **Chaconne**。因此本批量距和线形先在各自作品内比较，不把两份成品的观感差异都归给字体或布局。本线没有提取字体、改字体或联系字体任务。

后续自主审谱时，先辨事件是同时还是交替，再选头／干／共同列参照；先辨线的功能和范围，再决定是否拉齐；先追前文建立的连音与路线，再判断省略。优先比较阅读作用明确的部分梁短括号、重复措辞和固定预算的间距候选，不复制官谱坐标。
