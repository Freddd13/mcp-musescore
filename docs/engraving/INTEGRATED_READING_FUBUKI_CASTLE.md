# 《吹雪》与《无限城》：连续运动、慢线与小节续接

2026-10-27，单代理整曲问题回查。A046《Fubuki》7页40系统；A048文件名为“Entrance to Infinity Castle”，谱面题名为 **To the Infinity Castle**，7页41系统。完整看14页81系统，近看56处系统及4处范围放大；复读13页规范，新读Gould印刷p413–424／PDF433–444十二页。定位用PDF页、系统和行内小节，不补造全曲小节号。[本批证据](fubuki_castle_closeout_evidence.json)保存来源哈希、99张阅读图的本地定位、计量及源图元核查。

## 1. 先作判断

两首都把连续快音写成可辨认的短组，并让慢旋律、持续及手的提示各司其职，主要组织应保留。《吹雪》K的十六分音内部近稳定，换小节所需的占位集中在边界；这比拿整行所有头距求一个平均更符合实际阅读。

优先列两种改进候选：**《吹雪》跨页拆小节的落点**，以及**只覆盖共同梁一部分的三连标记范围**。前者影响连续跟读，后者影响计数。两项目前是有依据的编辑建议，未生成原生替代或宣布采用；用户原谱和官谱均保持只读。

## 2. 《吹雪》：稳定脉冲与分行预算一起看

### K的三小节可以怎样用来判断间距

p6 s3上表有48个普通十六分音，按拍分成四音梁组；下表同时维持二分和弦及“八分＋附点四分”的两拍循环。第二、三小节下表出现升号／还原号，上表图形仍连续。

源PDF中各小节内部相邻头原点为 **8.674–9.102pt**；两次跨小节的头原点距离为 **16.812、15.534pt**。这份PDF为525×742.5pt，数值只用于本图内部比较。上表同向单头运行可采用同一种参照，不能把它与相反干向或二度位移的头距直接混算。

**保留。** 演奏者能沿稳定的十六分运动跟读，同时从小节线和下层和声变化得到分段。边界留白还要容纳小节线和必要变音；若强把这些距离也压成约9pt，就会把边界预算挤回符号或相邻拍。若出现明显的组内宽洞，才进一步比较局部占位、其它声部中间进入和整行撑满的影响。

这给未来MuseScore诊断一个更实际的目标：分别检查**同型组内部是否稳定、拍间是否清楚、边界占位是否合理、重复材料是否一致**。Gould p39–40的常规相对间距与p200／490的多层对位要合起来用。规则可以约束候选，不能凭一个全行方差选出“最好看”的版本。[间距专题](SPACING_DECISIONS.md)

### 一个4/4小节确实按3＋1拍跨页

p3 s6最后一小节，上表先两组五连三十二分，再普通“三十二分四音＋十六分两音”，最后八个普通三十二分，合3个四分单位；下表十二次十六分同样合3拍。行末没有小节线。p4 s1首先补上八个三十二分及下表四个十六分，再出现小节线：两页合成4拍，分割为 **3＋1**。

这种安排让上一行放进繁密的开头，下一行还能接后续材料，节约整行空间；代价是第四拍要在新页重新定位，长弧也需要跨页接读。Gould p489允许在少数空间条件下拆长小节，p490要求按整拍拆、提示未完小节，并明确器乐分谱不应把小节拆到两页。

**本线优先比较把这个小节留在同一页的方案。** 可先移前一个换行点，或重新分配相邻两行的容量，保住快音尺寸及段落位置。若仍需拆行，再比较明确的续接提示。加提示可以帮助定位，却不能独自消除跨页的操作代价。这里尚未核实际装订、双页显示或翻页方式，不声称已经证明某一次物理翻页无法完成。

### 同页另有2＋2拍，不能套同一个结论

p5 s1末小节为八分和弦加十二个普通三十二分，合2拍，行末无小节线。p5 s2先八个普通三十二分，再慢层“附点八分＋十六分”，补2拍。后半拍的独立快层实际为六个三十二分加一个十六分，跨表、共头和反向干使缩图很容易数错。

**同页拆行暂保留，续接提示列候选。** 它避开把密集运行塞得过紧，整拍处接续仍能计数；没有跨页操作的同等代价。可比较Gould p490所示的未完小节提示或带括号小节号，具体选哪种要与本谱整体体例一致。不能为“每行都整小节”压小字体、降低净空或另造2/4拍号。[行页专题](PAGE_FLOW_STUDY.md)

## 3. 标记的进入时间往往先于字母段号

《吹雪》D前的f、J前的pp、L前下表mp旋律及M前的f，都有明确的提前进入。p6 s5上表也在L前一小节已经由普通十六分改为六连；到L才换调号。**保留各自位置。** 读者先得到新的力度、细分或弱起，再进入有字母标识的结构段。把它们吸到同一条段首竖线上，会丢掉准备和预示。

G段上表p连续十六分与下表mp慢旋律分层，K起始小节上表整小节休止，下一小节才开始运行。长干、反向干和局部休止都有说明角色与等待的用途。不能把K后一行的快型提前复制到段首，也不能把两层力度统一为一条“居中主力度”。[钢琴织体](PIANO_TEXTURE_STUDY.md)、[标记归属](DYNAMICS_ARTICULATION.md)

八度线也随材料局部开闭：I的旧线结束后才出现下一次新线，J前先开始、下一行括号续写；p7 s1转慢型前又结束。它们减少加线且保连续读法，范围须逐次核，不按整个字母段补长。[八度专题](OCTAVE_READING.md)

## 4. 《无限城》：不同角色需要不同程度的显写

F／L的慢旋律在上表以反向干或附加干从十六分伴随层中浮出。p3 s3第一小节还出现邻二度的水平位移；这给各层留出可辨认的头与干，头不在一个x上不自动构成时序错误。Gould p57的附点归属、p307的钢琴共头、p311的辅助旋律省休止要按具体构型使用。

p3 s4第一小节慢层为二分加四个八分；快层为十六分休止加三音、四音、两音加八分休止，最后四分休止。各自合4拍。**保留快层的停止提示**：慢旋律仍在走，休止说明另一条运行在哪里退出；不能见到附加声部就批量补休止，也不能见到钢琴就全部隐藏。

p2 s6的虚线引导及M的l.h.小括线帮助识别跨表旋律和手。Gould p307说明虚线可追踪中声部，实线接头像滑奏的风险更大；M即使音符写在上表，手的提示仍有实际作用。只根据谱表猜左右手会漏掉这些组织。[跨表专题](CROSS_STAFF_STUDY.md)

H附近上表p、下表mf分别生效；p4 s3下表cantabile在第二小节最后两个八分先进入，下一小节才全面改变伴随型。E／K的八分梁4＋4与第一、第四音重音分别提供计数和语势，不能仅凭两个重音补成3＋3＋2。N的poco agitato、O的Grave未给新数字速度，保留文字层级，不擅补BPM。

### J的7、6、3不能只按梁中头数解释

p5 s1第二小节下表核为：七个7:4十六分占1拍、**梁外普通四分占1拍**、六个6:4十六分占1拍、四个普通三十二分加最后普通八分占1拍。比例分母由完整计量推得，谱上只印数字。放大与源梁端点均确认七连梁在第七音止，后一个黑头独立。

p5 s2第一小节改成：七连、普通四分、六连，然后**三个三连十六分＋普通八分**。最后四头共用主梁，3只管前三头。p6 s2《吹雪》的2/4也有类似“三连十六分＋普通八分”组。

**保留现有时值和快慢交替；对部分梁的三连数字比较短括号。** Gould p200要求用括号说明只占共同梁一部分的连音。这里短括号能减少把普通尾音也算入组的风险，代价是增加墨迹及与梁／弧的净空需求。七连与六连各自占完整梁时，无须因同一页有候选就全部补括号。初看曾把七连后的四分误当八分，已由放大和原图元纠正。[连音专题](TUPLET_READING.md)

### 末尾的空表、开口弧和震音分开读

p7 s5的2/4下表先一对四分头两音震音，共占1拍，再普通八分与八分休止。三短划与两根干分开是合法的震音结构（Gould p226–227），不能当成装饰小音或梁断开故障。

p7 s6上表八度和弦后的两条弧到休止前收尾，没有接收音头，是开放留声弧；接着四分休止、二分休止，再整小节休止，后面才有低音谱号的新sfz长和弦。**保留等待和新攻击的区分**。Gould p337允许用开口弧提示共鸣，不能用普通tie语义替它补接收音或合并起音；确切共鸣释放与踏板控制仍需本谱说明。

下表先写出八分及四个普通三十二分，再以一对附点二分头缩写3拍震音；下一小节全音头对缩写4拍，第二头才tie到后续整八度。这里有写出的脉冲、持续交替与停止后的接收，不能按每个纸面长头直接相加，也不能在省写处只播放两次攻击。[记谱细节](NOTATION_DETAILS.md)、[持续](SUSTAIN_AND_RESTS.md)

## 5. 书中弦乐后文：精确提示如何节省阅读负担

新读p413–424十二个完整图文页，其中p415／416／417／420为自然／人工泛音四张正式表，计入十二页，未重复加数。涉及弓击／敲弦位置、自然泛音、触弦位置、人工泛音、提示音、低音提琴移调、泛音滑奏与半按泛音，并读到scordatura开头。

可迁移到钢琴净书的主要认识是**提示自身有角色和范围**：p418空心菱形不能单独承担普通音头的时值区别；p420实按头与菱形触点共干，时值由实按头承担；p421发声音高提示应小型加括号，避免接到干上看似另一次演奏；p422大量提示挤坏主行时，可改辅助提示表或脚注，提示用谱号也不自动改变随后实音的有效谱号。

这些是按乐器条件成立的例子。钢琴图中共头／附加干、括号持音、临时手部引导也应先判断“演奏动作、持续、路线还是说明”，再决定字号、连接和占位。不能把菱形一律改成普通节奏头，或把所有括号都解释为可删的弱提示。p423–424又提醒：需要精确节奏时才逐个写出泛音，独特符号必须说明并明确恢复；省写是否清楚取决于读者要控制的内容。

弦乐章后文及scordatura仍未读完。当前全书查阅覆盖 **539/696页＝500实质图文＋39辅助，余157页**；这只表示已实际覆盖的范围。[教材记录](BEHIND_BARS_NOTES.md)

## 6. 如何用到后续自主净书

本批增加了三类可调用判断：稳定快层先保护组内分布，边界另分配预算；复杂纹理先辨独立层、辅助干、共头与休止作用；分行和连音候选须说明读者具体在哪里失去计数或定位。遇到新谱可先提少量有位置、有阅读收益的建议，同时保留合理排法。

后续需要原生比较的优先项为跨页拆小节、同页续接提示及部分梁的短连音括号。届时固定字体与版心，检查两手、相邻行、整页连带和完整音乐内容，再判断收益。本批没有新增MuseScore候选、播放验证、实际打印或软件适配。
