# Gurenge／Hacking to the Gate：先认重复的写法，再看间距与持续

2026-10-27，单代理整曲问题回查A053、A054各六页。完整看12页、69个双谱表行及48处系统行放大图；A053 p4末行有跳转前与Coda两个分开的系统片段，行数不等于片段数。新读Gould p449–460十二实质页，复读十五页。[证据](gurenge_hacking_closeout_evidence.json)保存图页、源字符／图元及16处局部计量核查，原件只读。

**本批保留两曲的大部分组织。** 连续细分可以稳定而不僵硬；短震音、长保持和写出的变化承担不同阅读任务。值得比较的候选是部分梁三连的短括号，以及短震音首次出现时写全的说明方案。后者改变书面组织，应与单纯美化分开。

## 1. 首拍里的悬空短线，不能误认成普通副梁

A053 p3 s3第一小节，上方先一个普通十六分和弦，接两个附点八分双音组成的两音震音，再接两个二分双音组成的震音，末尾七个7:8三十二分下降。两对震音各共同承担附点八分和二分的时长：**1/4＋3/4＋2＋1＝4个四分拍**。不能把每个端点顺次相加，也不能把开头几颗黑头全按普通三十二分读。

这里附点八分对保一条连接两干的普通梁，两条短震音线悬在两干之间。源PDF短线x约79.20–87.96pt，左右干约75.96／90.49pt，短线两端确实都离开符干；它们没有分别接成普通beam hook。后面的二分对则三条连接可附干。数字7只管随后七颗黑头，下降方向和短弧交代一次写出的变化。

Gould p225规定两音震音每个端点写整组时长；p226区分二分与其它值的连接方式，p227要求第二端点落在逻辑半程，p228又建议各对与普通材料分开。**保留本例缩写及下降的边界。** 震音让交替音域和持续块迅速可见，下降写全则把路线交给眼睛；将所有段落缩成黑条会丢掉变化，将所有震音展开则增加重复解码。

短附点对第一次出现时仍有认读成本，可比较写全一个短组或附简短说明；尚未生成原生候选，也没有由三条墨迹推定精确演奏次数。A054 p5 s7另有普通八分、四个三十二分，再接一对附点二分震音，**1/2＋1/2＋3＝4拍**，两白头及两附点各有归属。[震音](NOTATION_DETAILS.md#11-震音的省写时值与同步)

## 2. 稳定的快层，让另一层的复杂度容易定位

A053 F（p4 s1）三小节各十六个普通十六分。排除小节边界，45个相邻头原点间隔为 **9.716–9.971pt**，接近稳定。主梁按4＋4＋4＋4提供拍位，短弧多按6＋6＋4的轮廓分句；二者同时工作，不必把梁改成每条弧的长度。

下表同时有全音符背景、延迟进入的旋律和接收。第一小节运动层先附点八分休止，再一个正常字号十六分，接六个八分；最初的旗尾音与其它头大小相同，不能因独立旗尾或紧接同音tie就认作装饰音。**保留上表p sub.、下表mp和各层进入。** 全局合并力度、补满休止或统一干向，都会使读者更难分清谁在继续、谁刚进入。

A054 G的p5 s4／s5上层普通八分，分别核38／39颗书面头；只量同小节内连续八分，步长 **11.502–11.700pt**。下层有整小节保持、局部旋律、mf进入、一次还原号，仍没有把快层逐格撑成忽宽忽窄。小节边界留白另判，不能把整行所有头距混成一个方差指标。

**保留这两处的层内脉冲。** Gould p39–40讨论相对时值和同值稳定，p200又承认复杂对齐可能使另一层让步。应用时先保护活动层的节奏轮廓，再核低层真实进入和必要占位；本例给出一个正向参照，尚未证明每一格已经最小，也没有由成品推断MuseScore一定无法做到。[间距](SPACING_DECISIONS.md)、[梁干](BEAM_STEM_STUDY.md)

## 3. 局部八度、手提示与同音分头保护不同信息

A053 C（p2 s4）把下干中层旋律、上方短高音和下表持续分别写出。前两小节上方短8va只包局部高组；随后仍用原位加线，下一行又重新给短8va。下表同一音高的长保持与较短运动分头，不能因音高相同就删除一个头，或把全音符错当第二次攻击。

C后的l.h.括形、F后r.h.接管，以及H／I／J的慢层与背景各有局部范围；J新增上干提示旋律而下干八分继续，不为附加干自动补满一套休止。Gould p311给出提示旋律的条件，不能从工程voice容器数量决定要印多少休止。K的下方8vb又只包明确低区，后面的同谱表音不因同属一行而全部移低。

A054 B（p2 s1／s3）上方六连十六分后另接普通四分，随后四分休止；首小节前面还接收一个四分和弦。8va在组内才开始并延续到长尾，六连数字与八度线的范围各自读取。下部r.h.括形、斜虚线、接收及独立起音保留；虚线用于追踪跨表声部，不能改成tie，或把最近两个头直接连起来。

A054 H（p6 s2）快十六分上方运行继续，部分头同时有向下的附加干；同位置可有两个书面头／干角色。**不能按头数生成第二次起音，也不能以重叠去掉旋律提示。** 共享音与真正同时多音、先后攻击须分别识别。[织体](PIANO_TEXTURE_STUDY.md)、[跨表](CROSS_STAFF_STUDY.md)、[八度](OCTAVE_READING.md)

## 4. 延后进入、部分接收与开放留声

A054 p5 s2，G旁的fp在小节线前最后八分和弦上，延音弧把它接入G；不能把fp拖到下一小节接收头上再起一次。后面的sfz大和弦则在上层八分休止时进入，长保持延续过下一小节。p5 s3后续sfz也各有新进入，不能按整行只保一个动态。

p3 s3有部分音继续tie、另一部分改变；p6 I第二小节的长背景下仍有新运动。检查和弦须逐头找接收，不能整和弦一键并长。书写时值、手指保持与踏板共鸣又分层：p5尾部及p6末尾的开口留声弧没有接收头，旁边仍有普通完整tie，不能用一个弧线整理规则处理全部。

Gould p334允许长踏板用Ped.和释放号减少长横线的干扰；p337说明开放弧可提示持续共鸣、手持则需要足够书面长度。**当前保留两种提示。** A054 p5末释放后p6 a tempo／H是新的状态；p6 J前又有局部Ped.。没有工程和演奏证据时，不把旧踏板持续到所有后续开放弧，也不以开放弧删除附近休止。[持续](SUSTAIN_AND_RESTS.md)、[弧线](CURVES_STUDY.md)、[标记](DYNAMICS_ARTICULATION.md)

## 5. D.S.的落点，须把接收一起接回

A053 p4末行先用独立短片段结束D.S.，再留明显空白给Coda的两个小节。纸面路线是：D.S.回p3首行D的segno，读到p3 s4末的To Coda，再跳到p4末行Coda，随后进入p5 H。跳前与落点的接收弧属于路线的一部分，不能将Coda首头一律当新攻击，或顺读回原来的E段。

**保留分开的Coda落点和留白。** 其收益是回找目标显著，代价是同一横行中间有断口。若改成连续满行，必须保目标可辨、跳前状态及后续接收；无需为四小节网格填满。这里核的是纸面导航，物理翻页与原工程展开仍待核。

Gould p234–235的重复段状态提醒可支持回查，但D.S.／Coda的具体操作仍应合读[导航专题](REPEAT_NAVIGATION.md)，不能只据一般反复小节规则下结论。A053回跳前后的调号与C拍保持，局部8vb仍按自己的末端读。E后两个5:4组与G前部分梁三连也分别看范围，不从一条长弧推一个总比例。[行页](PAGE_FLOW_STUDY.md)、[连音](TUPLET_READING.md)

## 6. 本批知识怎样用

遇到类似谱面，先做三项判断：悬空短线是否在缩写重复；运动层的同值步长是否稳定；新音、接收与共鸣分别在哪里。再选间距、梁形、括号或换行候选，避免从“看起来不齐”直接改头位。

新读声乐后文p449–460保存于[声乐文字](VOCAL_TEXT_READING.md)：主／替代歌词的干向、字号、休止和弧线，发音、哼唱、说话与无声技法均须按角色解释。它提醒本线不要把小头、虚线、交叉头和括号当成固定语义；不会直接套为钢琴默认。

A054源音乐子集名为Chaconne；A053音乐子集被标为FE开头名称，本批不凭外观认定其完整字体家族。没有提取嵌入字体或联络字体任务。
