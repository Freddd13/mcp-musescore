# Aether重建：先核音乐，再判断间距是否值得改

2026-11-02。**四处重建检查4/4；在本次MuseScore行宽分配中，m30、31、33、35都先保留默认间距。** m30／31／35的连续八分已近乎均匀，m33也有足够空间容纳还原号，强行再均分没有可见收益。此前官谱的纸面重分仍是待比较方案，不能将新重建谱的结果写成官谱已经改善，或证明两种软件谁更好。

同时更正前批的一处读谱错误：**m31印出的还原号在D4上，属于音高必需；B3随小节线恢复自然，没有这个印出的还原号。** m33的E4还原仍是前小节E♯之后的确认提醒。两者都保留，但理由不同。

本批只读官谱，私下重建m29–36的八小节；参考[纸面分析](AETHER_SPACING_LAYERS.md)及[整曲阅读](INTEGRATED_READING_RUMBLING_AETHER.md)。没有出版社工程文件。重建输入、渲染、MIDI及阅读图只保存在本机研究目录，未当作原创CC0谱例发布。

## 1. 为什么先纠正音名

源第1页末系统，高音谱表下线E4的字形基线约719.143pt。m31还原号在721.092pt，与同和弦D4的头相同高度；B3头在724.990pt。完整系统图和第二套PDF字符读取均支持这个定位。

调号有四个升号，包含D♯。m31的D4需要还原号才能得到谱面音高，不能按“前小节结束后变音失效”删掉。前一小节的B♯则随小节线结束，m31的B自然无需另印一个还原号。前批把这两个变化混到一起，已更正正文、专题入口和证据；原几何测量不变。

m33的E4不同：调号本来是E自然，上一小节的E♯通常不会自动延续到下一小节。本谱仍印E还原以帮助确认，前批Gould p81–82的条件解释继续适用。

还有一个软件层面的提醒：本次显式写入的两个还原号，MusicXML都导出为`cautionary="yes"`。这并不能证明两个都是可省的提醒。必要性须结合调号、实际音高、同小节状态和声部情境判定，不能由这个标志单独决定。

## 2. 可见符头、逻辑音符和实际起音是三种数

八小节手工分层后，共有93个逻辑音符、3个休止。另按原PDF的谱位做了16/16个“谱表×小节”头数和音名核查，得到92个可见头，差别在m36的后半拍组：

- 同一C♯4符头服务于上层四分音符和内层八分音符；两个声部的干向与后续路径不同。
- 乐谱结构仍需两个音符及其各自时值，不能因为只看到一个头就合并掉一层。
- 本次原生SVG有93个Note绘制记录，共享位置也可能被多次绘制；记录数仍不能直接当作独立可见头数。
- 考虑七条同音连线的接收音，MIDI有86次起音；这又不等于92或93。

这与前批m30“PDFium文本页漏同刻和弦头”的情况不同：一个是提取不完整，一个是同头的真实声部写法。以后处理PDF，应先分清共享头、和弦头、连结持续及重奏，再讨论自动识别或改写。

## 3. 本机宿主实际排出了什么

使用既有冻结宿主，exe SHA-256为`7b4e6fbfdee1863a4801f018535fa6b2082500d9a2b851dc79579b9ace95aa25`，复用原1936文件资源集合。独立配置、Leland、谱间1.375mm、可打印宽184mm；四个目标小节保留长音、内层六八分、低部活动与持续、力度和片段内连线。原谱是Sibelius 7／Opus系列输出，字体与完整样式并不相同。

初次自动排版把m29–35拆为5＋2小节；最终为便于上下文核查，明确在m33后换行，八小节为5＋3。另一次试图用禁止换行标记保七小节，实际输出为1＋6＋1，未实现目标，作为失败探针保留。没有据此宣称七小节绝对排不下，也没有继续降低一串参数硬挤进去。

最终完整两手原生图已实看：长音连结及低部入口保留；`dim.`延伸到m32后半的`mf`前，上下力度通道仍分开。m36至m37的外出乐句弧超出片段，不在重建中伪造一个闭合终点。末线使用普通小节线，片段不冒充全曲结尾。字体、弧形、梁坡及标记距离均未复制原工程，也不作为个人审美采用稿。

## 4. 核查范围与输入探针

最终一份输入及其宿主另存后重载，共2次MusicXML读回：每次93音、3休止，按谱表、声部、音高拼写、起点、时值、附点核对；7条tie、2条片段内slur、4处tenuto保持。MIDI独立核对86次起音，最终锚点及片段末线修正前后736字节MIDI完全相同。这里未做MusicXML重新导入的往返，也未认证原作全部播放细节。

两个重建细节保留为经验：`lineStyle`须写宿主能读的枚举值，错误文本值未形成预期虚线；tenuto仅写`direction=up`仍有两处落在和弦下方，最终用明确的上方和弦锚点，经实际图核对。21次CLI中最终有效7次、前置／失败探针14次；最终条件1/1、保存重载1/1，未新增局部美化版。

重载不是逐字节同图：402个元素中86个的序列化属性有微差，最大0.01 SVG单位，约0.000513sp；元素类型、路径命令结构和音乐记录均保持。可打印宽由输入7.244094488…英寸保存为7.24409，观察到参数精度变化；不能把这张图报作精确相同或宣称已定位所有微差成因。
