# 第一叙事曲续读：按每拍的节奏负担分配空间

2026-11-02。**空间分配先查每拍最复杂的节奏，旋律身份另由声部、干向和标记维护。** 两者需要一起判断。R07的连续运动在上下谱表之间换层，为这个判断提供了实际对照；速度变化本身也不要求把同值音的间距改宽或改窄。

随后完整复读Gould印刷p40、43、490三页，沿用已核的物理页＋20映射。教材覆盖仍696/696，没有新增首次页数。所有参考输入只读；本机渲染环境超时后改用一张反复覆盖的阅读图，未堆积每格裁图。

## 1. 上下换层的连续运动：先认节奏负担，再评整齐

**350秒（格71）：保留上部连续音型与低部离散进入的分层。** 上谱表有连续连梁音，低部以较疏的音、休止和和弦进入。读者要跟住上方运动，再认下面何时加入；不能为了让低部看起来等距，扰乱快层的组形。

**400秒（格81）：保留下部连续伴奏与上方较长旋律／和弦的分层。** 这次快层在下谱表。上部的保持、再次起音、休止和较大跳进仍需清楚，但横向预算不能只按旋律的音符数量安排。两处都不能从显示谱表直接认定左右手，更不能固定“右手优先”或“左手伴奏永远优先”。

Gould p490在多部总谱的讨论中，把这个取舍落实到**每一拍**：优先让最密的节奏容易读，其它层按时间对应，必要时再局部缓解另一层最大的失衡。本例将这一方法用于钢琴的独立层，比“选一个主要跟读层”更具体；旋律可能最重要，较复杂的伴奏仍可能决定这一拍需要多少空间。同一拍内谁的读法更复杂，也不只由整小节音头总数决定。

今后审MuseScore间距，按拍找重复细分、真实同时点和插入点；先确定候选能否让复杂读法稳定，再检查另一层的轮廓、符号净空和共同起音。调整后仍可留下有理由的不均匀，不能把“有另一层”当作所有鼓包都合理的解释。本缩图没有足够精度评价毫米步长或引擎成因，下一步应在清晰输入上做固定预算的原生对照。

## 2. 速度改变，先保生效点与时值轮廓

**200秒（格41）的Meno mosso留在系统中部；460秒（格93）的Meno mosso在行首；500秒（格101）的Presto con fuoco也在行首。** 三个入口各有前后音乐条件，不能从其中一处抽出统一换行模板。

前一处在长音／休止及和声收束后进入新伴奏，保留同一系统有利于看清连接；后两处从新的视窗行首清楚建立材料。预览只证明这些水平关系，不能证明原PDF的分页或翻页策略。

Gould p40的条件适用于间距判断：同一系统的同类时值应保持稳定的空间读法，速度变化也不自动改变它；相邻系统可以因容量和符号负担而改变步长。因此，不能用“这里变快了”替一段同值音突然挤紧辩护，也不应为新慢速凭空拉出一块宽缝。先核符号、时位和整行预算，再判断有无可改善的失衡。长短值也不按毫秒或时长比例机械分配面积。

## 3. 变音与换号：把必要空间用在真正需要处

R07各段有明显不同的变音、音域和换号负担；仅因都有连续音型，就要求它们具有相同像素步长，比较条件不成立。Gould p43同时给出两个方向：空间允许时尽量让单个新增变音不打乱节奏；密集多变音需要额外空间时，均衡符号之间的可见分布可能比硬保相等符头距更好。

这要求对用户关心的MuseScore鼓包逐处找原因：先核变音是否已有可用前缀空间、换号两侧是否过松、共同时间列有没有错；再看额外宽度是否值得在相邻间隔分担。不能在未核字形净空前把全部变音都贴紧，也不能看到一个升号就预设整组必须按最大间距拉宽。

这是规范与当前段落条件的结合，没有从低分辨率预览反推出原编辑的手调值，也没有证明现有每处间距都最优。既有[间距取舍](SPACING_DECISIONS.md)和[实曲间距迁移](SPACING_TRANSFER.md)继续提供几何及原生候选方法。

## 4. 收束时各层的状态仍需分读

**535／550秒（格108／111）：保长音阶、后续和弦／休止及最后保持的先后。** 快速线条占据很大的横向范围；到最终视窗，上方活动已经结束，下方终止和弦仍有保持，延长记号各有承载。上表出现休止，不能直接判钢琴全体停止；图面上一片较空，也不能把这一终止阶段压掉。

这一读法沿用[速度、延长与断开](METRE_TEMPO_READING.md)及[持续与休止](SUSTAIN_AND_RESTS.md)的分层方法。细小连音、跨小节梁的精确界线和最后所有时值仍不由缩图补全，未生成重分梁或改时值提议。长音阶的外形可以提示运行方向，其成员和时位需要更清楚的谱面才能改动。
