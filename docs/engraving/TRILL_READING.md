## 1. 为什么好排法先让人知道“什么在动，动到哪里”

tr字样回答动作是什么，波线交代持续范围，tie交代后续音是否重新起音；辅助音提示回答在主音之外交替哪个音，小装饰组则可能交代开头或收尾。它们看似都在长音附近，却不承担同一个任务。把几个符号统一高度、删掉一条线或换成同样细的字体，不能替代这些信息。

Gould p134–135允许较大音程的交替用trill或两音震音表示，但提醒同类连续材料宜采用一致语法；trill与两音震音的起始音突出程度、传统联想也不完全相同。因此不能为了字形统一，自动把tr全部换成三划震音，也不能由波线长短推算唯一重复次数。两种记法的选用属于编辑／奏法判断，几何整理另做。

| 情境 | 推荐判断与阅读理由 | 代价与例外 |
| --- | --- | --- |
| 单个时值的颤音，p136 | 仅tr可能足够，波线可选；不要为了“完整”给每个短音补长线 | 多音持续、确切截止或复杂邻层需要更明确范围，不能推广为所有波线可删 |
| 跨同音tie的连续颤音，p136–137 | 波线覆盖完整持续，tie保护不重新起音；两个信息都检查 | 为减黑把波线缩到最后一个音头，会像在那里停止；只留波线也不能替代tie |
| 主音继续保持但颤音提前停止，p136–137 | 书中用拆分时值、保留tie来标出准确转换；必要时截线钩澄清“先停止，后进入下一音” | 这是读法说明，不能仅拖末端制造没有清晰时间锚点的新奏法；拆时值属记法提议 |
| 每个音重新起颤，p137 | 分别用tr，通常不以tie连接；读者不必从一条长线猜重启 | 历史版本可能有不同语法。看见重复tr不能直接合成一条连续线、补tie或删除“重复字样” |
| 只有一层颤动，p135–136 | 将符干和标记归属做清楚；双干下层可将tr放在谱表下方 | 净书诊断先说明歧义，重分voice／干向不能混进自动美化；单人双颤与第三层另判 |

这解释了一种出版观感：不是符号最少，而是读者不用逐项猜测动作、持续与归属；有用的空白也不应被当作可回收的浪费。

## 2. 辅助音、起音与收尾小音不能混同

p138中，tr附近单独的升降号修饰通常的上方相邻辅助音，**不等于修改主音本身**。可放tr之后或上方，分别节省竖向或横向空间；选择要看实际拥挤方向，不规定所有升降号同一X。没有辅助音提示时，书中采用按调号解释上方相邻音的惯例；这不是对所有历史风格的起音、速度及收尾作决定。

p138–139进一步区别三类信息：

- 起音或收尾可用grace组说明，slur指向前／后主音或包住整段，表达的连接不同；不要只为弧尾整齐改变归属。
- 非惯常辅助音可用主音之后、括号中的小音头写出，不能直接当成要依次弹过的grace。尤其同字母不同变音的交替，需要写明音高，不能只凭tr上的升降号猜成主音升降。
- 辅助音在连续tr中不变时，跨小节／系统通常不必重复；改变时必须提示。短的第一个系连音若已很挤，可把说明放在稍后的系连音旁，减少不必要的首拍横向膨胀；同时核tie不能穿过提示头。

所以“把首拍撑宽”有时能通过更合理的说明位置改善，未必需要强挤符号或改节奏比例；但不能只凭小头大小决定它不占时间、可删除或可挪到另一拍。PDF不足以提供工程对象身份，实际修改还须核结构。

## 3. 官谱的具体选择与规范建议并不总相同

**A021《Bloody Stream》p1第一系统末：上部颤音与中层取音并存。** tr贴在上部较长音的起点附近，波线短收；下面还有l.h.、mf及独立短音。将tr拉到整行末或搬到中层文字通道，会模糊哪一层在动。其清楚主要来自干向、起点和分开的通道，字体只决定tr／波纹的具体轮廓。这里只读图面，没有该谱工程，不反推内部voice编号或精确的宿主锚点。

**A043《Extra Magic Hour》p6末系统：颤音不是整段运行的装饰背景。** tr波线在长音段收住，后面转入明确写出的快速音，途中再有8va，L处a tempo另起新的状态。即使同属自由引入，也不能把波线延长覆盖整串运行，或为减少多种线而将8va、slur与波线对齐到同一终点。各线不同长度让读者知道动作何时交接。

**A092《My Dearest》p5 I及下一系统：续行可依靠邻层与tie解释。** I的长保持／颤动与另一层伴奏分开，之后颤动材料换到较低区域；下一系统首处只续波线，没有再印tr，可见tie帮助读者追踪。Gould p137更推荐新行用括起的tr提醒，或让波线先于tr；只续波线是书中承认但认为较不清楚的方案。官谱采用了后一类实践，不能因此一律判错，也不能把“官谱这样”升级为永不需要续行提醒。

在密集、跨页或多层易混的位置，括起的续行提醒值得作候选；如果本来很容易跟踪，新增字样也增加黑度和空间。**重复动作提示与重奏指示的区别，不能仅按字串相同判断。** 本页星号装饰组的拍上脚注仍只约束其所指组，不扩大到全页所有tr起音和收尾。I的和弦上单一tr等细节还需完整奏法语境，本轮未擅自判双颤成员或补两个tr。

**A015《Attack on Titan (Main Theme)》p3末至p4首：背景连续感不证明同一条逻辑颤音。** 各处tr与长音、下层自由运行形成反复出现的背景；不能因为波线在行尾接近边界，就断言全是一个跨页持续对象。可见音高／新起点、tie与是否重奏必须分别核。旧逐谱笔记的“tr延续”描述这一段的织体延续，不可据此自动合线或删重复tr。本轮没有重建其演奏或内部连接。

## 5. 后续怎样用在净书诊断

先查主音、辅助音、起止／收尾、连续／重奏和所属层，再查波线、tie、grace与普通音符是否共同说明这些任务。疑点要具体说成“波线看似提前结束”“辅助音提示像先弹的小音”或“续行难认所属层”，不笼统报波纹太长／线太多。

当前可先比较局部避让、说明位置与条件性续行提醒。合并Trill、增删tie、改变起音／辅助音、拆时值或写出震音都另列记法提议。软件侧将来至少要分别读到逻辑范围、各系统绘制段、tie连接及辅助音身份；本次只保存需求与反例，不开发接口。

格式参考也要分类：[MusicXML trill-mark](https://www.w3.org/2021/06/musicxml40/musicxml-reference/elements/trill-mark/)表示tr字样；[wavy-line](https://www.w3.org/2021/06/musicxml40/musicxml-reference/elements/wavy-line/)另有start／stop／continue及编号来表示延伸。这不证明任一宿主完整往返它们，本轮没有做导回测试。交换格式、字形外观、演奏实践与可见范围的保护各有证据，不能互相替代。
