## 先学什么、怎样避免收集代替理解

优先补Kokecola前后图：在同一片段分辨哪些差异来自梁、变音列、间距和垂直位置。若图片暂不能看，保留具体图链接与缺口，继续可读教材和本地原谱，不由文字想象图形。

随后将MOLA、MPA与Gould逐项区分适用范围；再读可追溯的B站实践。每次形成“情境—读者要看什么—怎么排—为什么—替代代价—例外”，配原生副本候选后才交用户评价。无需先购买课程、安装新软件或让用户审一整套规则。
