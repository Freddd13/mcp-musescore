# 同音异时值：何时分头，何时共头，附点属于谁

2026-10-19。接续[符号细节第9节](NOTATION_DETAILS.md#9-共头附点与分离附点是在解释声部不是数点)，复看Gould印刷p307–308完整图页，合用此前p54–60；检查《如果有来生》既有研究副本m89、99、101、103及原生第4／5页，再作原创原生对照。[证据](unison_dots_evidence.json)记录实际输入、图与检查范围。用户原PDF／MSCZ本轮未重新打开或修改，私人乐谱与教材图不入Git。

## 1. 同一个键，可以承担两个音乐角色

钢琴同拍新奏出的同音，可以由一次实际击键兼任保持线和伴奏动作。两条逻辑音符可以各有时值；一个可见头也可能承担两条干的连接。不能按可见头、工程音符或MIDI事件的数量互相推导。

Gould p307允许在已建立的键盘反复型里，共用不同时值的音头，包括带点／不带点、二分头兼作梁组起点。它减少重复图形和局部占宽，让已熟悉的动作继续流动。p308紧接着建议：**孤立的一次同音交会，两个头更能说明声部写法。** 这是两种读者任务，不能只摘“可以共头”或“必须分头”其中一条。

判断顺序是：哪条线继续、哪条线另行运动，哪个时值须保持，当前是否已有可辨的反复模式，干和梁能否分别说明各部。共头若使读者反推附点究竟延长哪一部，应优先保留分头；分头若重复展示一套已经明确的动作，则可以提出局部共头备选。两种选择都可能合规，共头不自动比原版好。

### 一次真实的误判风险

最初只按MusicXML `<note>`上的`print-object`筛选，会把这四对都列成“两个可见头”；m99／101／103实际导出的是`<notehead>none</notehead>`，与原生Note的`visible=0`相符，梁和干仍然可见。**音符存在、音头可见、音符是否播放，是三个状态。** 初筛只能找候选，不能独自报告重叠错误。

这也说明为什么外观任务应保留原生未改字段。上述`play=0`不是“无用音符”的标记；不能通过删除声音角色、重置隐藏或格式往返来清理版面。MusicXML补充读取可见关系，原生字段和实际渲染仍需核对。

## 3. 原创四小节：比较选择性共头与全部共头

独立创作的双谱表3/4练习，不含用户或官谱摘录，CC0。上表两voice，下表一voice。固定Leland／Leland Text、spatium 1.57mm、A4与7.08772英寸版心，四小节一系统：

- m1上部附点四分C5，对下部普通四分C5后继续B4／A4，测试不在梁组里的孤立交会。
- m2／3上部附点四分后继续，下部各有六个八分；两小节建立相同的梁组动作，测试较有条件的共头。

### 当前宿主的一个重要细节

`headType=quarter`画出的仍是正常黑头，却不等于没有保存这项覆盖。只读`layout.cpp`约410–433行可见：在其它条件满足时，显式匹配的类型或恰好一头隐藏，可以强制共头；默认自动类型对不同附点／头型等采取较保守处理。原生对照验证了这项行为，未修改软件。

因此“清理与默认等价的显式值”也可能改变排版。以后读取工程，应保留AUTO与显式值的区别；不能只保存最终字形名称，也不能把共头当作删除某条voice。源码与宿主分别记录哈希，没有证明本机二进制精确对应某源码提交。

## 4. 验证到哪一层

三版原生XML除上述`headType`节点外完全相同。31个事件的音高拼写、起点、实际与书写时值、附点、谱表及voice均与当前MusicXML导出对应；下表单声部的voice标签1→5单独核对。MusicXML另增加预期的显式`notehead normal`及filled属性，只在指定首音检查并归一化，其余非布局内容相同；没有过滤所有notehead后冒称无差异。

三版MIDI文件逐字节相同。这证明此次显示方式没有改变该练习的MIDI输出，**不证明三版读起来同样明确**，也不是用户实曲所有播放属性的往返测试。

SVG三版都有31条Note绘制元素、8条NoteDot，但重合后独立墨迹位置分别为31／29／27；不能按SVG元素数判定没有共头。选择性版保存重载后，两个显式覆盖、事件、完整SVG和PNG保持一致。均为1页1系统；未做一般碰撞、打印、试奏或独立审美评测。

## 5. 怎样用于后续自主净书

遇到同拍同音，先识别是否同一实际起音的多重音乐角色，再看各自时值、梁／干／tie、隐藏和播放状态。保留已有可读的角色配合。只有在重复模式、归属和持续都清楚时，才考虑共头；孤立或易歧义处可保留分头。随后检查附点和加线，而不是先让所有同音共用一个坐标。

本次能支持按情境提出显示候选和保护现有设置；后续[二度归属专题](SECONDS_OWNERSHIP.md)已补单音双部交叠／单部带点候选及变化同音自动样张。多音密集二度和弦、不同大小字头、变化同音的连接替代与所有跨表情况仍须另核，不能从本次31音练习推广；也不在本次实现MCP／插件／本体适配。
