# Adabana Necromancy：音区状态、持音留白与整曲行页

2026-10-23。A009《Adabana Necromancy — Zombie Land Saga — Opening Theme》全曲复读，实际查看 **7/7 张完整原页图、9 张必要局部图**，再核既有专题。旧批次近读p3–4，后续p1–2已有音区定向阅读；本轮不是新增7页首次阅读，也不是逐音校对。来源、图哈希和范围见[证据](adabana_reading_evidence.json)。原件未改，无原生替代版、试听、打印或用户审美选择。

本文的p指PDF页序；本谱印刷页码恰好也是1–7，但它们都不单独证明实际装订的左／右页。系统自上而下编号。阅读收益是本线根据图面和规范作的解释，不是出版者亲述的编辑意图。

PDF矢量给出了一个稳定的物理骨架：页面约210×297mm，五线高度约5.97–6.01mm，横线宽约184.6mm；同一大谱表上下两表的首线距离约18.0mm。p2–6相邻系统上表首线相距约44.2–44.3mm，p7五个系统则约55.4mm。p1有题名区，谱面从更低处开始。测量取线中心，不是已知MuseScore样式值，也不代表用户打印一定按100%缩放。

**阅读收益是参照稳定、内容可以变化。** 行首、表距与上下手的相对位置容易重新找到；每行仍能容纳不同数量和复杂度的材料。比如p4 H所在第4系统仅3个完整小节，p6各系统可见5小节的组织，p7又有拆行。不能将出版观感归纳成四小节一行、全页小节线对齐或所有符头等距。p7较大的空间主要是系统之间的外部留白，不是把每个大谱表内部的两表一并拉开。

这种稳定骨架也不是无条件优越。特别高低的加线、跨表动作、长弧或文字需要另核局部通道；从成品看出大体规则，不等于知道作者是设了固定参数、逐行调整，还是使用其它布局方法。

## 2. 八度不是消除加线的全局开关

### F至G：先保存音乐状态，再处理续行

p3第4系统末小节F，在上谱表先有休止，随后才开始8va旋律；下谱表的运行并未因此一并获得上方8va。p3第5、6系统及p4第1、2系统，行首均有括号续示。跨行的收益是无需为每行重新宣告一次新的音区动作，也不必从新页回翻寻找最初起点。

旧[行页专题](PAGE_FLOW_STUDY.md)所说“在G之前结束”方向正确，但不足以用于自动操作：**p4第2系统的8va实际止于第3小节首和弦之后；其后的休止和上行材料已经在范围外，G在下一小节。** 不能把终点吸到G、小节末或行末来制造整齐。终止前后图面音高也不能直接相减当作真实跳进，必须先应用各自的八度状态。

Gould p29–31区分整行持续、跨行续示、最后作用音及短休止：持续线跨行到小节线，续行重新提示；真正结束时，通常在最后音头／时值点后结束，而非一直画到该音实际释放时刻。短休止可以处在同一八度范围内，长间隔则可能值得重新标示。p324–325又要求分清谱表范围及同表原位层。本例支持的是这些条件，不能由PDF反推软件只有一个跨度对象或其内部voice。

**当前保留：** F后的连续状态、各行提醒，以及p4真实结束边界。若制作候选，只能先改续段的高度／避让并读回全部作用音；修改音区或作用谱表属于记法方案，须另核实际音乐。

### 同页保留加线与局部8va，有两种不同成本

p1–2既有较高和弦的实际谱位，也有运行末端的短8va；p4 H后的连续材料中，一些高处运行保留多条加线，另一些峰部用短8va。可见出版者没有用统一的“超过几条加线就转换”阈值。

Gould p324的理由是：偶发极端音保留实际谱位有助于看轮廓和键盘距离，持续高区用八度标记则减少加线负担，并尽量保持一个完整材料处于同一转置状态。减少加线会换来状态切换，减少切换又可能增加高处的认读负担。p4这些片段不是已经校成音高完全相同的一组对照，不能据其外观宣布其中一种天然更好。

**候选成本：** 若将短8va扩大为整段，会改变图面轮廓与进入／退出位置；若全部写回实际高度，会增加加线和外部空间。应先确认完整音型、同时层与相邻谱号，再比较少量原生版。本轮没有证明需要统一这些选择，也没有发现MuseScore在此场景的可复现缺陷。

### 低处的短线不是持音计时器

p3第3系统及p7第3、5系统可见低谱表下方、作用于少量低音的8va标记；某些终止角紧接单个音头，而该音本身是长值。下方位置给出向下八度的读法，短线减少极低加线，终止角又避免将后续材料误纳入。

这与Gould p30–31关于单音和普通长音八度线的说明相容：**线短不等于音短，也不表示踏板在那一点释放。** 它标出的是哪些音按八度读，不是延音动作的长度。若后续要改变这类符号，必须核实际音高、作用谱表和范围，不能仅量虚线长度；也不能将同一表中原位持续层默认纳入，见[八度阅读](OCTAVE_READING.md)及[ninelie反例](INTEGRATED_READING_NINELIE.md)。

## 3. 持音与留白：少攻击不等于少任务

### 开头：另一层在长值之内运动

p1第1系统第4小节，上谱表延接全音符和弦，下谱表同时有运行；第2系统首小节，上谱表整小节休止，下谱表仍有一个全音符，并承接前一系统的线条。随后上谱表又在较晚处进入。

长值／休止使重复攻击减少，让读者看见保持与再进入；另一层的运行仍需相应横向空间。把看似空的上谱表压得很窄，会挤到实际在读的下部；把上表休止直接判成可翻页，又漏掉下部仍需保持的音。图面并没有提供用踏板代替手指的完整指示，不能替作者补一个释放方案。

p2 D之前、p3 E及p5 I也反复出现保持层与继续发音层的组合。p6 J则更直接：上谱表的独立干向把较慢旋律与重复和弦分开，后者提供容易追踪的连续脉冲。这里的黑度、横距和空白应在整个大谱表里判断，不能逐表各做一次均匀化。

### p6的延长与K前：停顿有形状，但不自动提供空手

p6第3系统末段，先有跨小节tie的和弦与另一层运行，再进入带fermata的长音。上方8va仍覆盖到该处的高音；下一小节上谱表先半小节休止、后出现二分值，下谱表却以tie继续保持长音。第4系统首又有两表的二分值，随后K的连续八分运动展开。

这一段从密集攻击转为等待，再回到持续运动，空白帮助识别这种状态变化；不能为降低整页密度方差把停顿填满，或把所有长值一律拆成重复攻击。反过来，也不能把它直接当作理想翻页口：按曲首四分=171，两拍的普通时长约0.70秒，一整4/4小节约1.40秒；fermata持续时间又不能用这个速度精确换算。下方仍有保持任务，是否能由某只手／踏板承接、是否有翻谱人，PDF没有交代。

这里还有一个不应掩盖的体例差别：p6首个fermata和弦上方的8va终止角靠近该小节末，晚于全音符音头；这不完全符合Gould p30通常紧接最后音头／时值点结束的推荐。下一次上部攻击又在下一小节的休止之后，当前没有由此看见多覆盖一个攻击的证据。故记录为可比较的线长选择，不因喜欢官谱就把它当规范，也不把它解释成精确释放指令；若收短，仍要检查fermata、句弧和下一音的归属。

**当前保留：** 音头、tie、休止、延长、恢复运动的不同提示。未来若需要纸谱翻页候选，应先确定使用条件，再评估能否在较早处准备；不从“白”直接得出“手空”。

## 4. p7拆行：值得学的是权衡，不能直接学成常规

p7第1系统的末小节没有行尾小节线。局部高分辨率复核可见：下部只有四个八分，即两拍；第2系统开头再接四个八分，随后才出现该小节结束线。上部快层与慢层也相应接续。因此这是一个4/4小节在两拍后拆行，**不是漏印一个2/4，也不是新行自动重开一个短小节。** 前两行各约容纳4.5小节，而不是按垂直线条数各统计成相同的完整小节数。

这种选择让两拍音型在完整拍之间续接，行宽预算可以利用半小节；代价是换行后仍须继续数同一小节，变音状态和导航也不能重新开始。当前图面没有采用Gould所示的全部分谱续接提示，不能凭没有小节线就认为所有读者都能立即恢复。

复看Gould p489–490：书中将拆小节限于整小节长到放不进一行，或三小节更适合分成两行各一小节半的例外；还要求在完整拍之间拆、行尾不画小节线，并讨论续接斜线／括号小节号。**本例的九小节分两行不同于书中三小节分两行的情境；PDF也未证明这个小节长到整行都容不下。** 因此可以记录成真实出版选择及其空间收益／计数代价，不能将它认证为满足该书全部条件，或默认用户喜欢经常拆小节。类似对照见[Akuma no Ko](INTEGRATED_READING_AKUMA.md#4-行中入口和寻行要同时看到过渡与下一步)。

后续有必要时，可比较完整小节的4＋5／5＋4安排和现排法的行内节奏、两手对齐及续读成本。那需要相同输入和字体的完整两行候选，本轮没有渲染替代版，也不能断言完整小节版本一定更好。工程若实现拆行，应保护一个逻辑4/4小节及其变音／计数状态，不把视觉两段存成两个普通短小节。当前MuseScore的具体实现能力尚未在本例验证。

## 5. 页面边界不等于演奏者已经能翻页

先确定媒介。若第一音乐页实际在右页，常见双面对开可同时看到p2／3、p4／5、p6／7，翻动发生于p1→2、p3→4、p5→6；若用另一种两页配对、单页屏幕、散页或卷动，需重新判断。PDF的印刷数字1在左下角，并不能决定它在某本装订中的物理左右。以下覆盖全部 **6/6 相邻页界**，只证明可见条件。

| 页界 | 页尾／页首的实际任务 | 当前判断与候选代价 |
| --- | --- | --- |
| p1→2 | 两表的伴奏／旋律仍在发音，p2立即继续相关材料 | 未见页末整组同时休止；不能用本页较早上表整休止代替这里的窗口。提前翻需要记忆或另一种展示安排 |
| p2→3 | 上部和弦tie跨页接收，下部运动继续 | tie表明保持／接收，不提供自动空手；须同时能读到新页的下一次攻击 |
| p3→4 | 上部8va继续，低部末尾仍有快速音，p4立刻进入三连型 | 续示解决音区记忆，未解决手翻谱；这是复杂材料中间的边界，不能因换页而重置八度 |
| p4→5 | 页尾和弦tie接到p5，上行／下行运行仍属连续段落 | 需要保护接收和运动的连续性；若成为实际翻页，应比较更早的窗口／对开预算，而不是只移动一条弧 |
| p5→6 | 页尾两层仍有攻击，p6接相关和弦／伴奏，J稍后在行中开始 | J不是该页开头，不能用结构字母替页界辩护；改变页界可能联动此前I后的材料和行宽 |
| p6→7 | 上方长句及下方快速分解持续到页界，新页两表立刻继续 | 本页较早fermata不是当前页界的证据；若提前翻到那里，需能同时读后面仍在本页的系统，不能忽略这一段距离 |

Gould p559–562要求围绕真实可用时间组织对开，允许为了演奏留下较大空白，也提出无休止时的其它展示安排；p561还特别提醒键盘复杂段中的翻页及翻谱人的判断困难。其“四秒”是某位演奏者的计算示例，不是本曲硬指标。本轮没有进行手部／踏板编排、实际翻页试奏或纸谱装订验证，故六处都未被认证为可自行翻页。

## 6. 怎样用于后续净书判断

| 触发情境 | 可直接使用的判断 | 候选前必须补的证据 |
| --- | --- | --- |
| 8va跨系统／页或在段前结束 | 先恢复全段状态，定位最后作用音，分别处理续示和终止；不吸到标签／行末 | 拟改版本的实际音高、谱表／同时层和输出范围；不能只查spanner数量 |
| 持音、休止看似空白 | 同时读另一表、tie和下一进入，区分攻击密度与保持任务 | 若用于翻页，须有真实空手／踏板或翻谱人条件及使用媒介 |
| 高音段加线很多 | 比较完整轮廓、持续长度和状态切换次数；允许保留原谱位 | 同型片段的逐音关系、少量原生候选与整体空间代价 |
| 行尾无小节线 | 检查两侧完整时值、拍号和接续，而不是补拍号／新小节线 | 逻辑小节、变音记忆、编号／跳转及导出后续接；拆行收益须与完整小节版比较 |
| 想统一每行小节数或把段首都另起行 | 先读密度和过渡；本曲A–L中多数是行中入口，H／L才是行首 | 完整前后行与页预算，不能只展示字母旁的局部 |
| 想把末页压紧以“统一密度” | 分别比较大谱表内部与系统之间的留白，保住寻行参照 | 实际字号、打印缩放、阅读距离和改后全页；当前几何值不是全谱预设 |

本轮形成的是可定位、可反驳的保留与候选理由。它扩充全曲上下文，也发现了既有粗略记录容易遗漏的拆小节和八度终点；没有新增用户审美定论，没有把官谱全部选择变成规范，更没有从出版PDF直接推出MuseScore应改哪段代码。
