# One Last Kiss／One more time：活动骨架、拍内归属与末尾留声

2026-10-29。A099《One Last Kiss》五页30系统、A100《One more time, One more chance》五页29系统全部复读，另看35处完整系统细图；随问题复读Gould印刷p40、43、72–73、185、190、200、213–215、311、315、323–324、337、487、490共17页。62张不同实际视图、276个选定实头、163个普通活动间隔及11项时值配方见[证据](kiss_chance_closeout_evidence.json)。整曲问题回查达到92/146、余54份；教材／资料覆盖保持。

判断：保留连续活动层的稳定步幅、同表主次及持音接收，优先澄清Chance H的部分梁五连范围。Kiss结尾开放弧有持续用途，不能补造接收音；Chance I之后的a tempo应联系新近Poco meno，不能机械恢复开头66。两份成品提供可迁移的读法，也保留需要进一步取得原工程的边界。

## 1. 为什么密集音列仍能板正

Kiss p3末系统，四小节上部各16个普通十六分时间列；多数列是八度，最后小节末部转单音。四音小组的首音较低并有重音，随后三音重复，主梁按四分拍组织。60个组内头原点间隔约6.894–7.092pt。读者顺着近稳的细分跟读，并在每四音识别一次重心；不能看到反复三颗高音便给它们另加三连比例。

L在p4第五系统，上层先八分休止再14个十六分，下面还有独立二分保持；之后三小节各16列。去除小节线／休止起始占位，活动间隔约7.074–7.272pt，第二、三小节约7.074–7.092pt。半音头和下部慢线没有让每个四分都变成一个新宽洞。层次首先由干向、音值及连接识别，稳定活动则让眼睛更容易预测后续。

Chance p2第五系统首小节为双音／单音交替十六分，16列间隔约10.328–10.566pt。p5第二系统第二小节也是16列八度，约14.633–14.888pt。它比前例宽很多，仍然稳定：两处所在行内容、梁形和音域预算不同。不能把“好看”缩成一个通用列宽。

E在p3第二系统中间小节，16列约9.120–13.085pt；升号前及同列下部变音需要局部空间。Gould p43主张先压实前缀自身两侧的多余空隙，p490优先照顾当拍最密活动；它们没有要求密集和弦也强塞进单音列宽。今后检查MuseScore时，应固定字体及整行预算，区分前缀必需净空、同刻头位和可重分空白，再提出候选。这里的同向头原点数值不等于完整墨迹净空，也不独自证明软件缺陷。

## 2. 切分中的接收仍然占时间

Kiss开头普通4/4、四分112，和弦反复型可按四分为1核为：

`3/4＋1/4＋1/2＋1/2＋1/4＋3/4＋1/2＋1/2＝4`。

其中有tie接收，不能把可见头都当新攻击，也不能因两次攻击相距较远便把它们均分成相同节拍。下部全音低音与上部切分属于不同角色。p1第一系统末小节，mp旋律在后半进入，伴奏仍继续；新的前景不必从下一系统才开始。

后面渐强到f的最后八分先发声，下一小节全音为接收；随后还有明确2/4：上部二分接收、下部整小节休止，各占2q。再回common进入B。这个短桥接承担保持与换段的呼吸，不能凭整休止形状补成4q，或为了规整行宽把它并入相邻小节。

N在p5第三系统，低部半休止2q、四分休止1q，最后三个三连八分共1q；mp拾起最后一拍的动作。随后相似小节继续局部三连，最终又改普通八分。Gould p215允许稳定重复中有条件省略数字，却不能让simile跨过实际改变的节奏，把后续普通八分也读成三连。

## 3. 裸5究竟管哪几音，必须看短梁

Chance p4末系统的低部，每半小节有两个不同细分：先一个普通十六分和六个普通三十二分，共1q；第二束梁的前五音是5:4三十二分，共1/2q，最后两个普通十六分再占1/2q。因此一半小节为：

`1/4＋6×1/8＋5×1/10＋2×1/4＝2`。

第二束梁的主梁、次梁包七音，短第三层只包前五音。数字5放在梁下，不能理解为整束七音或末五音；第一半重复两次组成完整4/4。上方普通十六分是另一条活动线，不能以最近头位置强配所有细分。

本轮初看曾把5猜成梁末五音；完整系统图、实头与短第三层向量将它纠正为梁首五音。Gould p200指出：连音只占完整梁的一部分时，用短括号明确范围。这里优先比较只包前五音的短括号，保留后两音、共同主梁及大拍起止；它比拆散整次琶音更直接，代价是梁下增加一层线条。复杂相邻弧线仍须在原生上下文检查，先不改官谱。

这与已完成的[部分梁短括号原生例](PARTIAL_TUPLET_BRACKETS_STUDY.md)是同一种范围判断，后者能验证宿主已有显示能力；它没有替这份实曲认证保存、声音或用户审美。

## 4. 同一行有多个力度，来自同时存在的主次

Kiss C附近的più f与随后meno f有不同落点；meno f从后半小节生效。D的fp和弦短型与后来mf八分句也不同；H再用连续十六分填充同类重音，不能因轮廓相似就去掉其中一层。E／I反复出现dim→pp→mf，是每次乐句重新展开的力度包络，不能按重复文字去重。

J强奏的8va上行还会抬高以避让高弧，下面另有8vb。两条线结束位置不同；它们的空间关系服从音域与弧形，不能强制同高、同长。p4第二系统中的mf／mp落在各小节最后两个八分的入口，保留前面的持续与后来的新活动。K的simile交代已建立的伴奏习惯，不把上方旋律全部附上同样的断奏。

Chance p2第四系统末小节，上方p背景和下方mf旋律都在第一拍之后进入；下一系统下方mp接同一前景角色。之后低部p与上方逐步减慢仍有不同起点。Gould p323要求分层力度靠近所属线：把它们拉到同一水平通道虽齐，可能让读者误把旋律也弹成伴奏的弱度。

## 5. 恢复速度可以先于旋律，也可以落在旧接收

Chance开头四分66。D在p2第五系统末小节a tempo已经从小节首生效，上部先四分休止，cantabile的12个普通十六分从q1开始，下部八分伴奏在q0。若把速度文字吸到旋律第一音，会让前一拍的伴奏继续旧的减速。

p4第三系统首小节，poco riten.从最后四个十六分、即q3开始；下一小节a tempo在q0，上方先八分休止，低部已经普通十六分运行。恢复时点应由整层时间判断，不能只追最高的黑头。

H末allarg.之后，p5首行a tempo／ff grandioso先落在上部八分tie接收，新的十六分随后进入。新速度和新层次不要求每次都伴随重新攻击。

I在p5第五系统行中建立Poco meno和pp dolciss.，随后poco riten.；下一行a tempo应回到这段新建立的较慢基本速度。图上没有I的数值BPM，不能把任何a tempo一律写成开头66。最后dim. e rit.、延长、rubato、rit.和终止又各有范围，延长不是可以当作固定倍数的额外拍。Gould p185／190用于区分渐变、状态建立与共同停顿；原工程播放仍待取得。

## 6. 附干、跨表与短八度线服务于不同读者任务

Chance B末的上方四分旋律与跨表内层十六分并存；r.h.短括形交代局部接手，谱表边界不直接等于手界。p3第一系统中间小节，上表没有写满休止，主要活动暂在下部；Gould p311允许钢琴附加旋律干及有条件省略额外休止。诊断要先识别辅助层的连续性，不能只因voice容器不足四拍就补一行休止。

H两手跨表三十二分长跑另有慢旋律、长弧和手的提示。共同梁保持动作方向，长弧绕开跨表轮廓；p315要求梁角、最短干及谱间净空一起判断。把所有梁压平或把长弧改成相同高度，可能损失走向且制造相撞。

p5第三系统的快层第一小节为两个八分＋24个普通三十二分，第二小节32个普通三十二分；上方另有附点长音。短8va仅包高处峰顶，前后并未全处在同一移位。p324说明八度线按所属谱表及端点读，不能从同一条长弧推成整行共同升八度。是否改成更连续八度标法，应另比较加线数量、键盘轮廓和状态切换成本。

## 7. 开放持续弧为什么不能自动补齐

Kiss尾声O先pp长背景，旋律在半休止后进入；最后perdendosi与ppp让活动逐渐稀疏。末和弦从上下多个白头继续开放短弧，另有旋律全音延长；有些弧有明确下一音，有些越过终止边界后没有接收。后者不能仅按“悬空线条”删除，也不能补造下一音或强接最近音头。

Gould p72区分开放持续弧、写满时值的tie及留声指令；p73／337又说明钢琴踏板可承担持续，开放弧可以额外提醒共鸣，手指保持的音应有完整长度。这里可以确认图面有继续留声的提示；没有明确踏板捕捉／释放说明时，不能自动决定哪只脚、哪一音先释放。

Chance终止则有明确的全音接收、慢内层移动及上下各自延长。视觉上同样疏，却与Kiss开放结尾不同。把它们统一改成l.v.或统一连到末音，会改变音乐读法。这个区别也延续到用户已说明的A八度选择延音：先保持续意图，再比较提醒方案，不套用另一曲的具体踏板。
