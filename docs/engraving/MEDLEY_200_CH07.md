# A005第七章：稳定的节奏骨架，与必须分清的局部范围

2026-10-31，完整回查《200 Anime Songs Medley》PDF p77–89，Romance Anime、所印Songs99–117，共13页77系统；另看p76、90衔接，放大15处。累计**7/13章、89/154页，余6章65页及全组曲衔接回查**；整份问题回查仍145/146、981/1135页。[总进度与完整计划](STATUS_AND_ROADMAP.md)／[逐章目录](corpus/READING_MEDLEY_200.md)。

**本章值得保留的是清楚的节奏骨架和精确的局部提示。** 稳定八分、独立完整连音梁、共头的持续角色、局部八度与选手括号，让复杂材料仍有可追随的线索。另有J／L速度等式，值得在确认意图后比较更明确的新旧单位标法。它的阅读歧义有规范依据，不能直接据PDF改播放速度。

下文p为PDF实际页，s为系统行，q以四分为1，从小节q0计。坐标用于追溯PDF图形，原工程voice、对象边界和播放未验证；本批没有新原生候选或软件适配。原PDF／MSCZ只读，16页教材复读不增加查阅覆盖。

## 1. 好间距既能稳住脉冲，也给真正的符号占位留空间

**p85 s2首小节，K／Sparkle：保十二个普通八分的稳定步幅和四组3。** 上部q0至5.5共十二次起音，梁分3＋3＋3＋3；和弦与单音交替并未使节奏摇摆。符头起点相邻距离约8.316–8.496pt，读者能快速把视线归到四个复合拍。下部附点四分、四分、八分、附点四分、附点四分，起于q0、1.5、2.5、3、4.5，全部落在上部已有八分位置，不必额外制造时间列。

它说明在这个音型里，稳定快层与准确对齐可以同时成立。若对每个和弦机械追加宽度，会把同一节奏写得忽松忽紧；若只看上部平均距而忽略下部，则可能在其它确有中间起音的案例中误压空间。这里保原排法，是因为材料与共同时间关系支持它。Gould p40的统一间距条件与p490的共同时间关系可互相核查。

**同一行末小节，K：保临时升号的实际空间，但不把六个头误读成六连。** 此处先附点二分3q，再六个普通十六分1.5q，最后附点四分1.5q，合12/8的6q。没有连音数字；末组双梁只是普通十六分。六头起点457.398、463.428、469.620、475.650、487.152、493.362pt，其中q3.75到q4一格约11.502pt，其它约6.012–6.210pt；升号就在较宽格内。

这处局部变宽有可见占位。若日后在用户谱遇到类似位置仍显突兀，先检查变音自身的距离和整组／整行预算，再比较分散少量空间的方案；不能把后一音单独拖回平均值，挤掉升号净空。当前PDF也不能证明MuseScore会怎样排同一段，软件弱点须另作固定字体与预算的原生复现。

**p79 s1，C接D／DADDY! DADDY! DO!：跨调号的长间隔保留。** D标题、ff和换高音号已经在前小节末八分q3.5引入；新五升调号在随后的边界。上部起音X170.352接下一小节同音X220.464，头距约50.112pt，中间有调号／边界和tie的读法。两手接续应连同上下文读。

这个间隔承担识别新调号和延续的任务，不能与一组内部相邻八分作同一种均匀度比较。把标题、力度、谱号统统吸到调号后，也会抹掉引入。诊断顺序应是先确认时间、接收和前缀占位，再评价几何余量。

## 2. 完整连音的范围靠梁和时段辨认，音头总数不够用

**p79 s6末小节，E／Grand Escape：保六连16与其后的普通四分。** 前四个八分占q0–2，接完整独立六连双梁，占q2–3，最后q3普通四分。看得到七个靠近的上部头，但第七个X534.078已在六连梁外；六连本身X494.064至527.346。下部q2.5的八分与六连第四音同位，q3再与尾四分同位，给出共同时间检查。

**p80 s4倒数第二小节，E：保四个普通16与五连16的分界。** 前半为四分、八分休止、八分和弦；q2–3是四个普通十六分，q3–4才是五个16的完整5:4组。两组各有独立双梁，数字5的范围已清楚。下一小节首个高八度是自己的q0四分，随后八分休止、八分八度与四个八分，不能把它收作五连尾音。

完整梁给组界，外面的slur给动作或分句，二者任务不同。这里保简洁的裸6／5；若是数字只管共梁中的一部分，才应另按具体范围比较短括号。Gould p199–200、203支持这种按成员与时段判断的区分。K那组六个普通16又是反例：同样六次起音，实际占1.5q；E六连占1q，读法和同步位置都不同。

## 3. 附加符干和不同头型保住持续，不能按“重复图形”去重

**p81 s4，F／God only knows Daisanmaku：保快线和共头上的持续角色。** 前一小节附点二分后四个普通16，8va仅罩这四个，到边界前结束；下一小节是十六个普通16，四组各四个双梁。末组q3的头还接上向四分干，q3.25的头另有上向附点八分；各自延到下一小节边界。运行层继续q3.5、3.75，另有自己的接收。

这让一次起音同时属于连续运动和保持层。末端三条tie接下一和弦的三个相应头，长slur另组织整段。只保快线会丢失应保持的声音；把附加干算成新起音又会破坏节奏。PDF在两处共头坐标有重复绘制，额外干、附点、旗和tie使不同持续可见，但绘制次数不能证明源工程用了几个voice容器。

**p86 s5，N／Orange（Toradora!）：保低音与上方和弦各自的时值。** 上部旋律先四分，再六个八分。下部最低音是附点二分q0–3，然后q3四分；其上三音和弦先附点四分q0–1.5，q1.5八分接q2二分接收。三和弦白头出现时，低音仍在自己的保持中。

黑／白头及不同干在告诉读者何时起音、哪些声音继续。若为了整齐，把四个音强并成一种时值，就改变了分层读法。Gould p311的双层记谱条件帮助核对这类持续；p305说明手的提示与谱表角色另判。这里的N与本章S同名Orange来自不同动画，分析和检索须保留副标题。

## 4. J／L速度等式：先标清旧、新，再谈自动解释

**p83 s4引入J：Slower、四分130已在前一小节休止处出现。** 上部先二分休止，再四分三连休止＋三连八分，以及三连四分＋三连八分，两组各占1q；实际三次起音在q8/3、3、11/3。休止也是组员，两个3不能只按三个可见头重新分组。

**p83 s5，J／secret base ~Kimi ga Kureta Mono~：12/8新小节里印“附点四分＝四分”。p85 s3，L／Todokanai Koi：回C新小节里印“四分＝附点四分”。** 两个等式均整段放在新小节内。若按传统的“左为新单位、右为旧单位”，J可读为新附点四分130，L再回新四分130，保持相邻主拍的连贯性；这是有上下文支持的候选解释，原作者意图和播放尚未核实。

Gould p185明确指出传统与现代速度比例体例方向不同，建议把等号置于变化边界、使两侧单位明确归属。故本例值得比较更明确的标法：J写“旧四分＝新附点四分”，L写“旧附点四分＝新四分”，或在确认意图后给新速度数字。新旧标签是本研究的说明方案，非要求所有出版谱都写中文标签。

这项改进减少首次阅读时临时猜体例的负担，又保留比例关系。它需要确认音乐意图后在副本比较；现在不直接倒转等式、补写BPM或指定播放。详见[速度专题的两种体例](METRE_TEMPO_READING.md)。

## 5. 八度、先行引入和选手提示为何必须精确到局部

**p77，A／Kawaki wo Ameku：保短8va与低八度的实际端点。** s1末小节上部8va只罩q2.5的一个八分和弦；q3八分休止，q3.5末八分已在范围外。s2下部8vb罩前两小节及第三小节q0四分，到q1第一个八分和弦前结束。若按整梁或整小节扩展，就会改错音区；若仅凭一处高音推断全段loco，也会丢失前段关系。

F的8va也只罩前小节最后四个16，下一小节首音已恢复；高处外观相近，八度线边界仍不同。Gould p324–325帮助按作用谱表、实际终点与音区轮廓检查，不能把短线当装饰或自动延满一行。

**p89 s2，Q接R／Ref:rain：保引入时点。** 旧8va从前小节延至引入小节q0四分八度，随后q1休止之前结束。Slower、四分74位于休止引入处，R标题在后；pp则从q1.5两个16开始。下部原whole继续保持，不能为了“标题对齐”把速度、力度和八度结束吸到同一X。分清三种生效时点，读者才知道怎样进入下一段。

**p89 s6末小节，S／Orange（Your Lie in April）：r.h.只选最后一个八分q3.5。** 下部普通八分共八个，q2换高音号，但r.h.括号两端只界定末音，不能自动把换号后的四个音都交右手。上部whole承接前八分并有延长，下部末动作也有自己的延长承载。保持与运行的角色不同，不能强行把延长号全吸到一个起点。下一章p90另起三降调、C与四分120，本批只作为接续上下文。

## 6. 反复房子服务实际来路，开放线尾不代替范围核查

**p88，P／Sakura Kiss：保共同三小节、第一房子两小节、第二房子一小节。** 反复起点在s1，房子在s2；第一房子闭合，第二房子开放，随后还有tie接到下一小节二分和弦。读者须分开首次进入、反复返回和第二次出口的路径，逐条核对接收与力度。

开放第二房子不表示后续全部持续都属于房子，也不能把第一房子结尾线性接到第二房子。Gould p235–236的结尾与反复条件可用于检查两条路线；播放展开仍须源工程另验。这里的紧凑布局靠清楚路线成立，省去一个括端不等于省去对实际路径的理解。
