## 2. 稳定活动层不因慢部缺头而撑洞

Key P（p8s3）上部每小节八个普通八分，六小节内相邻原点约9.198–9.558pt；前五小节为9.378–9.558pt。下部首小节也连续八分，下一小节却是四八分加两个四分。上部仍保持近稳步长。保留这个坐标骨架，不能把下部四分之间没有头的时间变成上部宽洞。

KICK I（p4s6）中间两个完整八分小节为14.346–14.526pt；次页选定三个完整小节约13.986–14.184pt。下部有长和弦、二分、四分旋律和手提示，活动层仍连续可数。次页略紧有整行内容预算的背景，不能跨页用一个绝对步长判错；也不把“近稳”要求套给真实长短节奏或有必要变音占位的全部音组。

Key C（p3s1）又说明**不同数字不一定改变速度**：后两拍的下干快层为八分休止、3:2十六分、6:4十六分，上干二分和弦同时保持。两组每音都是四分单位1/6，3组占半拍、6组占一拍。保组边界及与慢和弦的分层，不按数字3／6自动设两档间距，也不为合并九个快头而丢掉原组的拍位。

## 3. 段号、引入、换调和变速会错开

## 4. 5/8为什么是3＋2，弧为何跨整小节

Key Y在p11s2行中开始：上部五个八分以三音梁、二音梁分开；下部三八分加一四分，表达相同3＋2。短slur跨满一个小节，说明一个连贯动作；梁说明内部拍组。两种范围同时存在有用，不必让slur在第三音也断开。

p11s3前五小节仍为5/8，第6小节改6/8，第7小节回5/8。6/8上部前组三八分、后组八分加四分；不能把五个起音误认成继续5/8。下一系统六个5/8后才回C。按全部时值读，才能知道多出来的是哪里的一份时间。

Gould p178允许优先用梁和长音／休止分割显示变动重音；p179的固定交替拍号又有自己的条件。当前两手已经建立3＋2，暂不加每小节分组数字、虚线或另一层小音符说明。若面向不熟悉变拍的使用者，可比较首处一次性3＋2提示；增加的文字也占版面，不能直接当全谱默认。

## 5. 主次、手和奏法要分别保护

KICK I首小节可按四分单位定位：0处突出和弦sfz，1处开始上部八分背景mp／sempre legato，2处下表上干部二分旋律mf。三项有不同时间与角色，合成一个“整表力度”会丢失主次。后面下表`r.h.`括形让右手接慢线，快音仍留上表，便于连续追踪。Key I下表r.h.、H末上表l.h.、U开头下表r.h.同样按局部材料指手，不能全谱一表一手。

Gould p311允许附加干突出旋律而不补满独立休止，p323要求独立层的力度贴近所属材料。它支持保留这里的分工；不支持仅凭PDF给出软件voice编号或实际手指持键方案。

KICK E（p3s1）的短slur连接两个音高不同的和弦，末音另有断奏点，首音重音；K的再现保留这种组合。短弧连起动作，点交代末音的收束，后续单独点另有任务。**保留，不统一删点或把短弧延长到整行。** Gould p121–122的弧内外层级也提示：同音时奏法内外还会影响重奏／tie读法，不能把“弧加点”当成可删除重复信息。A段`sempre staccato`与I的`sempre legato`各自有语境，不混成同一全曲触键状态。

## 6. 滑奏和震音：动作不能被几何整齐覆盖

KICK开头上部四分休止，下部双梁五头组占一四分，按书面5:4十六分计；另有gliss.与短8vb。末尾又以四个十六分加一个四分的图形写上行gliss.，8vb到最后滑奏头结束，后面的休止在范围外。末小节上部二分加二分休止；下部先接收四分持续，接滑奏，再到四分休止。上部开始休止时，下部仍有滑奏末头，不能裁成整齐的共同停止。

F前和M前则用叉形起点、下行波线与gliss.，没有给普通终点；不得把最近下一个和弦自动当滑奏落键。Gould p326偏好动作线，指出写成普通音阶会暗示逐音指法。这和官谱以计量音型加gliss.说明的体例有差异。**原写法先保留；以后可单独比较明确总时长／起终点的动作线版，不能删掉音型就称等价。** 原工程及演奏未核，书面计量不证明每个经过键都要求精确独立发音。

p5s5的上部整小节双音震音，下一小节先二分震音再二分和弦；下部二分后九个双梁音填两拍，按9:8十六分重建。之后`col pugno`明确另一种击键动作，不能因头挤在一起就自动拆开成普通和弦；两次白头之间的持续、后续开放弧分别读。Tempo I后的两组三连八分占前两拍，八个普通十六分占后两拍，三连解释不能延伸到全部快音。p7s1另有两个5:4十六分组。

Gould p225–226要求双音震音两端各写整段持续，梁按两个端点的实际位置安排；p229又允许用整组slur避免每对都tie的复杂。所以上述两个白头不把时长相加，震音右端也不能当第二次独立落点硬吸到活动层最近头。p221单音震音笔画偏细的建议不直接套给双音震音，后者p225明确采用普通梁厚。字体、字重与几何位置应分项判断。
