## 这一页新增的判断

### 1. 声部编号不能代替音乐作用

m53–55的上表辅助层在拍点补低音区和声，m56–57同一层改为高音强调；另一层仍持续八分／十六分的重复双音。m65之后，辅助层又承担内层跑动。因此，不能给voice 1永久标“旋律”、voice 2永久标“伴奏”，再据此统一干向、移表或分配力度。

源谱通过干向、音区、重音及起音位置让强调层从重复音型中浮现。重音移到高处时，符干方向随该层任务改变，仍能保持每一组的连续轮廓。自动处理应先识别当前片段的线条与强调，再读取对象voice作为结构线索。这里的三条实现容器是本次转录选择，PDF不能证明出版者原工程的内部编码。

### 2. m57的换号点给后半音组作准备

低表第一拍四个十六分依次上行，第二拍从B3继续到E4、G4、B4。G谱号放在第二拍开始：起首B3付出一条下加线，后三音落入谱表；若继续使用F谱号，后续上行会增加上加线。换号同时落在两个四音梁组之间，计数和音程轮廓都容易接续。

这提供了具体的选择理由：看后续整组的音区与拍边界，再判断换号位置。只看当前第一个音是否需要加线，会错过这个收益。不能据此规定所有上行都在第二拍换号；组形、读者准备及下一段音区仍须核对。原页H段延用G谱号，直到m65第三拍才回F谱号。

### 3. 同型重复要核重奏与保持

m54–56的主层以八分、十六分、十六分组织拍内轮廓，末十六分经常接到后续同音。m59、61、63低表第二拍后半的E4八分继续接到第三拍的二分音符。三个普通大小的二分符头保留了持续层，不能因符头提取漏判而改成四分，也不能把相邻重复音全部自动tie相连。

本次逐组核对后补回m63→64的E5/G5与m67→68的四音连接，避免局部四小节样本的截断约定混入整页。重复音的保持关系需要可见弧线和音乐上下文共同确认。

### 4. 相似和声不保证相同节奏

m69与前面的对应小节共享和声与高音区材料，开头却是两个十六分后接四分，辅助层先四分休止再进入；m67开头是附点四分，内层更早开始。直接复制旧小节的节奏、休止和梁组，会抹掉进入方式的差异。m68与m70可以帮助核重复结构，但不提供改写m69的理由。
