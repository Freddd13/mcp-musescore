# Mixed Nuts：何时少写，何时把拍点写出来

2026-10-22。A091完整五页复读，Gould印刷p166–171完整图文复核，另放大节奏、续行及末小节。来源、实际视图、分数计数与裁图局限见[证据](mixed_nuts_reading_evidence.json)。此前已经读过本谱笔记，本轮是主agent续学，不是独立盲评。原PDF／教材只读，没有原生改排、播放或用户审美选择。

本轮主要判断：D／H保留简明长值；B／F保留把第三拍显出的tie；先核书写时间和声音持续，再谈符号密度与间距。另更正首批笔记把末尾局部8va称作“8组”的错误。

## 1. 规范不是“所有跨拍音都拆开”

Gould p166–168要求必要的拍结构可辨：不规则、复杂的跨拍持续通常需要更多分界；从拍后开始的长值尤其要帮助放准后面的音。简单拍子中，从拍上开始的长值又可直接写长音；三拍与复合拍还有各自的分割要求。不能把4/4的一个处理直接移到6/8。

p169–170另区分有意与拍子对抗的重音、普通分组和奏法。写法会让读者预期不同重心；如果不想形成切分，却把重要界线完全藏起来，就需要拆分。长而复杂的连续型仍要留基本拍的计数线索，慢速时也可更充分地展开。

**p171明确列出常见型的例外。** 例如短—长—短、4/4的四分—二分—四分，以及拍内十六分—八分—十六分，书中推荐保留熟悉的整体形状，不额外用tie画满所有细分。这是整体识别带来的简洁；不能反过来只查一个局部子串便批量合并，也不能将“第三拍常需显露”当成没有例外的定律。

p170的3+3+2说明尤其有用：它讨论的是重音分组，组内仍可有额外起音，不能把分组数字当全部音头数。符梁、tie和奏法分别组织计量与动作，短促的音也不需要仅为“看起来短”拆成独立旗尾。

## 2. D／H：长音和熟悉的半小节型让层次变清楚

p3第三系统D起、p5第四系统末H起，都出现最高层整小节长值、其下旋律和低部参照。旋律按四分单位为：

`3/2 + 1/4 + 1/4 | 3/2 + 1/4 + 1/4 = 4`

也就是两次“附点四分＋两个十六分”。两个半小节的开头都可辨；低部四分运动又提供拍点参照。这里把每个附点四分再拆成四分tie八分，只会增加接收头和弧，当前没有相应计数收益。最高层也不必为了显示四拍改成四个相连四分。

**保留理由不是只剩下层帮忙数。** 旋律自身的重复型与半小节入口已清楚，长值又从拍上开始；低部是进一步的配合线索。另一部有脉冲，不授权把任意复杂跨拍都合成长值。

H的长音跨到下一系统首八分，那里是延续，不是仅凭有一颗头就算重新攻击。随后同一高处八分线的第四、第五个书写位置又以tie连接，保留第三拍边界。该条线虽写八个八分头，其中行首接收与中间一个接收不产生新攻击；此处只按可见连接读六个新起音，不把它说成整架钢琴／内部voice或实际MIDI的计数。

这也解释了为什么不能先按“相同听见的起音数”删头：有些头说明跨行持续或强拍边界，有些头才是新动作。反过来，新增tie头也不自动帮助阅读。

## 3. B／F：多出来的接收和弦有定位用途

p2第三系统B第一小节、p4第三系统F起，主层节奏相应。以四分为1，第二拍的上部依次是八分音、十六分休止、十六分和弦；末和弦tie到第三拍的八分接收，再接三个八分。全小节书写事件为：

`1 + 1/2 + 1/4(rest) + 1/4 + 1/2(tied receiver) + 1/2 + 1/2 + 1/2 = 4`

第一和弦在0，拍前和弦在`7/4`，其接收在`2`；接收之后的新音在`5/2`。两组梁把第二拍小单位与后半小节区分，读者可以同时认出“提前攻击”和“跨过第三拍保持”。第一八分下方的点是奏法，不是给该音加长的时值附点。

把那对十六分＋八分tie合成一个附点八分，听见的持续可能相同，却会拿掉第三拍的接收和弦，并牵动两侧梁组。此曲保留有明显计数收益，不能作为纯几何去重。熟悉型可以少写与这里保留tie并不冲突：判断对象是完整拍位、上下文和读者下一次进入，不是遇到tie便合并或遇到跨拍便拆。

这还影响间距解释：下部在对应时位仍有自己的符号，删掉上部接收头也不意味着共同时间列或整小节宽度等量减少。少一点黑线与更稳定的跟读不是同一个指标。

## 4. 末小节：五连、八度与最后一个动作要分开

首批[逐谱16](corpus/READING_016.md)写了“最后8组／尾部上行8组”。本次放大完整末小节和单独旗梁后更正：**是两个标5的十六分组；8与虚线说明局部高八度。** 初始紧裁漏了前面的八度与普通十六分，已扩大到完整系统／小节，旧裁图保留为局部视图。

上部先有八分八度、两个普通十六分；再各用五个十六分占一拍，最后八分高音和八分休止。按该处4/4、相同细分及下部配合的常规读法：

`1/2 + 1/4 + 1/4 + 5×(1/4×4/5) + 5×(1/4×4/5) + 1/2 + 1/2(rest) = 4`

这两个5组各占1，组内每音为`1/5`个四分；不是8等分，也不能因末段印8就把音区范围等同于连音范围。本式是对印谱的时间核读，没有反推原工程Tuplet字段或证明实际演奏严格等长。

高处最后八分之后上部休止，低部最后的八度在这个尾部时位进入，f也放在附近。弧、8va、发夹、休止与低部奏法各有自己的结束／作用位置；把它们统一拉到最高音、最后一根竖线或同一列，可能改掉读法。这里先保留，并不从PDF字样坐标确定播放scope。
