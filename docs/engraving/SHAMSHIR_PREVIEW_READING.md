## 1. 四小节行与三小节行，各自在帮助读什么

前16小节四次交替出现较连贯的旋律／保持低音，以及较短促的节奏riff。mf、mp反复交代状态恢复，长slur和低部tie又承担不同任务。四小节行使这些短单元容易对照；不能因力度重复或已有弧就删除其它提示。

m17起，上部带装饰／三连的旋律与下部细休止、和弦及短音交错，末两行各三小节。此处空间要容纳两条同时运行的事件，而非只看旋律头数。**本例保留三小节行**；增加一小节要连前后行及完整符号预算比较。本批没有证明四小节必然放不下，也没有确认净书者当时的具体操作。

m17、m21等末尾在休止后出现八分引入，新弧先从引入开始再跨小节；不能为了段落／行首整齐而把短语起点推迟。页末弧跨出预览，下一页未见，不能把它当作漏收的弧或擅自闭合。

## 2. m18的间距：不只量三颗头

按可见记法，m18开头为普通八分、三颗十六分三连、两颗普通八分。以四分为1，前两拍上部起点为：

| 角色 | 起点q |
| --- | --- |
| 普通八分前缀 | 0 |
| 三连三音 | 1/2、2/3、5/6 |
| 后续普通八分 | 1、3/2 |

下部第一拍为八分和弦、十六分休止、十六分音，休止在q1/2，后一个起音在q3/4，恰位于上部2/3与5/6之间。下一拍含十六分、十六分休止、八分和弦。休止也是时间信息，不能把两个相近的头吸到一起；也不能把数个文字／梁片段当成新的时间事件。

对原分辨率JPEG的四个明确音头窗口做墨迹包络测量，三连三头横中心约681、710、738.5，随后普通音约760像素，相邻间隔约**29、28.5、21.5像素**，窗口估计误差约±1像素。前两段近稳，到普通音更紧；这四点的逻辑间隔均为1/6q。只是栅格局部观察，不换算毫米、不反推出源软件或精确排版参数。

这个例子印证两件事：有额外伴奏事件时，旋律内部仍可以近似稳定；只量组三头又会漏掉最后到达的收紧。新增全局时间列不能自动成为不匀的充分理由。Gould p40要求同值在系统中保持可预测性，p41给出符干方向等光学例外，p200也允许复杂同步时优先上部的均匀感。后续应同时看主要跟读脉冲和另一层的可读时间位置；[十二对十一研究](POLYRHYTHM_SPACING_STUDY.md)的具体引擎机制不能直接套来解释本JPEG。

## 3. 共梁跨休止，与延梁包住端头休止不同

m17–22低部多次用梁把八分—十六分休止—十六分，或十六分—十六分休止—八分组织为一拍。梁帮助认出拍，而休止保住原曲打击式的分断；把全部休止抹掉再加断奏会改变写出的持续。

这里的所选休止在组内，两端都有音；Gould p164的按拍越休止共梁可直接解释其收益。p165另讨论延梁覆盖拍首／拍尾休止并使用短符干的图式，不能不分条件地套来要求本页每个内部休止都补短干。本例保留这些拍组；中间另有带旗短音与休止，是否更合并须按重复动作和归属判断，不能统一共梁或统一拆梁。

上、下干方向也不独自证明多个voice或手别，PDF没有源容器信息。

## 4. 裸3能读，不等于组界已经最明确

m9、m13及m18等处的三颗十六分三连，只占一条包含普通八分的主梁的一部分。次梁和本小节计量帮助认出三颗成员；前缀和尾部仍是普通音。

Gould p200对这种部分主梁要求括号。本线建议**在首次／复杂同步处比较只罩三颗的短3括号，保留连续主梁**。代价是多一条局部线及与数字／弧的通道需求；不是改比例、拆整串梁或把所有头纳入三连。当前裸数可解释为本版简省，不能直接诊断成音乐时值错误。

## 怎样用于后续审谱

先按整小节复算普通前尾、连音、休止和接收，再看主要脉冲；测量覆盖最后快音到接收，不只组三头。解释同一排法的收益及代价，保留成立的分组和容量选择。遇到部分连音先补清范围，遇到休止先区分组内与拍端。作者参与声明、当前可见排法和软件原因各自记录。
