## 3. m33说明为什么不能整小节机械等距

源活动列为`369.472、382.629、391.521、403.703、413.205、422.097pt`。第四列的还原号在本列头左边，前一列低音头也靠近它的下部：

| 还原号与前一头的关系 | 原排法 | 全小节固定首末后均分五格 | 保住还原号前一格再重分 |
| --- | ---: | ---: | ---: |
| 横向框间隔 | 1.961pt | 0.304pt | 1.961pt |
| 对应纵向框间隔 | 0.437pt | 0.437pt | 0.437pt |

还原号高而窄，不能只看其基线或音头中心。两框即使未真正相交，0.30pt的横向距离与很小的纵向距离仍会使局部拥挤；这是有阅读理由的宽格。Gould p43允许保留的变音符号占位，同时建议减少无用的节奏扭曲，不要求为此把所有其它格都拉到相同大距离。

m31印出的还原号在D4，取消调号中的D♯，它决定该处音高；B♯→B的变化则由小节线恢复自然，无另印还原号。m32→33的E♯→E才对应此处跨小节确认：调号本为E自然，小节线已结束前一变化。Gould p81建议在下一小节确认／取消前一变化，p82再解释提醒符号的读法，适用于m33的提醒解释。保两处符号再解决间距；m33是否省写另作编辑判断，不能将m31必要还原按提醒删掉。

本批纸面比较保q1→q1.5的12.182pt，将其余四格余量重分为约10.111pt。这样保住还原号与前音的相对距离，也保持第一、最后活动列及整段宽度。实际实施须连同该时点的低部音、休止、`mf`等所属标记联合移动，不能只拖右手头。

这组坐标用于解释候选的约束，尚不是可直接应用的预设。弧线、完整字形墨迹、下部所有时点和整页联动仍须原生重排复核。

## 4. m30／31／35有余白可重分，仍保原版作基准

保首末活动列的等分诊断，能把这些小节首格缩一些、其余格放松一些。所列相邻同高加线的端点间隔最小值，m30／31由约0.609pt增至1.486pt，m35增至1.632pt；没有出现“缩首格就必然挤坏所有加线”的结果。

这里量的是线段端点，未计线宽，不能当作墨迹净空或理论最小值。音头紧框按同字形、同字体及实际字号平移缩放后比较；这只是纸面占位模型，不替代完整曲线与原生图。

因此保留三个优先比较位和m33的受约束比较，而不把六处都列成错误。Gould p490要求按每拍最复杂的活动安排空间，再让其它层与其同步；这能帮助我们决定先稳定内层八分，也保留必要符号与上层长线。它不自动证明原版或本候选全局最优。
