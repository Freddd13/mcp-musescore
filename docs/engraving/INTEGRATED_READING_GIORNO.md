## 1. 相似不等于重复：全曲怎样分配阅读注意

| 位置 | 读者正在认什么，当前排法的作用 | 一致化的代价 |
| --- | --- | --- |
| p1前两行至A前 | 短音、短弧与休止组成识别度很高的动机，随后由单音加厚成八度／和弦；低部先稀疏、后增加动作 | 把短弧改成长句弧或删断奏，会改变动作；把空拍收紧到像连续快音，会损失停顿与进入线索 |
| p1行中A至p2前两行 | 上部长旋律／和弦和内层切分并存，下部含半音变化的活跃伴奏；同一上表有相反干向 | 不能把上表所有音当同一右手动作、按中线重定干向，或把长头视为空白容量；上部宽度不由它自己的头数独定 |
| p2 B及其后两行 | 熟悉切分与低部跳进；B后有simile，但局部结尾、变音和短运行仍写出；末尾一小节另改三连并标energico | simile不授权省去实际不同音；三连与后面的普通细分不能共用“同样几个头”的距离／时间假设 |
| p2 C至p3 D | C建立较长旋律弧与切分重音和弦，D又回到短型，并在随后增加下部连续运动 | 熟悉材料帮助识别，但不是把C的长弧、D的短奏法统一；角色变化应允许不同局部密度 |
| p3行中E至p4首行 | con bravura后的和弦、单音运行及六连逐步提高密度，上部运动较密时下部仍保自己的节奏 | 强制四小节一行会挤压运行；只按下部八度间距拉齐上部，则失去组内节奏与真实共同点 |
| p4 F及随后两行 | F的和弦切分之后，另有上部保持与内层短音；再以mp、mf、f各带cresc.逐级推进 | 几个cresc.各有起点和起始强度，不是重复排版错误；长音与内层休止、tie接收不是可删的“冗余头” |
| p4第五行及G，p5前部 | D.S.要求返回；隔开的Coda有双滑奏，再接G的p dolce，后又增强 | 路线入口、音区、动作与后来的主题入口分别生效；不能让最大的G标签代替Coda或合并先后力度 |
| p5 H、I与Tempo I | H重新出现短型；I先2/4整小节休止，后恢复C拍号并进入rubato长和弦、延长与踏板，最终回到熟悉脉冲 | 休止、换拍、速度恢复、手分配、持续和释放共同组织尾声，不能以“最后一行很稀”直接压缩或重写 |

本例的统一感有一部分来自**同类材料保留可识别的组形，变化发生时仍明确写出**。字体影响符号外形，梁、弧、休止、层次和行页选择决定这些符号怎样成为可读的音乐组织；两者不能互相替代。

## 2. 梁与tie怎样既交代切分，又保住计数

p1 A首小节，上方长白头独立保持，下干部和弦有短梁及tie；p4 F后的上表也同时有白头长音、下干部休止与切分。这些短梁和接收头让读者在持续中继续找到内部时间位置。接收头不重新起音，却仍是书面时间参照。若只按NoteOn或只数黑头平均分布，会把持续和活动合成错误的一条线。

这里并没有“切分必须拆得越细越好”的规则。Gould p170要求在表达切分、长小节基本计数及慢速逐拍细写间取舍；p171保留熟悉节奏的简洁惯例。本谱B和F也出现跨拍的较长值与局部tie，不能为每拍都有音头而全拆；需要先确定所表达的节奏、读者熟悉程度及两手计数任务。改写音值／梁组属于记法候选，不能悄悄混进纯间距优化。

p3第二系统下部连续短音多用平缓／水平组形；p4首行上部六连既有下降也有上升梁，较长slur又跨过多个组。两种线各司其职：**梁让组与方向易认，slur把多个组联系为一个较长动作**。长弧不意味着连梁应该跨过所有拍，也不要求组内所有符干等长。

Gould p21–23说明梁角、靠梁的内部音、首尾音和重复型各有条件：梁不照抄最高低音的极端音程；全在加线外时还可能更平缓。p4首行后部高音组留有加线，也没有为消灭加线不断换谱号。当前可以保留这种组形分工；本轮未测每组最短干、梁厚或印刷白缝，不宣称官谱所有梁都达到书中比例，也不提出全曲平梁或固定坡度预设。原生正反例见[梁干研究](BEAM_STEM_STUDY.md)。

## 3. 间距与行容量随“最难读的活动”变化

本曲普通系统常见三或四小节，而不是全曲固定四小节：p2前两行各三小节；p3第二、第四、第六系统也各三小节。p1标题占高，只排五个系统；p2–5各六个系统，其中p4第五行还包含断口两侧的两个片段。这里的系统指实际阅读横行，断口右侧不另算新增一行。

p3 E在第三系统第二小节进入，p1 A也在行中；D、F、G、H、I又在各自行首。保留行中入口能避免前行不必要的松散，把前导与到达放在同一阅读范围；行首入口又提供较强定位。这是音乐容量与定位的联合选择，不能从其中任一段推出“段首必须换行”或“永远不用换行”。

间距判断也须随活动换重心。p3第二系统，下部连续十六分型成为稳定脉冲参照，上部有较疏且不规则的切分、短休止及局部细分；p4首行则是上部六连最密，下部仍需在自己的时间点对应。Gould p490支持逐拍先照顾密部，再协调其它层、避免过度失真；它没有授权全行只选一只手，更不允许以头的序号逐个吸齐。

本轮据图确定上述组织，**没有量出A047各组的间隔，也没有证明哪一格已经是最小必要宽度**。变音、加线、tie、短休止和不同细分可能需要空间，但“含变音”不能自动为任何不均匀免责。若在可编辑实曲发现疑点，应像[T02间距应用](SKILL_TRANSFER_SPACING.md)一样，先核真实时间、符号占位和整行预算，再作少量固定预算候选；本轮不把另曲测量搬成此曲数据。

p5末系统容纳六个完整小节，开头包括2/4整小节休止，后面又有长保持。它与密集运行的三小节行不是同等信息密度。不能只根据小节数判“末行塞太满”，也不能把长头、延长及等待均匀拉成与快音行相同的视觉格子。

## 4. 回跳省纸，也把路线和状态变成版面任务

已知路线复核：首次从头经过p2第四系统末To Coda继续；到p4第五系统左段末D.S.，返回p1第三系统行中A／Segno；再次到p2出口，转p4同一行右侧Coda，再接下面G和p5。它不是从D.S.直接顺序演奏右侧片段。此前的mf恢复及八度范围已在[变音实际来路](ACCIDENTAL_CONTEXT.md)说明，本轮不重复列作首次发现。

Gould p239支持行中断口以及恢复谱号、调号和大括号，让落点可独立进入；p240也建议返回／跳过段落尽可能从新系统开始，并对大谱表D.S.的下方位置有建议。本谱A在行中、D.S.在上方，所以不能把它包装成完全照书实现。当前标识仍可辨，另起A或移动指令只能是比较方案，须兼看占宽、前导、其它文字和页界。

比“留白好看”更深的一层取舍是：**少写重复材料节省页数，但演奏者要多次跨页找路**。本谱D.S.从p4回p1，再从p2去p4，Gould p239也提醒这种路线可以考虑写出部分或全部重复。展开会增加页数并重做翻页，不能直接认定更好。本轮保留原布局，把可编辑输入下的“少量展开／原路线”列为未来比较；没有改写音乐或做实际播放。

按首音乐页在右的通常双面装订假设，顺序p1→2、p3→4是翻动，p2／3、p4／5在同一对开；回跳又有另外的翻找任务。p3→4连续运行、p1→2也有正在继续的两手材料，没有凭空出现已证实的自翻窗口。Gould p560按正确速度单位把可用休止换成时间；休止在哪、手是否真空闲、单页屏幕／装订方式及有无翻谱人仍须分别核，不能拿较后的I休止或Coda上表整休止替较早页界认证。

## 5. 同是跨表线：动作、交接、持续不能合并

p4 Coda两条上行波线各带gliss.及特殊端点，还伴随r.h.、局部八度和下谱表换谱号。方向、两条独立动作和各自范围应保留。Gould p326把钢琴滑奏与逐音指法区分；本谱波线而非书中偏好的直线属于风格差异。不能由谱号变化后的图面Y或内部数字音高猜精确末键，也不能删一条让版面更轻；详细动作边界仍沿用[滑奏专题](GLISSANDO_READING.md)。

p5 Tempo I附近是另一情境：上表已经换低音谱号，熟悉短型处有虚线跨表引导，下部紧接对应运动。这里的虚线帮助追踪交接，和Coda有gliss.的两条动作线不能按线段外形归同类。Gould p303–306说明音域、手分配和音乐轮廓需要共同考虑；换到低音谱号不自动表示旋律改由左手。当前没有工程／全体触键说明，不按虚线独自重建每个内部voice或完整手法。

I后的长和弦旁有l.h.，下表短引入与上表和弦之间也有连接；另一处有明确完整tie、延长号、渐强渐弱及踏板。它们不是同一种“多余曲线”。本轮保留该组合，不把宽和弦的分手、无声持键或滚奏细节从外形猜成确定动作，不替作者加精确秒数。

Gould p324–325又提醒八度线按谱表与具体范围读，不能随同一动作跨表自动继承。p3→4运行的续八度、D.S.前已经结束的短线、Coda的独立八度、p5 H附近及末尾的局部线都需各自识别；段名、长slur和小节线不替代这些边界。rubato与Tempo I改变速度读法，也不自动将仍写出的拍号／时值改成时间—空间记谱。

## 6. 接入自主净书的取舍顺序

遇到相似题材，先对照同动机的初述、加厚、运行、保持和恢复，找出哪些组形应保持可认、哪些信息已经变化。再分别问：最密的活动在哪一拍／哪一层，梁和弧各在说明什么，行中标签是否已有好入口，跳转后读者从何处恢复状态。最后比较局部空间和整页代价。

当前值得保留的是拍组与持续的分工、不同密度的容量、各次力度起点、Coda断口及交接／滑奏的区别；可再研究的是回跳跨页成本、某些入口另起系统的收益及密部间距的实际几何。不能把后几项仅凭PDF判成软件缺陷。
