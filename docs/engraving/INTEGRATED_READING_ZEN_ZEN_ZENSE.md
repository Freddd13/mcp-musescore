## 1. 先读全曲的运动和角色

开头是五升号、C拍号、四分音符184，三连引入后有普通八分运动；后来的poco riten.与a tempo是局部收放。清单旧任务名“慢速进入”容易让人误以为全曲慢起，现改为“分层进入、局部变速、八度通道与结束布局”。

## 2. K段：可以弯折，仍须避免交叉

p7第四系统第二小节，即K m160开始，8va虚线先平行，随后下降到长连线内侧。高清原图可见虚线的斜降段穿过长连线。长连线还覆盖后面已回普通音区的材料，因此不能简单让两线共用一个起止框。

Gould p29的条件很具体：空间许可时倾向平行；竖向紧时允许随音符轮廓升降以避其它记号；与乐句线／连音括线共存时，较长范围可在外侧。**线形、层序与避碰须一起满足。** K长连线在外侧有阅读理由，穿线的过渡则让眼睛多做一次辨认。

候选应先比较两条线各占清楚通道：保住8va首尾目标音，给起段或长弧更多高度，使虚线进入内层时不穿弧；也可比较把短八度线整体安在可用内层空间。要同时看上方系统和后续高点，不能从局部裁图保证平线一定放得下。

不采用“所有八度线拉平／一律放最外”的批量规则。本行8va在末小节前结束，下一行又有自己的范围；合并到整行会把普通音区也罩住。后续自动诊断应报告具体相交及作用对象，单凭折角数量不报错。

## 3. p8：六拍、恢复、停顿、慢引入各有位置

本页第三系统依次是：

1. **m180：一个6/4小节。** 上部快十六分、另一层3组与跨表路线共存。它在本系统获得明显更多宽度；长拍数与密集事件都需要预算。只按音头总数或“同一行四格”分配会压缩这一段。
2. **m181：回C。** 上部长和弦保持，下部在后面还有短活动及局部8vb。长音的空白容纳了另一层进入，不等于可以无条件抽掉。
3. **m182：延长与双斜线。** 上部整小节休止带延长；下部先有短音，再有休止及自己的延长。不能把它简写成从小节开头全员休息，或把上下延长号拖成任意一条竖线。
4. **m183：Meno mosso、pp。** 上部四分休止后接三颗四分音符，下表整小节休止；**m184下一行才是M**，长保持主题展开。

这个顺序使眼睛先完成运行，再确认静止和呼吸，最后从慢引入走进新主题。把Meno挪到M会晚一小节生效；把M拉到m183又改变了结构标签。Gould p184、187–190支持分别追速度参照、停顿的承载对象和各层实际活动，不支持按空白外形合并所有阶段。

p9的N m200写Più mosso，m208再写Tempo I。前者是加快的阶段，后者指回开头速度；两者不能合并成一次a tempo，也不能从文字自行补一个新BPM。

## 4. 结尾：动作、音区和保持分别收束

p9末运行后的O m224回三连引入；P m234仍在第三系统第三小节，fp慢内层与后续f短回答、p前景互换共存。低部连续活动不因上层换角色而中止。这里保留行中入口，比为了整页方正重分段更能保持前后动作的连贯。

末行m244–245继续八分高潮，m246有ff／rit.，m247–248为最终tie连接的和弦和延长，上表已换低音谱号。下表8vb从m246后部开始，线尾附近绕开低头与tie的形状有实际空间原因。

Gould p30通常让普通八度线末角紧随最后音头／点，原谱末角却在全曲终止线附近。它没有罩住新的后续攻击，又有明确终止情境，所以先列低优先级体例候选；收短可能更简洁，但不能借此标示松键，也不能把避让低头的折角一起抹掉。K的实际穿线更值得先处理。

## 6. 新规范：信息量由读者任务决定

新完整读图Gould p591–598／物理PDF p611–618，八个实质页，电声章尚未结束。它们把分析谱、演奏谱和技术操作分开：电子背景提示可以用最可辨认的节奏／音高或图示，精确同步和复杂互动又要求增加细节。背景用小字的条件，与关键同步采用正常字号并存；触发者附近的提示、不同框形及准确落点有不同功能。
