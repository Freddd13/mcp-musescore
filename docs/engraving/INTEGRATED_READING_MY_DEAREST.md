# My Dearest：异分运行的汇合，和有理由不对齐的地方

2026-10-23。A092完整十页复读，结合Gould印刷p125–131、40–43、200–202完整图文复核；p123–124章首页／目录也看过，不算两页技术正文。原PDF只读，来源、实际视图、七处测量和时间核算见[证据](my_dearest_reading_evidence.json)。主agent已知旧笔记，不是独立盲评。本轮没有原生替代、播放或软件适配。

装饰音脚注的判断在[既有专题](NOTATION_DETAILS.md#6-装饰音拍点对齐和局部弧线的取舍)已有详细解释及原生验证，这次是复核，不冒充新规则。本轮新增重点是把它放回整曲，并用P段七处对应运行区分**真正共同的时位、不同细分的近邻、必要的换号空间和局部汇合疑点**。

## 1. P段：十二个普通快音，对十一连组

p8最后系统P起的两小节，以及p9前两系统四小节、第三系统第一小节，共七处相应构型。这里只计上下两条快线的音头，不是整架钢琴的起音数；低部还有长保持，上部也有独立长和弦及后续接收。

每处上方是十二个正常大小、三层梁的三十二分音符；下方是十一个正常大小、两层梁的十六分音符，梁上标11。下方运行中还换谱号、局部进入8va。它们都不能仅因“华彩感”或音很多而改成不占计量位置的grace。

按本段4/4、前面的八分休止及运行后的二分音符作常规核算，以四分为1：

- 上方：`1/2(rest) + 12 × 1/8 + 2 = 4`。
- 下方：`1/2(rest) + 11 × 3/22 + 2 = 4`。因此这段11组占`3/2`，按十六分单位推为`11:6`。

两组都从小节位置`1/2`开始，在`2`汇合。内部位置分别为`1/2+n/8`和`1/2+3k/22`；除开始与结束，没有另一个精确重合点。不能把第2个上音吸到第2个下音，也不能按相同梁等级推同值。这里的11:6是由印谱完整时值推定，不是读取到原工程比例，更不证明演奏者严格等分；初次阅读若需更明确，可以比较首次写全比例的记法提议，不能悄改原谱。

Gould p200–202要求连音与其它部保持时间关系，并按共同细分计算位置；p200同时承认复杂部优先时另一部的等距会受影响。对这个12／11例，132份共同细分可以核算关系，每份为`1/88`个四分，上下各隔11／12份。**这是分析用的时间坐标，不是要求纸上画132个等宽格。** 不同表的近邻事件也不需要各自占满一份普通符号间距；真正约束是时间次序、同刻关系、各表墨迹和读者能否认出两组。

## 2. 同一官谱也有应单独讨论的局部疑点

七处运行后的上下二分音头使用相同嵌入字体、同一字形与缩放，且均为上干；此处没有二度和弦的正常侧错头或共干跨表关系。结合完整谱面，比较这对头的横位是合理的，不是拿不同字形的文本框硬对齐。

| 位置 | 下方到达头相对上方的横差 | 本轮判断 |
| --- | --- | --- |
| p8 P第一小节 | 左移3.545 PDF pt，即约`0.833sp` | 时间上应汇合，图上有可见错列；值得比较校齐候选 |
| p8 P第二小节 | 0（按PDF现有坐标精度） | 保留共同到达点 |
| p9第一、第二系统各两小节及第三系统首小节 | 五处均为0 | 不推广首处差异为整段失效 |

谱间从该PDF实际谱线间距量得4.254 pt。相同字形／矩阵使本次原点差也代表同样的墨迹横移；它不等于所有和弦或不同干向都应按字形原点吸齐。首处上方正常长音和另一层休止也在同一列，进一步支持这是一个具体的汇合核查点。

这给出一个**局部排版改进候选**，没有证明制作软件的算法错误、出版者意图或演奏真的错拍。若有可编辑输入，可在固定整行预算内，以共同末点重排下方十一连组，保留组内换号净空；完整比较两手及后续接收。仅拖最后一头可能把末次短音到长音的间隔孤立拉宽，也要比较。原PDF不作修补，本轮尚无这个原生候选。

这与“官谱很好看”并不冲突：应学习它的组形与信息层次，也能发现局部可改进处，不能将参考当成逐坐标的真值。

## 3. 换谱号会占宽，但不自动说明时间排错

P段下方11组在中途换到高音谱号，随后仍保持一整组梁。换号让后半高音区易认，代价是组内需要给谱号留出位置；不能只根据某两个符头较远就判不均匀，也不能把谱号压到看不清来恢复等距。

Gould p40的同值稳定目标须与p41的干向光学校正、p43的换号／变音占位及p200的异分同步合读。p43优先尝试压实附加符号周围空白，也承认多个变音等情境要给额外宽度；不是无条件固定每头距离。当前没有独立量完全部净空或证明P段组内分配最优，保留必要不等距与审查共同末点是两个可同时成立的判断。

本次按局部窗口提取PDF音头时，最初两个上下分界窗口混入了另一层的加线音；已根据完整图及实际谱位分开，才核到七处各12／11。固定页面Y阈值不能当voice或谱表身份识别器，字体字符数也须经音乐分层核读。

## 4. 星号装饰：正常拍列和拍上动作并非同一条图轴

p5第四系统第二小节，星号指向颤音前的三个小音，页脚明确要求在拍上演奏。三个小头仍位于正常主音左边，下部正常音与正常主音列对应。这与Gould p127–129的约定相容；不能为了模拟实际同时发声，把低音挪到首个小头下。后面另有两颗收尾小音，不能因同样缩小便把星号说明扩到它们或全曲。

这正是与P段不同的情境：装饰组的显示顺序和实际起奏需要本谱说明；P段两条有计量值的运行则应按各自时间分法判断。仅用“可见头要对齐／不必对齐”的一条规则会在两边都误判。

星号组的独立小弧让目标可辨；同曲普通长句、颤音波线、tie和8va各自说明动作、保持和音区。Gould p129–130允许为装饰保留独立短弧，也允许仅含在大弧中来减少繁杂；不能只按弧多便删。局部三层小梁属于已承认的出版体例，不按梁数精确推实际装饰时长。此节复核既有判断，没有重复计为新增原生验证。

## 5. 全曲读法：同一音型的角色与进入时位会变

开头和A的上部十六分脉冲与下部较长旋律分开；J则在更密的三十二分背景中保留上层较长的梁与tie，让读者认旋律而不必把所有快头逐个追成主线。L／Q再现时又有持续、休止后的进入和r.h.／l.h.局部交接，不能因音型相似就抹去这些差别或复用同一组坐标。

p10第三系统的S在一小节延长休止之后、同一行中进入。首小节上方先四分休止、八分休止，再两颗十六分，后半小节重复；上方第一次起音在`3/2`，下方二分音组从`0`开始。上方pp与下方p不齐有明确的层与进入依据，不能照P段共同末点的判断把这两个力度吸成同一列。把S一律移到新行又会改变前后行页预算，当前先保留。

后续诊断的顺序因此是：认角色和完整书写时值，找真正的配合点，排除装饰约定、共头／错头及必要占位，再比较局部候选与整行代价。当前优先候选是P首处汇合，明确保留的是内部不同步、换号所需空间、星号装饰约定及S的不同进入；没有新增用户审美定论。
