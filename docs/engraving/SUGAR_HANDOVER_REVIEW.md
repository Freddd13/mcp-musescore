# Sugar Song：换手范围、稳定间距与行中段首的复核

结论：**保G段的连续运动及六音换手提示；保重升号前有理由的宽格；L段提高另起行比较的优先级。** 本次最有用的修正，是不再用“行中也读得懂”直接支持保留所有行中段首。

## 1. 六音换手跨过小节线，也跨过拍组的一部分

**保留原排法。** p4s2，`r.h.`左括角位于第二小节下层末两音之前，右括角位于第三小节下层前四音之后；它指定六个十六分音符，由“前小节最后半拍＋后小节第一拍”组成。

| 范围 | 书面起点q | 符头左沿x，pt |
| --- | --- | --- |
| 前小节末两音 | 3.5、3.75 | 390.828、400.222 |
| 后小节前四音 | 0、0.25、0.5、0.75 | 417.946、427.340、436.734、446.128 |

左右括角的横向外框约385.865–389.942与452.510–456.410pt，和实际图相符。**括号没有接管前一梁的全部四音，也没有接管后一小节的全部运行。** 两个括角之间没有另画横线；须结合`r.h.`、角的朝向和成员位置读，不能把它当缺了一段的连音括线去补。

这里的三种边界各有任务：

- 梁保留拍内节奏单元，前小节最后一拍的四个十六分音符仍连在一起，换手发生在这拍中间。
- 手括角说明演奏分工，右手接两音、过小节线，再奏四音后交回。
- 长弧覆盖更大的上行—下行运动，不随换手中断。

这样排的收益是：读者仍能一眼认出连续音型和拍组，另用很小的提示解决具体用手。若把每次换手都改成新的梁组，会削弱原拍的组形；若把这六音另接成跨线新组，还会增加一种原谱没有强调的分组。把六音移到上表虽更直接显示手，仍要处理加线、两个声部及弧线通道。仅因同属右手就搬谱表，收益不充分。

Gould p305允许保持声部所在谱表，用文字／括角指示另一手；p306要求恢复分工时有相应提示。此处结束角承担返回边界。书中的一般条件支持这个读法，**具体六音范围由本谱图和时值核实**。

上层还有一项独立约束：前小节第三拍开始的二分音符书面持续到小节末，而右手在最后半拍已经接管下层。这说明保持的音乐与接管的动作有重叠，不能据`r.h.`把上层长音缩短。原页没有给出这次重叠的精确踏板／替手方法；本次保护持续和手分工，不替作者补演奏处方。上表仍处于8va范围，下表的右手六音也不能因此跟着升八度。

可用于以后审谱的判断：**先分别找拍组、手的接管／返回、音乐持续，再判断三种范围是否清楚；不要求它们共用同一组界。**

## 2. 连续十六分：多数稳定，一格为重升号留空间

**保留当前间距作为比较基线。** p4s1第三小节下层有16个普通十六分音符。按同字体、同字号的填实符头原点量15个相邻步长：

| 所选步长 | 当前结果 |
| --- | --- |
| 其中14段 | 10.280–10.458pt |
| 第11→12成员 | 12.939pt |
| 相对全部步长中位数10.281pt | 宽约25.85% |

第12成员有重升号，符号横框约499.834–504.565pt，音头起于505.329pt；前一个头起于492.390pt。宽格和必要前缀在同处出现。其余步长维持近似稳定，读者无需因每个升降号都重新适应整串的粒度。

这个例子解释了出版谱的稳定感：先保连续运动的大部分步幅，再为具体形状局部让位。它没有把整组扩成最宽一格的统一间距，也没有强压那一格。Gould p40讨论同类时值的相对稳定，p43允许密集条件下为记号调整、也提醒不要无条件扩大符号周围空间；p490按每拍最复杂节奏组织其它层的对齐。

本次只证明可见布局及其合理用途，未证明当前12.939pt已是最小净空。各四音小组干向不同，这份量测是同字形的**头部步长**，不能替代全部符干轴／实际墨迹间距。需要原生比较时，仍应同时保护旋律共同起音、重升号辨认和整行预算。不能从本例推导“超过某个百分比就修复”的阈值，更不能据Finale成品直接诊断MuseScore某个算法。

## 3. 行中段首可以清楚；另起行仍有需要比较的收益

初判偏向保留p2 C/D、p6 L/M的行中入口。看整曲时，它们都有段号和明显织体线索，过渡与到达连续摆在一行，阅读可以跟上。

**查规范后修正优先级：p6 L值得优先比较另起行。** Gould p487将段落变化尽量放在新系统，目的是让边界更显眼。这里的“可以读懂”只证明现版可用，还不足以证明它优于另起行。

L位于p6s3第三小节，前一小节有`riten.`，L处同时`a tempo`、`f`并恢复节奏型；这是速度、力度、织体共同变化的定位点。另起行可以让演奏者更快预见恢复位置。M在p6s5第三小节，前面已有黑键滑奏等显著过渡，当前行中的边界也很醒目；它的换行比较优先级较低。两处不能仅按同样的方框字母打同分。

完整p6现有六系统，小节数依次4、4、4、4、4、3。要比较L另起行，应重分周围数行并看下一页承接；**未试排就不能宣称一定多一行／多一页，也不能宣称能保持现页预算。** 两个较疏的K行是否容得下更多小节，需实际预算与原生图验证。当前保留源版，记录有依据的候选，不拖音符来伪造新断行。

本次未重算p7整小节21连音。旧笔记已经核到21:16分析比例及第8／9成员间的8va终点；初读中的比例疑问经旧笔记定位，不算新的独立时值证明。以后比较该处，也要保跨页tie与行中八度恢复，不能把整串统一套8va。
