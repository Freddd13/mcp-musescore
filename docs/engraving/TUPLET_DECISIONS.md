# 连音标记的三种判断：保留、补范围、说明比例

2026-10-31。复核本页预选的**8/8个情境**：四处保留，两处比较短范围括号，两处比较首次说明比例。重新看Gould印刷p200、203–209八页，五份官谱的七张目标整页及三张拍号上下文；共18张旧图复用，无新媒体或原生试排。此批是已知旧研究后的归纳复核，不计新的阅读覆盖、迁移测试成绩或用户偏好。[证据](tuplet_decisions_evidence.json)给出逐例位置、源哈希及精确计量。

**先判断读者还缺哪种信息，再决定增加什么。** 能算出一个整数比，不自动说明纸面必须印出这个比；一条完整梁已足以表范围时，也不必再补同宽括号。另一方面，数字位置居中、内梁有断口，不总能代替明确的局部范围。下文把这几件事分开处理。

## 规范怎样一起用

| 依据及条件 | 读者得到什么 | 对实际动作的限制 |
| --- | --- | --- |
| Gould p200：连音占完整梁，数字靠梁；梁本身完整罩住拍内休止时也有省括号条件 | 直接看到一整组的成员 | 不能将“有休止”一律判成必须加括号。核梁是否真的延伸罩住该休止 |
| 同页：连音只占一条主梁的一部分 | 短括号排除不属连音的普通前尾音 | 重点是组界；比例原本正常时不必顺带加冒号或拆主梁 |
| p203–206：简拍、复合拍、传统二／四连及不同基值 | 同样的数字在当前拍组中采用什么分法 | 不能让软件对数字的一个默认比例凌驾于拍号、音值和上下文。复合拍传统二／四连允许扩张读法；含更多复杂连音时，书中更偏向统一收缩体例 |
| p207：非标准长度、复合拍歧义、混合音值使单位不清时说明比例 | 免去不必要的反算，建立新的时值关系 | 本条有条件；必须与该页“整小节均分通常不需完整比例”一起读 |
| p208–209：5/8、7/8等完整时段的均分及不寻常跨度 | 让人先认整个时段被等分的手势 | 分析可用的等价分数不一定是最好的印刷标签。慢速精确配合又可另比较显拍／tie写法 |

这里的“保留”有规范依据；“比较”仍要看本谱既有体例、阅读任务和实际空间。Gould对部分主梁的括号要求，比官谱某些简省做法更明确。应将这项差别写成有理由的局部记法建议，不能把所有未加括号的官谱归成节奏错误。

## 八个具体情境

q以四分音符为1。表中比例用于解释严格计量；原PDF的内部Tuplet对象和实际演奏均未从中反推。

| 情境 | 判断及阅读理由 | 替代方案的代价 |
| --- | --- | --- |
| **J01，Gould p208–209：5/8整小节三等分** | **保留3及全小节范围。** 三个四分形状成员各占5/6q，总计2.5q。以八分为单位可分析成6:5；书中直接用3表达三等分，并未要求把这项换算印上去 | 硬标一个不说明单位的3:5容易误导；展开真实节奏／tie有助慢速计数，也会增加头和连接 |
| **J02，A076《Kimi no Shiranai Monogatari》p6 s6末小节** | **保留裸22。** 前一小节已有自己的小节线；22个双梁成员独占完整4/4小节，完整跨表梁与小节线提供范围。内部可核22:16十六分 | 补22:16增加信息但未解决新的组界问题。不能把上一小节白和弦计进22，也不能裁去下表末三音后另造比例 |
| **J03，A088《Merry-Go-Round of Life》p4 F的两次整小节下降17组** | **保留裸17。** 两次都由完整双梁占3/4整小节，可分析17:12十六分。rubato不取消书面时段；相邻上行13／15只占普通四分之后的两拍，另按局部跨度读 | 不因为17:12的分母不是常见二进制数就自动补比。也不把旁边13／15和17统一成相同时值或同距 |
| **J04，A005 p149 s1末小节，C** | **保留裸11和独立完整双梁。** 普通四分＋11个十六分＋普通四分，按11:8正好四拍；下部二分的q2落在快组中间 | 再加11:8通常收益有限。先前“四分看成八分”会制造假缺口；补分母或改间距都不能补救这种识别错误 |
| **J05，A005 p136 s5末小节下部，F** | **比较只罩前三头的短3括号。** 三个十六分三连与末普通八分共主梁，3只作用前三；内梁断口提示恢复，短括号能直接排除尾音 | 多一点线条；不必把普通尾八分拆出主梁，也不需将正常3:2另外印全 |
| **J06，A077《Kizuna Music》p3 s1、E前** | **比较只罩后五头的短5括号。** 第二拍先四个普通32，再五个5:4的32；共同主梁保存整拍动作，局部括号保存后五头的分法 | 破开主梁会削弱连续动作；把5括到九头又改了含义。完整5:4标签单独不能画清边界 |
| **J07，A071《JANE DOE》p2 s4、D前第二小节** | **比较首次说明5:6十六分。** 9/8里两组各五个双梁成员，每组占一个附点拍，之后附点四分。当前写法采用扩张比；p204／207支持明确这类关系 | 说明后不必每次重复完整比。另改写成五个八分5:3是独立记法选择，会改变梁层和视觉密度，应另列比较 |
| **J08，A005 p152 s1末小节，F** | **比较将最后10首次写成10:6。** 前两组六连各占1q，10组占1.5q，末普通八分占0.5q。前两组建立的四分跨度在10处发生改变；明确比例比再加范围括号更切题 | 10:6没有授权把其它普通尾音纳入。若只因数字大便给所有完整组加冒号，会连J02–J04也一起过度标记 |

J08的10:6也出现在Gould p206的复合拍表，但本处前两组六连的局部四分跨度和整个四拍上下文需要分别读。不能仅见1.5q便认定整段已变成复合拍，也不能反过来将11:6／10:6在所有作品里都称作同一种异常。

## 为什么简洁与清楚会给出不同答案

J02／J03的边界由整个小节和完整梁共同承担。目光只需认出“在这段时间内走完这一组”；再印分析比值未必减少跟读成本。J04在普通四分之间有独立的完整组，前后值及下部参照能直接校核。

J05／J06则是另一种阅读任务：同一主梁里发生了普通／连音的转换，读者需要知道哪些头受数字约束。短括号对准这件事，保留大梁的整拍轮廓。把所有数字写成完整比值却不限定成员，仍留下原来的范围疑问。

J07／J08的成员本身已有各自完整梁，主要负担在“这组占多久”。首次说明能建立关系，后续同型重复再沿用既有体例。单纯把组画宽或画窄，不会使音值和占时变得更明确。至于是否真的需要改写，须与已有读者熟悉度、谱面空白及前后的一致性一起比较；本页没有生成原生替代图。

## 实际审谱时怎样用

1. 看完整小节及前后拍组，识别普通前尾音、休止、和弦、tie接收、梁层和正常／小音身份。
2. 找出组成员和总时段：整小节、完整拍还是拍内局部；把可计算的分析比值与纸面显示分开记录。
3. 先试能否有理由保留。不能仅以“大数字”“分母不是2的幂”“有休止”触发修改。
4. 范围缺信息时比较短括号；占时／单位缺信息时比较首次比例说明。两者都缺时分别说明，不靠一条大括号包办。
5. 若音值、另部参照和整小节无法同时闭合，先记具体冲突。A005 p51 P的两个6仍属待核的另一类情境，不能把本页“整小节等分可省比例”拿去掩盖不闭合。

对未来自动净书，这些是判断前提与正反例。本阶段没有新增MCP／插件／本体能力，没有把PDF比例推读登记成已核原生字段，也没有向任何原谱写回。
