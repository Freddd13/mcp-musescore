# WORLD／Reason：稳定活动、再现变化与真正的范围问题

2026-10-30，单代理回查A129《the WORLD》七页41系统、A130《There is a Reason》六页36系统。13张整页、52张双表系统细图、九张歧义／扩大图及Gould20张完整页均实际查看；共94张不同图，33复用、61新图。[证据](world_reason_closeout_evidence.json)记录来源、图页、144条头原点、132个内部间距及17项有理时值配方。Gould均为复读，新增覆盖0；原PDF、用户工程和教材只读，无新原生候选或软件适配。q以下指四分单位，页／系统从1计。

**本批最有用的判断：先认活动层和真实梁端，再评整齐。** WORLD的稳定八分与Reason的连续十六分可以保住跟读步幅；主题再现若换了伴奏密度，不能照搬宽度。完整梁中的连音数字已经交代范围；真正的部分梁才值得补短括号。下面的阅读收益是本线解释，未获出版者亲述。

## 1. 活动层可以稳定，慢线仍按自己的时点读

**保留WORLD I的连续八分。** p6s3四小节上表各八个普通八分，4＋4分梁、每小节一条较长句弧；32次上部时间事件的28个内部原点距约14.328–14.526pt。下表另有上干旋律和下干保持／切分：第一小节上干为八分、八分、四分、八分、四分、八分，合4q，并未随上方八个头一起重新起音。

读者能用上部反复轮廓持续向前，同时由下部干向、符尾和tie看清长短及接收。把稀疏一层均匀铺成自己的六格，会破坏真实同时点；按上下两表总黑度反复伸缩八分，又会打断稳定运动。Gould p40、43、490要求结合时值、附加符号和密集层安排，不把每个谱表分别排齐。跨小节距离另有小节线预算，本次量值没有混入它们。

**Reason p4s2与p6s1的四小节快速层，各为八分休止＋14个普通十六分。** 两处共112条头原点，104个内部距：没有临时号的普通格约7.254–7.452pt；两处第三小节各有两格扩大到约12.4pt，对应上行中的升号前缀。相邻慢线、下表和弦及加线仍占自己的空间，不能只挪某一只手消除宽格。

这说明成品也会保留局部不均匀。这里有明确可见的占位理由，普通格又恢复熟悉步幅，因此优先保留；需要优化时再查真实墨迹净空，比较能否在共同时间轴减轻最大失衡。原点距不等于墨迹净距，更不证明12.4pt就是软件最小值，不能据此认定某引擎优劣。

## 2. 相同主题不必拥有相同的小节宽度

**Reason G／J再现要保主题识别，也要尊重伴奏变化。** p4s1与p4s3的低部常是首四分加六个八分，共七次时间事件；p5s6的J及p6s2则进入十六分运行。上方相近的切分和弦，不代表两段完整织体相同。前段可以凭较简洁的低音运动留出呼吸，后段需要让快速轮廓容易追踪；统一每小节宽度会把后段挤压，统一所有段的最密格又会把前段拉散。

p4s2及p6s1的快层由2＋4＋4＋4个十六分组成，最初八分休止为慢层留出进入；p5s4首小节则是四分休止＋12个十六分，以三个四音组进入。它们有相似弧形，但不能因外形相近便补成相同音数。上梁与内层下干之间的长度差帮助分层，不统一干长；分手括形的任务也与拍组、句弧不同。

Gould p153、155解释4/4半小节层次，p311–312区分独立节奏与附加旋律指示。WORLD I的下部和Reason D／快层下的慢线，应先判各层任务，不能先删“多余休止”或给所有附加干补满整小节。两者的例外条件须分别核，不把稀疏或干向直接当作某只手。

## 4. 跳转来路、提前力度与引导线都在帮助接手

**WORLD先走实际路线，再检查开放tie。** Segno／A在p1s1第三小节；To Coda在p1s4末；p4s1末印D.S.，返回A，再到To Coda跳p4s2首Coda，之后接E与后半曲。首次到To Coda仍顺读p1s5及B–D。引子末与D.S.末均有通向A接收的延音，To Coda末则既有首次顺接、又有跳到Coda的来路；不能按纸面相邻两行配对，或把行末开放弧一律删掉。

A在行中，Coda独立从新系统开始，E又在同一系统中部；这些位置分别服务于路线落点和后续主题。Gould p238–240支持把回跳指令明确为D.S. al Coda，以及让目标显著可寻。这里可优先比较补全回跳措辞；Coda轻微缩进／A另起系统的收益再和全页预算比较，不强制所有标签到行首。静态路线已核，实际展开播放与物理翻页尚未核。

WORLD p4s2的mf在E前最后八分，随后tie进入E；Reason p3s1的mf也在E前最后八分。它们给引入动作新的力度，不能为视觉对齐把力度推到字母下。Reason p1s6的pp、p与后来mp，以及WORLD p6s2末上部p／下部mf，也应跟各自层和时点读，不合成全钢琴同一入口。

**Reason p5s2末至I有跨系统虚线引导。** 它从上表末音指向下表带括形的接手，I末又引向下一系统上部；形状在告诉读者线条去哪里，不能自动当tie、slur、gliss或碰撞噪声去掉。保留不同线条的任务，清楚度需要时再调整局部通道，精确软件对象身份仍待工程核查。

## 5. 干奏、踏板、八度和结尾各保真实范围

**Reason的secco不是全曲不踏板指令。** C在p2s2以干奏重复低音开始，p2s3明确加入Ped.／释放与simile；I在p5s3再写secco，下一系统改为con Ped.。这些变化塑造同一旋律的干湿和层次，诊断不能合成连续踏板，也不能把后来的Ped.当作违背整段secco而删除。踏板可改变听感，不能用它抹掉写出的休止或推断每根手指的释放。

长8vb、局部8va和短低八度角端另按实际谱表／范围读。Reason C低部两层同表，不能因不同干向擅定只转置重复低音；按Gould p324–325，若作者意图存在同时原位层，须有明确区分后再改写。K上部8va在首二分和弦后才收角，后面sfz八度已恢复原位；下部8vb继续跨到最后系统。上下两条线不互相替代，也不因换页／力度自动结束。

Reason p5s5中间小节为两个全音符端点的三划交替震音：共同覆盖一个4q时段，不能加成8q或按两颗普通全音符均匀排开。Gould p224–226区分计量／非计量震音及共享时段；源谱没有在此证明精确32细分的播放率。前小节的四分接收、八分三连、两组六连十六分合4q；后面gliss与高音延长各有角色，不把它们合并成自由小节。

WORLD倒数第二小节上部是四分和弦、两个四分休止、末四分琶音和弦；下部为两个八分、八分休止、两个八分、八分休止、末四分，均4q。末琶音后tie到最后全音符及fermata，空心错头仍属和弦，不能删“重叠头”。Reason末尾三小音、pp终和弦及低部跨小节延续分别保留；上部和声改变不代表低部一定重奏，具体小音借时仍未由PDF确定。
