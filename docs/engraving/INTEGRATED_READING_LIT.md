# lit五变奏：相同主题怎样保持不同的阅读任务

2026-10-23，A006全5/5页整曲复读，另看七处两表上下文及Gould p200、203–209完整图页。之前的换谱号研究和逐谱笔记保留，本次补整曲关系，不算陌生skill评测或原生候选。定位采用PDF页、自上而下系统及行内小节；源文件只读，[证据](lit_whole_reading_evidence.json)记录实际看图及与旧账本的关系。

## 1. 先认出每一段要求怎样读，而不统一密度

这些是可见构型及规范支持的阅读解释，不是出版者制作过程的自述。原PDF没有可编辑voice、精确播放或手工调整记录。

## 2. 主题的拍子、标记与系统边界各有时间

曲首实际是**八分音符=70**，不能把70直接记成四分BPM。主题第一行四个6/8小节后，在行末预告3/8；下一行先完成一个3/8，再恢复6/8。短小节是音乐的一部分，不是为了行宽而少写半小节。末系统Theme回归也要按本地时值读，不能由标题认定完全照抄。

上部常见的八分—八分—附点八分—十六分，与下部十六分起音、八分及tie接收一起组织复合拍。两层实际节奏不同，邻近头距不能只按一个字形序列比较；tie接收也不是新的攻击。时值附点在头后，奏法点按所属音／部在上下方，二者不能为了“整齐”共用一条横线。Variation 2把这种差别放大，更适合作为识别任务而非统一点位的目标。

## 3. Variation 3的5／6提醒：先算完整小节，再谈均匀

p2第五系统首小节，下部依次是6、5、6、6四个三十二分音组，在既有6/8内接续；相邻组的头数不同，上方还有错开的进入与持续。**不能从一个5就套用ninelie J的5:4**：若所有四组都按单拍5:4／6:4读，总跨度对不上此处既有6/8。

按四个等跨度半拍组理解时，每组占3/16，六个普通三十二分正好填满，五音组相应为5:6的展开读法。这是由全小节、书写单位和相邻材料作出的读法推导，不是取得了原工程Tuplet字段；PDF也未在此印完整比值。因此本线把**比例是否需明确、六音数字是否为分组提示**保留为记法回查项，不将推导默默写入工程。

Gould p203–207区分收缩体例、展开体例与复合拍，p207要求非标准或易混的比例明确交代。它给本例一个有用问题：初见者能否从上下文可靠知道分组跨度，而不只是“数够五／六个头”。要改成完整比值或另一套书写单位时，属于记法提议，还要比较额外数字、梁层和密度的代价。当前不据此宣布官谱错音，也不假装验证过全部组的播放。

本轮补看的p208–209继续说明：若整段跨度本身不规则，等分与比值的书写还须说明所占时值，不能在组前多放一个看似独立声部的长音来当标尺。慢速或合奏需要时，展开计数可能优于压成少数头。教材表里的“实际节奏”是时值说明，不能照抄为所有钢琴运行都要拆tie。

## 4. 同一运行怎样随上表角色改变书写位置

Variation 3起始还没有持续和弦占满上表，部分组可跨到那里，保持连续动作；p3上部逐渐有长和弦和旋律，运行留在下部并局部换号。换号是在解决另一层已占位置后的音区识别问题，不是简单违反“少换号”。代价仍包括读者重设音高参照及短组内干扰，不能由“出版谱这样做”免去逐处比较。

p3第二系统的8va从后部开始，次系统以括起的(8va)提醒并很快结束；这与下表的高／低音谱号各自独立。续行字样不是新八度动作，谱号恢复也不等于八度恢复。既有[换号研究](CLEF_READING.md)与[八度阅读](OCTAVE_READING.md)提供规范和原生反例；本轮保留其条件，不新增本曲的软件范围结论。

p5六音运行又处在不同上下文：下部有长低音背景，活动组中局部高音谱号，上表有自己的持续与运动。不能因为同是六音组，就将Variation 3的跨表路线复制过来。下部一条休止也不代表整位演奏者空闲；实际手、层与谱表关系仍需独立核。

## 5. Variation 5的三连、长弧和末7组是三个层次

p4第二、第三系统下部每个三音小组独立标3，较长弧线又按更长动作包住若干小组。短组帮助识别内部脉冲，长弧帮助追踪动作；不能让一条长梁／长弧代替所有层次。重复数字是否可省可另议，但这是减轻墨迹与避免跨行／变化后重新推算之间的取舍，当前保留，不直接批量删除。

p4第四系统末的上行7组，前两组由各自梁组和数字说明；末组还有括号，不能当“样式不一致”删去。放大图及PDF同型黑头的位置核到，运行是**7＋7＋5个黑头，后接一个十六分休止**，不是三组各七个发声音。最后五个三十二分与十六分休止合为七个三十二分单位；因此边界与时值必须一起读。Gould p200区分完整连音梁、梁只部分属于连音及延伸梁包休止的情形，支持在有歧义处保留说明。

这也限定了空间判断：休止实际占两份单位，不能把最后五头到休止的所有距离要求与前面的七个等值头完全相同。另一层还有自己的三连、长值与跨行连接；要做原生候选须先取得明确配方，不能按这张PDF只抽头坐标便声称音乐保持。

## 6. 回归、页面与当前保留判断

各变奏标题都给出入口，但没有强制每段另起一页；Variation 1从p1中段开始，Variation 3在p2下部，Variation 4在p3下部，Variation 5从p4第二系统开始。前段可以自然结束，后段又有标题、织体和动态共同定位。另起页可能使结构更醒目，也会增加页数、留白及翻动，需要同输入比较，不能只看一个整洁的段首裁图。

通常奇数右页装订时，p3→4才涉及物理翻页，p4／5在同一展开面；其它媒介另判。p3末端延长号和持续低部并未独自证明手可空闲，当前没有试奏／打印或装订验证，不把它报为确定分页错误。

此次有理由保留的是各变奏不同的密度、持续与重奏、梁／弧层次和必要换号；值得继续核的是Variation 3非显式比例的初见读法，以及实际翻页条件。没有新增原生替代、用户偏好选择或软件成因判断。不同字体固然影响字形，**同一字体下这些阅读任务已经不同**，不能仅靠换字体或全局间距参数统一解决。
