## 具体认识及应用

| 情境 | 本次读到的依据 | 对净书判断的用处 |
| --- | --- | --- |
| 圆／方括号 | PWM以圆括号记小型真实异文、方括号记编辑补充；HN862以圆括号记编辑补充、方括号标来自次级来源的补入 | 先查本版图例，不能把括号统一识别成可省音或提示音 |
| m9及类似处的一条弧 | Henle结合原稿图说明，上表弧也作用于下表伴奏 | 几何靠近哪一表不足以确定作用层；避免为“补齐”给另一表再造同义弧 |
| m26–27的连接 | 两份评论都讨论tie在传承中被误作分句弧的问题 | 先核是否延续同音及来源说明，再安排弧形；长短或跨小节本身不决定类别 |
| m103–105的末拍 | PWM把初版加入和弦理解为作者修订；HN862在103–104保手稿，并对105新增和弦提出刻谱错误判断 | 这是编辑选择分歧。选定版本前不补齐音／休止，也不把差异归罪软件 |
| m179的对齐 | PWM给出解释谱例，结合手稿位置与约略时值讨论演奏 | PDF列位置可参与解释，转成严格同步前仍要核实际计量；勿先按等距目标挪头 |

这些条件解释了专业版本为什么有时保留看似不统一的写法：它还在传达来源、可选读法或特定声部关系。布局优化要让这些信息更容易分辨。两家对m103–105的解释有实质分歧，当前保留分歧，不按出版社数量投票选“正确版”。

共享弧的阅读收益，可解释为把两表伴奏作为一个动作，并省掉重复线；代价是读者须识别该约定。真正独立的层仍应分别表达。版本选择还会改变音符密度：比较软件间距前，须先对齐音乐输入，避免把不同音数的空间需求误当排版优劣。

用于本项目时，先记录作品／版本及本谱定义，再把问题分为音乐编辑、记法表达或几何排布。音乐选择未定仍可指出碰撞、归属和局部空间问题，候选须保护当前读法。例如m97的C5音头括号继续保留，其含义按作者定义；不因本次某家括号约定直接改写它。
