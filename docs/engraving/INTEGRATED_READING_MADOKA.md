# Madoka组曲：换一种材料，重新安排读谱的重心

2026-10-23，A085《Madoka Magica - Piano Suite Medley》全部10/10页综合复读。近看12张新上下文裁图（其中两张扩大以补全低音），并复看已有速度细图；核Gould印刷p153、155、184–188、305、307、310–312、490、560共14个旧图文页。全页图与教材图均复用，没有重渲染整套材料。承接[首轮逐谱十五](corpus/READING_015.md)与[速度专题](METRE_TEMPO_READING.md)，不是新的独立或盲测。[证据](madoka_whole_reading_evidence.json)保存来源、实看范围及未解项。

本轮补全的是不同织体、入口、持续、手分配和行页预算之间的关系。E的单位与m92等式疑问早已记录，本次只复核，不再当首次成果；下文的阅读收益是本线的解释，不冒充出版者的实际制作理由。原PDF、用户MSCZ及软件只读。

## 2. 整齐不等于删休止，也不等于每层补满休止

**p3 m58起的C。** 上表下干部有慢旋律和跨小节持续，上干部的和弦则常在第二拍进入，第一、第三拍有休止。较高的休止看起来占空间，却帮助读者把这一层读成有自己出入的节奏；不能把它们全当软件填充、藏掉后宣称清爽。m65等处角色又有变化，应沿前后句确认，不能固定追同一高度。

Gould p310–312要求把自由附加材料、突出旋律的附加干／梁、真正独立的节奏分别处理。两条独立节奏在同表时，休止帮助交代完整时间；只为突出旋律添加的干则可以不增加休止。**判断依据是该层在做什么，不是软件里用了几个voice。** C的周期性出入有明确计数作用，当前保留。

**p5 F与p6 H提供另一种条件。** F下表有上／下干与梁，低处还留长音；H上表的快型中又用另向符干和tenuto突出较慢材料。Gould p311允许在完整快速音型已交代真实时值时，用附加梁突出同时的旋律，某些传统写法的附加值甚至偏重轮廓便利。不能只把这些上、下两套头各加一遍时值，便报小节超时；也不能据此断言本谱所有附加头都是省写。

本轮没有逐头重建F的全部持续配方。可确认的是慢线／填充／低音的不同读法和再现，不能把所有共同头拆开、把每层塞满休止作为默认修正。需要编辑时，先从可编辑输入核真实时值、连接、重复型及附加层功能，再选择保留或单列记法提议。[同音附点](UNISON_DOTS_STUDY.md)和[持续与休止](SUSTAIN_AND_RESTS.md)中的原生反例仍适用，不能由本谱外形直接推内部对象。

**p6–7的实斜线也不是缺了弧度的slur。** m123末到124、m125／127及m128→129等处，有斜线接续慢材料的跨表走向，旁边仍有普通slur、tie与tenuto。Gould p307更偏好显眼的虚线，避免实线看成glissando；本谱采用实线是应辨认的体例差异。有误读风险时，可以比较虚线候选，但须保住端点、交接与所有连续片段，不能只换一段漂亮裁图或套用滑奏播放。

## 3. 拍组、速度单位与真正同时分别核

p3下部六个八分在3/4中常连为整小节长梁。Gould p153允许2/4、3/4的较长八分组，同时警惕写成容易误认6/8重音的形式；p155又明确不同拍号的分组。这里有3/4、另一层逐拍出入和一贯音型作参照，不能因为看到六个头就改成6/8的3＋3，也不能把这种长梁复制到后来C拍号的所有运行。

**m92的等式保持未知。** 左边二分、右边附点二分，整串在新C拍号后，未印方向箭头。Gould p185–186所述体例差异仍成立：左旧右新会得新四分为旧四分的3/2，反向解释则为2/3。Calando、之前rit.或后面accel.都不能单独消歧。没有本谱说明／音源，不把式子改成自己觉得合理的关系。

**E／m96是附点八分164。** 本轮整页初览仍容易漏看旗尾；较大上下文图和已有细图清楚支持旧记录。其名义等值为四分123、附点四分82；这只是单位换算，不是测得的演奏速度，也不证明m92方向。不能按12/8常见大拍习惯写成附点四分164；将这些小音符当普通文字附件，会带来两倍的错误。

**p10 m186–189的三对四。** 下部每拍三等分的八分三连与上部普通十六分位置相对；上部快层在某些拍首还有休止，另有慢音在拍首保持。两手有共同拍界，内部第几个头却通常不同步；“相同序号对齐”会改读法。m190–191上部音型又换了，不把前四小节当整个尾页的唯一时间网格。

m192–193继续有低处长音、跨表运行，六连之后末尾还有三连；数字、梁数、完整组时长需共同核，不将所有6当同一持续范围。当前保留这些细分与共同拍界，未由静态PDF测出整个异分段的误差、完成逐音校勘或定位宿主缺陷。[连音](TUPLET_READING.md)与[间距取舍](SPACING_DECISIONS.md)提供后续可编辑复核方法。

## 4. 行容量为什么从六小节变成两小节

按印刷小节号与可见小节线逐行复核，59个阅读系统、201个完整小节及开头弱起。该数只是容量描述，不是逐音内容校对。几个有用的对照是：

| 位置 | 行内容量 | 阅读理由与不能推出的结论 |
| --- | --- | --- |
| p1 | 标题后5行，前段有一行6小节；末两行各5小节 | 疏旋律、3/4与有限符号让容量较大；不能因此推荐所有钢琴谱六小节一行 |
| p2 | 6行，每行5小节 | 伴奏与旋律型已经熟悉；后半反复换谱号又有确认成本，需和轮廓一起衡量，不能以加线少宣布一定最优 |
| p3 | 6行，每行4小节 | 多层出入和完整伴奏，比前页需要更细的阅读通道；这是内容变化，不是发现一个四小节模板 |
| p4 | 前3行各5小节，随后3、2、2 | 过渡、绝对速度入口及密集12/8逐渐改变横向需求；E仍可留在行末，下一行继续其新组织 |
| p5–6 | 每行2小节 | 12/8本身比3/4每小节的四分单位多一倍，又有密集运行和叠层；小节数、总时长与符号密度不能混作同一指标 |
| p10 | 4、3、3、2、4、4 | 异分／跨表运行需要较大宽度，M的较长值和最后休止又允许增容；不同系统不必同一小节数 |

Gould p490的逐拍密部优先，可解释为什么F中下部活动、H中上部快型及后来的角色交换，不能只选“右手间距”或“左手间距”为整曲模板。对照应先核正确时间列、必要符号和整行预算，才评价不均匀；本轮没有量A085所有内部间隔或证明现有分配已经最小，不能用“音乐很密”给任何宽格免责。

新段也不全部另起行：m20、A／m24、E／m96、J／m146、K／m164及L／m176都可以在行中；C／m58、F／m104、G／m112、H／m122、I／m138、M／m194又有明显行首定位。强制全部入口换行会重新分配前后行和页高。反过来，若来回寻行或标题挤压确有问题，另行仍可比较；当前未重排，不能说行中一定更好。

## 5. 准备、进入、保持和终止各有边界

**m20与A。** m20已经开始新速度和伴奏，A到m24才加入主题。上表四小节休止有准备／等待作用，不是可压掉的无用空白。按154的名义四分速度，四个3/4约4.68秒；它距实际p1→2边界m27→28尚有主题材料，不是当前页末自翻窗口。

**m145→146。** 前一12/8长和弦有延长，低八度通过两条明确tie接进J的C拍号。新前景先有两拍休止，下部在第三拍有两个八分，上部到第四拍才有两个八分；p位于这次新进入附近。停顿后改变拍号／速度，并未要求低音重新起音。若把所有材料、p与J统一吸到段首，或因上表先休止而隐藏整张谱表，都可能削弱等待、接续和进入次序。

**m160–164。** 先保持，再于m162伴奏accel.，K及其四分142在m164出现；不能让新标题追着第一颗音走。下表m.d.与括形涉及局部低声材料，Gould p305允许以文字／括形明确另一手所取的音，p307又区别手分配与跨表声部引导。不能把m.d.扩成整个后续下谱表的演奏手，也不能把括形当装饰删掉。本轮未建立完整触键方案。

**m198–201。** 上部保持／rit.与下部六连还在发展，m200的sfz及下部tie接收后，m201两表是带延长号的整小节休止。Gould p187–188将延长的承载对象分开：休止上的等待不等于前一和弦继续保持。当前保留终止后的等待，不将最后符号搬到最后有声音的音上；精确释放、踏板共鸣和停顿秒数仍须作品／演奏说明。

顺序阅读的行页漂亮，不等于实物可以自翻。按首音乐页在右的通常双面装订假设，p1→2、3→4、5→6、7→8、9→10才涉及实际翻动；m27→28、81→82、115→116、140→141、181→182两侧均仍有活动。Gould p560要求把真正可用的休止按速度换成时间，并核手的占用；本轮没有认证自翻窗口。C在p3页首的视觉定位也不证明它为了翻页而设置，媒介与装订仍未知。

## 6. 下一次遇到相似问题怎样用

先沿整曲找相似材料的初述、变厚、交换和恢复，确定当前注视轨道；把节奏独立层与突出旋律的附加干分开，把速度单位与数字一同读出，把准备和到达分开。再评价梁、弧、休止、符号净空和容量。需要替代时，同时保留前后层、页界和原方案，不从一张漂亮裁图推全曲预设。

当前保留C的独立休止、F／H的分层线索、不同密度的容量、段前准备、m145跨换拍持续及末休止。可继续研究p2反复换号的取舍、实线引导是否值得改虚线、密部空间是否有可重分余量；这些仍是有条件的比较题，不是已判定的软件bug。m92体例方向、完整手法及全曲播放／音高未校勘问题保持。
