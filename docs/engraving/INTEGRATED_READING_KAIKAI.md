## 2. C与G：相似音型帮助读者预判，变化仍要清楚

对照p2第4／5系统与p4第2／3系统。C／G首系统都有反复的上层短形、插入的上干和弦、下层运动和跨小节tie；下一系统仍有相似的上层起落。读者第一次学到的组形可以在后一次继续使用。

但下一系统的下层并不照抄：G附近低处八度、更高的填充位置和连接轮廓发生变化，上表后部的和弦构成也不同。因此当前判断是**保持可辨的组形，按实际内容分配空间**。不复制前一次全部坐标，也不为了每行黑度一样而削掉增厚层。这里没有逐音证明两段完全相同；相似的边界、梁组与持续关系已经足以成为比较入口。

这也解释一种“板正”：读者能预期从哪里进入一组、沿什么轮廓看下去、哪一层仍在持续。必要变音、不同干向和另一手的新细分可以占用额外空间，仍应尽量少扰动可重复的阅读线索。把变音净空压没，或把整段都摊成最拥挤时点的宽度，都会付出代价。相关依据与真实间距候选见[间距取舍](SPACING_DECISIONS.md)、[实曲迁移](SPACING_TRANSFER.md)。本曲没有测出唯一间距原因或试出参数。

H至p5首系统提供另一种分层：较慢上层多用上干，连续较短音用下干／梁；较长slur追踪外层轮廓，局部tie只连接须保持的音。它让厚织体仍有可追的线。若统一干向或把所有弧画成相同高度，即使黑度更整齐，也可能抹掉这份层次。字形和线重会影响观感，却不能替代这些组织。

## 3. E／F：长短演奏说明不能误判为变速

放大p3第4系统E上方：左边是两个十六分音符，右边是同一三连组内的**八分＋十六分**。右边第一音只有一层梁，第二音带第二层短梁；上方3和括号属于这串小音符说明。它解释直写十六分如何长短摆动，不是“旧拍＝新拍”的整曲速度改变。

两边总量可独立核算：左边`1/16 + 1/16 = 1/8`；右边`(1/8 + 1/16) × 2/3 = 1/8`，内部示意为2:1。p3末系统F边界附近又印两个十六分＝两个十六分，结合E的既有定义，可以理解为恢复straight读法；不能因为左右相同就当无用文字删除。PDF没有提供其工程播放、精确挂接对象或每层生效范围，不从字样x补出这些数据。

阅读收益是用一次解释保留简洁的正文，同时让长短关系和恢复处可找到。代价是读者必须记住这条局部解释，所以范围、恢复与其它真正的连音不能混淆。E附近正文仍有显式三连组，不能把它们自动再乘一次swing，也不能把整段普通音符都重写成带3的音符。

这对间距研究增加了一个前提：**通常的书写时间位置、约定的演奏长短、实际导出的播放时点分别核对**。不能把演奏2:1直接当符头横距2:1的要求；演奏时间也不是通常乐谱排版的逐毫秒横轴。先辨识当前记法，再按拍组、共同位置和符号净空组织，特殊比例记谱另查。这个判断不否认真实严格连音需要按实际比例对齐。

[MuseScore 3官方Swing手册](https://musescore.org/en/handbook/3/swing)也将swing播放、可见图形提示和Straight恢复分别说明，支持将“看见说明”与“工程已正确实现”分查。这里没有在当前MuseScore分支验证其实现，不以旧手册对图形输入的限制推定本体仍缺功能。[换拍与速度](METRE_TEMPO_READING.md)中的真正速度关系案例与本处应分开。

本轮复看Gould印刷p185–187的完整图文，确认那些段落讨论的是变速等式及其摆放；不能仅因E有等号就套用。全书文字关键词定位没有获得可核的swing规则正文，未据此声称Gould没有讨论，也不把搜索当通读。此处解释主要来自实际音型、前后恢复及上述一手手册。

## 4. 行中入口：保留过渡与进入的因果关系

B前运行在同一系统里走完，接B的重复型；I前的高处强和弦收束与I的弱起环境同处一行；J前的渐弱和短音型把注意力引向新质地。段首本已由字母、双线、音型和力度共同提示，另起行的额外醒目程度未必值得其预算。

这些位置的共同收益是读者能同时看见“怎样到这里”与“接下来怎么读”。如果为每个字母另起行，需要重新分配前行、系统头和页高；可能使过渡小节过松，或把代价推到后页。反过来，真正难找的入口也可能值得另起行，不能把本例固化为“段首永远放行中”。Gould p487的有条件另行建议与[页面层级](PAGE_HIERARCHY.md)及[实际分行试验](PAGE_FLOW_STUDY.md)可联合使用。

I尤其说明，段首、旋律发音和长值背景不必同一事件：新环境中下表长值已开始，上表先休止后运动。不能为让字母对首颗上表音而把它挪到后面，或因下方较空就隐藏这条建立背景位置的谱表。

## 5. 首尾呼应：组形相似，计数和结束动作不同

p1引子首小节3/4，上部三组三连音、下表整小节休止。p6倒数第二小节仍在4/4语境，上部是**四组三连音**；下表有前音的持续及后续运动。首尾的高处重复组带来识别感，但不能按“再现开头”复制前三组的数量、整小节时长或空表处理。

末小节上部整小节休止带延长；下表还有低处的八分音符，随后是八分、四分、二分休止，最后的二分休止承载延长。上表整休止与下表二分休止的时值、起点不同，即使两个延长在纸面相近，也不意味着它们是同一类型的休止或全小节都无人发音。不能把下表改成整休止以求对称，也不能以此自动给出可翻页时长。

保留拍组三连数字、低处结束动作和最后等待，比把所有末行空白压到统一长度更有根据。末行疏密仍有风格取舍；本轮没有替代渲染，不评价哪一版用户更喜欢，也不提出全曲末行拉伸值。

## 6. 作为以后自主诊断的做法

1. 先在整曲建立术语、读法说明和持续范围；首尾／前后变奏对照时，重新读实际拍号、进入和变化层。
2. 找可重复的组形、慢线和动作边界，解释它们怎样降低寻找与跟读成本。稳定的线索可以保留，逐音坐标不直接复制。
3. 间距疑点先分书写单位、真实连音、swing解释、共同时间位置和必要符号空间，再提出局部或整行候选。不要由演奏音长比例生成排版比例。
4. 行中段首先看已有导航和前后联系；确需另起行时，比较过松前行、系统头及后页代价。没有替代版时只给理由与待比方案，不称已优化。
