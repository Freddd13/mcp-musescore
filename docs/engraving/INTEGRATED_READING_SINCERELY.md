# Sincerely：把空间留给正在辨认的那一层

2026-10-24，A113全9页、16处局部及3处高分辨率核查。**本轮判断以保留为主：多声部干向、跨表接续、震音缩写和随内容变化的小节宽度都在帮助跟读。** 最可迁移的经验是，行容量、某个复杂小节的宽度与两谱表间距应一起考虑；先找到读者要跟的线，再分配空白。

原件为用户新官谱目录的Sincerely - Violet Evergarden Opening Theme.pdf，SHA256为e9dc32eddcd18df30310564566f0512725e64924c02c04ea6c20ad30d976b990。原谱与教材只读，图留本机；[证据](sincerely_whole_reading_evidence.json)记录完整页、局部、几何及本轮Gould六个新实质页／两个标题目录页。以下小节号为本线从1连续人工计数。

## 1. 哪条线该突出，不能只看最高的音

引子p1 m9附近，较高长层的p与下方进入层的mp分别安排；A的上部型标pp，后来下表进入的旋律另标p及接手提示。它们让读者分辨背景和前景。将同列附近的力度合并，会丢掉层间关系；将所有标记拉到两表正中，又会让归属更难认。

D=m76延续同样的角色意识：上干短高组有自己的短弧、休止，下干旋律按较长时值和tie连续，下表另有低音／和弦。前景处于快组之下，长短弧跟不同层。这里应保留独立休止；它们交代进入和等待，不能因其它层仍在响就删除。Gould p312的条件是两条节奏独立线各自交代计量，短暂附加层和单线跨表又有省写条件。

G=m126以较疏组织重新出现；K=m217回到高组叠旋律并加重低部奏法。相似材料保留熟悉轮廓，和弦、低音及力度的变化仍要读。再现可以帮助认型，不授权复制旧段所有位置和省略。

## 2. 梁保持组形，弧追较长的线

C=m60、F=m110、L=m233的连续双梁十六分，以四音组为基本参照。C首组内部音更靠近上梁，使用平梁；后面升降方向明确的组允许浅斜梁。D的高组也较平稳，小短弧在外侧另说明局部动作。

复看Gould p21–23：首尾、靠梁内音、重复型和实际谱面位置共同决定梁形；音域折线不应直接复制成梁坡。**保留平、斜交替的局部处理。** 全谱抹平会丢走向并拉长某些干，逐音追随音高又容易形成锯齿黑边。已有[梁干原生例](BEAM_STEM_STUDY.md)提供两类代价，本轮用实曲确认适用情境。

p3 m71的虚线导向下表长音，和快运行的梁、外层弧各有任务。E=m88后，下表上行的连续材料进入上表，外部长层仍独立；p4又用谱号帮助读后续音域。这些接续信息值得保留。若把一切都固定在一只手一张谱表，会增加加线或拆断动作；只收窄表距又可能挤掉提示通道。

## 3. J第三行：一个小节可以多用空间

J=m185先用慢旋律与下表两音震音建立背景。前两行各六小节；第三行m197–200只有四小节，末小节有3、5、6组及继续跨表的写出运行。

PDF的该行边界为x36.234–558.918pt，末小节从361.188pt开始，跨度197.730pt，占整行边界跨度约37.83%。前三小节共同使用其余空间。这里比较的是小节线之间的预算，行首段还包含谱头。

**保留这个不等宽分配。** 前三小节靠长值、装饰和持续背景读，最后一小节要辨多种细分、上下行与跨表到达。四等宽会使末小节少约三分之一的横向预算，另三小节则更空。后续候选可以研究是否仍有可压实处，等宽本身没有给出阅读收益。

同一行的两表边缘空隙约8.58sp，为本谱所量最大值；全53系统约6.00–8.58sp。同页相邻系统的谱线边缘空隙约14.45–15.17sp：系统内随内容让位，系统之间仍有稳定分隔。数值来自各行十条实际谱线，不含文字外框，适合作为参考关系，不能直接复制成用户全谱参数。

C起行p2第6系统、下一页第1系统及L起行p8第4系统，都用四小节且小节边界完全相同：36.234／183.222／308.412／433.602／558.918pt。它们给相似快运动一种熟悉尺度；下层材料不同，内部每个头位仍须分别判断。这也说明局部重复的秩序可以与全曲不同的行容量共存。

## 4. 缩写、留声与真实重奏分开读

J初段两音震音以整音符头及三条连接表示，各头共同代表这一段持续，不能当成两个依次奏完的整小节。后面有普通低音接附点长值震音、半小节成组及普通写出运行。Gould p225、229解释了两音端点的共同持续和跨值slur；p223–224又提醒明确节奏与不定速重复的区别。三条连接本身不能给出本曲精确播放速率。

m200的写出变化后，m201开始ff pesante的慢和弦主题，下方仍用重复背景并出现局部8vb；K再回到普通活动织体。应保持这些技法边界，不沿用震音状态到后面的普通音。若把整片背景全部展开为短音，会增加黑度和逐音计数；若反过来把有轮廓的运行缩写，则会丢掉变化。

p6末系统m177–184，上部渐弱并calando；下部完整tie与开放留声弧后接休止，Ped.及末端释放另提供共鸣参照。Gould p337支持方便时值加踏板范围，并可用开放弧帮助读者识别持续。**保留这些开放弧与休止并存的组织。** 不应补接到附近任意音头，也不应为了“干净”把弧和踏板提示一并删掉。

N=m269标a tempo、ppp及cresc. poco a poco，上表短暂换低音谱号再恢复高音谱号；末行m277又标a tempo、ff，最后到fff及延长。末行两处r.h.指向下表独立低音，手与谱表继续分开读。准备播放／原生替代时还须核完整时值、精确手／踏板动作；本轮未据PDF补出这些实现。

## 5. 八度终点必须跟材料变化走

A的上部8va跨p1两行延到p2第1系统中途，后面的音已回原位。B又有短8va，结束处局部loco作确认；p7 pesante后的8va与下表数个8vb也有各自短范围。

这些短线和重复数字在回答音区状态。Gould p325要求同表原位／移八度层有清楚区分，优先考虑分表或明确局部范围。因此保留p4高处长层的加线有理由：不能为消灭几条加线，给同表较低活动层一起加8va。遇到单层持续的特殊需求，另比较明确限定的方案。

## 7. 新读分谱规范：先明确为谁排

Gould p583–588六个新实质页，把合并分谱、弦乐divisi和打击乐演奏分谱的条件连起来。p583要求各演奏者能认清自己的线与力度；p584–586避免让弦乐演奏者在一行中换所跟的谱表；p587–588又讨论共享全谱的协调收益、更多翻页／信息的代价，以及固定演奏者顺序和可靠cue。p589–590仅为下一章标题、目录，单列覆盖，正文p591未读。

可迁移的理由是减少认错身份和回找。适用动作随读者而变：合奏每人追一条独立线时宜稳定所属谱表；钢琴家读同一大谱表中的两手材料，E的共同动作跨表反而连续。不能把弦乐“行中不换表”直接套来禁止钢琴跨表，也不能把合并分谱“各表下方重写力度”套成钢琴统一规则。详见[提示与替代](EDITORIAL_ALTERNATIVES.md)。
