# 自由反复与时间—空间记谱：先确认横向距离承诺了什么

2026-10-23。完整读图Gould印刷p621–640／本地主PDF p641–660：p621复读，p622–640为本轮19个新实质图文页，未含目录／标题空页。p640已读到近似音高开头，后续p641起尚未读，本篇不声称该专题完成。另复看用户p8、Here p8、Last Stardust p6完整缓存图。来源哈希、实际图页及边界见[证据](time_space_repetition_evidence.json)。这是规范学习和已知片段回查，没有原生候选、陌生评测或软件适配。

这段材料解决两个容易混淆的问题：自由段里的重复是否仍共享时间；“间距应该稳定”是否意味着把整个谱面改成时间尺。它补充[自由段](FREE_PASSAGE_READING.md)与[间距目标](SPACING_MODELS.md)，不把现代特殊记法当成普通钢琴谱的新默认。

## 1. 一样在重复，读者可能需要三种不同关系

| 实际任务 | 教材中的具体区别 | 后续判断与代价 |
| --- | --- | --- |
| 在既定拍内严格重复 | p621将按完整拍／小节计量的反复与独立反复区分；写出或普通省写仍让人知道按原拍走 | 不因图样重复就改为自由循环线；省墨可能丢掉拍内长度和起音次数 |
| 在自己的速度中反复 | p622–624允许独立速度、独立渐快／渐慢或未定长度；首次说明与谁同步、速度、间歇及持续条件 | “freely”不足以补出所有关系。总共奏几次要含首次说清，不能把“总奏四遍”改成“再重复四遍” |
| 一组人内部同步，但独立于其余人 | p626–627先按同速关系对齐；长笛例中2／3共同以约90开始并一起减慢，1／4仍在另一条计量进程中 | 同步是局部关系，不能用全曲一个“严格／自由”开关代替。独奏钢琴的谱表／Part也不自动变成这些不同演奏者 |

p626同速独立材料仍有节奏对齐的参照，明显异速材料则按可能的合奏进程安排；反复框和内部拍号也要有可认空间。它纠正的是“只要独立便不需任何对应”的过度概括，不证明自由段中每颗头都是精确同刻。

## 2. 续线的终点可能在表达退出方式

p625对照了两种指令：收到信号立即进入／停下；或收到信号后完成当前循环／规定小段再进入／停下。前者续线到信号位置为止，后者可稍越过该位置。p626又举一种作品体例，将直线与波线分别赋予这两种含义；**必须先有本谱定义，不能把这套对应当所有音乐的通用字典。**

这解释了看似“线拖过小节线”的一个有意用途。机械吸齐虽更整洁，却可能将完成当前动作改成立即打断；反过来，普通八度线／踏板线的长尾也不能借这个例外免查。先辨它是音区、音长、反复、留声还是分句，才能谈端点。

p623的箭头可表示反复跨系统继续，波线可以借颤音线字形制作；这不把被反复的整个音组变成单主音颤音。跨系统的续线与终止角各有导航作用，不能按“重复图元”删除。大谱表中共同控制的线与不同演奏者的线又须区分，不是见多表就合并。

p628的正反例尤其具体：合奏小节线与自由循环边界并存时，内部可用点线避免混淆；说明继续半小节的时长用音符值，不能用休止符代替，否则看似要求先停奏。独立循环超过一个合奏小节时，另设提示线／表可能更清楚；不强塞所有边界到一条表上。

## 3. 普通稳定间距，与以距离直接读时间的记法不同

p629–630的时间—空间记谱把横向长度赋予持续含义，适合某些不需精确拍型的音乐。p630并排展示传统音值、梁组、休止与tie，及按秒尺度排列的黑符头：后者墨迹更少，却需要读者从距离判断时长，原先可一眼识别的拍组和有管理作用的小节边界减弱了。

**这是“简洁”不必然“好读”的具体原因。** 普通钢琴谱的符头、干、梁、附点和tie已经承担时值信息；横距可优先帮助跟读和容纳复杂形状。若换成距离直接计时，局部扩宽一个变音就不再只是外观调整，可能改变所读时间。p630要求为最密处留够空间；这也可能把其它长时段拉得很宽、增加翻页负担。

用户关注的伴奏忽宽忽窄，仍应按[五连原生例](FIVE_FOUR_SPACING_STUDY.md)分清必要占位和联合轴弹性，再局部比较。不能用本章否定稳定跟读需求，也不能借本章给普通有拍钢琴谱删除音值／改成无干黑头。软件文档的“proportional spacing”可能仍保留完整传统记法，不能与这里的整套记谱制度仅按名称等同。

## 4. 比例也有范围，时间标记也有不同身份

p636–638的对照把尺度选择说得更细：

- 固定尺度下，同页标出的时段按持续比例占宽；最密材料决定最低可用尺度。只在开头给一个参照，比连续给时标允许更自由的估量。
- 固定尺度使大量材料过松时，可分别给区段预算；**区段之间不必同比例，区段内部仍按各自时间比例。** p638的1秒密集区和8秒稀疏区并未按1∶8占宽，靠各段的明确标示保留时长。不能把这个备选说成每个音随便摆，或假定没有范围说明的整页都采用变尺度。
- 单段持续和累计经过时间要分清。p638累计时间放在段末并用不同外框，不能把相邻累计数字直接当每段长度。与他人协调时，各分谱采用相同的时间单位／分界，不能各自为了美观改变音乐范围。

p636–637还说明时标放在哪里更易跟读：自由估量时可用表外短标，信号或受限竖向空间可改用靠表／表内点线。精确起点原则下，音头与时标对齐、前置变音放其前；为了避碰，也可将音及其前置符号整体放在点线后，**同时明确这里仍从单位起点发声**。因此“头没压在线上”可能是已声明的读法约定，不能仅凭X坐标诊断晚进入。

## 5. 持续画法须连同信息量与误读风险比较

p631–634比较无干符头、音头高度的延长线与带干延长梁。无干写法可着重起音，实际持续／衰减须按本谱说明；开放tie还可表示声音越过后续音继续留响。若要直观看不同音的保持长度或重叠，延长线更明确，却会增加谱线附近的黑线，密和弦容易遮住谱位和后来的起音。

带干延长梁把线从音高轨道移开，更易看分部、重叠和熟悉组形；代价是容易看似普通等八分。这里通常用平梁是为了让横向长度更容易读成时间，**不是普通钢琴梁坡应全部抹平的理由**。若计量与这种带干写法混用，p635要求在外形不够明显时补明确说明。

音头高度延长线为避后一个近邻音／变音而提前断开，不必等于断奏：p632通过分句或短连接弧交代连奏。p633同时承认，密集进入时不得不切开保持线会有似断音的风险，所以另比较带干写法；不能把所有断口一概判作碰撞，也不能宣布所有断口无害。p634新系统的括起音与前置续线可提醒原音继续，不能自动当新起音。

p639至p640上部又比较完整演奏总谱和精选cue：依赖他人进入的情况下，要给足够的前导事件；处处加箭头或把全部其它声部塞进一条cue表会反而干扰。几位演奏者使用总谱是一个选择，精选提示又常更轻便；这不是给独奏钢琴额外加一套合奏提示的要求。
