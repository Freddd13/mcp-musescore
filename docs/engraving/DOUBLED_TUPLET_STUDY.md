# 连音比例恰为2:1：多一条梁为什么可能更清楚

2026-10-31。回查[A005第四章P段](MEDLEY_200_CH04.md#2-p开头两个6先记节奏一致性疑点)的条件建议，复看p51整页、局部及Gould p203。本轮用一份原创两小节谱比较普通32与实际6:3十六分；三次原生导出，完整看两页PDF，核38音／12休止和实际播放。[证据](doubled_tuplet_evidence.json)；[CC0可编辑谱](fixtures/doubled-tuplet-equivalent.mscx)。原PDF及用户MSCZ只读。

**判断：本例优先采用普通三十二分表达。** 两种记法在给定时段下完全等值，普通32直接给出熟悉的音值；6:3方案少一条梁，却要求读者额外处理比值，没有给这组六个同值音增加有效信息。净书不能只追求黑线和数字更少，还要看读者需要做多少转换。

这里2:1指连音数量6:3的压缩比；[摇摆研究](SWING_ALIGNMENT_STUDY.md)的2:1指两个音的长短关系，两种含义分别记录。

这不等于已经确认原官谱写错。本轮确认的是：**若两手四拍及所见同步点是本意，普通32是可行而直接的候选。** 原工程到底保存6:3、6:4或其它定义仍待取得。

## 1. 原疑点仍成立，不能靠挪头解决

A005物理p51第2系统P首小节，上部两次各六个正常字号双梁音，之后各有独立带旗十六分和八分休止，末有四分休止。按通常裸6的6:4十六分理解，总长为：

`2 × (1q + 1/4q + 1/2q) + 1q = 9/2q`。

下部却闭合为4q，且第一组独立尾音与下部q0.75相应，第二组首音与下部q1.5相应。完整页未显示在这里自由伸缩的文字说明。局部间距再整齐，也不能决定哪一层的时值定义才是作者本意。

沿用下层与这些相应点时，每组六个快音须合占3/4q，独立十六分再占1/4q。六个普通32各占1/8q，或六个6:3十六分各占`1/4 × 3/6 = 1/8q`，都可闭合：

`2 × (6 × 1/8q + 1/4q + 1/2q) + 1q = 4q`。

## 2. 原创原生对照实际验证了什么

输入为两小节4/4，旋律音高独立设计。每小节上部两次六音上行加一个普通十六分尾音，下部五次起音与三处休止；相同的音高、有效时值和相应点重复一次。第一小节用普通32，第二小节用真实Tuplet：actualNotes6、normalNotes3、baseNote16th，并显示完整6:3。

固定宿主EXE SHA-256 `7b4e6fbf…aa25`，复用已验证的完整资源集合，预建本批配置目录。Leland／Leland Text、Spatium1.57mm、纸幅150×64mm；没有复制运行时或原谱。

| 核查对象 | 实际结果 |
| --- | --- |
| 原生PDF | 2/2页完整看图；两个小节各在一系统，分别落到两页 |
| MusicXML有效音休止 | 50/50记录：38音、12休止；每个谱表每小节均4q；两小节的音高／起点／有效时值／休止相同 |
| 普通快音与连音成员 | 第一小节无Tuplet；第二小节两组六音均为6:3十六分，各成员1/8q；普通尾音仍为1/4q |
| 实际播放 | 480PPQ；每组六音间隔60tick，尾音在该组起点后360tick；两小节全部19次NoteOn及对应NoteOff按小节归一化后相同 |

两页的谱头、页码与小节号不同，本例没有据此做固定音符区宽的几何优劣测试；比较的是记法含义、辨读任务和计时。没有生成原官谱替代版，也未做保存重载、MusicXML导回或实际打印验证。

## 3. 为什么推荐增加一层梁

Gould p203在压缩比左项恰为右项两倍时，推荐改用下一层梁。对本例，读普通32可直接认出常规细分；读6:3则要先辨六音范围，再把六个十六分按三份时间缩放，最后确认其与尾音、另一手的关系。

这项转换没有提供新的节拍信息，因为本例没有嵌套连音、混合成员或其它必须保留的比例结构。普通32虽然更黑一点，却使快速音值一眼可认，数字负担也减少。可以先把梁坡、内层白缝和组内步幅做好，不能为追求两道梁的清爽外观保留一层多余解释。

这条判断仅用于确实等值的情境。正常6:4十六分每音1/6q，不能换成每音1/8q的普通32；完整整小节17、22等省写案例也不由这条规则推翻，见[连音决策](TUPLET_DECISIONS.md)。

| 实际取得的证据 | 判断与动作 |
