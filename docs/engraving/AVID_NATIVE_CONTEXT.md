## 1. 先认清读者要跟的层，再讨论整齐

原PDF第4页第四、五行之间拆开m65。前半的延长与休止之后，第三拍同时出现a tempo、ff sub.、tre corde和下降快线；I／m66才换成三升号。把奏法恢复移到I，或把新行当作新小节首拍，都会改变读法。

快线由一个三十二分休止及九音组成10:8的一拍，随后五个三十二分音构成5:4的半拍，再接组外普通八分音。它跨过谱表，长弧随整段下降引向末音所在列。上层同时有附点、切分及延音，不应跟着快线逐音挤成同一种轮廓。

这里还有同音重叠：第三拍的上层E5仍在持续，快线经过E5另有写出的起音。不能仅因音高相同便删音、合并声部或自动改成tie。PDF足以证明写出的两层，不能单独证明原工程voice编码、具体指持和踏板释放时刻。本次选择上表voice1为旋律、voice2为快线／内层、下表voice1为低音，是实现映射。
