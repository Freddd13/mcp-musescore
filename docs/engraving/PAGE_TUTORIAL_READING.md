## 1. 加小节改变音乐结构；框架与分页安排版面

**本教程最值得用于审谱的区别，是新增音乐时间和新增纸面空间要分开。**

| 预览标注时间／格 | 可核的画面 | 用于净书的判断 |
| --- | --- | --- |
| 50–70秒／6–8 | 空小节被选中，菜单出现`Insert One Measure`及`Ins`，随后谱面重新安排 | 先定位插入目标。作者简介明确说明插在所选小节之前；此命令会增加真实小节，不能用于给现有乐句腾一点白空间 |
| 80–160秒／9–17 | 空谱继续延展，出现第二页；页面上的系统数量又变化 | 页数是内容和排版共同作用的结果。出现新页不证明软件新增了某种独立“空白页对象” |
| 200–270秒／21–28 | 选中留白区域，检视器明确显示`Vertical Frame`及顶部留白控制，区域增高、系统下移 | 大空白应先查框架和它的用途；不要先压音距、删小节或把它报成间距引擎错误 |
| 310秒／32 | 批量插入空小节的数量对话框 | 这是结构操作，和把同样的小节重新分行不同；所选范围、插入处及原小节引用均需保护 |
| 970–980秒／98–99 | 框架的底部留白和高度、左右余白等字段出现 | 框架外框和内容区有自己的预算；标题或说明文字需要的空间不能只按音符密度评价 |

本次不能逐事件重建作者的每次点击或选择变化。对教程的整体读法是：空谱练习展示了多种控制；采用到完整钢琴谱时，先辨识对象和目的，再选择其中合适的控制。一个谱表的空白也不自动说明钢琴两手都可休息或翻页。

## 2. 小节实际时值和几何宽度必须分读

**保护小节实际占时；横向净书使用空间控制。**

400–430秒（格41–44）出现小节属性对话框。放大条能辨认`Nominal`与`Actual`两个独立字段，实际时值的分数输入有变化。具体末值、应用动作及保存结果不由这些静帧确定；本次也不把其中的数字写成净书参数。

这一类控制关系到弱起、不完整小节等音乐结构。若只为挤进一行而改实际拍数，即使页数少了、纸面仍印原拍号，音乐结构也可能改变。已有[跨线三连原生研究](CROSSBAR_TUPLET_NATIVE_STUDY.md)实际核到音符事件相同却拍号元事件不同，说明“听起来音符一样”也不足以保护结构。

本教程还展示了几个作用范围不同的控制：

| 时间／格 | 可核的控制类别 | 先确认什么 |
| --- | --- | --- |
| 460–480秒／47–49、990–1010秒／100–102 | 页面设置中的纸幅、余白和全局谱间 | 物理尺寸与全谱比例；缩小全局谱间会同时改变更多符号的实际大小 |
| 550–600秒／56–61 | 小谱表选项、其样式比例，以及谱表／乐器属性中的缩放等 | 缩放属于哪个谱表或哪类对象；不能把小谱表和单个提示小音混用 |
| 490–510秒／50–52、690–710秒／70–72 | 小节样式、最小宽度，以及音符／变音／小节线附近的间距项 | 全局最低预算与局部实际占位；换了控件不等于已经解决目标宽格 |
| 640、730–740秒／65、74–75 | 检视器中的段列前留白 | 局部时间列和其它同时发声的层；独移某一层仍须核真实对齐 |
| 1080秒／109 | 谱表竖向伸展选项 | 调整的是纵向分配；它与末系统横向填充是不同维度 |

这些字段在画面里可见，不代表作者的每个值都已经可靠读出，更不构成本项目推荐值。具体操作用于当前Evolution版本时，再确认当时界面和实际作用对象。

## 3. 粗排能先规划，终排仍要服从实际音乐

870秒（格88）能看到增删系统分隔的批量命令。它可帮助搭空谱骨架；作者简介也建议先大致规划行数、拍号和调性，避免内容复杂后才大改。这项流程建议有实际用途。

**我们的采用条件：** 先按预计密度、段落与演奏任务给大致预算，输入实质音乐后再核真实容量。空谱中容易成立的固定小节数，遇到半音、多个声部、跨表组、长文字和持续线，仍需重新分配。

已有[段首／末行对照](SECTION_ENTRY_CASTING_STUDY.md)提供实际取舍：重分邻行可以让恢复点到行首而不增行，直接多插一行却把前段撑得太松；末行填充又需单独检查。这样理解批量分行工具，才能把“会操作”用于有理由的净书选择。

本例可迁移到下一份PDF／工程的三种检查：

- 发现大空白：查标题框、垂直框架、强制分页和实际内容预算，再评它是否有阅读用途。
- 发现一行太满：核真实拍数和必要符号，比较邻行容量、局部空间与断行；保持实际小节时值。
- 发现几处字形忽大忽小：先辨全局谱间、谱表缩放和局部音符身份，定位原因后再讨论字体或布局改善。
