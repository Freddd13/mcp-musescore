## 1. 同样是两个靠近的音，附点条件会改变排法

Gould p56–58是在保护“点延长谁”，不是追求所有点同X或所有头靠拢：

- **普通高低两部，只有高处上干部带点。** 点若在低音头上方，可能像低部的断奏；p57允许把带点部放右边，使点清楚离开两部。因此“带点部必须在左”不能作为一般规则。
- **声部交叠、上干部的音反而低一度，且只有它带点。** p57建议上干部在左，用点分开两部。反向紧贴时，读者更容易把点归给另一部，要再追符干来消除疑问。
- **交叠的下干部在线上、只有它带点。** p58将点放到该线的上方间，以避开上干部；不能把“下部的点向下”机械用于所有干向／音高组合。
- **两部都带点。** p56允许两点共列，交叠时p57也容许紧凑重合；没有必要把单部带点的分隔方案强套过来。多音和弦又要分别组织各部附点，空间不足时有更紧的例外。

这里的“上干／下干”指符干方向，不等于实际音高的高低。实际音高、voice容器和干向三者必须分开。另一部的头或干若隔在点和所属头之间，单纯增大`dotNoteDistance`可能让归属更弱；应先判断是否需要换列或分隔。

## 3. 变化同音：紧凑可以成立，连接形状也有信息

Gould p50–51对单干部C／C♯这类组合，优先让每个头紧随自己的变音，必要时用避开变音的斜接或分叉干连接。斜段与旗尾／梁也要互相避开；它在说明“这些头属于同一和弦”，不能看作多余线条自动拉直。

拥挤时，书中允许两头分居干两侧、两个变音都放在前面的紧凑替代，但明确更难直接分清归属。升号与还原号的先后还要避免看似取消重升；两个音都须有相应变音，不能让它们看起来同音。p91双部的交叠和变化同音又须按各部归属读，不能用单干方案一律替代。

本例m7／8的自动输出均保留自然C与C♯及两枚必要符号；m8采用紧凑的错头方式，没有形成教材优先展示的斜接／分叉连接。本轮未制作该连接候选，也没有完整审计所有宿主能力，因此不宣称“软件完全做不到”或已经修复。可保存为后续表示／控制需求：在有空间时，能否以更明确的连接保留拼写、时值、同步与附点，而不是通过改成另一种音名来避开问题。

## 4. 实谱读取的额外提醒：小数alter未必是一个要改的变音

筛选时遇到用户既有副本P1 m91的MusicXML `D6 / alter=0.1`。原生对应Note是`pitch=74`、`tpc=16`、`tuning=10`，该小节开始8va。只读导出源码也分别处理移八度和`tuning/100`。这里不能把小数四舍五入，或推断谱面漏了一个微分音升号：需分别读取拼写、八度线和音高微调。

本轮未判断这项调音是不是用户有意，也未改它。这是输入保护案例：纯净书不要借格式往返重建整谱，更不能把演奏微调误当外观缺陷；它不构成新的调音功能开发。
