## 为什么不能直接套钢琴经验

### 1. 加线数量只是换号判断的一部分

Gould p393对小提琴使用高音谱号的惯例，与中提琴、大提琴的谱号条件分别说明。换号的成本包括演奏者熟悉的指板／谱位关系，不只包括加线多少。官方谱58一行的高音运行，应先按这个阅读任务理解；不能从钢琴“较少加线”的候选自动推导出低音／次中音谱号方案。八度标记也须核乐器惯例及端点。

可迁移到钢琴的是：**连续音程轮廓、进入点和读者熟悉程度，要与加线一起权衡。** 钢琴的宽／窄音域对照见[梁内换号](CLEF_IN_GROUP_READING.md)，那里同样没有把最少加线当成唯一目标。

### 2. 指法、弦号和弓法各自解决不同问题

Gould p394：通常罗马数字表示弦，I最高、IV最低；0表示空弦。p396讨论指法与其它奏法的层次。先判断数字身份，才知道能向哪里避让；把III当成连音数、voice编号或第三把位，会导致错误诊断。初级教材另有把位的专门条件，不能仅凭字形排除它。

本谱44一行的III与周围指法应按这些不同角色读取。钢琴可借鉴“先认归属再排层次”，不能复制弦号含义。所谓干净，是读者容易分辨任务；将所有数字排成同一水平线反而可能混淆。

### 3. 弧线先辨音乐功能，随后才修形

Gould p401–402把弦乐slur与一弓内的音联系起来，同时讨论换弓仍可连奏及专门例外。检查这类弧时应先问是否影响弓法，再区分tie、普通slur及其它线。成品上看见一条漂亮长弧，不能直接移植为钢琴分句模板，也不能把相邻弧合并来减少线条。

钢琴仍按其作者说明、持续、分句及成员关系判断；本项目用户谱S.P.长弧的明确说明优先，见[偏好与意图](PREFERENCES.md)。可迁移的是端点清楚、层次一致、避让有序，以及修改后复查功能。

### 4. 同一谱表也会有真正独立的阅读层

Gould p396、398说明复音中不同持续可用独立符干；双弦同音、和弦滚奏另有弦乐条件。官方谱48一行的上下层、休止和力度提示，提醒我们先问“谁在何时继续或退出”，再决定休止位置和标记通道。不能为了横向整齐就删休止、合并符干或统一力度位置；弦乐和弦的弓法约定也不自动变成钢琴琶音规则。

## 以后怎样用于审谱

先确认乐器／配器、演奏者、版本及特殊说明；遇到高音、曲线、数字或复音问题，再核该乐器的专门条件。可以跨乐器迁移的主要是分层、预读、空间预算和一致性；谱号、奏法、省写及动作约定须重新判断。只有具体可疑处值得改时才生成少量原生副本候选。
