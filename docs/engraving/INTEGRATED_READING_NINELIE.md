# 《ninelie》整页续读：稳定组形、分层与八度作用域

2026-10-20。A098《ninelie》第4页从历史“仅全页浏览”池预先选定，先写整页判断，再看相邻p3／5、旧笔记及规范，最后用原创例检查一个实际疑点。保留、修正和未知都有具体位置；不是出版者编辑过程的复原，也不是独立盲评。原谱／教材只读，未改用户工程或开发软件。输入、选择方法及实际验证见[证据](integrated_reading_ninelie_evidence.json)。

## 1. 这一页首先要求读者做什么

首系统左侧仍延续前段，F从系统中间转入长和声背景与快速运行；第二、三系统中，长时值层与较密音群并置，再转入较慢的上层线条与低音／高和弦的交替。第四系统的渐强和ff引向G，G也没有另起行；第五、六系统让和弦旋律与低部活动继续发展。

这页的可读性不能只归给字体。梁组先使快音群成为可辨认的动作，干向、长时值头和休止保住另一层，tie和slur分别交代持续与连接，双纵线、F／G和力度再提示较大的结构。若把所有符头当成一个序列来评分，反而会把这些分工误诊成不均匀或繁杂。

以下“收益”是结合可见排法与规范给出的阅读解释，未测眼动／试奏，也没有声称出版者确实按这个步骤制作。

## 3. 间距判断：先决定哪一层需要稳定，再评估让出了什么

首系统F的六连快组、第二系统的密集运行，与下方长和声的任务不同；第三系统开头也比后面慢线需要更多起音位置。第六系统低部反复伴奏可供眼睛按组跟读，上部和弦却有不同长度、切分与连接，不能要求上部每个相邻头都像伴奏一样均匀。

Gould印刷p490的建议是**按每一拍的实际密部优先安排稳定间距，再使其它层按真实时间关系对齐，必要时回调密部以减少其它层的过度失真**。它不是整页永久指定某只手为主，也不是允许另一部任意松散。这个顺序解释了本页为什么能同时有稳定组形和不等宽的慢层空白。

本页仅作视觉判断，没有把PDF坐标反推成精确tick，也没有量出“官谱严格等距”。以后用于用户工程，应先找具体哪个拍的哪层失去轮廓，再查另一层细分、变音／加线、共同起点和小节预算；不要把本页的像素距离或每行小节数做成模板。[实曲间距迁移](SPACING_TRANSFER.md)已有必要不均匀与软空间重分的原生反例，可与本页的阅读理由合用。

## 4. 必须修正的初判：短8va不自动属于一个voice

**初看时将局部8va暂列保留，虽注明音区／边界待核，却没有指出同表两部同时原位／转置的具体歧义。** 放大后，第四系统G之前的短8va与上干和弦邻近，同一时点下方还接收前小节的多条tie。若只凭“线很短、贴上层、干向不同”就称作用域明确，证据不够。

回看Gould印刷p324–325完整图页后，判断改为：**这是需要音区作用域复核的记法问题，不能当作无条件可复制的好排法。** 一般八度标记作用于同一谱表的各部；若同表同时存在转置和原位材料，可行时应改分谱表。空间不允许而偶尔混写时，还须把目标范围说明得绝对清楚；书中给了竖向虚引导或限定loco的办法。干向本身不是“仅转置这一部”的通用说明。

因此要先核对这处持续层与上层的实际音区和意图，再比较：

1. 孤立高和弦直接写实际音高，以少量加线换取清楚的纵向音程／持续关系。
2. 多层若长期重叠，分到独立谱表，再分别使用八度状态，付出纵向空间。
3. 必须同表局部混写时，提供明确的范围限定，并核输出与演奏解释，不能只靠短横线的位置。

这不是已证明官谱错音：没有官谱工程、原生对象或已确认的演奏音区，不能直接给它改音或重写延音。它也修正了“参考中看到便应保留”的倾向：官谱可以同时提供可取的组形和值得复核的记法。后续诊断应保留这个分辨能力，而不是把来源的出版身份当作正确性保证。

## 5. 原创原生例：照外形加八度线会怎样

为验证上节的**软件操作风险**，另作两小节4/4、16个写出音的原创CC0例，固定Leland／Leland Text、spatium 1.57mm及同一页面宽度。上层是较高的二分音符和两个四分，内层分别为C4、D4全音符，低表每拍一个音。它没有转写官谱音符，**也没有模拟官谱的接收tie或推断其演奏**。

三版各16次正NoteOn，**计数相同也能错一个八度**。错误控制仅在第二小节起点把内层62换为74；MIDI起点为四分单位4，长度均为1919/480、力度均80。原生字段可表示当前记谱层，不能把字段未改直接等同实际音高未改。

分表版与实际音高版的MusicXML全部音符时间／实际音高／时长一致；合并轨道后的MIDI起点、音高、长度、力度也一致。轨道／谱表分配本来不同，不称完整MIDI字节相同。分表版另经原生保存重载：一页、SVG除标题、RGBA像素、完整MIDI及上述XML事件保持；没有做MusicXML重新导入、试听或打印。180dpi图仅合白底、同框裁切，完整保留两小节和全部谱表，没有移动／缩放符号。

本次没有开发voice专属八度接口，也未由这个输入推断所有MuseScore版本都不能实现特殊分层；验证范围是冻结宿主`7b4e6fbf…`的这组原生输入。

## 6. 前后文让页面判断更具体

p3的E同样在系统中间进入，p4页首继续前一阶段，F才改变织体；因此“页首就是段首”不成立。p4末系统的和弦tie延至p5页首，p5明确重述接收和弦，随后继续较密材料并在行中到H；不能把p4裁成独立结束，也不能仅因跨页有tie就判分页错误。

**p4→p5也不自动等于物理翻页。** 在常规偶数左／奇数右的对开装订里，这两页同属一个展开面；单页平板和其它装订方式则另判。本轮没有用户实际媒介或试奏，既不承诺安全，也不把“同音在持续”解释成两手一定腾得出空翻页。长时值、踏板留声和手占用须分别确认，见[行页专题](PAGE_FLOW_STUDY.md)。

## 7. 怎样进入下一次自主检查

这个案例提供的不是一套新样式值，而是一个可复用的判断顺序：

1. 先说明整页正从什么织体转到什么织体，哪些层需要持续、进入、分组和导航。
2. 对具体位置分别作保留／调整／记法复核／未知的决定，给替代代价；不要求每页都找一个可改外观。
3. 参考中看似顺眼的局部也查作用域；规范与例外冲突时记录条件，不以出版身份或外形代替解释。
4. 有工程时验证实际音乐，特别是八度、转调、微调、静音与范围状态。单独的音数、原生pitch字段或外观相似都不够。
