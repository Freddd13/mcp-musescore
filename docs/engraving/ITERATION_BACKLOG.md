## 后续开发可用的具体缺口

- **间距控制**：Local relayout会在某些混合细分情境破坏两手同步；联合调整仍需保主要活动层、变音占位与整行预算。已有正反例，通用诊断／优化器尚未开发。
- **跨线连音显示**：受控单行组合可成形，动态重排和MusicXML导回仍失败；不能以改长小节拍号换取外观而称语义等价。
- **范围与归属**：跨表括号、弧、力度和持续提示需读取真实成员及显示层，不能只看对象名、父Voice或外框。
- **行页容量**：Avid指定两版整页比较已闭合；第五行余量约0.05mm，换字形／宿主后需重验。它不是通用分页算法或全局最优证明。
- **交换与保存**：跨表琶音成员、逐层梁、隐藏表及部分显示对象已有具体差异；后续按当时版本复现，不能直接套历史补丁。

这些是候选需求。首批开发从试用中反复出现且收益明确的情境选择；已有参数能解决时先用参数／插件，必要时再补MCP或最小本体能力。
