# Aether m33：保住还原号，把边界余白分回音组

2026-11-02。**m33在官谱的小节宽和首末音预算内，已形成一个可行的原生局部候选。** 保还原号前约3.133sp，其余四格约2.592sp；没有把整小节拉成等距。四处源密度后继完成**1/4，余m30、31、35三处**。本次是Leland重建片段的预算比较，尚未回迁原七小节系统或获用户采用，原PDF未改。

这一例把“更整齐”落实为具体取舍：先给还原号留可辨的空间，再让其它八分稳定。默认版已基本稳定；候选另把末音后的部分空白分回活动层。关闭所有和弦外围形状避让也能得到近等距，但它使还原号与前音近贴角，本例不取。

## 3. 为什么末音后的空间也要参与判断

只观察六个音头，容易漏掉最后一列到小节线的空白。相同小节总宽下，默认分配给这块约2.596sp；候选取源约2.250sp，把约0.345sp分给四个自由格。还原号前的3.133sp不动。这样改变的是余白分配，时值、同刻关系与六八分的3＋3连梁均保持。

Gould p40要求同值活动在系统内稳定，同时允许不同密度的系统改变单位间距；p42区分表头与行中小节的留白，不能将行首预算直接当成内部小节占宽；p43又要求顾及符号占位及符干与小节线的辨识。三页完整复读后，本例的取舍是：四格稳定、变音格放宽、末端保有余量。候选九根符干到相邻小节线，扣除线宽后的最小净距约1.410sp，保住书中至少一格的要求。

这并不说明小节末端越紧越好。最后符头、加线、符干、续接及下一小节入口都要看；本轮保源边界预算，未把边界压到能容纳的极限。若整行换号、末端有旗、加线更长或下一小节带变音，应重新判断。

## 4. 同刻的低部和标记须一起走

候选不是只拖内层八分。按共同起音联合移动m33的相关Chord／Rest及力度：内层第三、第四列各约右移0.172sp，第四列的低部C♯3也同步，实测正常侧头差0。上层与低部起点保持，A4续接保持。

`mf`横移也为约0.172sp；宿主自动避让另把它上移约0.200sp，不能宣称所有纵坐标未变。其紧框仍在下表下方约0.539sp，与本小节符头框不交，完整两手图已检查。语义保持和图形保持分别记录。

## 5. 输出成功不等于预算成立

最初一份孤立输入，MusicXML报宽15.869sp，谱线也只有这个宽度，实际小节线却在18.131sp处，超出谱线约2.353sp。它不符合比较前提。表头隐藏后仍有布局留白，括号／系统左侧保留也占空间，不能将设定的可打印宽直接当作内部小节线间宽。

最终按谱线、小节线中心与真实音头三者回读，修正这部分预算。头尾距离参数仅在隔离研究输入中用于建立边界，不推荐把本例的小数直接设成全谱风格。完整八小节取消额外拉伸／首行缩进的探针仍输出6＋1＋1，并未恢复原七小节行；21次前置／失败探针保留，不作成功候选计数。

只读本地源码可见，`basicStretch()`存在下限1，最小距离与弹性伸展分开处理；和弦外围形状也参与占位。这提供调查线索。实际exe与当前源码提交未证为同构建，本轮结论以已观察的原生几何为界，未修改软件或接口。

紧、宽窗口的差异还能帮助解释间距为什么会时好时坏：最初的紧窗口中，只关闭上层长音和弦的外围形状参与，首格由约2.399降到2.200sp，第三格仍约3.133sp；修正到合法窗口后，这个开关与默认排出相同活动列。符号的最小占位与剩余空间的伸展是两件事，某个约束在紧窗口显著，稍宽就可能被伸展覆盖。最初窗口超宽，不能当合格成品评分；该探针也没有证明原Sibelius的具体原因，或把影响单独归给一个附点。
