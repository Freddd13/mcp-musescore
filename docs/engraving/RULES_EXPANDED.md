# 扩展规则卡 R15–R26

2026-10-09。接续 [R01–R14](RULES.md)，案例见 [E15–E35](CASES_EXPANDED.md)，教材来源 S17 见 [阅读笔记](BEHIND_BARS_NOTES.md)。均为**待实现、待副本验收的情境规则**，不是已发布自动修改能力。

规则需要用户选择或明确音乐证据才能启用。自由织体、严格对位、手分配和演奏解释等无法从 PDF 确定时保留 unknown；模型推断与用户确认分别存储。给出建议不等于更改工程声部。

## R15 — 先识别音乐层的持续身份，再处理符干和休止

- **触发/级别**：同谱表多层、临时附加符干、休止拥挤；钢琴情境规范。
- **依据/输入**：Gould p310–313；软件 voice、实际时点/时值、逐音 tie、独立发音/力度、乐句及用户指定织体。增加 `musical_role` 与 `role_confidence`，不把 voice 编号直接当音乐角色。
- **候选**：先提示明确与疑似持续层；自由织体比较保留、局部合干/省显休止方案；严格对位优先保持各层身份与完整休止。语义改写不进入普通图形 patch。
- **例外/冲突**：两条独立节奏在 p312 仍需补足小节；临时突出旋律在 p311 可不用附加休止；严格对位 p313 各部始终独立。不能只按“小节有几个 voice”自动分类。
- **保护/验收**：E16 与 E28；另用教材自由/严格成对自制 fixture。保持原 voice、所有声音与攻击；未确认前不隐藏任何休止。时间以有理时值/宿主 tick 计。

## R16 — 同音共头、部分延音和弦是有条件的记谱方案

- **触发/级别**：同音异时值、附点同音、和弦部分 tie；情境规范与语义保护。
- **依据/输入**：p307–308、310–311；独立层、重复音型、时值、附点、发音与力度、逐音 tie、双干锚点。
- **候选**：比较维持共头与分头；部分延音和弦可保留整体干与逐音 tie。先由自制片段证明引擎对象模型能表达原意。
- **例外/冲突**：重复音型可提供理解上下文，孤立同音更宜分头；同节奏但独立发音/力度的音不能随意合并。跨乐器规则不能直接照搬。
- **保护/验收**：E28/E29；半头内孔、双干连接、符点归属、二度及每部实际时长均检查。图形去重不删除逻辑音；字体相同 advance 不等于连接净距相同。

## R17 — 跨谱表共梁同时评价最短干、谱线与整体轮廓

- **触发/级别**：同组相反干向、跨谱表短音、梁角突变；情境规范。
- **依据/输入**：p314–316；所有成员显示谱位、干向、层数、上下谱线、真实系统距离及内外声部占位。
- **候选**：原生布局、平梁、有限缓斜；先检查干有足够长度，力求两方向最短干平衡，再评梁与谱线的可辨认度、整体音型方向。
- **例外/冲突**：水平梁避开谱线可优先于严格对称；端点趋势与多数内音冲突时不机械用端点坡度。p315 的至少 2½ sp 是此类共梁条件，不是普通所有符干的统一值。
- **保护/验收**：E17/E31；成员、分组、拍点和 staffMove 保留；量化最短干/梁净距/增加高度，不能用总干长一个分数决定结果。

## R18 — 连音数字和括号表达成员及时间组

- **触发/级别**：长短混合、内层、跨谱表或相邻不同连音；情境规范与时值保护。
- **依据/输入**：p193–197、319–320；actual/normal 比例、base duration、成员实际/书面时值、括号方式、梁、休止、分组与占位。
- **候选**：外围数字/括号、内层近梁数字；视觉中心与复杂组节奏中心候选；相同分割的上下组可比较括号端点对齐。
- **例外/冲突**：通常数字在干侧，跨谱表共梁需另看干向与内层；不能全提到最高处。末长音组可考虑延至假想末细分位置，而非一律括号终止于最后发音头；不同分割不能强制等长。
- **保护/验收**：E17/E34/E35；括号不吞入首音前的变音、装饰音、琶音线；数字不误归相邻组；保留成员及比例。未读工程时不能从“6”推断为6:4或6:3。

## R19 — 装饰音的图形位置与实际演奏时点分开

- **触发/级别**：小音群、斜杠、倚音或琶音前置符号；语义保护与情境规范。
- **依据/输入**：p125–130、131–133；宿主 grace 类型、所属主音、小音组、斜杠、脚注／拍上拍前说明、发音方式，以及琶音成员、共同／独立组、方向和时序。2026-10-20补原生装饰音身份例，见[装饰音续学](NOTATION_DETAILS.md)；跨表成员与延续低音见[琶音续学](CROSS_STAFF_STUDY.md)。
- **候选**：只调整局部留白、主音前位置和比例一致性；普通时值的小音不自动改成 grace。琶音线覆盖音头而非所有符干。
- **例外/冲突**：斜杠/大小不能独自决定抢拍或占拍；小音组梁数有出版差异。跨双谱表连续一根琶音线与每手各一根的动作不同，不能为了对齐合并。
- **保护/验收**：E18及[CROSS_STAFF_STUDY第5–7节](CROSS_STAFF_STUDY.md)的原创琶音例；已补共同／独立、延续低音、局部避降号与拉长反例，不等于所有跨表情境。保护计量列、装饰音身份／顺序／目标，以及琶音成员／分组／方向；主音对齐不等于声音同起，同MIDI的拉长线也可误示成员。本例MusicXML实际漏下表琶音，须核成员与原生重载，不只数符号；小字形或size=cue不代替grace／cue身份。几何误差用sp，不用像素距离推算声音先后。

## R20 — 震音必须走专门的时值与几何模型

- **触发/级别**：单音斜杠震音、两音连接震音；语义保护。
- **依据/输入**：p219–228；tremolo类型、端点／实际slot、总时长、是否有节制、已有梁／旗、首次写出／持续说明、奏法及伴随声部。2026-10-20完整图文及部分原生应用见[NOTATION_DETAILS第11节](NOTATION_DETAILS.md)。
- **候选**：先辨是否适合长重复缩写、是否需要写全建立细分；记法改写单独提出。外观可比较两音连接的对称短梁，保持第二头在逻辑半程与共同音列；不让普通梁整理器接管或按视觉中点移动头。
- **例外/冲突**：两音震音两个端点均写整段时值，不能当普通短音相加。单音震音略细的线建议不能套到两音震音的普通梁厚；三条线不能直接认定执行速率。
- **保护/验收**：E19；已补原创whole c16／r16的短梁选项与同MIDI的错列拒绝例。原生duration／实际slot与书面type分读，MusicXML的2:1不再重复折算或新建Tuplet。分类／时值、实际图面、NoteOn／NoteOff／控制事件分核；原生重载与MusicXML往返结论分别保存。带旗、附点／复杂连音、跨表与自由震音连接仍待原生例，不以本次检查替代。

## R21 — 书面节奏、连音时值与 swing 演奏解释分别保存

- **触发/级别**：swing/straight 等式、局部解除/恢复、拍号与速度单位改变；语义保护。
- **依据/输入**：E20 的明确等式；书面细分单位、ratio、有效区间、取消点、tempo beat unit、重复跳转。此卡是本例推导，未宣称 Gould 已直接核查 swing 正文。
- **候选**：检查提示能否辨认、范围是否缺省；保持书面节奏，不自动改写为连音。
- **例外/冲突**：Kigeki 是十六分 swing；不能把常见八分模型硬套。同一作品有 straight、swing 与 12/8；视觉等式不证明播放已相同。
- **保护/验收**：E20；区分“未知播放参数”与“已知书面提示”。音符/ticks 不变；演奏设置另作用户确认的编辑任务。

## R22 — 踏板类型、作用区间与键上保持独立建模

- **触发/级别**：踏板符号/线跨系统、retake、release、踏板与翻页；语义保护及情境规范。
- **依据/输入**：p332–337；damper/sostenuto/una corda、启用/释放/换踩、文字/括号提示、逐音持键/tie、手映射、时间锚点。
- **候选**：调整最下通道、局部对齐和续行提醒；保留精确时点与既有记谱方式。精确线式和概括文字是不同信息量，不默认互换。
- **例外/冲突**：Ped. 对音符图形对齐是传统惯例，不能直接当作脚的毫秒时间。连续踏板线可增加噪声；短符号不必全系统同基线。sostenuto 与 damper 不能混称。
- **保护/验收**：E23/E33；跨系统延续、快速retake、断开、多个踏板及键上保持自制例。不能因声音由踏板延续就缩短原持键时值，不能据一个voice休止判定可翻页。

## R23 — 先建立演奏跳转图，再检查上下文和提示性记号

- **触发/级别**：反复、不同结尾、D.C./D.S./segno/coda、可选衔接；语义保护与导航规范。
- **依据/输入**：p235–239、559–561；控制流节点/条件、跳转目的地、各入口的有效谱号/调号/拍号/速度/力度、页序与实际使用方式。
- **候选**：先诊断歧义和缺失上下文；再建议重复提示、coda留白/缩进、跨页替代布局。完整写出重复段是编排/记谱选择，不属纯图形 patch。
- **例外/冲突**：仅写D.S.可能依赖其它coda标记；不擅自补解释。多章PDF页码重置不改变音乐对象编号；进入coda不能只查纸面上一小节。
- **保护/验收**：E25/E26/E33；跳回后拍/调/速度检查、不同结尾与翻回必验。未解析全曲控制流只列候选路径和unknown，不称播放顺序已验证。

## R24 — 碰撞分类包含允许交叉与归属损失

- **触发/级别**：矩形相交或实际墨迹接触；情境规范。
- **依据/输入**：p313、322–324；对象类型对、实际墨迹/曲线、层与作用范围、邻组，以及至少一个替代位置。
- **候选**：先排除包围区假碰撞；再检查是否为允许交叉；比较避让与归属。采用分类型策略而非统一“零重叠”。
- **例外/冲突**：必要时梁可穿另一声部干；发夹最后可穿干但不能穿梁；跨谱表Slur穿梁应避免。这不是所有交叉的许可；字符/符头被遮挡需单列。
- **保护/验收**：E30；假重叠、许可交叉、不许可遮挡至少三类。避免把标记推远至失去归属；可接受交叉也要记录原因与人工复核状态。

## R25 — 页面容许多个片段，层次与空白必须有功能解释

- **触发/级别**：coda重起、标题、稀页、章节起页、密度转换；情境规范与风格选择。
- **依据/输入**：p239、488–490；页面/横行/实际系统/片段/音乐范围映射、标题类型、内容外框、brace/clefs、用户锁定、跳转与翻页。
- **候选**：保留片段分隔；按内容需求分配双谱表内部空间和系统外空间；比较标题行首/行中，不为满页强拉极稀页。
- **例外/冲突**：空白可用于导航、动作准备和翻页；留白功能未明也不能假定最优。相邻行小节线全重合的跳行风险可提醒，不为了错位损伤时间间距。
- **保护/验收**：E26/E27/E32，首批E11/E12/E13同时复用；不能把一横行两个coda片段合成一条连续时间网格。字体和版心固定后比较，屏幕与实际打印分开。

## R26 — 指法、替指和连音数字保留各自类别

- **触发/级别**：数字密集、指法小弧、同拇指多音、指法与连音混淆；情境规范。
- **依据/输入**：p193、308–309；对象种类、关联音、和弦排列、替指关系、字体/字号/直斜、内外层及作者指法。
- **候选**：在保留数字和归属的前提下，比较直立小粗体指法与斜体连音数字、外侧与干端布局。
- **例外/冲突**：无指法可为版本选择；不能自动补删指法。替指小弧不当作普通Slur处理。内层指法靠干端可能更清楚，不能一律全放外侧。
- **保护/验收**：E35 是教材例，不是官谱已覆盖；先自制fixture，再引入真实指法工程。此卡评布局，不负责生成钢琴指法。

## 对首批规则的修正

R04 的“声部身份”增加音乐角色与软件容器的区别；R05 把上右下左视作常见键盘读法，明确提示、交叉和对位等可覆写，unknown不升级为事实。R06/R12 使用类型化碰撞，不把所有墨迹接触当错误。R14 的时长必须记录演奏者/设备假设，教材4秒示例不是全钢琴阈值。

这些修正不削弱原工程保护：研究发现某种合干/省显方案合理，并不授权自动合并voice、删休止或改演奏参数。
