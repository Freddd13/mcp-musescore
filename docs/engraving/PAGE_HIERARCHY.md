# 页面秩序：谱表内距、系统间距与最外层符号

2026-10-20。接续[分行与翻页](PAGE_FLOW_STUDY.md)，完整阅读并看Gould印刷p481–490／PDF p501–510，复看A035 p3–4、A037 p5–6、A007 p6–7和用户PDF p3–4。重点是解释空间的层级，不再试图以“每行／每页一样多”或某个均匀度替代净书。三份官谱都已有总览／部分近读，此次不增加历史379页计数；教材p488–490也是复核。[证据](page_hierarchy_evidence.json)记录实际尺寸、谱线几何、渲染条件和原件哈希。本次只读研究，没有原生排版候选、软件适配或用户审美选择。

## 1. 空间有三层作用，不能共用一个对齐目标

**同一大谱表内部，距离帮助认出共同的演奏单位。** 两手应能纵向找同拍，但还要容纳干、弧、力度与跨表运动。距离过大，读者需跨过大片空白合读；过小则标记拥挤。Gould p488–489的三种同曲对照说明，足够空间不是把上下表拉得越开越好，也不是越紧越好。

**系统之间，空白帮助换行与辨认下一组。** 这是不同于两手之间的阅读边界。书中建议条件允许时，系统间隔大于相邻系统中最宽的表内间隔；它以分组清楚为目的，不是要求每一处实际白带都等宽。短谱表、跨表动作、三／四表系统和外围标记都可能改变预算。

**页面外围，先看实际印刷内容是否有呼吸空间。** p487–488一般希望各页谱表顶底较一致，但给标题、上方文字／加线／八度线和下方踏板明确例外：应退让谱表，保持最外层内容的页边空白。不能只看最后一条五线谱是否齐底，也不能把页码加入音乐墨迹的外框后评分。对开要求还须先知道实际装订、起始左右及显示媒介。

这三层相关却不同。把可用余量全加到两手之间，可能破坏乐器归组；将所有系统强压到相同实际白带，则可能不必要地撑开稀疏行。后续应先满足局部内容，再分配剩余空间，而不是先定一个全页网格。

少一系统的代价是换行距离变大，纸面更舒展却非免费收益。A035尾页的简单长线较容易重新定位；若是密集、相似的反复运行，过大的换行扫视可能更不便。书p488还对“极少系统”的稀页允许保留正常间距、缩短页面深度，而非强行填满；这些尾页并非只有一两行，不可由此推出一行结尾也要拉满页高。

A007提供另一种正面取舍：最后一页第4→5系统谱线净距81.96pt，大于其它几处。这一带上行有低八度、Ped.／释放，下一行有N、附点四分=66和上八度提示。若只为统一谱线间距把它压成53pt，会削减这些各有归属的通道；是否能用其它位置减省，需要原生同曲候选，不能凭表格直接确定。本次保留原例，不把第6页与第7页的内距差解释成字体差异。

## 3. 用户两页：等谱线间隔没有证明排得差

用户PDF p3五系统之间的谱线净距均约82.12pt；p4五系统之间均约73.83pt。但表内距不同，p4末系统还是三谱表，说明实际层级并非一个等距格子。仅凭几何不能判断这些位置来自手工调整还是某项软件默认，也不能把当前release5工程的样式当成成品PDF的完整制作历史。

以PDFium按144dpi渲染原PDF，在每条系统走廊中寻找贯穿主体横宽的最大白色横带，p3得到约43.5／35.5／32／21pt；p4约20.5／11／21／28pt。**相等的谱线间距确实不等于相等的可见白空间。** p3最后一处要容纳F、速度等式和Vivace，p4第2→3系统要容纳前行踏板与G／Comodo，解释了为何它们的实际白带变窄。

本轮判断是保留这两页的全局尺度，继续按局部识别需要筛查，不建议为了模仿官谱直接压紧全页或强拉白带相等：

- p3 F是新运动方式的入口。标记需要空间；白带比前几处小，不自动构成缺陷，也不能删掉等式换来留白。
- p4前两行的踏板外形已有[独立候选](USER_PAGE4_REVIEW.md)，应先判断其归属和重复负担；不能顺便挪系统，把字体、标记方式和纵向分配一起改变。
- p4三表echo系统有实际分层理由；不能拿A035双谱表尾页的内距和行数直接套用。全曲还有四表系统，局部省高可能把成本推到后页。

这些是具体保留／诊断的理由，尚无“哪种纵向方案用户最喜欢”或“某个参数已解决整曲观感”的证据。横向节奏分配也仍是另一任务，不能指望仅改系统间距解决它。

### 为什么连“实际白带”也不能变成美观分数

A035 p3第1→2系统的整宽共同白带在本测法下为0，但完整图与边界裁图可见：前行发夹、下一行括起8va／弧和高音在不同横位置分布，并没有因此证明墨迹碰撞或归属不清。它们的纵向投影可以重叠，局部空间仍可使用。

所以这个量只能解释“谱线间隔为什么不代表实际空白”，不能作为最小安全间距、碰撞检测或排序目标。若把所有白带拉到相同正值，会有把本来可用的交错空间浪费掉的风险。应检查对象组合、局部轮廓与读者需要经过的位置；不能把整行外框变成一堵墙。

## 4. 同宽截图掩盖了实际字号与纸张

A037这份PDF纸张约185.2×261.9mm，谱高约5.43mm；A035／A007约A4、谱高约6mm；用户PDF约A4、谱高6.28mm。按相同屏幕宽度查看，相当于用了不同放大倍率，不能由截图直接推断实际尺寸、黑度或印刷可读性。约6mm与6.28mm的差异也不足以独自解释全部风格差距。

本次保留来源的真实尺度，不推荐把用户谱一键缩至5.43mm。后续有实际字号候选时，应分别比较同物理尺寸与同sp下的字形／间距；将纸张、谱高、打印缩放和字体名称分别记录。不同图形字体还会改变相同sp下的墨迹重量，不能把“缩得小”直接归为“字体高级”。

读取A037时另有一个真实陷阱：PDF含50条完全落在页面外的长横线。原始统计p5有110条、p6有100条，限定可见页后才是60／50条，与6／5个双表系统相符。本例过滤完整页外对象有效，不意味着已处理所有裁切、变换或遮挡；基于PDF对象数的自动布局判断仍须对照真实渲染。

## 5. 段落、新乐章和导航标记分别处理

Gould p484–487对小节号、排练标记与乐章入口给出不同目标：小节号是位置参照，排练字母帮助找到有意义的起点，新乐章则通常重新起行、缩进和重述拍号。连续与非连续乐章的预告、双线和attacca又不同。不能看到框字母就推定为新乐章，或把每处速度恢复都当成重新开始。

p487也倾向在可行时让段落／反复／Coda起点另起系统，目的是醒目，措辞不是不计成本的硬要求。本库先前保留用户行中G／H及官谱行中入口，与此并不矛盾：额外一系统、过松的孤立小节、续接与翻页是实际代价，须一起权衡。新乐章的缩进惯例不能据此批量施加到普通段落。

p485的排练标记／速度排法还有先后层次：标记靠近实际小节边界，速度可接其后或按空间上下安排，避免把框字母放在速度文字后而仿佛属于另一小节。用户p4的G、Comodo和mf已有原生同起点核查；字样墨迹左边界不一样，不构成必须吸齐的理由。

## 6. 后续自主净书怎样使用

先确定本行／本页的演奏单位和进入位置，再分清表内、系统间和页面外围的任务；取实际内容轮廓与原生有效设置作诊断，不能从PDF推定全部编辑来源。选择版面预算后再做局部间距，任何分行改变都复查续接和后页。

可接受的后续动作包括保留、局部让位、重新分配系统余量，或比较分行；均应解释改善哪种寻找、同步和归属，代价是否值得。对极疏页允许不填满，对复杂行允许额外通道，对可交错的空间不强行清空。本轮没有开发这些控制；未来需要的是真实布局、内容范围与失败请求的读回，不能只用系统数或均匀度返回“净书成功”。
