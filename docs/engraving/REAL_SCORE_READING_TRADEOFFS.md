## 1. 完整组帮助读什么：先分普通三音和真正连音

### Kuchizuke Diamond，A079 p4第五系统J前三小节：保留三音动作

低部连续24个普通八分音符，分成八组三音梁；第三、六组跨越小节线。每小节仍是八个普通八分，三小节后组界与小节界重新汇合。上部有自己的长音、休止、错开进入和tie，不能说它全程提供四分脉冲。

按四分为1，从J起算，低部时点为`n/2 (n=0…23)`；三音组起点为`0、1.5、3、4.5、6、7.5、9、10.5`。第三组三音的第三头在q4，是第二小节起音；第六组的第二头在q8，是第三小节起音。两个新小节都有普通八分起音，位置与上部相应事件相合；此例没有“跨线后的首头必然晚到”的连音条件。

三音梁把反复的低—高—低／相邻和声动作直接组成块，视线可沿同型追踪；跨小节线也仍保持动作连续。若统一改成每半小节四音一梁，会更显拍，但也会把一个动作拆开、把不同动作接在同梁下。这是可讨论的重分组提议，当前优先保留原排法。

Gould p170–171说明切分／交错重音的分组与基本拍子的关系，也提醒偏离拍子的分组会增加计数负担。这里的保留判断来自实际反复音型及完整三小节的可追踪性；不把它升级为所有跨线梁均应保留。**三个头并不自动构成三连音**：给这些普通八分加入3:2会改变时长和共同起音，不能作为美化动作。

### Kura Kura，A080 p4第二系统：初判的处理顺序需要修正

快组实际为`8、7、8、5、5`，共33头。第一组前有普通八分和弦；第三组8的前三头在小节线前、后五头在线后；两组5各有两层梁，之后另有两个普通八分事件。完整下降／回转组形有利于分块跟读。

初判优先保留组形，也记录了比例未知。复核后，**优先动作改为查明比例与跨线接点，原排法暂存**。流畅的组形不能单独支持间距修改。若采用旧笔记的条件重建：8:6、7:6、8:6十六分及两组5:4，跨线8起于四分单位3.5，第四头在`4 + 1/16`；原PDF第四头却与下表新小节和弦同用`x=242.424pt`的字形原点。这个可见事实已重新提取核对，比例假设仍未成为作者时值。

Gould p207要求非标准长度明确比例；p210–211允许完整跨线组，要求线两侧音数及实际时间位置正确。确定比例后才能比较完整比例提示、保组形并校准接点，或拆分显露小节起点。后者会增加接收头／tie、减弱流动外形；收益须针对真正的计数需要说明。

两例共同的判断顺序是：确认实际时值和组界，再评价完整形状的收益。A079可作保留判断；A080留下具体问题及取得节奏依据后的两条方案。不能用前者替后者消除未知。与[跨线三连原生例](CROSSBAR_TUPLET_NATIVE_STUDY.md)的计数任务不同，不能照搬那一例优先显拍的结论。

## 2. Mixed Nuts：同一首里，少写和显拍各有理由

复看A091 p1–4，核4/4及D、B/F相应片段。[原专题](INTEGRATED_READING_MIXED_NUTS.md)的主要判断保持。

| 位置 | 读者需要认什么 | 本轮判断及理由 | 另一写法的代价 |
| --- | --- | --- | --- |
| p3第三系统D首小节 | 最高层长音与内层两次半小节运动 | 保留最高层全音符及内层`附点四分＋十六分＋十六分`的重复；内层长值分别从q0、q2开始，下部四分是辅助参照 | 把每个附点四分拆成四分tie八分，会增加两个接收头和tie，当前没有相应定位收益；拆最高层又会掩盖持续轮廓 |
| p2第三系统B首小节；p4 F同型 | 第三拍前的提前攻击及之后第一次新音 | 保留q7/4十六分和弦tie到q2的八分接收，再于q5/2进入新音；第二拍小单位与后半小节各有梁界 | 合成附点八分会删去第三拍的可见接收，读者须从提前音重新推算后面的入口；梁组也会随之改变 |
| p3 E的独立层 | 哪层尚未进入、哪层仍持续 | 保留相应休止、不同干向和错开起点 | 只按同表有声音就删休止，会抹掉层次；休止稠密与无用休止须另判断 |

D内层以四分为1：`1.5 + .25 + .25 + 1.5 + .25 + .25 = 4`。B首小节为`1 + .5 + .25休止 + .25 + .5接收 + .5 + .5 + .5 = 4`，接收不新增攻击。它们是完整位置关系不同的两种情境。

Gould p166–168以拍号、起点和复杂度决定显拍程度，p167允许简单拍子中从拍上开始的长值直接写出；p170–171还区分有意切分和明确的常见型例外。D的保留并不需要把它硬归为p171某一幅例图，也不能只因另一层有脉冲就允许任意合并。

实际建议须说出“多一个头帮助定位哪一拍／下一次进入”，或“删掉它后还靠什么一次认出节奏”。只说省墨、整齐或MIDI相同，无法决定这里的取舍。

## 3. unlasting：同一范围的续行、明确终点与未定延续

复看A137 p5–6，分别处理三条链，不能仅按相似字样或最近力度连接。
