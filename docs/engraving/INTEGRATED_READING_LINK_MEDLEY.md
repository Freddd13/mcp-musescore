# A Link to the Past Medley：组曲怎样让人连续读下去

2026-10-23。A008，9页全部复读，并看13处前后文裁图，再回核旧[逐谱二](corpus/READING_002.md)、[行页专题](PAGE_FLOW_STUDY.md)及[p6综合应用](INTEGRATED_REVIEW.md)。本轮补整曲关系，不把原有Q／R、N／O及V／W的局部观察算成首次发现。实际顺序、原件哈希和阅读范围见[证据](link_medley_reading_evidence.json)。原PDF只读；本轮没有原生试排、工程改写或软件适配。

以下理由是本线对阅读效果的解释；PDF不证明出版者实际采用了这些设计思路。可见事实、规范条件、候选取舍和未知分开记录。

**这份谱的整齐来自稳定的阅读轨道和有层次的变化，而非固定四小节一行。** 字母标记、预先进入、换拍／换号、力度和前后页共同帮助读者恢复状态。它也没有证明所有页界都适合自己翻纸：组曲段落、换行、换页、物理翻页是四种不同边界。

## 2. 字母、准备、实际进入，不必吸在同一列

**A在p1首系统中间。** 前两小节是有C拍号的快跑引子和长值，A才改3/4、f并进入较简明旋律。当前同一行呈现“引入—落定—开始”，可直接接读。若让A另行，入口更突出，却可能多占系统、扩大引子空白并推移后文；没有原生试排，不能承诺不增页。这里没有把有拍号引子误读成自由华彩。

**D的速度先从前一小节开始。** p2第三系统末，上方先有两次四分休止，再以附点八分／十六分引入，四分=120和f maestoso已经落在这对引入音附近；D与下一系统的C拍号才是随后完整入口。把速度和f统一移到D，会让读者不清楚引入应按何种速度／性格奏。行末的拍号提示与下一行重述也各有用途，不能按“重复”全删。

**E前先恢复动作，E再明确新织体。** p2第五系统末，延长之后的低音谱号、a tempo与p已经引入；第六系统E才展开下方重复八分及长低音，并写senza Ped.。保留这个顺序比把所有文字堆到E上更准确。随后simile承接已建立的重复写法，p3后部另有con Ped.；换页不清空这些状态，con Ped.也不自动等于取消所有手指奏法。

**J的结构入口和快层入口又不同。** p4第四系统，mf在J之前一小节的尾部；J在本行第四小节。J下拍已有长层与下方伴奏，上方快层却先有四分和十六分休止才进入。框字母指向结构位置，不能以第一颗快音代替，也不能为了清爽隐藏这些有再进入作用的休止。若单独把J移到新行，仍须保护先到的mf及层次，不能将所有标记拉齐。

这些判断与Gould印刷p484–487的定位原则合用：字母用于有意义的恢复点，正式新乐章另有新系统、缩进及拍号要求；p487也建议在可行时把转段放到新系统以增加显著性。**所以行中入口是一项有代价的出版选择，不是新的硬规范。** 本谱有连续A至W，却未把每个字母声明为独立乐章；不能借乐章规则强制23次另行，也不能反过来说段首永远不应另行。

## 3. Q／R的空表，是等待的时间和位置

p7第二系统末开始Meno mosso；第三系统继续重复三连型并收束，后有两表长和弦的接收、两表休止加延长号、双斜线，以及行末取消降号的提示。Q在第四系统开始，明确四分=70、p，上表连续四个整小节休止；R在同一系统第五小节才以mp cantabile引入旋律。

这里有三个层次：先结束旧动作，再建立新的伴奏时间，最后进入旋律。R与Q在一行，读者不用重新找回上表，就能在四小节等待后沿同一轨道奏入；双线和框R仍使入口可定位。这是保留空表的具体收益。删上表再在R接回会增加寻找谱表／谱号和范围的任务；把钢琴整体写成四小节多休止则直接漏掉下方伴奏。

按写出的4/4和四分=70计算，四小节是16个四分、名义约13.7秒。**这只是上谱表等待，不是已确认的右手空闲，更不是当前p7→8的页末翻页窗口。** 后面同页还有R的12小节。若提前把纸翻过去，会失去尚未读到的R材料，除非另有记忆、重复提示或其它媒介安排。p8末r.h.写在下表、p9 V／W的l.h.写在上表，也直接提醒：谱表不能等同于手。

Q／R因此不仅是“该不该隐藏空表”的例子。它说明等待音型的可数长度、未来入口的位置、实际手任务和物理页界必须一起看。

## 4. 明显的段首，未必是实际翻页处

先假设常规双面装订、第一音乐页在右：p2／3、p4／5、p6／7、p8／9各为同一对开；实际翻动是1→2、3→4、5→6、7→8。Gould p559允许根据较少、较从容的翻动选择首音乐页左右，故这个奇偶关系是分析条件，不是从PDF页码得出的装订事实。

| 此假设下的实际翻动 | 原页看到了什么 | 当前判断 |
| --- | --- | --- |
| 1→2 | 页末两表加密并指向C，下一页C恢复；没有把大谱表整体停下的明显窗口 | 标记为需核的连续进入，不因p2页首有C就宣称翻页已安排好 |
| 3→4 | 过渡经3/4回C，快动作之后紧接H的a tempo | 应核两手、持键与实际翻动；不能把低部长值直接当离手许可 |
| 5→6 | M的上方短休止／反复和弦与下方旋律继续 | 某层的短休止可能给单手机会，仍不能只数图形或按上表判手 |
| 7→8 | R仍连续，页末已有f引入，下一页S为molto espressivo | Q的等待早已过去；此处没有明确全架停奏。保留为真实媒介下的优先核查点，不直接判官谱错误 |

p6→7反而是最显眼的P新调号、largamente与ff，却在上述假设的同一对开内，无需此时翻纸；仍须从左页底部跨到右页顶部恢复状态，行末预告降号有阅读收益。p8→9的U至V亦有新手任务和密度变化，但在该假设下只是对开内寻行。单页平板、脚踏翻页、单面纸或不同起始左右须重算；PDF所有页的页码位置不能替代这些条件。

若以后为自己翻纸安排候选，可先比较两种**尚未试排的**边界：

- 在P末休止／延长／双斜线之后、Q之前结束页，让停止和新速度分开；代价可能是留白及后续重分页，静默中翻纸的噪声也须考虑。延长号并不提供一个已测出的固定秒数。
- 把Q的四小节准备放在页末、R放下一页，使等待与旋律进入组成翻前／翻后提示；须先确认实际分工、能否单手维持伴奏、另一手能否离开，并核新的全曲行页代价。不能因为上表空着就自动通过。

Gould p559–561支持先找长休止、必要时允许留白、按正确拍单位换算，再核恢复定位和实际演奏条件；p561还特别提醒键盘复杂段及安静段的限制。这里没有将书中的四秒演算例或某个谱高当钢琴硬阈值，也没有把V.S.作为掩盖坏页界的默认修补。

## 5. 连续读法还依赖状态和归属

**再现不是每次重新设全局默认。** D／H／K／O及P能认出同族节奏，伴奏与音区却有变化；a tempo、转拍、换号与力度各在真实位置恢复信息。Q明确新速度70，后面的S没有再印速度，并不表示回到全曲开头90；p7页末的f也不能因为换页而丢失，或擅自推迟到S第一音。

**L／M反复材料也有保持与重奏之分。** p5 L的上方和弦脉冲与跨行tie共同出现，下方有跨小节长保持；M又让下部线条活动。重复符头不是每颗都重新起音，有tie的接收头也不能删来让页面少些黑；把反复型全并成长和弦则会抹掉节奏。当前只据可见连接解释，没有官谱工程或MIDI互证。

**手提示属于具体层，不属于整条谱表。** p8末系统前两小节用r.h.及括形圈定下表中的较长音；p9 V与W又以l.h.及括形指向上表内层。它们帮助在连续的音区／声部轨道里临时接手。为“左右手分开”把整层搬回惯用谱表，会改变眼睛追踪的轮廓，还可能拉长干或挤占通道；删提示又会丢失动作归属。也不能从括形外观直接反推内部voice编号。

p9的局部括号变音继续保留旧[提示变音研究](ACCIDENTAL_CONTEXT.md)的条件判断：不是每个和弦重写，也不按黑度自动删除。本轮没有逐音复核所有提示是否必要，未把“看完九页”说成全部音高与节奏校勘完成。

## 6. 已学到的判断与下一步

对整首可作的决定是：保留多层、等待轨道、预先引入与不同容量；把行中A／J／R看成有显著性代价的可解释选择；将物理翻页问题留到明确媒介后优先核真实边界。无需给每页找一个必须修改的外观问题。

这次新增的是整曲关联：D／E／J的不同锚点，P收束到Q准备再到R进入，R至S的当前页界，以及U／V的临时接手。这使旧局部结论更能用于自主诊断。后续若对可编辑谱提出候选，应先列出旧材料结束、新状态开始、首次实际进入和持有／接手的关系，再看系统／页预算；不能只按框字母、空表或音头数量重排。
