# 从参考谱学到的净书判断，怎样用于下一份谱

2026-10-19。基于目录146份、1,135页全页审视、379页近读及定向规范学习。它是后续任务的判断入口，不是已训练好的模型、用户审美的全部定论或自动修改器。原谱索引见[INDEX](corpus/INDEX.md)，个人方向见[PREFERENCES](PREFERENCES.md)。

## 先认音乐，再找视觉问题

出版谱的秩序感，很大一部分来自读者能一次识别一个拍组、一条声部或一种反复动作。符头告诉音高，梁和时值告诉拍组，干向帮助追踪层，短弧/句弧与文字告诉如何连接，行和页帮助寻找结构。几种信息各有稳定的视觉线索，眼睛就少做逐音计数与归属猜测。这个解释有教材和大量谱例支持；不是出版者的设计自述，也没有本项目眼动实验。

后续发现问题要说清楚读者卡在哪里：拍点忽宽忽窄、旋律被背景盖住、文字像属于另一部、弧线找不到接收、相似句难以认出，还是换行后容易丢位置。“不像出版谱”只说明感受，还不是诊断。

| --- | --- | --- |

| 高处快速音不是旋律 | A063 p3 G、A144 p5 L，[逐谱11](corpus/READING_011.md)、[逐谱25](corpus/READING_025.md) | 上干背景、下干慢线、低音各有身份；干向、长短时值和局部手标识让主线可追。机械按高低分主次或按一表一手改写，会丢掉层次 |

| 连音数字、括号很多 | A116 p1/p6、A145 p5，[逐谱20](corpus/READING_020.md)、[逐谱25](corpus/READING_025.md) | 已建立的相同三连可省重复数字，含休止/变化处重新明确。A145上干3与下干9属两层，不能当一个嵌套组。省写减少噪声，也增加读者依赖上下文的程度 |
| 弧、八度、力度都挤在一起 | A124 p2、A143 p2/p4及[跨表专题](CROSS_STAFF_STUDY.md) | 先分别确认手、声部、触键、踏板和跨度终点，再安排通道。非连奏与不用踏板是不同维度；清楚的归属比所有标记同高重要。允许的交叉和真正遮挡也须分开 |
| 一行挤、一行散，段落不在行首 | A118 p3–4、A142 p1，[逐谱21](corpus/READING_021.md)、[逐谱25](corpus/READING_025.md) | 长运行多给宽度、少放小节，慢背景可多放；行中段首可由速度、力度、织体充分说明。另起行更醒目但耗空间，固定小节数则可能放大密度差 |
| 标记少了，看起来更干净 | A136 p4、A139 p7和Gould p215/494，[逐谱24](corpus/READING_024.md)、[记谱细节](NOTATION_DETAILS.md) | 相同动作的simile和数字省写可减少重复识别；新行、复杂组、反复力度/分句需要重新确认。不能按“最少对象数”评分或删真实tuplet结构 |

这些是按音乐机制检索的入口。具体A编号可由INDEX找到原文件；页码均为PDF页码，m为谱面可核的小节号。未给小节号的地方使用页、段落字母和系统描述，不伪造精确定位。

## 横向间距：五种原因，五种处理

用户重视的稳定感，应先在相同角色和相同节奏层里比较；不是把全页所有头排成网格。

1. **新增时间位置。** 另一手突然从八分变十六分或连音，原有脉冲间多了事件。先保护所有共同拍点，再试能否少扰动持续层。现有自制原生探针已经复现约25%变幅，机制与小节弹性分配吻合，但尚无改善候选证明最佳取舍。
2. **同一时点变宽。** 半音、多列变音、附点、旗尾或和弦错头增加净空。先检查列内排法，必要时才加宽时间距离；局部真实占位不能用全段最大间距平均摊开。
3. **绘制原点与视觉外形不同。** 下干/上干、错头、加线会改变白空间。Gould p491正常侧对齐尤其说明：二度和弦外框中心并不是时间轴；量错对象会把正确排法误报为不齐。
4. **入口和终点需要空间。** 谱号、调号、小节线、组末休止、接收与跳转要可辨；这些距离不一定与组内同值一致。先确认功能，不能全用一个最小净距覆盖。
5. **整行分配不同。** 两个小节内部各自很稳，却可能整体粒度不同。检查系统剩余宽度、小节拉伸、有效样式与手调状态；必要时比较少量断行，而不是逐头拖动。

详细证据与源码位置见[SPACING_STUDY](SPACING_STUDY.md)。LilyPond的常见细分基准和Dorico的整体/局部节奏位置控制提供研究思路，尚未用同一输入运行双软件对照；不能凭品牌判胜负。

## 系统与页面：给音型预算，同时帮助导航

先估计真实密度，再找乐句边界、进入点和可用翻页处。长组与半音多处需要较宽预算；较疏段落可多放小节，但末系统不能为了铺满而让少量音散得失去关系。相邻系统的黑白节奏可以有变化，只要变化与音乐相符。

段落标题、旋律进入、伴奏建立和换行是四件事。A097、A102出现伴奏先行，A118长组每行明显少放小节；YMD《悲怆》样页还把长小节拆行并标续小节号。后者是一个有代价的实践解法，尚未核完整规范与MuseScore实现。拆行、独立coda留白、另起页都应保留导航，不能只看空间利用率。

翻页则须看速度、哪只手何时空闲、持键还是踏板共鸣、跳回路线和纸面使用方式。长音不保证手能离键；MOLA的乐团分谱尺寸也不是独奏钢琴硬门槛。当前只记录潜在机会，没有用统一秒数或PDF页尾证明实际翻页可行。

## 用于用户工程时，怎样从感觉走到建议

以现有《如果有来生》材料为例，已经有三个不同层面的入口：m51低部八分后半约宽25%，有上部细分改变的触发；m50与m52各自均匀却平均粒度相差约12.5%，原因尚未排完；m41的mf/pp实际时间不同，不能因视觉接近合并。前两类分别查局部细分和整行分配，第三类先保护标记语义。PDF和release5未证明逐对象完全对应，实际试验必须重新记录当前输入与版本。

下一份诊断应交付少量完整片段，每处写：**可见问题、当前音乐读法、已定位原因/未知、保持原样的理由、候选改变及代价**。若建议重分voice、拆合时值、改谱号或省略标记，单列为记法提议，不混入几何美化。没有问题也应给出保留判断，不为展示工具能力制造改动。

## 从现可调项到开发目标

| 顺序 | 具体工作与当前状态 | 通过后才进入下一层 |
| --- | --- | --- |
| 先诊断 | 本库已能提供条件、正反例和检索入口；工程读取、实际几何仍须按当前宿主补核 | 能解释症状属于上述哪类，保护音乐读法，不靠方差阈值自动判错 |
| 参数/现有局部属性 | 样式、选定小节伸展、断行、局部梁/弧/标记可做独立副本候选；本轮未新改用户谱 | 同一字体、宿主、宽度预算比较；其它系统不明显变差，重排后稳定 |
| 插件与候选预览 | 先验证API实际能读写的范围、单位、人工覆盖、撤销；MCP封装已验证操作 | 不把图形offset冒充共同时间列控制；原生渲染可复现，语义差异可审计 |
| 必要的最小本体改动 | 优先研究细分弹性、变音最低宽与跨表光学策略；目前仅第一项已有原生行为复现 | 有具体失败例、参数/插件不足的证据及正反例收益，按AGENTS补日志/用户指南/提交 |

最值得先做的受控实验是：固定节奏只变变音，固定变音只变细分；再用上/下干与跨表改变检验光学轴线；最后在相同整行宽度下比较。不得同时换字体、缩纸幅、重分voice再声称某个间距算法有效。

**10月19日基线修正：** 字体线实谱复查发现，真正内置Leland原工程为8页，保持轮廓的改名Control也变9页；名称会触发当前宿主的brace布局分支。另有数字8相对真实内置字体仅约61.2%，先前接近101%的结果只相对改名Control。后续以真实内置字体＋原工程＋同宿主为主基线，同时核实际Music/Text/回退路径；改名Control只作辅助，不代替原谱行为。两类干扰须在布局比较前说明，不能通过改用户括号跨度或字号掩盖。来源、证据边界与更正见[INPUT_HISTORY](INPUT_HISTORY.md)及[字体线实谱评审](../../fonts/kumo-engrave/APPEARANCE_REVIEW.md)，本线未独立重跑。

## 哪些知识已经可靠，哪些还要继续学

可直接用于现在的分析：区分拍组、声部/手/谱表、范围、真实占位与弹性；给出有依据的保留或候选；查教材条件和参考反例。不能直接承诺：唯一最美参数、任意PDF的准确语义、所有官谱都最优、已经知道用户在所有密度下的取舍，或自动写回可用。

规范学习仍有边界：全书未通读；严格对位、指法/替指、三踏板、复杂跳转后的提示变音、跨页曲线和实际翻页尚缺成套原生对照。部分公开教程图片、视频与课程内容未取得，见[资源核查](RESOURCE_RESEARCH.md)。它们是明确的后续补课项，不伪装成本轮已掌握。

持续积累依靠项目文档和下一次具体判断。用户后来选择某个候选时，记录他在这个情境喜欢什么、接受什么代价，再更新PREFERENCES；不把一次选择推广成全谱规则，也不声称这些Markdown已经永久训练了模型。
