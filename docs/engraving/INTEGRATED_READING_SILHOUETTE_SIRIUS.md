# Silhouette／Sirius：先分清读者要追的层，再决定哪里值得改

2026-10-30。A112《Silhouette》全7页44系统、A114《Sirius》全8页47系统回查；近看70处系统、7处放大，复读22页Gould。114张不同本地视图中35复用、79新图；122个选定符头字形、53个普通活动间隔、23项时值核算与源矢量见[证据](silhouette_sirius_closeout_evidence.json)。累计问题回查**102/146，余44份**；Gould **696/696查阅覆盖**，本批复读增量0；外部资料**15/25，余10项**。原件只读，无新原生候选或软件适配。

判断：两首的优点是让稳定活动、较慢旋律、保持与局部动作各有可追线索。完整五连／七连和共头应保留；值得比较的是部分主梁中的三连范围，以及Silhouette页末引子与次页主题的组合。仅凭“音头不等距”“梁很黑”“有休止但还在发音”无法判定问题。

以下页／系统均按PDF从1计数；q为小节内四分单位、从0计，属于可见记法核算。没有对原工程逐音高校对、全曲播放或实曲候选验收，不将这些观察写成用户已经认可的审美参数。

## 1. 空心头能同时交代旋律保持和快速音型

Silhouette P，p7s1前三小节的第一头为**空心二分头**，同时向上有慢层符干、向下接三连八分梁。快速角色仍是每小节十二个三连八分时点，慢层首音保二分，再接两个四分。PDF将部分共头画了两次；可见头、音乐角色和字符绘制数需要分开。

判断为保留。演奏者先认出连续波形，再从向上的长符干追旋律，不必在同一个位置读两个挤在一起的头。将白头补成黑头会遮掉持续线索，另加一个普通黑头又会让人误以为有两次发音；按字符数统计则会报重复或漏音。Gould p311讨论附加符干提示旋律的钢琴惯例，它不授权给所有辅助旋律加补齐声部的休止。

这三个小节的快速列步长约9.477–9.613pt。这种稳定帮助眼睛预判音型；白头没有迫使第一格突然变宽。p7s1下部同时有低音、八分活动及另一层半休止，不能把半休止解读为整只手都不发音。

Sirius C／D是另一种分层正例：上部附点二分和弦保持三拍，q3有八分休止；同谱表的快速线在q3仍有八分音发声。这个休止结束的是上方保持角色。把它插进快速线，会凭空算出超时并提出错误修补。

## 2. 间距首先维护可预测的活动和真实先后

Sirius p7s3第三至第五小节，每小节八个普通八分列，源头步长约11.682–11.880pt；末系统第二、三小节约14.166–14.346pt，最后的和弦多头仍只占一个时点。跨小节宽度可变，单小节跟读角色却相当稳定。它们值得保留，不能因为另一层有长音就把空位任意拉开。

Silhouette M，p6s2第二小节是十六个普通十六分。多数步长约9.7–10.0pt，一处为12.608pt；该处有临时变音及其它角色的局部占位。先核符号与共同列所需空间，再决定是否存在可压缩余量。相邻第一、三小节却是十五头的混合时值，包含普通八分，不能一起用“十六格等距”评分。

Sirius C／D第一小节的快速层为：四分休止1q＋四个普通16占1q＋五连16占1q＋两个普通8占1q。C五连的头位约6.372–6.552pt一步；E另一处完整五连约7.254–7.452pt，其后四个普通16约8.496pt一步。不同分法和小节预算允许不同步幅。

**C下部q2.5的八分头x143.082，落在快层q2.4的x139.896与q2.6的x146.268之间。** 两手在这里本来不同起；保住中间先后比吸到最近符头更重要。下部q1、q1.5、q2、q3、q3.5才分别与快层相应时点相遇。Gould p40–43、200、490支持按局部复杂层安排空间、兼顾其它声部的同步与先后；最终不能只最小化符头距离方差。

这些是PDF字形原点，尚非干轴度量或引擎归因。后续在同字体、同小节预算下，才可用它们提出和比较软件行为。

## 4. 八度线的短范围在保存音区走向

Sirius C的8va只管最初四个普通16中的**前三音**，第四音已经恢复原位；不罩后面的五连。D的8va却从五连开始，延续到组后第一个普通8，最后普通8恢复。两处轮廓相似，声音的八度分布不同。它们通过局部折回减少极端加线，同时保留写出的升降方向；复制同一个8va外框会改变实际音区。

Silhouette L，p5s4第三小节是十二个三连8。短8va仅管前三音，到第四个相似书写音型时已经低一八度发声。拉长八度线能少一个视觉断口，却会改变后九音的声音，不能当作单纯美化。其后的斜虚线又追较慢旋律由下表到上表再返回，任务与8va、slur和gliss各异。

Silhouette Meno末系统还将上部8va、q3换低音谱号及局部8vb依次组织。线尾在小节中途结束，下一角色有自己的起点，不应统一延长到行尾。Gould p324要求看作用谱表与连续音区；p315的共同梁准则关注靠梁的最短干和净空，没有要求每根干等长。

## 6. 页末引子值得比较，先明确它解决什么

Silhouette p4s7先结束持续和声，下部另有p琶音，随后两表整小节延长休止；**最后一小节却是四分休止＋三个pp四分引子**，J主题在p5s1才到达。现排法把引子留在前页，读者弹完三个音后跨页寻找主题。值得比较的方案是将这个完整引子小节与J一起置于次页，使段前停顿与引子／主题的组合更直观。

代价也具体：p5首系统现有五小节，再加引子将成六小节，可能压缩主题或迫使整页重新分行。不能仅看一个漂亮裁图。先比较整页容量与后续页数，再判断是否采用；不拆小节、不改pp起点、休止、持续或预告谱号。

**这是跨页阅读候选。常规奇数右页装订下p4与p5同在一个开页，并不需要翻动纸张。** 单页屏幕、散页或其它装订又有不同动作。Gould p487的分行与版面预算、p557的演奏条件、p560–561的实际空闲与翻页条件需分别运用；不能因有延长休止就宣称翻页已解决。当前未移动原谱，未做实际打印或原生整页候选。

## 7. 不同线和小头不能只按形状合并

Silhouette L的斜虚线追慢旋律的接点，O的上行波线表示另一个滑奏动作；Sirius开头特殊叉形端点、短8va和gliss.又给特定动作的范围。先分功能，才判断遮挡、坡度和黑度。特殊端点的精确落键不能仅由附近普通头或PDF字符推定，适用条件承接[滑奏专题](GLISSANDO_READING.md)已核Gould p140–146／326。

本批复读p567–568实际是**cue的选择与范围**，并非滑奏章节。它们说明提示要服务于真正可辨的进入，重复提示未必有益；不能拿其中的叉头节奏cue例，给所有钢琴叉头套一个统一音高含义。这里保留明确的来源边界。

## 8. 怎样带入下一份谱

1. 先找快速活动、慢旋律、保持及休止各自的角色；空心共头、反向干与叠画字符不报成漏音／多音。
2. 保稳定活动和真实中间先后；普通八分、普通十六分、混合值与连音分别比较，必要前缀另核。
3. 完整独立梁可以保持简洁；只在部分主梁范围含混时提出短括号，先保护组外普通音。
4. 逐一追八度、力度、手、弧和滑奏的起止，重复轮廓不等于范围相同。
5. 分行／分页先说明读者要完成的动作，核整页预算及真实翻页条件；本批优先保留页末引子组合为后续候选。
