## 2. 长音该放哪里：先看是不是整小节、其它层有没有运动

Gould p41的传统例外针对**覆盖整小节的单音，且任何其它部没有别的时值**：可置于略偏左的中心；很宽的小节又可更靠近小节线。它不限于全音符字形，书中也有其它拍号下占满一小节的音。若别部有其它时值，则回到正常小节起点。不能把这里的“占满一小节”替换成“看到空心音头”。

| 当前材料 | 后续应怎样判断 |
| --- | --- |
| 一个音独占整小节，各层没有其它时值 | 保留MPA起点式与Gould条件式两种体例，结合相邻材料的连续感和全谱一致性再比较；当前没有原生替代版或用户选择 |
| 一部保持、另一部有运行或后续起音 | 先保护共同起点与层间配合。不能从传统单音例外推导出把保持音单独移到中间 |
| 时值是全音符，但未覆盖该拍号的整小节 | 不能仅按字形使用整小节例外；先读完整计量关系 |
| 整小节休止 | 它代表整个小节无该部活动，居中并非迟到的起点；不能用音符起音位置的规则去“纠正”它，也不将字形自动等同固定四拍 |

这次改变的是诊断方法：看到长音居中，先查触发条件与所选体例；看到上下不同x，先查是否是整小节休止、错头或真正不同的音乐位置。现有[符号阅读](SYMBOL_READING.md)及[同音异时值](UNISON_DOTS_STUDY.md)的原生反例仍分别适用，不能把它们压成一个居中／左齐开关。

## 3. 对用户关心的变音与间距，补一项实际判断

MPA p12–13与Gould p39–43都重视相对节奏及必要符号空间。Gould p42的行首谱例尤其说明：首音前已有留白时，新增变音可以利用那块预算，不能仅按新增字符的宽度推断音符应向后移动多少。

后续检查顺序是：辨认谱头／小节前沿与时间区间；检查既有留白能否容纳；检查符号列能否在保持归属、清晰和净空的条件下压实；再比较共同时间列与整行预算的调整。跨小节还需看前一末音到下一起音的连续感。单量两个头中心，会混入前沿、符干与小节线的光学影响。

这是有来源的候选思路，尚未在本轮构造原生行首对照或定位引擎原因。此前[实曲m86](SPACING_TRANSFER.md)只证明其特定构型能保住必要净空并重分普通间隔；不把旧数值套到行首，也不据此宣称现有MuseScore没有利用这些空间。

## 4. 怎样进入之后的自主净书

查规则时保留来源、对象和条件，读同页后文、图例及专章；一般概括、专门条件与本谱定义应连起来理解。真正的体例分歧保留为有代价的备选，待同曲、同字体、同预算的原生候选验证；当前阶段可有理由保留，不要求用户先选择一本书或逐条批准规则。
