# Snow halation／Sparkle：省写要靠可辨的模式，局部澄清要有具体理由

2026-10-30。A115《Snow halation》全7页41系统、A116《Sparkle》全7页45系统回查，另看68处系统细图、8处范围放大及18页Gould。108张不同本地视图中32复用、76新图；192个选定符头、96个稳定活动间隔、21项时值核算与梁矢量见[证据](snow_sparkle_closeout_evidence.json)。累计官谱问题回查**104/146，余42份**；Gould **696/696查阅覆盖**，本批复读增量0；外部资料**15/25，余10项**。原件只读，无新原生候选或软件适配。

判断：Sparkle开头相同三音型的数字省写值得保留；B首次变成混合时值的一拍，则值得局部重申3及范围。Snow的连续五连有内梁和逐组数字可追，优先保留；与普通32共主梁的第一组五连、J开头部分三连才是更有价值的短括号候选。两首的持续、手、力度和导航另有各自边界，不能用同一个“整齐模板”处理。

页／系统从1计；q为小节内四分单位、从0计。数字、时值、梁层和范围经过图面及来源核查，原工程逐音高校对、全曲播放、实曲新排法和打印仍未验证。阅读覆盖不记为掌握率，也没有形成用户新的具体审美选择。

## 1. 同样是没有3，有的地方简洁，有的地方值得补一句

Sparkle首小节以四束三连八分、四个3建立模式，后续三个相同小节省写数字。上部每小节十二时点，选定四小节步长约8.984–9.256pt。重复形状、组宽和慢低音共同支持沿用读法，满页继续印3会让每个本已可预测的拍组多一个注意对象。

A中上部仍p，低部mp在四分休止后的q1进入旋律；低部先三个三连8，再在后一、后二拍各以三连四分＋三连八分组成一拍，背景全音独立。相同的“印出来是四分”可能属于三连，也可能是背景普通四分。p1s5起，十二音的活动移到低部，较慢的上部旋律沿自己的节奏走。不能见十二个头就直接改成12/8或给每个voice统一乘2/3。

**B，p2s1首小节，是可比较的澄清点。** 上部前三个三连8占1q，接一个三连四分2/3q＋两个三连16各1/6q，再接六个三连8占2q。这个第二拍已换成混合时值，却仍省数字；读者必须从先前的模式和另一手反推。在新页、新段首次出现这里，可以比较只为这一拍补3和短括号，沿用本谱稍后已经采用的混合连音表示法；后续重复不必加满。

这项建议有明确适用条件：相同音型／分组继续时保省写，改变时值结构或首次重新进入时核是否需要重申。Gould p215支持可辨的重复省写，p213要求按整个划分标记混合连音；p207在基值／比例不能直接看出时要求更明确的表达。不能将“本谱常省3”扩成全曲永远是三连。D的marcato已转普通八分与四分，保它的新读法。

## 2. 3可以包四个符号，也可以只管长梁中的前三音

Sparkle p3s2最后一小节上部，先六个三连8占2q，再一个普通四分占1q。最后一拍的括号**从第一个八分休止开始，含两个八分休止及两个十六分音**：1/3＋1/3＋1/6＋1/6＝1q。不是漏了第三个音，也不能把其中一个休止抽到组外。f从两个16的第一个开始，即q11/3，早于下一系统E。

到D.S.前，p5s3末小节先九个三连8占3q，最后一拍改为三连四分＋两个三连16，仍以括号标3；f同样在q11/3。斜虚线从低部末音追到上部这个较低的四分音，帮助辨认旋律路径，没有新增一个发音。两处3表达相同的单位划分，组内符号和头数却不同。

Snow J，p5s1首小节，又是另一种范围：四分休止1q＋附点八分休止3/4q＋三个三连32共1/4q，到q2后是普通附点8、16及两个8。三连32与后面的普通音共享主梁，数字3只管前三头；p5s2首小节同样起步，后面转六个三连8。这里优先比较局部短括号，减少把整条梁误读成一个比例组的风险。

Gould p200区分完整与部分梁，p203给三十二分／十六分的基值，p213提醒混合值按整个划分理解。判断须先看全部梁层、括号端点、休止与慢层拍点，再核分数。数字不能等同于符头个数，和弦多头亦只占一个时点。

## 3. 连续五连和普通音之后的五连，需要不同优先级

Snow H前，p4s2首小节先四个普通8占2q，再四组5:4三十二分，每组1/2q。前十五音在上表，最后五音下移到低表。源矢量显示主梁把相邻两组连成十音，内两层却各按五音分开，并逐组印5；上部两条大弧各罩十音。读者能同时认出半拍五音和十音下降动作，跨表处不需要重新猜组。

判断为优先保留这一紧凑表示。Gould p200对部分主梁给出加括号的严格做法；若按该体例制作，可给每组加范围。但本例已有内梁断口与连续相同5组，整片括号的收益低于混合普通音的局部。规范要求与本次编辑优先级分别记录，不能据此宣称该书允许省略所有部分梁括号，也不能把官谱每束五连都报成同等严重错误。

更值得比较的是p2s6首小节及p4s6的同类上行：16休止、两个普通32之后，才进入三组五连32。首个5只管随后的五头，同一主梁前面有两个普通音。优先为第一组补短括号，保普通两音身份；临时还原号等必要空间也保留。该处五音步长约7.621–10.812pt，宽格涉及变音，不能把所有五连一律压成H的8.508pt。

H前短8va涵盖第一组五连，后组恢复音区；上行另一处的局部8va、普通峰顶8及f又有自己的边界。内梁、弧和八度线说明的是三种不同关系。

## 4. 密集与黑度先看真实细分，再看能否让层次更清楚

Snow p4s1前两小节上部各十六个普通16，步长约9.571–9.749pt；G首小节p3s6的十六分也近稳，约9.214–9.394pt。较慢下干旋律与更低伴奏各有方向和时值，不能因快层更密就把其它角色删成“多余”。p7s3的长运行是普通32，梁的三层来自真实细分；短弧与重音提示局部音型，不能仅为减黑改音值或统一成长弧。

Sparkle p7s6反复首小节特别能校正视觉误读：开头四分和弦1q，两个小装饰音不加普通计量；然后八个**普通32**占1q，接两组**七连16**各1q。第一组有三层梁，后两组只有两层，组内步长亦分别约8.03–8.41、8.86–9.00、8.76–8.88pt。同样紧密的下降并非同一基值。下一小节三组六连16各1q，再普通四分；下部最后一拍另有三连8。

Coda的首小节是四分休止＋6／6／7十六分各一拍，下一小节6／6各一拍＋15:8十六分两拍。15的第一时点还与低部普通四分同起，不能把低部头加成第十六个快音。变化后的数字重新出现，是帮助读者辨认新速度分法的必要信息。Gould p17、22支持梁的设计、靠梁音和方向条件；线宽或字体的改变不能代替这些层次。

## 5. 短组、手标识和持续各有自己的对象

Snow D／I通过反向干、局部l.h.和不同长短的弧，分开上部旋律、插入音和低部伴奏；N在下表高处用r.h.说明局部接收。P的短对音与休止让每次交接可辨，背景二分和弦同时保持。若把所有音按相邻位置串成一根长梁，手的交接点和慢保持都会难找。

Sparkle p6s1初次写下部混合三连旋律时，前三拍分别用括号说明四分／八分组合，第四拍完整三音梁保裸3；后面同型省写。p6s4第三小节首拍的3则包含四分休止与八分音，后面继续既有混合读法。另有低音全音／附点二分持续、上部pp和弦和下部p／mp旋律，层的休止不能串成单线总时值。

Gould p311讨论附加符干与钢琴旋律，p323强调独立力度尽量靠近其层，p324要求八度线看作用谱表。Sparkle I的长8va跨p5末至p6前两系统，局部l.h.并不让整条八度线同时作用下表；后面下表的8vb又独立。曲线、八度、手和持续需要逐条追起止。

## 6. D.S.与Coda按实际来路，结尾按自己的发音与等待

Sparkle p5s3 D.S.回到p3s3 E的Segno，随后在p3s6末To Coda转到p5s4 Coda。三个地标和出口要同时可找，不能按PDF相邻顺序从D.S.直接进入Coda。To Coda末小节上下部各自结束；Coda q0高处全音和弦有新攻击，快层四分休止后q1才进入。没有凭同音补跨跳转tie的依据。

p7s6另有一组清楚的两小节局部反复，起止都在本行，返回点a tempo／fff，次小节末低部谱号与八度状态要按回路核。Gould p233、235–236支持边界及返回时提示；本批核可见路线，没有宣称原工程展开播放已经校对。

Snow K之后的a tempo，承接局部Meno mosso与rit.，不能自动写成开头88；直到p6s3明确再次标四分88，才有数值依据。L的2/4小节恢复在q0的旧音接收上，最后三16晚些才出现；M的ff也在q0休止处先生效。恢复、力度和新攻击不必重合。

Sparkle Coda之后有低部末八分、两表延长休止，再进入I的安静长和弦；不能裁掉这些等待。全曲结尾则calando、低音跨四小节保持，上部换号后的全音和弦tie到下一小节，原谱没有末延长号。Snow结尾有保持、踏板换接／释放和实际延长，须保各自层次。Gould p65可用于跨行tie形状与读法；它讨论tie，不作为速度依据。

## 7. 带入下一份谱的判断

- **保省写，也识别变化。** 相同组形已有清楚基准时减少重复；首次混合、重入或导航落点核是否需要局部重申。
- **以单位与成员计量。** 两休止＋两头可构成3，主梁也可连接普通音与局部连音；不按字符数或头数改比例。
- **先解释梁的层级。** 连续五连的内梁断口与混合普通音后的五连，优先级不同；保拍点、动作弧与真实时值。
- **稳定间距保护活动角色。** 普通16、普通32、三连8和七连16分别比较，变音前缀与干向另核，不复制某个PDF坐标作为全谱预设。
- **按实际来路读状态。** 分别追Segno／出口／Coda、局部反复、八度、持续、速度与力度；候选必须回看完整上下手和整页。
