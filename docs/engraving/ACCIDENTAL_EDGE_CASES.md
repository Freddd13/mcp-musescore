## 2. 从和弦变音列复核：紧凑与归属共同决定顺序

**p89–90的两种顺序各有用途。** 密集三音以上和弦采用上下交替，能借用不同高度的白空间，避免所有符号向左展开成宽阶梯；八度的同类变音成列又便于一眼认成八度。相邻错头的少量变音，可以顺着头的高低轮廓安排，缩短“符号属于哪个头”的视觉搜索。变音很多时，后者会占用更多列，仍可回到较紧的常规排列。

所以不是找到一个“最佳排序”便全谱统一。先查读者是否能直接认出音高单元，再看列数和实际墨迹；字形不碰撞但离所属头很远，也可能不好读。反过来，以所有头的最大矩形禁止符号进入，会放弃下干错头旁的可用空间。既有[变音列研究](ACCIDENTAL_SPACING.md)已记录这些条件，本轮复核没有推翻它，也没有证实现宿主缺少这些机制。

**p90–91的双部例外不是一般共享状态的反例。** 同一表上两部通常可共同使用前方的变音区，但变化同音必须让符号贴近各自的部，尤其不能使另一部的还原号看似取消仍在tie延续的升音。这里解决的是可见归属；不能借此把同一钢琴的所有voice改成彼此独立的变音制度。已有[变音实际来路](ACCIDENTAL_CONTEXT.md)与[拼写](ACCIDENTAL_SPELLING.md)对此保持有效。

**p92–93的调号是另一种阅读单元。** 和弦变音要快速对应各头，调号则作为熟悉的整体形状被认出。不能把和弦里局部可嵌入的白空间，直接推广成调号中某两个降号特别挤、其它特别松。传统取消与当代只写新调号的体例仍应分别保留；行末预告和下一行正式表头各有作用，不能按“重复符号”去重。

## 3. p94补上的条件：两表的调号未必相同

接续p93的非调性／多调性段，p94明确允许同一件使用两表或更多谱表的乐器，各表采用不同调号，也有不遵常规五度顺序选取特定升降音的调号。它们可以减少稳定反复的变音，但要求读者掌握这套背景；并非任意少印几个升降号就更简洁。

这补充了既有文档的适用边界：正常调号的排列规则不等于所有合法调号都必须是某个常见大／小调，也不等于一件钢琴所有表必须相同。特殊调号仍要确认具体谱表、所指字母及各八度的作用、持续范围和后续取消方式；不能凭一个键数或MIDI音级推断全局调性，再替其它谱表“纠正”。同表多个voice也不能由此擅自各设调号。

**现在对普通钢琴任务的用法是保护与诊断。** 遇到上下表不同调号或非常规组合，先核它是否在作品中有稳定的音乐作用；无法判明时保留疑点。不会为了压缩临时变音给用户新造调号，也没有在当前软件中验证特殊调号的显示、播放或交换。教材允许某体例，并不证明任意输入中的同类现象都正确。

## 4. 微分音真正补强的是“符号有定义”，不是给钢琴增加装饰

**p94–96：方向提示与音高基准必须一起清楚。** 本章要求说明特殊音高符号的意义。箭头便于立即理解上／下方向，但方向并不独自给出具体音分。在本节明确的四分之一全音制度下，升号上的向上箭头是再升四分之一全音，不是把这个升号重新解释为仅升四分之一全音；此前已有普通变音时，只留下一个箭头又可能让参照基准含糊。

读者需要知道“在什么基础上改多少”，而非只认得一个漂亮字形。因此以后遇到这类输入，应分开保存书写拼写、可见符号定义、实际调音与作用范围。不能按符号外形、字体名称或整数MIDI音高猜其声音；也不能把一个带箭头符号换成较窄的普通升降号而称音乐保持。

**p96–97：符号的位置和形状是在减少误认。** 音高修饰放在头前，让它与普通变音在同一识别通道内。移到上方可能像指法或另一个动作方向；过宽的复合符号又把短时值拉散，让读者来回找头。紧凑的收益因此包括归属和节奏组形，不只是省纸。新符号还须彼此容易区分，不能为减少笔画把两个意义画得几乎一样。

这不与p83允许把**提示性而非必要**变音放上方的替代相矛盾：一个是可由既有状态推知的确认，另一个直接定义特殊音高。本轮完整回看p83图文后，既有[符号细节](NOTATION_DETAILS.md)对此的限定仍成立。不能把提示变音的压缩方案推广给全部必要变音。

**p97–98：一致的定义仍须配取消。** 同一套微分音箭头在一曲内不应暗中改换代表的细分；需要两种细分时应有可区别的符号和说明。在沿用通常小节变音制度的条件下，恢复普通音高也要明确取消，不能认为箭头只作用一次、下一个无符号音自动恢复。此处的作用规则要与作品声明合读，不能拿一种教材例子覆盖所有当代作品。

这些是本书2011版中的规范说明与本线阅读解释，本轮没有调查2026年所有微分音体系或其它章节的乐器实现。普通固定音高钢琴不能只靠在谱面添箭头就奏出这类音高；重调弦、电子调音或特殊技法需要另有实际条件。本线不会为增加规则或样例数量而向用户的普通钢琴谱添加微分音。

已有[二度归属](SECONDS_OWNERSHIP.md)记录用户研究副本中`tuning=10`的实例，说明外观任务必须保护调音数据；它不证明作者采用本章某种箭头制度，也不授权自动补画或量化到最近半音。本轮未再次读取那份工程。

## 5. p59并未推翻同音附点判断

p59允许只有一部带点时共头，但前提是两种节奏完全明确；正文紧接着承认自己的简短例子也可能不够明确，并建议歧义时用分头。书中同时提供通常上部在左、以及无点部先放以缩紧等不同方案。p60又给带点部在左、让点隔开两头的方案，并以加线是否分开帮助辨认。

收益不是“头越少越高级”，而是让持续与运动的两条线直接可读。分头会增加宽度，却降低猜测附点归属的需要；已建立的键盘重复型可以用较省墨迹的共头，孤立交会又可能需要更明确的两个头。当前[同音附点](UNISON_DOTS_STUDY.md)与[符号细节§9](NOTATION_DETAILS.md#9-共头附点与分离附点是在解释声部不是数点)已经带着这些限制，本轮没有发现需要纠正的旧音乐结论。

既有共头候选的MIDI相同仍不证明读法同样明确；本轮没有重跑那些原生实验，也不能由书中容许分头／共头推定当前软件的所有密集多声部都处理正确。需要新增验证的是具体尚未覆盖的构型，不是再用一个允许例外去消除归属检查。

## 6. 形成可直接调用的判断

看到符号多、上下调号不同或异常调音时，先确认它们各自承担的状态与音乐作用，再讨论压缩：是否必要变音还是确认，是否普通调号还是作品专用背景，是否一次音高修饰还是延续状态，是否两个声部需要各自归属。已经明确的内容先保护；只有符号排布的候选才归为外观调整，改变拼写、制度、调号、调音或持续读法的提议单列。

本次实质新增是p94–98的边界条件，并补录可追溯的旧页覆盖。未发现“所有原有变音／附点结论都错”的证据，也没有以新读5页宣称整个变音章已经稳定应用。后续仍应在实际输入中解释阅读任务、检查原生渲染和连带变化，再决定保留或小范围候选。
