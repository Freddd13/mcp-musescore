## 1. I段的三连与十六分在轮流活动

Kimi p4 I首小节，高部是“四分休止＋四个十六分”两次；低部是“三个三连八分＋一个四分”两次。中层两个二分保持另外一条线。以四分为单位：

| 层 | 书面起音时点 |
| --- | --- |
| 高部短组 | 1、1¼、1½、1¾；3、3¼、3½、3¾ |
| 低部 | 0、⅓、⅔、1；2、2⅓、2⅔、3 |
| 中层保持 | 0、2 |

高部休止的一拍由低部三连展开；高部四音下降时，低部已落在较长的四分。两活动层共同进入点是1、3，合14个不同时间列。**这里主要是拍与拍之间交替细分，不能直接诊断成同一拍内3对4。** 把两手所有相邻头都套同一距离，反而会丢掉这种接力。

原头位也支持这个组织：低部0→1拍跨度约25.931pt，高部1→2拍约27.836pt；三连内部步长约8.5–8.8pt，四音组约6.8–7.1pt。拍的大框接近，内部份数不同。当前保留。后面I的中层从二分改四分、出现l.h.括形及变音，不能只复制第一小节；手提示指具体材料，不让上表全部归右手。Gould p311支持用附加干凸显旋律，也提醒容器数量和读者感受到的角色可以不同。

## 2. 同为运行，8、22和11需要分别计量

Kimi p6s3、N前：旧和弦先接收一个八分，接八个双梁音，最后二分。下部普通八分提供拍位参照，八组占剩余的一拍半，故按**8:6十六分**读：½＋8×3/16＋2＝4个四分。开头和弦相邻头错在两个横坐标上，仍是同一次接收，不能数成两个先后音。

**建议比较将裸数字8改为完整8:6，并明确范围从和弦之后开始。** Gould p207要求非常规长度写完整比例；前导八分不属于八连音。代价是增加少量文字／括形空间，收益是无需先重算全小节才知道八组占多久。这个建议保护原时值，未在原工程实现。

p6s6的22组却占独立的完整4/4小节，前一小节的全和弦有自己的小节线。22个双梁头按**22:16十六分**占四拍，最后三个已在下表。p9s6两手的11组又只占后两拍，均按**11:8十六分**。不能因22是11的两倍，就按相同总时长分配空间；也不能裁掉下表后以19头计22组。Gould p203／207–209支持按实际总长及基值解释，整小节等分通常不必处处补完整比例，这与N前局部8组的情境不同。

## 3. 22组头距变窄，有符干连接的理由

该22组前19头在梁上方，后三头在下表、位于梁下方，头与干的连接侧改变。逐一核22条实际竖干后：

| 测量对象 | 相邻距离范围 |
| --- | ---: |
| 符头字符原点 | 5.513–9.971pt |
| 符干轴 | 9.720–10.560pt |

换侧处头原点519.723→525.236，看似突然挤到半步；实际干轴519.960→530.520，仍保持运行的近稳骨架。**保留头位和跨表连接，不为统一头原点把这一步额外拉宽。** 当前也不把轴距称完全等距：换侧处略宽仍存在，是否再微调须看整组和宿主连接。

这直接用于将来的间距诊断：先确认同值时间，再选择合适的视觉参照。变干向、二度移头和跨表时，头中心／原点可能改变，而读者追踪的梁与干仍稳定。单看头距方差会给出错误的“修复”。

## 4. 部分主梁的五连：保整拍，再补范围提示

Kizuna p3s1在E之前，第二拍主梁连接九头：先四个普通三十二分占半拍，再五个5:4三十二分占半拍。数字5位于后五头附近，第二、第三梁在4＋5边界分开。此前附点八分加十六分占第一拍，后面又有两个普通八音三十二分组；全小节合四拍。8va也在九头组后结束，下一组回原位。

主梁让读者仍看到整拍动作，内梁说明细分改变，这个分工保留。**另建议为后五头比较一个短连音括号。** Gould p200明确要求只占部分主梁的连音用括形排除范围歧义；内梁断口有帮助，尚不能代替该规范。原写法较简洁，但初读者可能把5理解到整条九头梁。加短括号会稍增墨迹，能免去由整小节反推范围的负担。

这也修正了只说“首行有五连”不足以指导操作的问题：应定位普通前导、连音起止及梁的各层，再决定添什么；不能把整条主梁拆掉、把前四头纳入五组，或把数字移到九头中心。

分行亦按阅读内容：p10 U首系统容三小节，最后系统容六小节，后者含保持和静默。把它们统一成固定小节数会让快行更挤、静段更散。当前保留这种容量差异；六个尾声小节还保住完整“减弱—延长—等待—强和弦”链，不因少头而压缩成模糊尾巴。

## 6. 同一主题的角色会交换，力度与手提示跟着角色读

Kimi Q在p7行中进入，上方pp、下方p；p8s1上方变p，下方pp，r.h.括形只选下表部分慢音；p8s2又回上方pp、下方p。两层有不同听觉任务，不能把一对p／pp视为全琴力度冲突，也不固定某谱表永远是背景。Gould p323支持贴近所属层放置力度，p324要求八度范围按谱表和目标读。

Kizuna C后p2s4的高部p细型，与同表下干mp慢线并存，后面crescendo和f又有自己的入口。组前十六分休止、短组slur及慢线tie不是可删除噪点。I快层另有重音和接收，H保持、J／K变体也不能因主题近似就恢复前一次全部状态。

速度同样保实际锚点：Kizuna E的四分85在旧材料收束之后；L前先pp／accel.，到短三连引入已ff，L才明确四分90。Kimi p6的a tempo在22组首头生效，不能推到下一页O。Gould p183–184将速度联系到实际事件，段字母与新行均不能代替生效时点。

## 7. 断开、等待和结束要读完整两手

Kimi R前上方整小节休止，下表先附点二分的双音震音，再有八分短音和八分休止，合四拍；随后双斜线给额外断开。震音两端各写整段持续，不把两个附点二分相加；Gould p225支持该计量，p187说明断开增加的时间与普通休止不同。保下部活动及其后的断开，不把整小节当全琴静默。

末页则是另一种完整链：perdendosi后，上方末四分与下方四分休止各有延长；下一小节弱全和弦再延长，之后一完整小节静默，才是两次ff强和弦，各有自己的引入／踏板，最后一次另有延长。首个延长不能当曲终，也不能因想尾页紧凑删掉后面的等待。

Kizuna最后系统先在下表休止上延长，随后下部引入／保持、高部运行分时进入；上下最后八度范围也不同。先保承载事件和范围，不将延长自动搬到某个和弦、或把两手所有端点吸齐。Gould p190的合奏共同拍点与p610–611的独奏／陪伴等待条件分开；本谱未明确标senza misura，不能仅凭独奏织体宣布取消计量。若要进一步澄清停顿，应结合作者演奏或工程，单列记法候选。
