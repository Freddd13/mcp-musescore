## 2. 怎样保持稳定，又容纳另一手

### 开头二度和弦：先认一组的轴

Chabrier m1–5上表为连续八分二度和弦，梁以3＋3组织；m1先有八分休止。两颗头分在符干两侧，不能把每颗头都当作独立时间列。取每个和弦相同一侧的头作参照，小节内部24个相邻起点距离为**14.200–14.333pt**。下表旋律、长音、休止变化，仍没有把上表重复步伐拉成一宽一窄。

**保留。** 这类稳定织体让读者用一个组形连续跟读，不必每拍重新辨认间距。它可作为后续MuseScore诊断的正例：同一时刻的错头先组成和弦，再比较连续起点；若直接对全部头计算“均匀度”，必要的二度错位会被误报。

### 同值较宽，有时在反复表达同一种需要

Borodine m33／35下表三个四分起点距离约22.854／22.854pt；m34／36则为**30.162／22.854pt**。后两小节的上部前一拍含两个八分音，并有临时变音；多出来的进入和符号在同一处占位。相同织体重复了相同宽窄轮廓。

**当前保留这组差异。** 把下表一律拉等距，会压缩上表的首拍或挪动共同起点。这里给出的借鉴是稳定地处理同类占位；以后若做更紧的候选，要比较两手完整一行，核清符号净空和各次进入。成品几何可以显示结果，不能独自分离排版引擎各项权重。

### 四连音与普通八分：两条线不能各自吸成格子

Chabrier m33下表六个普通八分，上表前景附点四分后接第二大拍的四连八分。选定上表四个起点的三间距为**19.399、15.014、15.148pt**；下表六个起点的五间距为18.602、19.266、18.602、24.182、20.197pt。四连组的第二个和弦前还有变音，占位与两手交错并存。

**保留真实先后和组边界；不把本例作为双手皆应等距的模板。** 第二大拍的上部在相对0、1/4、1/2、3/4处进入，下部在0、1/3、2/3处进入。对同一拍各做等距后再逐列吸附，会制造错误重合。Gould p200–202、490说明共同时间关系与较密层的阅读优先；它允许其它层局部不匀。若局部仍显歪，可比较在固定共同端点和符号净空下重分空间的候选，本轮没有原生重排。

## 3. 三谱表为什么值得付出空白

Chabrier m17–20把同一系统扩为三表。前两小节最低表是整小节休止，到m19出现低部独立进入、持续和后续运动；上两表同时承载旋律、内层、跨表动作及手提示。m21回双表。

**保留第三表及这一行的完整框架。** 它提前建立最低层的阅读位置，避免m19的低音、内声与旋律在两表里争抢干向、加线和弧线通道。前两小节空表占了高度，但使后续进入容易找到。压回双表的候选须连m17–21比较声部可追踪性、手提示和曲线；隐藏两个休止、局部截掉谱线，并不自动解决这些任务。Gould p303–304、307、310–311支持按手与音乐线条组织，并同时提醒过细的手编舞会遮住音乐形状。

同理，Borodine下表m17–26多次换谱号是在处理重复的大音区往返。当前保留，不能按“换号次数多”自动判错。减少换号值得比较时，应保持音高、音程关系及整句位置，连同新增加线一起评估；不把上／下表固定成高／低音号。

## 4. 方括、长线和速度有不同作用

- **Chabrier m9、13、37的括起休止仍有明确时值。** m9上层为八分休止＋四分音＋四分休止＋八分休止，正好6/8；下层仍运动。m37实际改9/8，下一小节恢复6/8；其上层附点四分后两组四分／八分休止计满九个八分。保留休止与换拍；不能凭括号把它们当可删冗余。PDF没有编辑前言，括起哪些内容属于增补仍需底本校勘。
- **m19的[m.g.]、m20的[d.]及角形范围追手，连音括号追节奏。** m27／29的2、两段3、7、8又有不同端点；最后一组包含休止，不能只数黑头。保留各个范围，7／8的完整比例说明可作为编辑澄清候选，先校底本；不由普通默认比例重建播放。m28／30另置的括起低音谱号也不可直接当成全表新有效谱号。
- **Borodine m45起的cresc.及m61末开始的dim.用虚延续线跨小节／系统。** 这些线表达持续变化，不能为了不碰撞只留下一个词，也不把后来p的生效点吸到新行头。Chabrier m9 Meno mosso在行中，m10才给avec charme；速度状态与后续句法表达分开。
- **Borodine m87八度到下一行仍继续。** 细图与源矢量确认末钩在m90二分和弦之后、四分休止之前（源x316.763pt；和弦起点286.735，休止329.253）。保留m90和弦的八度，不能在m89末提前取消，也不延到m91。m89下表六个普通八分在虚线弧下近稳，五间距16.077–16.210pt；虚线弧的编辑来源尚未校定。
- **Borodine m91后的m92、93全休止是结尾的计量。** 保留两小节等待；裁成“最后发声后即结束”会改音乐时间。Chabrier末尾则有具体Ped.与释放星，不能用同一结束模板替换。

本批曾在整页初看时误把八度末端估到m89；完整系统与末钩矢量已纠正为覆盖m90二分和弦。记下纠正，后续按真实目标音与端点核，不能从行号或视觉附近猜范围。
