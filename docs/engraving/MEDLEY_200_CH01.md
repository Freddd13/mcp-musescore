# 200 Anime Songs Medley第一章：连续演奏的读谱线索

2026-10-31。A005的Shounen Anime，PDF物理p1–12、所印Songs 1–17，本轮完整看12张整页、71个系统行，并放大六处具体疑问；p13只用于章际接续核查。当前组曲问题回查为**1/13章、12/154页，余12章142页及最终全组曲衔接回查**。全目录仍145/146份，完成整份所覆盖981/1135页不变。早期154页审视、34代表页近读与各章旧笔记保留在[原分段记录](corpus/READING_MEDLEY_200.md)，本批不重计首轮。

判断：这一章值得保留的主要是连续读谱线索。标题、速度、换调、八度范围和旋律入口可以各在自己的时点发生；版面把它们接起来，演奏者才能认出下一段而继续当前动作。把每个标题都排到新行、把每组音都强行等距，会损失这些关系。以下解释是结合可见谱面与Gould得到的阅读收益，不代出版者声称其亲自采用过某套算法。

## 1. 某格较宽，先看另一手是否在中间真的发音

**p10第1系统，M／BLOODY STREAM首小节：保留上部第三拍前半拍的额外宽度。** 上部九个书面头位按四分拍坐标为0、1/2、1、5/4、7/4、2、5/2、3、7/2；q2接收q1.75的同音tie，没有重新起音。q2至q2.5之间，下部在q2.25有一个真正起音的十六分低音，随后q2.5才上到伴奏较高音。上部相邻头原点从128.916到145.386pt，间隔16.470pt；下部中间头在137.070pt，分为8.154与8.316pt两段。相邻一些上部八分间隔约13.46–13.64pt，不能据此判这16.47pt失控。

阅读收益是下部短音能占有自己的位置，两手q2.5的共同点仍能追到。把上部该格硬压到周边八分宽度，会压缩下部两个短间隔；只移动上部又会破坏共同列。这里应先保留，再在完整系统确有挤压时比较共同预算。数值记录的是PDF字形原点，不能直接当MuseScore符干轴或offset处方；本批未制作新的原生候选。

**长短与梁也在解释空间。** 同小节上部有16＋8＋16的切分组，短次梁朝组内，短弧和断奏提示发音；下部先四分音、四分休止，再十六分休止与低音进入。让两手都看成一串八分就会漏掉真正的时间负担。此例比“所有变音都造成坏间距”的说法更有用：这里无需靠额外变音就会合理变宽。

依据：Gould印刷p40的时值空间压缩，p199–200、490的复杂节奏与同时关系。相关比较见[间距判断](SPACING_DECISIONS.md)、[既有五对四原生比较](FIVE_FOUR_SPACING_STUDY.md)。外观相似的问题仍须各自核时间列。

## 2. 梁先让读者看见一条运动，再让音头落到合适音区

**p1第3系统末小节：前六连十六分是下二音、上四音，共同上方双梁。** 随后六音留在上表，改为下方双梁，再落到两手重音。前一组内部字形原点约8.136–8.154pt一步，跨表也没有多出一次停顿；两组六连的梁位改变，仍各有清楚的六音范围。前一组六个十六分占一拍，后一组亦一拍，末尾普通八分、十六分休止、十六分及两个八分补足四拍。

收益是识别一条快速上行时不需要在谱表边界重新计数。长干在这里把跨表音接回共同梁，不能因“干太长”单独缩短；改为两表各自短梁会增加手间接续负担。组间视觉分节和共同落点又避免十二音全变成一条无参照的黑带。这里的梁、干长和步幅各承担读法，仅换头型不能替代。

**p1第4系统末小节的r.h.提示继续说明手的归属。** 下表中的上层交给右手，上表当时有休止；谱表、音区、手三者分别读。后续自动诊断遇到跨表，先追梁、声部和手提示，不能先按表号固定左右手。

依据：Gould p199–200、303、305、307。参见[跨表研究](CROSS_STAFF_STUDY.md)。

## 3. 两套梁重叠时，不要把完整三连误认成局部三连

**p12第4系统末小节，Q／Gurenge：保留下干三连的裸3。** 下干三头有自己两条完整梁；上方另一套上干普通八分梁横过更长范围。初看把上方长梁当成同一组，会误判下面3只管梁的一部分，进而建议补括号。放大与矢量复核后，三头为x492.1201、498.8521、505.566pt，两条梁均完整接到x506.016pt。它已有明确组界，无需为了统一外观再加一根线。

这一例的判断顺序是先分干向和层，再认各自梁，最后评价连音范围。低分辨率图、搜索到一个数字、按整片墨迹外框取组，都容易把另一个声部算进来。私有放大文件名仍保留初始`partial-three`标签，证据与本结论明确记录了纠正，不据文件名分类。

依据：Gould p199–200、203；完整梁与部分梁的条件见[节奏阅读](RHYTHM_READING.md)。

## 4. 曲名给位置，速度和力度告诉演奏者现在做什么

**保留标题前的实际变化点。** p2末系统尾部已印Faster四分=204及f，下一页才是C／Imagination；p5第2系统末尾已印Slower四分=190及f，下一系统才到F／Limit Break × Survivor。若把速度与力度吸到标题下，上一段结尾中的引入会被移晚。M在p10首行明确Slower四分=136，P在p12首行明确Faster四分=140；其它标题处没有新节拍器标记时，不能自行给每首重置数值。

字母、曲名、来源副标题、速度和动态的字形层级帮助读者同时认“到了哪首”和“此处怎么走”。标题可以在行中，给它上方通道；力度仍靠近实际发音位置。判断标题是否换行，要看接续、空间及文字冲突，不能只以标题X坐标不齐报错。

**章际速度核查还纠正了旧笔记。** p12末长音后给出接下一章的脚注和四升号预告；p13新章A／Guren no Yumiya，先用二二拍（₵）、二分=95，下一系统普通C、四分=190。两者的四分时长相同，后者更密的运动及拍感转换不能仅凭95→190判加速。第一章前段的四分=140也不能越过结尾与新章显式指示继续套用。p13仅作为边界上下文，不计本章之外的完成页。

依据：Gould p487、489及速度单位的一般计量；参见[拍号与速度](METRE_TEMPO_READING.md)。

## 5. 结尾房子是分支，tie和状态要沿各自来路读

**p6 G／Goya no Machiawase：共同段→第一结尾→回G→共同段→第二结尾→后文。** 两个结尾都能接到共同段末的和弦持续；纸面上第二结尾挨着反复线，不意味着它接收第一结尾末音。需要分别核共同段到两个结尾的tie、变音和动态。旧Oct20变音研究保留，本批没有把它重复算成新案例或声称已验证播放。

**p12 P／again：第一结尾在首行末，第二结尾在下一行开头，随后Q行中进入。** 这一布局把串烧接着走的空间保留下来，同时靠房子数字与范围识别分支。评价Q前空白或换行，需要同时看上一系统第一结尾；单裁Q标题会丢掉为什么前面还有一小段。第二结尾另起行可以是一种候选，但当前导航清楚时不必为统一另加断行。

依据：Gould p233–236、239–240；参见[导航](REPEAT_NAVIGATION.md)。

## 6. 标题和换调不会自动截断八度线

**p8第5系统K／Donten前后：保低八度的原有跨界范围。** 低八度先在K之前的低音起，越过双线和调号变化，覆盖K的第一个低音八度，再于下一次普通伴奏进入前结束。若按“每首重置”或“新调号就是线尾”来裁短，会改变前后的实际音区；把它延到K整组也同样有代价。p8末到p9的其它短低八度提示各自核，不把相似虚线合成一条。

横向布局除了留出低音加线，还要让八度线角端能看出最后被作用的音。线尾能放在哪里须按作用范围判断，不能只追求整齐贴小节线。相同原则适用于组中起止和跨页续接，见[八度研究](OCTAVE_READING.md)。依据：Gould p324–325。

## 已进入知识库的方法与下一步

现在可以直接调用三条判断：相邻同值头距异常先查另一手的中间事件；连音先分干向和各自梁再判断范围；标题、变化标记、跨界线及导航各按自己的发生点和来路保存。它们帮助发现值得改的问题，也帮助有理由地保留原排法。字体在这些比较中固定，未开发字体或MuseScore适配。
