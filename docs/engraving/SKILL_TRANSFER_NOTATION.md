# T06：Avid里的计量运行、自由收尾与记法边界

2026-10-25。先预选A016《Avid》p4并冻结判断，再复读全部五页、核11处完整系统区域与规范。本例为主agent在历史首轮已知材料上的预选应用；[证据](skill_transfer_notation_evidence.json)保留预选、冻结原文、修正、坐标与来源。它增加一个迁移情境和一份整曲问题回查，不作为全对次数。

**本轮判断：保留m65跨表运行的计量、组内休止和换调前的升号；保留尾声的自由收尾解释。** 两种快速音群采用不同的阅读方式。m65可从完整两手核算；m87的小音群有自由段的上下文，其严格比例尚未确认，当前不补24:16，也不改成不播放的提示音。

## 1. 初判怎样经过核查

预选时仅看p4整页，判断10／5应先按计量连音读，短音与grace分开，换调前的变音及una corda／tre corde要保留。初判没有数定10组的头／休止，也没有读到尾声。

高清复核补出了m65拆行、10组的一休止九音、5组之后的普通八分音，以及a tempo早于I的实际位置。这些具体条件让原先的“保留计量”有了依据。

**核查中有一次需要保留的修正。** 后续看p5时，我曾把24音称作正常大小，并优先怀疑缺连音比例。PDF矩阵显示这些头为12.222，m65普通头为16.2899，比例约0.7503；实际重新看图也能辨认它们较小。随后回读Gould p610–611，结合smorzando、持续背景及最终共同延长，改为优先保留自由收尾解释。原冻结初判不改写，错误发生在之后的整曲核查；这也说明只看放大的裁图会丢失相对尺寸。

## 2. m65：换行之后仍在同一个小节

p4第4行末，m65先写四分延长音和四分休止；行尾保持开放，没有结束小节线。第5行的a tempo处接该小节后两拍，随后I／m66才是新小节和三升调号。两表的时值、实际竖线和完整行页共同支持这个读法。

以四分音符为一单位，m65后半的运行这样读：

| 组成 | 书面材料及范围 | 本例对应的实际跨度 |
| --- | --- | --- |
| 10组 | 三十二分休止＋九个三十二分音，含跨表接续 | 10:8，占第三拍；最初0.1拍休止，上层同时已起音 |
| 5组 | 后接五个三十二分音 | 5:4，占第四拍前半 |
| 组外音 | 最后一音仅主梁连接，为普通八分音 | 占第四拍后半 |

总量为1＋½＋½＝2拍，与上方声部后两拍相合。5组的主梁还连到最后八分音，两个内梁先结束；**共同主梁的末端不自动等于连音组末端。** 这些比例是本例书面上下文的核算，不是取得了原工程内部tuplet字段。

保留起始休止有两项阅读收益：先让上层的八度响起，再进入下降线；组边界又让下一拍易于找到。若将第一个下降音吸到上层首头下方，便抹去这个先后。若把最后八分音算进5，整个后半拍的关系也会变化。实际修改时要保护完整时间轴、休止和组范围，再判断局部空白。

### 为什么此处愿意为拆行付出续读成本

前半的停留与后半的快速引入分处两行；长干、跨表下降和随后的厚织体得到连续空间。读者需要记住“新行从第三拍接”，这个代价真实存在。

Gould p489–490把拆小节作为例外，要求完整拍之间分开、行尾开放，并讨论续接斜线及括号小节号。本例满足完整拍及开放行尾；本轮未证明整个m65容不下一行。可以比较完整小节版，或比较增加续接提醒的版式；当前没有原生替代，不宣布拆行必需或完整小节版更好。不能补一个2/4，或按新行重置变音。

## 3. 换调前的升号与踏板文字各自在准备什么

m65后半仍沿用一升调号。下降线的上部写B–A–G♯–E，随后向低区接续；另一层有明确的C♯八度。G♯与C♯均在I的新三升调号之前，保留这些必要确认。将G♯换成A♭会改变这段的字母轮廓；把变音推迟到I又丢失提前准备。本例没有提出等音换写的理由。

Gould p79的条件继续适用：同一人同表的声部和手切换，不会各自重新建立独立变音状态；跨表及八度确认另核。PDF中的干向和头位置也不能单独提供voice编号。更省符号的写法必须同时解释音程、状态和后续材料，不能仅按同键处理。

H／m58的una corda与m65后半的tre corde构成软踏板及恢复；p3的E／F也有同类转换。Gould p336–337说明这类标记通常不需要其它踏板那样精确的逐音线形，必要时仍可加范围。当前保留文字和外围通道，不为整齐搬到I，也不画成普通延音踏板线。a tempo、ff sub.及恢复软踏板在引入处已有工作，新段号稍后才进入。

## 4. m87：小音群、保持背景与自由收束

p5末行先是3/4，随后C处有24个较小的十六分头，主梁与长弧维持完整上行／回转路线，下方长和弦从前小节tie过来并继续到最终延长。若按普通十六分逐个相加，会得六个四分单位；这项算术只能提示要查记法身份，不能独自证明漏记比例。

Gould p610–611允许自由独奏材料保留音值和不同分界；只有保持／等待的背景可用便利长值表示该自由段。这个阅读任务与本曲结尾相近。结合缩小音群、smorzando、持续背景和最终落点，**本线优先保留自由收尾的解释**；不把下方全音符当作必须均分24头的时间尺。

如目标读者会误读为严格计量，可比较增加quasi cadenza／自由处理等说明；这属于记法澄清。若原工程或作者定义证明确有严格比例，再讨论完整比例及共同点。当前不凭PDF补定播放。0.75尺寸也不证明是cue：Gould p125将装饰、cue的字号与设计区分，实际功能仍靠上下文；不能把这些实际收尾音静音或删除。

此例提供了有用的成对判断：m65要算清休止和连音；m87先判断是否应当严格相加。给两处统一缩小、统一补数字或统一拉匀，都会忽略它们各自的阅读任务。
