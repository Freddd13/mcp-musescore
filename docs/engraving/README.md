# 钢琴净书知识库 1.0.0

这套知识用于解释钢琴谱为什么这样排，判断哪些地方应保留、哪些值得调整，并为MuseScore原生副本提供有依据的候选。先识别演奏者要读的节奏、声部、用手、持续和导航，再讨论几何与风格。

**2026-11-03首版试用发布：`engraving-v1.0.0`。** 用户已明确暂缓补齐外部资料，先试用知识库与skill；开发阶段待试用认可后另行启动。原来25项资料的范围与缺口保留，详见[进度](STATUS_AND_ROADMAP.md)和[后续迭代](ITERATION_BACKLOG.md)。

## 当前可用的认识

间距先分必要占位、时间列与光学错觉；共同起音保持后还要看各层的节奏轮廓。局部更匀或碰撞更少，都不足以证明全段更易读。小节预算、内部弹性和整行分配分别判断。

梁、弧、括号与标记的范围承担音乐信息。可以有合理交干、独立线错列和行中段落标记；对齐与省写须有条件。跨表时同时检查动作方向、组界、最短干、数字归属及其它独立层。

净书外观候选和记法提议单列。改Voice、谱表、谱号、时值、拍组、提示变音或持续范围，应解释读法变化。原PDF、MSCZ只读，实验使用独立副本，原生渲染、音乐保护和整行连带由agent核查。
